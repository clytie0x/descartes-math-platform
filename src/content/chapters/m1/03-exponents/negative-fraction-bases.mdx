หน้าที่แล้วฐานเป็นจำนวนนับทั้งหมด แต่นิยามของ $a^n$ บอกว่า $a$ เป็นจำนวนใดก็ได้ ฐานจึงติดลบ เป็นเศษส่วน หรือเป็นทศนิยมได้ ความหมายยังเหมือนเดิมคือคูณฐานกัน $n$ ตัว เรื่องที่ต้องระวังเพิ่มมีแค่เครื่องหมายกับวงเล็บ

ลองตอบก่อนอ่านต่อ $(-2)^4$ เป็นจำนวนบวกหรือจำนวนลบ

## ฐานเป็นจำนวนลบ

ใช้กฎจากบทที่ 1 ลบคูณลบได้บวก บวกคูณลบได้ลบ แล้วคูณ $-2$ ไปทีละตัว

| $n$ | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| $(-2)^n$ | −2 | 4 | −8 | 16 | −32 | 64 |

{/* check: [(-2)**n for n in range(1, 7)] == [-2, 4, -8, 16, -32, 64] */}

เครื่องหมายสลับกันไปทุกครั้งที่คูณ เพราะ $-2$ สองตัวคูณกันได้ $4$ ซึ่งเป็นบวก ถ้าจับฐานเป็นคู่ได้ครบทุกตัว ผลก็เป็นบวก ถ้าเหลือเศษหนึ่งตัว ผลก็เป็นลบ

<Thm>

ถ้าฐานเป็นจำนวนลบ

- เลขชี้กำลังเป็นจำนวนคู่ ค่าของเลขยกกำลังเป็นจำนวนบวก
- เลขชี้กำลังเป็นจำนวนคี่ ค่าของเลขยกกำลังเป็นจำนวนลบ

</Thm>

<Example n={1}>
หาค่าของ $(-3)^3$ $(-5)^2$ $(-1)^{10}$ และ $(-1)^{7}$

<Steps reveal>
1. $(-3)^3$ เลขชี้กำลังเป็นคี่ ผลเป็นลบ ส่วนตัวเลขคือ $3^3 = 27$ จึงได้ $(-3)^3 = -27$
2. $(-5)^2$ เลขชี้กำลังเป็นคู่ ผลเป็นบวก ได้ $(-5)^2 = 25$
3. $(-1)^{10}$ ตัวเลขคือ $1$ เสมอ เลขชี้กำลังเป็นคู่ จึงได้ $1$
4. $(-1)^{7}$ เลขชี้กำลังเป็นคี่ จึงได้ $-1$
</Steps>
</Example>

{/* check: [(-3)**3, (-5)**2, (-1)**10, (-1)**7] == [-27, 25, 1, -1] */}

ทำแบบนี้ได้เร็วกว่าคูณทีละตัว ดูเครื่องหมายจากเลขชี้กำลังก่อนว่าคู่หรือคี่ แล้วค่อยหาค่าตัวเลขโดยไม่สนเครื่องหมาย

## (−3)² กับ −3² ไม่เท่ากัน

<Think>
เพื่อนหาค่า $-3^2$ ได้ $9$ เพราะคิดว่าลบคูณลบได้บวก เพื่อนพูดถูกไหม

<Reveal>
ไม่ถูก ใน $-3^2$ ไม่มีวงเล็บ ฐานจึงเป็น $3$ ตัวเดียว เครื่องหมายลบอยู่นอกการยกกำลัง ต้องยกกำลังก่อนแล้วค่อยใส่ลบ $-3^2 = -(3 \times 3) = -9$

ถ้าต้องการให้ $-3$ ทั้งตัวเป็นฐาน ต้องเขียน $(-3)^2 = (-3) \times (-3) = 9$
</Reveal>
</Think>

{/* check: [-3**2, (-3)**2] == [-9, 9] */}

<Note kind="warning" title="ฐานคือสิ่งที่อยู่ติดเลขชี้กำลัง">
ดูว่าเลขชี้กำลังเกาะอยู่กับอะไร ถ้ามีวงเล็บ ฐานคือทุกอย่างในวงเล็บ ถ้าไม่มีวงเล็บ ฐานคือตัวเลขตัวเดียวที่อยู่ติดกัน เครื่องหมายลบข้างหน้าไม่นับเป็นส่วนของฐาน
</Note>

<Example n={2}>
หาค่าของ $-2^4$ $(-2)^4$ และ $-(-2)^3$

<Steps reveal>
1. $-2^4$ ฐานคือ $2$ ได้ $2^4 = 16$ แล้วใส่ลบ จึงได้ $-16$
2. $(-2)^4$ ฐานคือ $-2$ เลขชี้กำลังเป็นคู่ จึงได้ $16$
3. $-(-2)^3$ ทำ $(-2)^3$ ก่อน เลขชี้กำลังเป็นคี่ ได้ $-8$ แล้วใส่ลบข้างหน้าอีกตัว $-(-8) = 8$
</Steps>
</Example>

{/* check: [-2**4, (-2)**4, -(-2)**3] == [-16, 16, 8] */}

## ฐานเป็นเศษส่วน

$\left(\tfrac{2}{3}\right)^3$ คือ $\tfrac{2}{3}$ คูณกันสามตัว การคูณเศษส่วนคือเอาเศษคูณเศษ ส่วนคูณส่วน จึงได้

$$
\left(\frac{2}{3}\right)^3 = \frac{2}{3} \times \frac{2}{3} \times \frac{2}{3} = \frac{2 \times 2 \times 2}{3 \times 3 \times 3} = \frac{2^3}{3^3} = \frac{8}{27}
$$

{/* check: Rational(2, 3)**3 == Rational(8, 27) */}

สรุปคือยกกำลังทั้งเศษและส่วน แต่ต้องเขียนวงเล็บครอบเศษส่วนไว้ ถ้าเขียน $\tfrac{2^3}{3}$ จะหมายถึงยกกำลังเฉพาะเศษ ได้ $\tfrac{8}{3}$ ซึ่งเป็นคนละจำนวน

<Example n={3}>
หาค่าของ $\left(\tfrac{3}{4}\right)^2$ $\left(-\tfrac{1}{2}\right)^3$ และ $\left(-\tfrac{2}{5}\right)^2$

<Steps reveal>
1. $\left(\tfrac{3}{4}\right)^2 = \tfrac{3^2}{4^2} = \tfrac{9}{16}$
2. $\left(-\tfrac{1}{2}\right)^3$ ฐานติดลบ เลขชี้กำลังเป็นคี่ ผลเป็นลบ ตัวเลขคือ $\tfrac{1^3}{2^3} = \tfrac{1}{8}$ จึงได้ $-\tfrac{1}{8}$
3. $\left(-\tfrac{2}{5}\right)^2$ เลขชี้กำลังเป็นคู่ ผลเป็นบวก ได้ $\tfrac{2^2}{5^2} = \tfrac{4}{25}$
</Steps>
</Example>

{/* check: [Rational(3, 4)**2, Rational(-1, 2)**3, Rational(-2, 5)**2] == [Rational(9, 16), Rational(-1, 8), Rational(4, 25)] */}

ฐานที่อยู่ระหว่าง $0$ กับ $1$ ยิ่งยกกำลังสูง ค่ายิ่งเล็กลง เพราะการคูณด้วยจำนวนที่น้อยกว่า $1$ ทำให้ได้ผลน้อยกว่าเดิม เช่น $\tfrac{1}{2}$ $\tfrac{1}{4}$ $\tfrac{1}{8}$ $\tfrac{1}{16}$ ลดลงทีละครึ่ง

<Example n={4}>
ปล่อยลูกบอลยางจากความสูง $81$ เซนติเมตร ทุกครั้งที่ตกกระทบพื้น ลูกบอลจะเด้งขึ้นไปได้สูง $\tfrac{2}{3}$ ของความสูงครั้งก่อน หลังกระทบพื้นครั้งที่ $4$ ลูกบอลเด้งขึ้นไปได้สูงกี่เซนติเมตร

<Steps reveal>
1. กระทบพื้นแต่ละครั้ง ความสูงถูกคูณด้วย $\tfrac{2}{3}$ หนึ่งครั้ง กระทบสี่ครั้งจึงคูณด้วย $\tfrac{2}{3}$ สี่ครั้ง
2. ความสูงคือ $81 \times \left(\tfrac{2}{3}\right)^4 = 81 \times \tfrac{16}{81}$
3. ได้ $16$ เซนติเมตร
</Steps>
</Example>

{/* check: 81*Rational(2, 3)**4 == 16 */}

## ฐานเป็นทศนิยม

ฐานที่เป็นทศนิยมก็คูณกันตามปกติ เช่น $0.3^2 = 0.3 \times 0.3 = 0.09$ และ $1.2^2 = 1.2 \times 1.2 = 1.44$ จำนวนตำแหน่งทศนิยมของผลคูณเท่ากับผลรวมของตำแหน่งทศนิยมของทุกตัวที่คูณกัน $0.3$ มีหนึ่งตำแหน่ง คูณกันสองตัวจึงได้สองตำแหน่ง

{/* check: [Rational('0.3')**2, Rational('1.2')**2, Rational('0.1')**3] == [Rational('0.09'), Rational('1.44'), Rational('0.001')] */}

<Think>
เพื่อนตอบว่า $0.3^2 = 0.9$ และ $0.1^3 = 0.3$ ผิดตรงไหน

<Reveal>
$0.3^2$ ไม่ใช่ $0.3 \times 2$ แต่คือ $0.3 \times 0.3 = 0.09$ ซึ่งมีทศนิยมสองตำแหน่ง ส่วน $0.1^3 = 0.1 \times 0.1 \times 0.1 = 0.001$ มีทศนิยมสามตำแหน่ง เพื่อนเอาฐานไปคูณกับเลขชี้กำลัง ซึ่งเป็นความผิดแบบเดียวกับการคิดว่า $2^3 = 6$
</Reveal>
</Think>

{/* check: [Rational('0.3')**2 == Rational('0.9'), Rational('0.1')**3 == Rational('0.3')] == [False, False] */}

## สรุป

- ฐานเป็นจำนวนลบ เลขชี้กำลังคู่ได้ผลบวก เลขชี้กำลังคี่ได้ผลลบ
- $(-3)^2 = 9$ แต่ $-3^2 = -9$ เพราะไม่มีวงเล็บ ฐานจึงเป็น $3$ ตัวเดียว
- ฐานเป็นเศษส่วน ยกกำลังทั้งเศษและส่วน และต้องมีวงเล็บครอบ
- ฐานอยู่ระหว่าง $0$ กับ $1$ ยิ่งยกกำลังสูง ค่ายิ่งเล็ก
- ฐานเป็นทศนิยม นับตำแหน่งทศนิยมของผลจากตำแหน่งของทุกตัวที่คูณกัน
