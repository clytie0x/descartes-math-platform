สมการในหน้าที่แล้วมีตัวแปรอยู่ข้างเดียว แก้ได้ในสองสามขั้น สมการที่เจอในโจทย์จริงมักยาวกว่านั้น ตัวแปรอยู่ทั้งสองข้าง มีวงเล็บ หรือมีเศษส่วน หน้านี้ใช้สมบัติของการเท่ากันชุดเดิมทั้งหมด เพิ่มแค่ลำดับการทำงานให้เป็นระบบ

<Thm label="ขั้นตอนแก้สมการ">

1. ถ้ามีเศษส่วน คูณทั้งสองข้างด้วย ค.ร.น. ของตัวส่วนให้เศษส่วนหายไป
2. ถ้ามีวงเล็บ กระจายวงเล็บ แล้วรวมพจน์ที่คล้ายกันในแต่ละข้าง
3. ย้ายพจน์ที่มีตัวแปรไปไว้ข้างหนึ่ง ย้ายค่าคงตัวไปไว้อีกข้าง ด้วยสมบัติการบวก
4. กำจัดตัวคูณหน้าตัวแปรด้วยสมบัติการคูณ
5. แทนคำตอบในสมการเดิมเพื่อตรวจ

</Thm>

## ตัวแปรอยู่ทั้งสองข้าง

ตาชั่งข้างล่างมีกล่องทั้งสองข้าง ข้างซ้ายมีกล่อง 5 กล่องกับตุ้ม 1 ลูก ข้างขวามีกล่อง 2 กล่องกับตุ้ม 10 ลูก ก่อนอ่านตัวอย่าง ลองหาว่าควรเอาอะไรออกก่อน

<Board name="c6-balance-both" label="ตาชั่งสองแขน ข้างซ้ายมีกล่อง 5 กล่องกับตุ้ม 1 ลูก ข้างขวามีกล่อง 2 กล่องกับตุ้ม 10 ลูก ปรับจำนวนของแต่ละข้างได้ด้วยแถบเลื่อน">
ลองเอากล่องออกข้างละเท่ากันก่อน แล้วค่อยจัดการตุ้ม
</Board>

<Example n={1}>
แก้สมการ $5x + 1 = 2x + 10$

<Steps reveal>
1. ข้างขวามี $2x$ ลบ $2x$ ทั้งสองข้าง เหมือนเอากล่องออกข้างละ 2 กล่อง ได้ $3x + 1 = 10$
2. ลบ $1$ ทั้งสองข้าง ได้ $3x = 9$
3. หารด้วย $3$ ทั้งสองข้าง ได้ $x = 3$
4. ตรวจ ข้างซ้าย $5(3) + 1 = 16$ ข้างขวา $2(3) + 10 = 16$ เท่ากัน
</Steps>
</Example>

{/* check: solve(Eq(5*x + 1, 2*x + 10), x) == [3] and 5*3 + 1 == 16 and 2*3 + 10 == 16 */}

จะย้ายตัวแปรไปข้างไหนก็ได้ คำตอบเท่ากัน แต่ถ้าย้ายไปข้างที่มีสัมประสิทธิ์ของตัวแปรมากกว่า จะได้สัมประสิทธิ์เป็นบวก คำนวณง่ายกว่า

<Example n={2}>
แก้สมการ $4x - 7 = 6x + 3$

<Steps reveal>
1. ข้างขวามี $6x$ มากกว่า จึงลบ $4x$ ทั้งสองข้าง ได้ $-7 = 2x + 3$
2. ลบ $3$ ทั้งสองข้าง ได้ $-10 = 2x$
3. หารด้วย $2$ ทั้งสองข้าง ได้ $-5 = x$ ใช้สมบัติสมมาตรเขียนเป็น $x = -5$
4. ตรวจ ข้างซ้าย $4(-5) - 7 = -27$ ข้างขวา $6(-5) + 3 = -27$ เท่ากัน
</Steps>
</Example>

{/* check: solve(Eq(4*x - 7, 6*x + 3), x) == [-5] and 4*(-5) - 7 == -27 and 6*(-5) + 3 == -27 */}

## ย้ายข้างแล้วเปลี่ยนเครื่องหมาย

หลายคนแก้ $3x + 1 = 10$ โดยพูดว่า ย้าย $+1$ ไปอีกข้างกลายเป็น $-1$ ได้ $3x = 10 - 1$ วิธีพูดนี้ใช้ได้ เพราะมันคือการลบ $1$ ทั้งสองข้างแบบย่อ ทางซ้าย $+1 - 1$ หายไป ทางขวาจึงเหลือ $-1$ ให้เห็น

<Note kind="warning" title="ย้ายข้างใช้กับการบวกลบเท่านั้น">
ถ้า $3x = 9$ ห้ามย้าย $3$ ไปเป็น $x = 9 - 3$ เพราะ $3$ คูณ $x$ อยู่ ไม่ได้บวกอยู่ ตัวที่คูณอยู่ต้องหารทั้งสองข้าง ได้ $x = \tfrac{9}{3} = 3$ ถ้าไม่แน่ใจ ให้ถามตัวเองว่าจำนวนนั้นบวก ลบ คูณ หรือหารตัวแปรอยู่ แล้วทำกลับด้วยการดำเนินการตรงข้าม
</Note>

## สมการที่มีวงเล็บ

<Example n={3}>
แก้สมการ $3(x - 4) = 2(x + 1) - 5$

<Steps reveal>
1. กระจายวงเล็บ ข้างซ้าย $3x - 12$ ข้างขวา $2x + 2 - 5 = 2x - 3$ ได้ $3x - 12 = 2x - 3$
2. ลบ $2x$ ทั้งสองข้าง ได้ $x - 12 = -3$
3. บวก $12$ ทั้งสองข้าง ได้ $x = 9$
4. ตรวจ ข้างซ้าย $3(9 - 4) = 15$ ข้างขวา $2(9 + 1) - 5 = 15$ เท่ากัน
</Steps>
</Example>

{/* check: solve(Eq(3*(x - 4), 2*(x + 1) - 5), x) == [9] and 3*(9 - 4) == 15 and 2*(9 + 1) - 5 == 15 */}

<Think>
แก้สมการ $5 - 2(x - 3) = 1$ เพื่อนกระจายได้ $5 - 2x - 6 = 1$ แล้วได้ $x = -1$ ผิดตรงไหน คำตอบที่ถูกคืออะไร

<Reveal>
$-2$ ต้องคูณเข้าไปทั้งสองพจน์ในวงเล็บ $-2 \times x = -2x$ และ $-2 \times (-3) = +6$ ลบคูณลบเป็นบวก จึงได้ $5 - 2x + 6 = 1$ หรือ $11 - 2x = 1$ ลบ $11$ ทั้งสองข้างได้ $-2x = -10$ หารด้วย $-2$ ได้ $x = 5$ ตรวจ $5 - 2(5 - 3) = 5 - 4 = 1$ จริง ส่วน $x = -1$ ของเพื่อนให้ $5 - 2(-4) = 13$ ไม่เท่ากับ $1$
</Reveal>
</Think>

{/* check: solve(Eq(5 - 2*(x - 3), 1), x) == [5] and 5 - 2*(-1 - 3) == 13 and solve(Eq(5 - 2*x - 6, 1), x) == [-1] */}

## สมการที่มีเศษส่วนหรือทศนิยม

เศษส่วนทำให้คำนวณพลาดง่าย วิธีที่ปลอดภัยคือคูณทั้งสองข้างด้วย ค.ร.น. ของตัวส่วนทุกตัวตั้งแต่แรก เศษส่วนจะหายไปหมด เหลือสมการที่มีแต่จำนวนเต็ม

<Example n={4}>
แก้สมการ $\dfrac{x}{3} + \dfrac{x}{4} = 7$

<Steps reveal>
1. ค.ร.น. ของ $3$ กับ $4$ คือ $12$ คูณทั้งสองข้างด้วย $12$ ต้องคูณทุกพจน์ รวมทั้ง $7$ ทางขวาด้วย ได้ $12 \cdot \dfrac{x}{3} + 12 \cdot \dfrac{x}{4} = 12 \cdot 7$
2. ได้ $4x + 3x = 84$ หรือ $7x = 84$
3. หารด้วย $7$ ได้ $x = 12$
4. ตรวจ $\tfrac{12}{3} + \tfrac{12}{4} = 4 + 3 = 7$ จริง
</Steps>
</Example>

{/* check: solve(Eq(x/3 + x/4, 7), x) == [12] */}

<Example n={5}>
แก้สมการ $\dfrac{x + 2}{5} = \dfrac{x - 1}{2}$

<Steps reveal>
1. ค.ร.น. ของ $5$ กับ $2$ คือ $10$ คูณทั้งสองข้าง ได้ $2(x + 2) = 5(x - 1)$ ใส่วงเล็บไว้ก่อน เพราะตัวเศษทั้งก้อนถูกคูณ
2. กระจาย ได้ $2x + 4 = 5x - 5$
3. ลบ $2x$ ทั้งสองข้าง ได้ $4 = 3x - 5$ บวก $5$ ทั้งสองข้าง ได้ $9 = 3x$
4. หารด้วย $3$ ได้ $x = 3$ ตรวจ $\tfrac{3 + 2}{5} = 1$ และ $\tfrac{3 - 1}{2} = 1$ เท่ากัน
</Steps>
</Example>

{/* check: solve(Eq((x + 2)/5, (x - 1)/2), x) == [3] */}

ทศนิยมก็ใช้หลักเดียวกัน คูณด้วย $10$ หรือ $100$ ให้ทศนิยมหายไปก่อน

<Example n={6}>
แก้สมการ $0.4x + 1.5 = 0.1x + 3$

<Steps reveal>
1. ทศนิยมมากที่สุดหนึ่งตำแหน่ง คูณทั้งสองข้างด้วย $10$ ได้ $4x + 15 = x + 30$
2. ลบ $x$ ทั้งสองข้าง ได้ $3x + 15 = 30$ ลบ $15$ ทั้งสองข้าง ได้ $3x = 15$
3. หารด้วย $3$ ได้ $x = 5$
4. ตรวจ ข้างซ้าย $0.4(5) + 1.5 = 3.5$ ข้างขวา $0.1(5) + 3 = 3.5$ เท่ากัน
</Steps>
</Example>

{/* check: solve(Eq(Rational('0.4')*x + Rational('1.5'), Rational('0.1')*x + 3), x) == [5] */}

## ตรวจคำตอบทุกครั้ง

การตรวจใช้เวลาไม่ถึงนาที แต่จับข้อผิดพลาดได้เกือบทุกแบบ ทั้งเครื่องหมายผิด ลืมคูณบางพจน์ หรือกระจายวงเล็บพลาด ข้อสำคัญคือต้องแทนใน**สมการเดิม**ที่โจทย์ให้ ไม่ใช่สมการที่เขียนเองระหว่างทาง เพราะถ้าขั้นกลางผิด สมการระหว่างทางก็ผิดไปแล้ว ตรวจกับมันจะดูเหมือนถูก

## สรุป

- ลำดับการแก้ กำจัดเศษส่วน กระจายวงเล็บ ย้ายตัวแปรไปข้างเดียว แล้วหารด้วยสัมประสิทธิ์
- ย้ายข้างเปลี่ยนเครื่องหมายคือการบวกลบทั้งสองข้างแบบย่อ ใช้กับตัวที่คูณอยู่ไม่ได้
- จำนวนลบหน้าวงเล็บต้องคูณเข้าไปทุกพจน์ ลบคูณลบเป็นบวก
- คูณด้วย ค.ร.น. ต้องคูณทุกพจน์ทั้งสองข้าง
- ตรวจคำตอบด้วยการแทนในสมการเดิมเสมอ
