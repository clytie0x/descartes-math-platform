ตาชั่งสองแขนข้างหนึ่งมีกล่องปริศนา 3 กล่องกับตุ้มน้ำหนักลูกละ 1 กิโลกรัมอีก 2 ลูก อีกข้างมีตุ้ม 11 ลูก ตาชั่งอยู่นิ่งในแนวนอน กล่องทุกกล่องหนักเท่ากัน ไม่เปิดกล่อง จะรู้ได้ยังไงว่ากล่องหนึ่งหนักเท่าไร

ให้กล่องหนึ่งหนัก $x$ กิโลกรัม ตาชั่งสมดุลแปลว่าสองข้างหนักเท่ากัน จึงเขียนได้ว่า

$$
3x + 2 = 11
$$

## ตาชั่งที่ต้องรักษาสมดุล

ลองเอาตุ้มออกจากตาชั่งข้างล่าง เริ่มจากเอาตุ้มข้างซ้ายออกข้างเดียว ดูว่าเกิดอะไรขึ้น แล้วหาวิธีเอาของออกจนเหลือกล่องเดียวโดยตาชั่งยังสมดุลอยู่

<Board name="c6-balance" label="ตาชั่งสองแขน ข้างซ้ายมีกล่อง 3 กล่องกับตุ้ม 2 ลูก ข้างขวามีตุ้ม 11 ลูก ปรับจำนวนของแต่ละข้างได้ด้วยแถบเลื่อน" caption="กล่องสีส้มหนักกล่องละ x กิโลกรัม วงกลมสีเขียวคือตุ้มลูกละ 1 กิโลกรัม ข้างที่หนักกว่าจะลดต่ำลง" />

สิ่งที่น่าจะเห็น

- เอาตุ้มออกข้างเดียว ตาชั่งเอียงทันที สองข้างไม่เท่ากันแล้ว
- เอาตุ้มออกข้างละ 2 ลูกเท่ากัน ตาชั่งยังสมดุล เหลือกล่อง 3 กล่องหนักเท่ากับตุ้ม 9 ลูก
- แบ่งของทั้งสองข้างเป็น 3 ส่วนเท่าๆ กัน แล้วเก็บไว้ข้างละส่วนเดียว คือเลื่อนกล่องข้างซ้ายเหลือ 1 และตุ้มข้างขวาเหลือ 3 ตาชั่งก็ยังสมดุล

กล่องหนึ่งจึงหนัก 3 กิโลกรัม ติ๊กช่องเปิดดูน้ำหนักกล่องเพื่อตรวจได้

## สมบัติสี่ข้อ

สิ่งที่ทำกับตาชั่งได้โดยไม่เสียสมดุล เขียนเป็นสมบัติของจำนวนได้ดังนี้ เมื่อ $a$ $b$ และ $c$ แทนจำนวนใดๆ

<Thm label="สมบัติของการเท่ากัน">

- **สมบัติสมมาตร** ถ้า $a = b$ แล้ว $b = a$
- **สมบัติถ่ายทอด** ถ้า $a = b$ และ $b = c$ แล้ว $a = c$
- **สมบัติการบวก** ถ้า $a = b$ แล้ว $a + c = b + c$
- **สมบัติการคูณ** ถ้า $a = b$ แล้ว $ac = bc$

</Thm>

สองข้อแรกฟังดูชัดเจนจนเหมือนไม่ต้องพูด แต่ใช้บ่อย สมบัติสมมาตรทำให้สลับข้างสมการได้ เช่นเขียน $15 = 2x + 7$ ใหม่เป็น $2x + 7 = 15$ ส่วนสมบัติถ่ายทอดทำให้เขียนต่อกันเป็นแถวได้ ถ้าขั้นแรกเท่ากับขั้นที่สอง ขั้นที่สองเท่ากับขั้นที่สาม ขั้นแรกก็เท่ากับขั้นที่สาม

### การลบและการหารอยู่ตรงไหน

ไม่ต้องมีสมบัติการลบแยก เพราะการลบ $c$ ก็คือการบวกด้วย $-c$ เช่นลบ $2$ ทั้งสองข้าง คือใช้สมบัติการบวกด้วย $-2$

การหารด้วย $c$ ก็คือการคูณด้วย $\tfrac{1}{c}$ เช่นหารด้วย $3$ ทั้งสองข้าง คือใช้สมบัติการคูณด้วย $\tfrac{1}{3}$ แต่หารด้วยศูนย์ไม่ได้ จึงต้องมีเงื่อนไขว่า $c \neq 0$

## แก้สมการด้วยสมบัติของการเท่ากัน

**การแก้สมการ**คือการหาคำตอบของสมการ หลักคือใช้สมบัติของการเท่ากันเปลี่ยนสมการให้ง่ายลงทีละขั้น จนเหลือตัวแปรอยู่ตัวเดียวข้างหนึ่ง ทุกขั้นสองข้างยังเท่ากันอยู่ คำตอบจึงไม่เปลี่ยน

<Example n={1}>
แก้สมการ $3x + 2 = 11$ ซึ่งเป็นสมการของตาชั่งข้างบน

<Steps reveal>
1. ต้องการให้เหลือแต่พจน์ที่มี $x$ ทางซ้าย จึงกำจัด $+2$ ด้วยการบวก $-2$ ทั้งสองข้าง (สมบัติการบวก) ได้ $3x + 2 - 2 = 11 - 2$ หรือ $3x = 9$
2. ต้องการ $x$ ตัวเดียว จึงคูณทั้งสองข้างด้วย $\tfrac{1}{3}$ (สมบัติการคูณ) ได้ $\tfrac{1}{3}(3x) = \tfrac{1}{3}(9)$ หรือ $x = 3$
3. ตรวจ แทน $x = 3$ ในสมการเดิม $3(3) + 2 = 11$ เป็นจริง กล่องหนึ่งหนัก 3 กิโลกรัม ตรงกับตาชั่ง
</Steps>
</Example>

{/* check: solve(Eq(3*x + 2, 11), x) == [3] and 3*3 + 2 == 11 */}

<Example n={2}>
แก้สมการ $x - 8 = -3$

<Steps reveal>
1. กำจัด $-8$ ด้วยการบวก $8$ ทั้งสองข้าง (สมบัติการบวก) ได้ $x - 8 + 8 = -3 + 8$
2. ได้ $x = 5$
3. ตรวจ $5 - 8 = -3$ เป็นจริง
</Steps>
</Example>

{/* check: solve(Eq(x - 8, -3), x) == [5] */}

<Example n={3}>
แก้สมการ $\dfrac{x}{4} = 6$

<Steps reveal>
1. $x$ ถูกหารด้วย $4$ อยู่ ต้องทำกลับด้วยการคูณ $4$ ทั้งสองข้าง (สมบัติการคูณ) ได้ $4 \cdot \dfrac{x}{4} = 4 \cdot 6$
2. ได้ $x = 24$
3. ตรวจ $\tfrac{24}{4} = 6$ เป็นจริง
</Steps>
</Example>

{/* check: solve(Eq(x/4, 6), x) == [24] */}

<Example n={4}>
แก้สมการ $15 = 2x + 7$

<Steps reveal>
1. สลับข้างให้ตัวแปรอยู่ทางซ้าย (สมบัติสมมาตร) ได้ $2x + 7 = 15$
2. บวก $-7$ ทั้งสองข้าง (สมบัติการบวก) ได้ $2x = 8$
3. คูณ $\tfrac{1}{2}$ ทั้งสองข้าง (สมบัติการคูณ) ได้ $x = 4$
4. ตรวจ ข้างขวาของสมการเดิม $2(4) + 7 = 15$ เท่ากับข้างซ้าย เป็นจริง
</Steps>
</Example>

{/* check: solve(Eq(15, 2*x + 7), x) == [4] */}

ลำดับในตัวอย่าง 1 และ 4 ไม่ใช่เรื่องบังเอิญ ให้กำจัดจำนวนที่บวกหรือลบอยู่ก่อน แล้วค่อยกำจัดจำนวนที่คูณอยู่ เหมือนการแกะห่อของ ห่อทีหลังต้องแกะก่อน ตอนสร้าง $3x + 2$ เอา $x$ ไปคูณ 3 ก่อนแล้วจึงบวก 2 ตอนแก้จึงต้องเอา 2 ออกก่อน

<Think>
เพื่อนแก้สมการ $3x + 2 = 11$ ว่า ลบ $2$ ออกจากข้างซ้ายได้ $3x = 11$ แล้วหารด้วย $3$ ได้ $x = \tfrac{11}{3}$ ผิดตรงไหน

<Reveal>
ขั้นแรกลบ $2$ แค่ข้างซ้ายข้างเดียว ข้างขวายังเป็น $11$ อยู่ เหมือนเอาตุ้มออกจากตาชั่งข้างเดียว ตาชั่งจึงเอียง ต้องลบ $2$ ทั้งสองข้างได้ $3x = 9$ ถ้าตรวจคำตอบจะเห็นเองว่าผิด แทน $x = \tfrac{11}{3}$ ได้ $3 \cdot \tfrac{11}{3} + 2 = 13$ ไม่เท่ากับ $11$
</Reveal>
</Think>

{/* check: 3*Rational(11, 3) + 2 == 13 */}

<Think>
สมบัติการคูณบอกว่าคูณทั้งสองข้างด้วยจำนวนใดก็ได้ ถ้าคูณ $3x + 2 = 11$ ทั้งสองข้างด้วย $0$ จะเกิดอะไรขึ้น

<Reveal>
ได้ $0 = 0$ ซึ่งเป็นจริงแต่ไม่บอกอะไรเกี่ยวกับ $x$ เลย ทุกจำนวนทำให้ $0 = 0$ จริง ข้อมูลในสมการหายไปหมด การคูณด้วยศูนย์ไม่ผิดกฎ แต่ไม่ช่วยแก้สมการ ที่เราใช้จริงคือคูณด้วยจำนวนที่ไม่ใช่ศูนย์ ซึ่งย้อนกลับได้เสมอ
</Reveal>
</Think>

## สรุป

- สมการเหมือนตาชั่งที่สมดุล ทำอะไรกับข้างหนึ่งต้องทำแบบเดียวกันกับอีกข้าง
- สมบัติของการเท่ากันมีสี่ข้อ สมมาตร ถ่ายทอด การบวก การคูณ
- ลบ $c$ คือบวก $-c$ หารด้วย $c$ คือคูณ $\tfrac{1}{c}$ เมื่อ $c \neq 0$
- กำจัดจำนวนที่บวกลบอยู่ก่อน แล้วจึงกำจัดจำนวนที่คูณอยู่
- ได้คำตอบแล้วแทนในสมการเดิมเพื่อตรวจทุกครั้ง
