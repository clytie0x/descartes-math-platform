สูตรขนมต้องใช้น้ำตาล $\tfrac{3}{4}$ ถ้วย แต่ในโหลเหลือน้ำตาลอยู่ $\tfrac{2}{3}$ ถ้วย พอไหม ถ้าไม่พอขาดอีกเท่าไร

ลองหาว่ามีมากกว่าที่ต้องใช้เท่าไร คือ $\tfrac{2}{3} - \tfrac{3}{4}$ ถ้าผลลัพธ์ติดลบแปลว่าไม่พอ หน้านี้จะคิดโจทย์แบบนี้ได้ โดยใช้กฎเครื่องหมายจากบทที่ 1 เหมือนหน้าที่แล้ว

## การบวกและการลบ

เศษส่วนที่ตัวส่วนเท่ากัน บวกหรือลบตัวเศษได้เลย เพราะเป็นของชิ้นขนาดเดียวกัน เช่น $\tfrac{2}{7} + \tfrac{3}{7} = \tfrac{5}{7}$ ถ้าตัวส่วนไม่เท่ากัน ต้องทำให้เท่ากันก่อนด้วย ค.ร.น. ของตัวส่วน

<Example n={1}>

หาค่า $\tfrac{2}{3} - \tfrac{3}{4}$ แล้วตอบคำถามเรื่องน้ำตาล

<Steps reveal>
1. ค.ร.น. ของ $3$ กับ $4$ คือ $12$
2. $\tfrac{2}{3} = \tfrac{8}{12}$ และ $\tfrac{3}{4} = \tfrac{9}{12}$
3. $\tfrac{8}{12} - \tfrac{9}{12} = \tfrac{8 - 9}{12} = -\tfrac{1}{12}$
4. ผลลัพธ์ติดลบ น้ำตาลจึงไม่พอ ขาดอีก $\tfrac{1}{12}$ ถ้วย
</Steps>
</Example>

{/* check: Rational(2, 3) - Rational(3, 4) == Rational(-1, 12) */}

<Example n={2}>

หาค่า $-\tfrac{5}{8} + \tfrac{1}{6}$

<Steps reveal>
1. ค.ร.น. ของ $8$ กับ $6$ คือ $24$
2. $-\tfrac{5}{8} = -\tfrac{15}{24}$ และ $\tfrac{1}{6} = \tfrac{4}{24}$
3. $\tfrac{-15 + 4}{24} = -\tfrac{11}{24}$ ซึ่งเป็นเศษส่วนอย่างต่ำแล้ว เพราะ $11$ กับ $24$ ไม่มีตัวประกอบร่วม
</Steps>
</Example>

{/* check: lcm(8, 6) == 24 and -Rational(5, 8) + Rational(1, 6) == Rational(-11, 24) */}

<Think>

เพื่อนคิดว่า $\tfrac{1}{2} + \tfrac{1}{3} = \tfrac{1 + 1}{2 + 3} = \tfrac{2}{5}$ ถูกไหม

<Reveal>
ไม่ถูก ตรวจง่ายๆ ได้ว่า $\tfrac{2}{5}$ น้อยกว่า $\tfrac{1}{2}$ แต่เอา $\tfrac{1}{2}$ ไปบวกกับจำนวนบวก ผลบวกต้องมากกว่า $\tfrac{1}{2}$ ตัวส่วนบอกขนาดของชิ้น จึงเอามาบวกกันไม่ได้ ต้องทำให้ชิ้นขนาดเท่ากันก่อน $\tfrac{3}{6} + \tfrac{2}{6} = \tfrac{5}{6}$
</Reveal>
</Think>

{/* check: Rational(1, 2) + Rational(1, 3) == Rational(5, 6) and Rational(2, 5) < Rational(1, 2) */}

### จำนวนคละ

เปลี่ยนจำนวนคละเป็นเศษเกินก่อน แล้วคิดแบบเศษส่วนธรรมดา

<Note kind="warning" title="เครื่องหมายลบคลุมทั้งจำนวน">
$-2\tfrac{1}{3}$ หมายถึง $-\big(2 + \tfrac{1}{3}\big) = -\tfrac{7}{3}$ ไม่ใช่ $-2 + \tfrac{1}{3} = -\tfrac{5}{3}$ ตอนเปลี่ยนเป็นเศษเกิน ให้ทำส่วนที่เป็นบวก $2\tfrac{1}{3} = \tfrac{7}{3}$ ก่อน แล้วค่อยใส่เครื่องหมายลบ
</Note>

{/* check: -(2 + Rational(1, 3)) == Rational(-7, 3) and -2 + Rational(1, 3) == Rational(-5, 3) */}

<Example n={3}>

หาค่า $-2\tfrac{1}{3} + \tfrac{3}{4}$ ตอบเป็นจำนวนคละ

<Steps reveal>
1. $-2\tfrac{1}{3} = -\tfrac{7}{3}$
2. ค.ร.น. ของ $3$ กับ $4$ คือ $12$ ได้ $-\tfrac{28}{12} + \tfrac{9}{12} = -\tfrac{19}{12}$
3. $19 \div 12$ ได้ $1$ เศษ $7$ จึงตอบ $-1\tfrac{7}{12}$
</Steps>
</Example>

{/* check: Rational(-7, 3) + Rational(3, 4) == Rational(-19, 12) and Rational(-19, 12) == -(1 + Rational(7, 12)) */}

## การคูณ

คูณตัวเศษกับตัวเศษ คูณตัวส่วนกับตัวส่วน

$$
\frac{a}{b} \times \frac{c}{d} = \frac{a \times c}{b \times d}
$$

เช่น $\tfrac{2}{3} \times \tfrac{4}{5} = \tfrac{8}{15}$ ซึ่งอ่านได้ว่า $\tfrac{2}{3}$ ของ $\tfrac{4}{5}$ เครื่องหมายใช้กฎจำนวนเต็มเหมือนเดิม ถ้าตัวเลขใหญ่ ให้ตัดตัวประกอบร่วมระหว่างตัวเศษกับตัวส่วนออกก่อนคูณ จะได้เศษส่วนอย่างต่ำทันที

{/* check: Rational(2, 3) * Rational(4, 5) == Rational(8, 15) */}

<Example n={4}>

หาค่า $\left(-\tfrac{4}{9}\right) \times \tfrac{15}{8}$

<Steps reveal>
1. ลบคูณบวกได้ลบ ที่เหลือคิดเฉพาะ $\tfrac{4 \times 15}{9 \times 8}$
2. $4$ กับ $8$ หารด้วย $4$ ได้ $1$ กับ $2$ ส่วน $15$ กับ $9$ หารด้วย $3$ ได้ $5$ กับ $3$
3. เหลือ $\tfrac{1 \times 5}{3 \times 2} = \tfrac{5}{6}$ คำตอบคือ $-\tfrac{5}{6}$
</Steps>
</Example>

{/* check: -Rational(4, 9) * Rational(15, 8) == Rational(-5, 6) */}

<Example n={5}>

หาค่า $\left(-1\tfrac{1}{2}\right) \times \left(-2\tfrac{2}{3}\right)$

<Steps reveal>
1. เปลี่ยนเป็นเศษเกิน $-\tfrac{3}{2}$ และ $-\tfrac{8}{3}$
2. ลบคูณลบได้บวก $\tfrac{3 \times 8}{2 \times 3} = \tfrac{24}{6} = 4$
</Steps>
</Example>

{/* check: Rational(-3, 2) * Rational(-8, 3) == 4 */}

อย่าคูณแยกส่วน คือเอาจำนวนเต็มคูณจำนวนเต็ม เศษส่วนคูณเศษส่วน แล้วนำมาบวกกัน แบบ $1 \times 2 + \tfrac{1}{2} \times \tfrac{2}{3} = 2\tfrac{1}{3}$ ซึ่งไม่ตรงกับคำตอบจริงคือ $4$ เพราะ $1\tfrac{1}{2}$ คือผลบวก $1 + \tfrac{1}{2}$ การคูณผลบวกต้องคูณทุกพจน์ไขว้กันด้วย เปลี่ยนเป็นเศษเกินก่อนจึงปลอดภัยที่สุด

{/* check: Rational(3, 2) * Rational(8, 3) == 4 and 1*2 + Rational(1, 2)*Rational(2, 3) == Rational(7, 3) */}

## การหาร

### ส่วนกลับ

สองจำนวนที่คูณกันได้ $1$ เป็น**ส่วนกลับ**ของกันและกัน ส่วนกลับของ $\tfrac{a}{b}$ คือ $\tfrac{b}{a}$ เมื่อ $a \neq 0$ และ $b \neq 0$ เช่น ส่วนกลับของ $\tfrac{3}{5}$ คือ $\tfrac{5}{3}$ ส่วนกลับของ $4$ คือ $\tfrac{1}{4}$ ส่วน $0$ ไม่มีส่วนกลับ เพราะ $0$ คูณอะไรก็ได้ $0$

<Think>

ส่วนกลับของ $-\tfrac{2}{3}$ คือ $\tfrac{3}{2}$ ใช่ไหม

<Reveal>
ไม่ใช่ $\left(-\tfrac{2}{3}\right) \times \tfrac{3}{2} = -1$ ไม่ใช่ $1$ ส่วนกลับต้องมีเครื่องหมายเดียวกับจำนวนเดิม ส่วนกลับของ $-\tfrac{2}{3}$ คือ $-\tfrac{3}{2}$ เพราะลบคูณลบได้บวก $\left(-\tfrac{2}{3}\right) \times \left(-\tfrac{3}{2}\right) = 1$
</Reveal>
</Think>

{/* check: Rational(-2, 3) * Rational(3, 2) == -1 and Rational(-2, 3) * Rational(-3, 2) == 1 */}

### หารด้วยเศษส่วน คือคูณด้วยส่วนกลับ

$3 \div \tfrac{1}{4}$ ถามว่าใน $3$ มี $\tfrac{1}{4}$ อยู่กี่ชิ้น หนึ่งหน่วยมีสี่ชิ้น สามหน่วยจึงมี $3 \times 4 = 12$ ชิ้น การหารด้วย $\tfrac{1}{4}$ จึงเท่ากับคูณด้วย $4$ ซึ่งเป็นส่วนกลับของ $\tfrac{1}{4}$ ใช้ได้กับเศษส่วนทุกตัว

$$
\frac{a}{b} \div \frac{c}{d} = \frac{a}{b} \times \frac{d}{c}
$$

{/* check: 3 / Rational(1, 4) == 12 */}

<Example n={6}>

หาค่า $\left(-\tfrac{5}{6}\right) \div \left(-\tfrac{10}{9}\right)$

<Steps reveal>
1. เปลี่ยนเป็นคูณด้วยส่วนกลับ $\left(-\tfrac{5}{6}\right) \times \left(-\tfrac{9}{10}\right)$
2. ลบคูณลบได้บวก และตัด $5$ กับ $10$ เหลือ $1$ กับ $2$ ตัด $9$ กับ $6$ เหลือ $3$ กับ $2$
3. ได้ $\tfrac{1 \times 3}{2 \times 2} = \tfrac{3}{4}$
</Steps>
</Example>

{/* check: Rational(-5, 6) / Rational(-10, 9) == Rational(3, 4) */}

## เศษส่วนกับทศนิยมในข้อเดียว

เปลี่ยนให้เป็นแบบเดียวกันก่อน ส่วนใหญ่เปลี่ยนทศนิยมเป็นเศษส่วนจะง่ายกว่า เพราะเศษส่วนบางตัวเป็นทศนิยมที่ไม่จบ

<Example n={7}>

หาค่า $0.75 \times \left(-\tfrac{2}{3}\right)$

<Steps reveal>
1. $0.75 = \tfrac{75}{100} = \tfrac{3}{4}$
2. $\tfrac{3}{4} \times \left(-\tfrac{2}{3}\right) = -\tfrac{6}{12} = -\tfrac{1}{2}$ หรือเขียนเป็นทศนิยม $-0.5$
</Steps>
</Example>

{/* check: Rational('0.75') * Rational(-2, 3) == Rational(-1, 2) */}

## สรุป

- บวกลบเศษส่วน ทำตัวส่วนให้เท่ากันด้วย ค.ร.น. แล้วบวกลบเฉพาะตัวเศษ
- คูณ ตัวเศษคูณตัวเศษ ตัวส่วนคูณตัวส่วน ตัดตัวประกอบร่วมก่อนจะง่ายขึ้น
- หาร คูณด้วยส่วนกลับของตัวหาร ส่วนกลับมีเครื่องหมายเดียวกับจำนวนเดิม
- จำนวนคละเปลี่ยนเป็นเศษเกินก่อนเสมอ และ $-2\tfrac{1}{3} = -\tfrac{7}{3}$
- เครื่องหมายของคำตอบใช้กฎเดียวกับจำนวนเต็ม
