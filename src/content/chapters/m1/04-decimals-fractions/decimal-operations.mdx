ช่องแช่แข็งอุณหภูมิ $-18.5$ องศาเซลเซียส มีคนเปิดประตูทิ้งไว้จนอุณหภูมิสูงขึ้น $3.75$ องศา ตอนนี้อุณหภูมิเท่าไร

โจทย์นี้คือ $(-18.5) + 3.75$ ซึ่งคิดเหมือนการบวกจำนวนเต็มในบทที่ 1 ทุกอย่าง ต่างกันแค่ต้องระวังจุดทศนิยม ทั้งหน้านี้ใช้หลักเดียว คือ**เครื่องหมายใช้กฎของจำนวนเต็ม ตัวเลขคิดแบบทศนิยมที่เป็นบวก**

## การบวกและการลบ

ทบทวนกฎจากบทที่ 1 แล้วใช้กับทศนิยมได้เลย

- บวกจำนวนที่เครื่องหมายเหมือนกัน เอาระยะห่างจากศูนย์มาบวกกัน แล้วใส่เครื่องหมายเดิม
- บวกจำนวนที่เครื่องหมายต่างกัน เอาระยะห่างจากศูนย์ตัวมากลบตัวน้อย แล้วใส่เครื่องหมายของตัวที่ห่างศูนย์มากกว่า
- การลบ คือการบวกด้วยจำนวนตรงข้าม $a - b = a + (-b)$

ส่วนการตั้งบวกหรือตั้งลบทศนิยม ต้องให้จุดทศนิยมตรงกัน เติมศูนย์ต่อท้ายให้ตำแหน่งเท่ากันก่อนก็ได้

<Example n={1}>

หาค่า $(-18.5) + 3.75$

<Steps reveal>
1. เครื่องหมายต่างกัน ระยะห่างจากศูนย์คือ $18.5$ กับ $3.75$
2. ตั้งลบโดยให้จุดตรงกัน $18.50 - 3.75 = 14.75$
3. $-18.5$ ห่างศูนย์มากกว่า คำตอบจึงเป็นลบ $(-18.5) + 3.75 = -14.75$
4. ตอนนี้ช่องแช่แข็งอุณหภูมิ $-14.75$ องศาเซลเซียส ยังติดลบอยู่ เพราะเพิ่มขึ้นไม่ถึง $18.5$ องศา
</Steps>
</Example>

{/* check: Rational('-18.5') + Rational('3.75') == Rational('-14.75') */}

<Example n={2}>

หาค่า (1) $(-2.6) - (-5.15)$  (2) $-0.75 - 1.6$

<Steps reveal>
1. ข้อ (1) ลบด้วย $-5.15$ คือบวกด้วย $5.15$ ได้ $(-2.6) + 5.15$
2. เครื่องหมายต่างกัน $5.15 - 2.60 = 2.55$ และ $5.15$ ห่างศูนย์มากกว่า คำตอบเป็นบวก ได้ $2.55$
3. ข้อ (2) ลบด้วย $1.6$ คือบวกด้วย $-1.6$ ได้ $(-0.75) + (-1.6)$
4. เครื่องหมายเหมือนกัน $0.75 + 1.60 = 2.35$ ใส่เครื่องหมายลบ ได้ $-2.35$
</Steps>
</Example>

{/* check: Rational('-2.6') - Rational('-5.15') == Rational('2.55') and Rational('-0.75') - Rational('1.6') == Rational('-2.35') */}

<Think>

เพื่อนตั้งลบ $5.75 - 3.2$ โดยเขียนตัวเลขชิดขวาแบบจำนวนเต็ม ให้เลข $3$ อยู่ใต้เลข $7$ และเลข $2$ อยู่ใต้เลข $5$ แล้วได้ $5.43$ ผิดตรงไหน

## การคูณ

ดูก่อนว่าทำไมการคูณทศนิยมจึงนับตำแหน่ง ลองเขียนเป็นเศษส่วน

$$
0.3 \times 0.02 = \frac{3}{10} \times \frac{2}{100} = \frac{6}{1000} = 0.006
$$

{/* check: Rational('0.3') * Rational('0.02') == Rational('0.006') */}

ตัวส่วน $10 \times 100 = 1000$ มีศูนย์สามตัว เท่ากับจำนวนตำแหน่งทศนิยมของ $0.3$ (หนึ่งตำแหน่ง) รวมกับของ $0.02$ (สองตำแหน่ง) จึงได้วิธีลัด

<Thm label="การคูณทศนิยม">

1. คูณตัวเลขเหมือนเป็นจำนวนเต็ม ไม่สนจุด
2. นับจำนวนตำแหน่งทศนิยมของตัวตั้งและตัวคูณรวมกัน คำตอบมีจำนวนตำแหน่งเท่านั้น
3. เครื่องหมายใช้กฎจำนวนเต็ม บวกคูณลบหรือลบคูณบวกได้ลบ ลบคูณลบได้บวก

</Thm>

<Example n={3}>

หาค่า $(-1.25) \times 0.32$

<Steps reveal>
1. คูณแบบจำนวนเต็ม $125 \times 32 = 4000$
2. $1.25$ มีสองตำแหน่ง $0.32$ มีสองตำแหน่ง รวมสี่ตำแหน่ง ได้ $0.4000 = 0.4$
3. ลบคูณบวกได้ลบ คำตอบคือ $-0.4$
</Steps>
</Example>

{/* check: 125*32 == 4000 and Rational('-1.25') * Rational('0.32') == Rational('-0.4') */}

<Think>

$0.2 \times 0.3$ เท่ากับ $0.6$ ใช่ไหม

<Reveal>
ไม่ใช่ $2 \times 3 = 6$ แล้วต้องมีสองตำแหน่ง เพราะตัวตั้งกับตัวคูณมีตัวละหนึ่งตำแหน่ง จึงได้ $0.06$ คิดอีกทางคือ $0.3$ คือ $\tfrac{3}{10}$ เอา $0.2$ มาแบ่ง $10$ ส่วนเอา $3$ ส่วน ต้องได้น้อยกว่า $0.2$ ซึ่ง $0.6$ มากกว่า $0.2$ จึงผิดแน่นอน เมื่อจำนวนตั้งต้นเป็นบวก การคูณด้วยจำนวนที่อยู่ระหว่าง $0$ กับ $1$ ทำให้ผลคูณเล็กลง ถ้าจำนวนตั้งต้นเป็นลบ ผลคูณจะเข้าใกล้ศูนย์และมีค่ามากขึ้น เช่น $-2 \times 0.5 = -1$ ส่วนศูนย์คูณแล้วก็ยังเป็นศูนย์
</Reveal>
</Think>

{/* check: Rational('0.2') * Rational('0.3') == Rational('0.06') */}
{/* check: -2 * Rational('0.5') == -1 and -1 > -2 and 0 * Rational('0.5') == 0 */}

## การหาร

การหารทศนิยมจะง่ายขึ้นมากถ้าตัวหารเป็นจำนวนเต็ม หลักที่ใช้คือคูณทั้งตัวตั้งและตัวหารด้วยจำนวนเดียวกัน ผลหารไม่เปลี่ยน เช่น $6 \div 2 = 60 \div 20 = 3$

$$
3.6 \div 0.04 = \frac{3.6}{0.04} = \frac{3.6 \times 100}{0.04 \times 100} = \frac{360}{4} = 90
$$

{/* check: Rational('3.6') / Rational('0.04') == 90 */}

คูณด้วย $100$ คือเลื่อนจุดไปทางขวาสองตำแหน่ง ทั้งตัวตั้งและตัวหาร ให้เลื่อนเท่ากันเสมอ

<Example n={4}>

หาค่า $(-7.56) \div 0.18$

<Steps reveal>
1. $0.18$ มีสองตำแหน่ง เลื่อนจุดของทั้งสองจำนวนไปทางขวาสองตำแหน่ง ได้ $756 \div 18$
2. $756 \div 18 = 42$
3. ลบหารบวกได้ลบ คำตอบคือ $-42$
4. ตรวจ $0.18 \times 42 = 7.56$ ถูกต้อง
</Steps>
</Example>

{/* check: Rational('-7.56') / Rational('0.18') == -42 and Rational('0.18') * 42 == Rational('7.56') */}

บางครั้งหารแล้วไม่ลงตัว เช่น $2.5 \div 0.6 = 25 \div 6 = 4.1666\ldots$ เลข $6$ ซ้ำไปเรื่อยๆ ไม่จบ ในชีวิตจริงมักปัดเป็น $4.17$ ส่วนเหตุผลที่มันไม่จบจะอยู่ในหน้า 4.4

{/* check: Rational('2.5') / Rational('0.6') == Rational(25, 6) and floor(Rational(25, 6) * 10**4) == 41666 */}

## หลายการดำเนินการในข้อเดียว

ลำดับเหมือนจำนวนเต็ม ทำในวงเล็บก่อน แล้วคูณหารจากซ้ายไปขวา แล้วจึงบวกลบจากซ้ายไปขวา

<Example n={5}>

หาค่า $2.4 - 0.6 \times (-3.5)$

<Steps reveal>
1. คูณก่อน $0.6 \times (-3.5) = -2.1$
2. $2.4 - (-2.1) = 2.4 + 2.1 = 4.5$
</Steps>
</Example>

{/* check: Rational('2.4') - Rational('0.6') * Rational('-3.5') == Rational('4.5') */}

ถ้าทำจากซ้ายไปขวาโดยไม่สนลำดับ จะได้ $(2.4 - 0.6) \times (-3.5) = -6.3$ ซึ่งผิด

{/* check: (Rational('2.4') - Rational('0.6')) * Rational('-3.5') == Rational('-6.3') */}

## สรุป

- เครื่องหมายของคำตอบใช้กฎเดียวกับจำนวนเต็มในบทที่ 1
- บวกและลบ ตั้งให้จุดทศนิยมตรงกัน
- คูณ คูณแบบจำนวนเต็ม แล้วนับตำแหน่งทศนิยมรวมของตัวตั้งและตัวคูณ
- หาร เลื่อนจุดของตัวตั้งและตัวหารไปทางขวาเท่ากันจนตัวหารเป็นจำนวนเต็ม
- ประมาณคำตอบคร่าวๆ ก่อน จะจับจุดทศนิยมที่ผิดตำแหน่งได้
