สามคนช่วยกันซื้อพิซซ่าถาดละ 100 บาท หารกันคนละเท่าไร กดเครื่องคิดเลข $100 \div 3$ ได้ $33.333333$ เต็มหน้าจอ ถ้าหน้าจอยาวกว่านี้ เลข $3$ ก็ยังเรียงต่อไปเรื่อยๆ ไม่มีวันจบ

หน้านี้ตอบสามคำถาม ทำไมบางเศษส่วนหารแล้วจบ บางตัวไม่จบ ทศนิยมที่ไม่จบเขียนสั้นๆ ยังไง และถ้าได้ทศนิยมที่ไม่จบมา จะเปลี่ยนกลับเป็นเศษส่วนได้ไหม

## จากเศษส่วนเป็นทศนิยม

เศษส่วน $\tfrac{a}{b}$ คือ $a \div b$ จึงเปลี่ยนเป็นทศนิยมได้ด้วยการหารยาว เช่น $\tfrac{3}{8} = 3 \div 8 = 0.375$ หารแล้วเหลือเศษ $0$ จึงจบ

{/* check: Rational(3, 8) == Rational('0.375') */}

ลองหาร $5 \div 6$ ดูทีละขั้น $5$ หารด้วย $6$ ไม่ได้ ใส่ $0.$ แล้วเติมศูนย์เป็น $50$

| ขั้น | หาร | ได้เลข | เหลือเศษ |
|---|---|---|---|
| 1 | $50 \div 6$ | $8$ | $2$ |
| 2 | $20 \div 6$ | $3$ | $2$ |
| 3 | $20 \div 6$ | $3$ | $2$ |
| 4 | $20 \div 6$ | $3$ | $2$ |

ตั้งแต่ขั้นที่ 2 เศษเป็น $2$ ทุกขั้น พอเติมศูนย์ก็กลับมาหาร $20 \div 6$ แบบเดิม จึงได้เลข $3$ ซ้ำไปตลอด $\tfrac{5}{6} = 0.8333\ldots$

{/* check: floor(Rational(5, 6) * 10**6) == 833333 */}

## ทศนิยมซ้ำ

<Def>
ทศนิยมที่มีตัวเลขชุดหนึ่งซ้ำกันไปเรื่อยๆ ไม่สิ้นสุด เรียกว่า**ทศนิยมซ้ำ** เขียนโดยใส่จุดไว้บนตัวเลขตัวแรกและตัวสุดท้ายของชุดที่ซ้ำ ถ้าซ้ำตัวเดียวก็ใส่จุดตัวเดียว
</Def>

| เศษส่วน | หารยาวได้ | เขียนเป็น | อ่านว่า |
|---|---|---|---|
| $\tfrac{1}{3}$ | $0.3333\ldots$ | $0.\dot{3}$ | ศูนย์จุดสามซ้ำ |
| $\tfrac{5}{6}$ | $0.8333\ldots$ | $0.8\dot{3}$ | ศูนย์จุดแปดสามซ้ำ |
| $\tfrac{3}{11}$ | $0.272727\ldots$ | $0.\dot{2}\dot{7}$ | ศูนย์จุดสองเจ็ดซ้ำ |
| $\tfrac{1}{7}$ | $0.142857142857\ldots$ | $0.\dot{1}4285\dot{7}$ | ศูนย์จุดหนึ่งสี่สองแปดห้าเจ็ดซ้ำ |

{/* check: floor(Rational(1, 3) * 10**6) == 333333 and floor(Rational(3, 11) * 10**6) == 272727 and floor(Rational(1, 7) * 10**12) == 142857142857 */}

ระวังตำแหน่งของจุด $0.8\dot{3}$ ซ้ำแค่เลข $3$ คือ $0.8333\ldots$ ส่วน $0.\dot{8}\dot{3}$ ซ้ำทั้งคู่ คือ $0.838383\ldots$ เป็นคนละจำนวนกัน

ทศนิยมที่จบ เช่น $0.375$ เรียกว่า**ทศนิยมรู้จบ** จะมองเป็นทศนิยมซ้ำก็ได้ โดยมองว่ามีศูนย์ซ้ำต่อท้าย $0.375 = 0.375\dot{0}$

### ทำไมต้องซ้ำ

ตอนหารยาวด้วย $7$ เศษที่เหลือแต่ละขั้นต้องน้อยกว่า $7$ คือเป็นได้แค่ $0$ ถึง $6$ ถ้าเศษเป็น $0$ เมื่อไรการหารก็จบ ถ้าไม่เคยเป็น $0$ เศษมีให้เลือกแค่ $1$ ถึง $6$ คือหกแบบ หารไม่เกินหกขั้นต้องเจอเศษที่เคยเจอแล้ว แล้วทุกอย่างก็วนซ้ำจากตรงนั้น

$\tfrac{1}{7}$ ได้เศษ $1$ $3$ $2$ $6$ $4$ $5$ แล้วกลับมาเป็น $1$ ครบหกแบบพอดี ชุดที่ซ้ำจึงยาว 6 ตัว ดังนั้น**เศษส่วนทุกตัวเป็นได้แค่ทศนิยมรู้จบหรือทศนิยมซ้ำ** ไม่มีแบบอื่น

{/* check: [(10**i) % 7 for i in range(7)] == [1, 3, 2, 6, 4, 5, 1] */}

### ดูตัวส่วนก็รู้

ทศนิยมรู้จบคือเศษส่วนที่มีตัวส่วนเป็น $10$ $100$ $1000$ ได้ และ $10 = 2 \times 5$ ดังนั้นตัวส่วนที่ทำให้เป็นแบบนี้ได้ต้องมีตัวประกอบเฉพาะแค่ $2$ กับ $5$

<Thm>

ให้ $\tfrac{a}{b}$ เป็นเศษส่วนอย่างต่ำ

- ถ้า $b$ มีตัวประกอบเฉพาะเป็น $2$ หรือ $5$ เท่านั้น $\tfrac{a}{b}$ เป็นทศนิยมรู้จบ
- ถ้า $b$ มีตัวประกอบเฉพาะอื่น เช่น $3$ $7$ $11$ $\tfrac{a}{b}$ เป็นทศนิยมซ้ำที่ไม่ใช่ศูนย์ซ้ำ

</Thm>

<Example n={1}>

เศษส่วนใดเป็นทศนิยมรู้จบ $\tfrac{7}{20}$ $\tfrac{5}{12}$ $\tfrac{9}{15}$ $\tfrac{4}{33}$ แล้วเขียนแต่ละตัวเป็นทศนิยม

<Steps reveal>
1. $\tfrac{7}{20}$ ตัวส่วน $20 = 2 \times 2 \times 5$ รู้จบ คูณทั้งเศษและส่วนด้วย $5$ ได้ $\tfrac{35}{100} = 0.35$
2. $\tfrac{5}{12}$ ตัวส่วน $12 = 2 \times 2 \times 3$ มี $3$ จึงซ้ำ หารยาวได้ $0.41666\ldots = 0.41\dot{6}$
3. $\tfrac{9}{15}$ ยังไม่ใช่เศษส่วนอย่างต่ำ ทอนก่อนได้ $\tfrac{3}{5}$ ตัวส่วนเหลือแค่ $5$ จึงรู้จบ $\tfrac{3}{5} = 0.6$
4. $\tfrac{4}{33}$ ตัวส่วน $33 = 3 \times 11$ จึงซ้ำ หารยาวได้ $0.121212\ldots = 0.\dot{1}\dot{2}$
</Steps>
</Example>

{/* check: Rational(7, 20) == Rational('0.35') and floor(Rational(5, 12) * 10**5) == 41666 and Rational(9, 15) == Rational('0.6') and floor(Rational(4, 33) * 10**6) == 121212 */}

ข้อ $\tfrac{9}{15}$ คือกับดัก เห็น $15 = 3 \times 5$ มี $3$ แล้วตอบว่าซ้ำ ทั้งที่ $3$ ตัดกับตัวเศษได้ ต้องทำเป็นเศษส่วนอย่างต่ำก่อนดูตัวส่วนเสมอ

ลองตั้งตัวส่วนบนกราฟข้างล่างเป็น $3$ $6$ $7$ $9$ $11$ $12$ แล้วดูทศนิยมในกล่องใต้กราฟ เทียบกับตัวส่วน $2$ $4$ $5$ $8$ $10$

<Board name="c4-fraction-line" label="เส้นจำนวนแสดงเศษส่วนที่เลือก พร้อมกล่องบอกค่าเป็นทศนิยม ถ้าเป็นทศนิยมซ้ำจะมีจุดบนตัวเลขชุดที่ซ้ำ" caption="กล่องใต้กราฟบอกค่าเศษส่วนเป็นทศนิยม จุดบนตัวเลขคือชุดที่ซ้ำ" />

## จากทศนิยมซ้ำเป็นเศษส่วน

หลักคือคูณด้วย $10$ $100$ หรือ $1000$ ให้หางที่ซ้ำเลื่อนมาตรงกัน แล้วลบกันให้หางหายไป

<Example n={2}>

เขียน $0.\dot{4}$ เป็นเศษส่วน

<Steps reveal>
1. ให้ $N = 0.444\ldots$
2. คูณด้วย $10$ ได้ $10N = 4.444\ldots$ หางหลังจุดเหมือน $N$ ทุกตัว
3. ลบกัน $10N - N = 4.444\ldots - 0.444\ldots = 4$ หางหายหมด เหลือ $9N = 4$
4. ดังนั้น $N = \tfrac{4}{9}$
</Steps>
</Example>

{/* check: floor(Rational(4, 9) * 10**6) == 444444 */}

<Example n={3}>

เขียน $0.\dot{3}\dot{6}$ เป็นเศษส่วนอย่างต่ำ

<Steps reveal>
1. ให้ $N = 0.363636\ldots$ ชุดที่ซ้ำยาว 2 ตัว จึงคูณด้วย $100$ ได้ $100N = 36.3636\ldots$
2. $100N - N = 36$ ได้ $99N = 36$
3. $N = \tfrac{36}{99} = \tfrac{4}{11}$ หลังหารทั้งสองตัวด้วย $9$
</Steps>
</Example>

{/* check: Rational(36, 99) == Rational(4, 11) and floor(Rational(4, 11) * 10**6) == 363636 */}

<Example n={4}>

เขียน $0.1\dot{6}$ เป็นเศษส่วนอย่างต่ำ

<Steps reveal>
1. ให้ $N = 0.1666\ldots$ มีเลข $1$ ที่ไม่ซ้ำนำหน้าอยู่ ถ้าคูณ $10$ อย่างเดียวหางจะยังไม่ตรงกับ $N$
2. คูณ $10$ ได้ $10N = 1.666\ldots$ คูณ $100$ ได้ $100N = 16.666\ldots$ สองตัวนี้หางเป็น $6$ ซ้ำเหมือนกัน
3. $100N - 10N = 16 - 1 = 15$ ได้ $90N = 15$
4. $N = \tfrac{15}{90} = \tfrac{1}{6}$
</Steps>
</Example>

{/* check: Rational(15, 90) == Rational(1, 6) and floor(Rational(1, 6) * 10**6) == 166666 */}

ทำแบบนี้หลายๆ ข้อจะเห็นแบบรูป สรุปเป็นทางลัดได้

<Thm label="ทางลัด">

ทศนิยมซ้ำที่อยู่ระหว่าง $0$ กับ $1$ เขียนเป็นเศษส่วนได้ดังนี้

- ตัวเศษ คือตัวเลขหลังจุดจนจบชุดที่ซ้ำชุดแรก ลบด้วยตัวเลขหลังจุดที่ไม่ซ้ำ
- ตัวส่วน คือเลข $9$ ตามจำนวนตัวที่ซ้ำ ตามด้วยเลข $0$ ตามจำนวนตัวที่ไม่ซ้ำ

เช่น $0.\dot{3}\dot{6} = \dfrac{36}{99}$ และ $0.1\dot{6} = \dfrac{16 - 1}{90}$

</Thm>

<Example n={5}>

เขียน $2.0\dot{4}\dot{5}$ เป็นเศษส่วน

<Steps reveal>
1. แยกจำนวนเต็มออกก่อน $2.0\dot{4}\dot{5} = 2 + 0.0\dot{4}\dot{5}$
2. หลังจุดมีเลข $0$ ไม่ซ้ำหนึ่งตัว และ $45$ ซ้ำสองตัว ใช้ทางลัดได้ $\tfrac{045 - 0}{990} = \tfrac{45}{990} = \tfrac{1}{22}$
3. ดังนั้น $2.0\dot{4}\dot{5} = 2 + \tfrac{1}{22} = \tfrac{45}{22}$
4. ตรวจด้วยการหาร $45 \div 22 = 2.04545\ldots$ ถูกต้อง
</Steps>
</Example>

{/* check: Rational(45, 990) == Rational(1, 22) and 2 + Rational(1, 22) == Rational(45, 22) and floor(Rational(45, 22) * 10**7) == 20454545 */}

<Think>

$0.\dot{9}$ คือ $0.999\ldots$ มีค่าน้อยกว่า $1$ อยู่นิดหนึ่ง ใช่ไหม

<Reveal>
ไม่ใช่ ใช้วิธีเดิม ให้ $N = 0.999\ldots$ ได้ $10N = 9.999\ldots$ ลบกันได้ $9N = 9$ จึงได้ $N = 1$ อีกทางหนึ่ง $\tfrac{1}{3} = 0.333\ldots$ คูณ $3$ ทั้งสองข้างได้ $1 = 0.999\ldots$ ถ้า $0.\dot{9}$ น้อยกว่า $1$ จริง ต้องมีจำนวนที่อยู่ระหว่างกลางได้ แต่หาไม่ได้เลย เพราะเลข $9$ ไม่มีวันหยุด
</Reveal>
</Think>

{/* check: 3 * Rational(1, 3) == 1 and Rational(9, 9) == 1 */}

## สรุป

- เปลี่ยนเศษส่วนเป็นทศนิยมด้วยการหารตัวเศษด้วยตัวส่วน ได้ทศนิยมรู้จบหรือทศนิยมซ้ำเท่านั้น
- เขียนทศนิยมซ้ำโดยใส่จุดบนตัวแรกและตัวสุดท้ายของชุดที่ซ้ำ เช่น $0.\dot{1}4285\dot{7}$
- เศษส่วนอย่างต่ำที่ตัวส่วนมีแค่ตัวประกอบ $2$ กับ $5$ เป็นทศนิยมรู้จบ ต้องทอนเป็นอย่างต่ำก่อนดูตัวส่วน
- เปลี่ยนทศนิยมซ้ำเป็นเศษส่วน คูณด้วย $10$ $100$ ให้หางตรงกันแล้วลบ หรือใช้ทางลัด $9$ กับ $0$
