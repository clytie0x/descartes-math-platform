เครื่องขายน้ำหน้าโรงอาหารรับรหัสสินค้าแล้วบอกราคา กดรหัส A1 ได้น้ำเปล่า $10$ บาท กดรหัส B2 ได้ชาเขียว $20$ บาท สมมติวันหนึ่งกด A1 แล้วหน้าจอขึ้น $10$ บาท แต่กดซ้ำอีกครั้งกลับขึ้น $15$ บาท เราคงไม่กล้าหยอดเหรียญ เพราะบอกไม่ได้ว่าต้องจ่ายเท่าไร

แต่ถ้ารหัส A1 กับ A2 ราคา $10$ บาทเท่ากัน ไม่มีใครเดือดร้อน ของสองอย่างราคาเท่ากันเป็นเรื่องปกติ ความต่างของสองกรณีนี้คือหัวใจของคำว่าฟังก์ชัน หน้านี้จะทำให้ตัดสินได้ว่าข้อมูลชุดใดเป็นฟังก์ชัน ทั้งจากคู่อันดับ ตาราง และกราฟ แล้วคำนวณค่าของฟังก์ชันได้โดยไม่พลาดเรื่องวงเล็บ

## หนึ่งข้อมูลเข้าต้องมีหนึ่งผลลัพธ์

ในบทที่ 8 เราวาดกราฟของ $y = 2x + 1$ และในบทที่ 25 เราเรียก $y = ax^2 + bx + c$ ว่าฟังก์ชันกำลังสอง ทั้งสองแบบมีสิ่งหนึ่งเหมือนกัน คือใส่ค่า $x$ หนึ่งค่าแล้วคำนวณ $y$ ออกมาได้ค่าเดียวเสมอ ม.ปลายตั้งชื่อสมบัตินี้ให้ชัด

<Def>
ฟังก์ชันคือการจับคู่ที่สมาชิกแต่ละตัวของเซตต้นทาง ซึ่งเรียกว่าโดเมน จับคู่กับผลลัพธ์ได้**เพียงค่าเดียว** ถ้าเรียกฟังก์ชันว่า $f$ ผลลัพธ์ของข้อมูลเข้า $x$ เขียนว่า $f(x)$ อ่านว่า เอฟของเอกซ์
</Def>

ทำไมต้องบังคับว่าค่าเดียว เพราะเราใช้ฟังก์ชันเพื่อทำนาย รู้ข้อมูลเข้าแล้วต้องบอกผลได้แน่นอน เหมือนเครื่องขายน้ำ ถ้าข้อมูลเข้าตัวเดียวให้ได้หลายผล สัญลักษณ์ $f(3)$ ก็ไม่รู้ว่าหมายถึงค่าไหน

เงื่อนไขนี้ห้ามเพียงทางเดียว คือห้ามข้อมูลเข้าตัวเดียวแยกไปหลายผล แต่ไม่ได้ห้ามข้อมูลเข้าหลายตัวมารวมที่ผลเดียว เช่น $f(x) = x^2$ มี $f(2) = 4$ และ $f(-2) = 4$ ก็ยังเป็นฟังก์ชัน เหมือนน้ำสองชนิดที่ราคาเท่ากัน

อีกเรื่องที่ต้องระวังตั้งแต่ต้น $f(x)$ ไม่ใช่ $f$ คูณ $x$ วงเล็บตรงนี้แปลว่าส่ง $x$ เข้าไปในกฎ $f$ แล้วดูว่าได้อะไรออกมา

แผนภาพลูกศรช่วยให้เห็นเงื่อนไขนี้ชัดที่สุด วงรีซ้ายเป็นข้อมูลเข้า วงรีขวาเป็นผลลัพธ์ วิธีตรวจคือนับลูกศรที่ออกจากข้อมูลเข้าแต่ละตัว ต้องมีหนึ่งเส้นพอดี

## แทนค่าทั้งวงเล็บ

เมื่อได้ฟังก์ชันมาเป็นสูตร การหาค่าฟังก์ชันคือการเอาข้อมูลเข้าไปแทน $x$ **ทุกตำแหน่ง** ข้อผิดพลาดเกือบทั้งหมดเกิดจากลืมใส่วงเล็บ ลองคิดว่า $x$ เป็นช่องว่าง เช่น $f(x) = 2x^2 - 3x + 1$ คือ $f(\ \ ) = 2(\ \ )^2 - 3(\ \ ) + 1$ ใส่อะไรเข้ามาก็ต้องใส่ลงช่องทั้งก้อน

<Example n={4}>

ให้ $f(x) = 2x^2 - 3x + 1$ หา $f(-2)$

<Steps reveal>
1. แทน $-2$ ลงในทุกช่องพร้อมวงเล็บ ได้ $2(-2)^2 - 3(-2) + 1$ วงเล็บบอกว่ายกกำลังสองทั้ง $-2$ ไม่ใช่ยกกำลังเฉพาะ $2$
2. ทำเลขยกกำลังก่อนตามลำดับการคำนวณ $(-2)^2 = 4$ จึงได้ $2(4) = 8$
3. พจน์กลาง $-3(-2)$ เป็นลบคูณลบ ได้ $+6$
4. รวมกัน $8 + 6 + 1 = 15$ จึงได้ $f(-2) = 15$
</Steps>
</Example>

{/* check: (2*x**2-3*x+1).subs(x,-2)==15 */}

<Reveal>
ไม่ถูก $-3^2$ หมายถึง $-(3^2) = -9$ เพราะยกกำลังทำก่อนเครื่องหมายลบ แต่ $g(-3)$ ต้องแทนทั้งก้อนเป็น $(-3)^2 = 9$ ค่าของ $x^2$ ไม่มีวันติดลบ ถ้าได้คำตอบติดลบก็รู้ได้ทันทีว่าลืมวงเล็บ
</Reveal>
</Think>

## แทนนิพจน์เป็นข้อมูลเข้า

ข้อมูลเข้าไม่จำเป็นต้องเป็นตัวเลข ใส่นิพจน์อย่าง $a + 1$ หรือ $2x$ ก็ได้ ถ้าค่าเหล่านั้นอยู่ในโดเมน หลักการเหมือนเดิมทุกอย่าง แทนทั้งก้อนลงในช่องพร้อมวงเล็บแล้วค่อยกระจาย ทักษะนี้จะได้ใช้อีกมากในหน้า 36.4 เรื่องฟังก์ชันประกอบ

<Example n={5}>

ถ้า $f(x) = x^2 - 1$ หา $f(a + 1)$ แล้วเทียบกับ $f(a) + 1$

<Steps reveal>
1. แทน $a + 1$ ลงในช่องของ $x$ ได้ $(a + 1)^2 - 1$ ต้องมีวงเล็บ เพราะยกกำลังสองทั้งก้อน $a + 1$
2. กระจาย $(a + 1)^2 = a^2 + 2a + 1$ ด้วยการคูณพหุนามจากบทที่ 15 แล้วลบ $1$ ได้ $a^2 + 2a$
3. ส่วน $f(a) + 1$ คือหาค่าฟังก์ชันที่ $a$ ก่อน ได้ $a^2 - 1$ แล้วจึงบวก $1$ ได้ $a^2$
4. สองนิพจน์ต่างกัน เพราะ $f(a + 1)$ บวกหนึ่งก่อนเข้าเครื่อง ส่วน $f(a) + 1$ บวกหนึ่งหลังออกจากเครื่อง ลองแทน $a = 2$ จะได้ $f(3) = 8$ แต่ $f(2) + 1 = 4$
</Steps>
</Example>

{/* check: expand((a+1)**2-1)==a**2+2*a and (x**2-1).subs(x,3)==8 and (x**2-1).subs(x,2)+1==4 */}

<Note kind="warning" title="f(a + h) ไม่เท่ากับ f(a) + f(h)">
ถ้า $f(x) = x^2$ แล้ว $f(a + h) = (a + h)^2 = a^2 + 2ah + h^2$ ไม่ใช่ $a^2 + h^2$ การแยกวงเล็บแบบนั้นใช้ไม่ได้กับฟังก์ชันส่วนใหญ่ ถ้าไม่แน่ใจให้ลองแทนตัวเลข เช่น $a = 1$ และ $h = 2$ จะได้ $f(3) = 9$ แต่ $f(1) + f(2) = 5$
</Note>

## อ่านจากตารางต้องรู้ว่าข้อมูลบอกแค่ไหน

กราฟที่วาดจากสูตรบอกค่าได้ทุกจุด แต่ตารางที่มีเพียงบางค่า เช่นอุณหภูมิทุกชั่วโมง ไม่ได้บอกว่าระหว่างชั่วโมงเกิดอะไรขึ้น ถ้าจะลากเส้นเชื่อมจุดหรือประมาณค่าตรงกลาง แปลว่าเราสมมติแบบจำลองเพิ่มขึ้นมาเอง ต้องแยกสิ่งที่อ่านจากข้อมูลตรงๆ ออกจากสิ่งที่สมมติ หน้าถัดไปจะดูว่าแบบจำลองที่ใช้บ่อยมีกี่ชนิด และเลือกชนิดให้เข้ากับสถานการณ์อย่างไร

## สรุป

- ฟังก์ชันให้ข้อมูลเข้าแต่ละตัวมีผลลัพธ์เดียว แต่หลายข้อมูลเข้าให้ผลเดียวกันได้
- ชุดคู่อันดับ ให้หาตัวหน้าซ้ำที่ตัวหลังต่างกัน กราฟ ให้ใช้เส้นตั้งตรวจ
- ข้อมูลชุดเดียวกันอาจเป็นฟังก์ชันในทิศหนึ่ง แต่ไม่เป็นในอีกทิศ
- หาค่าฟังก์ชันด้วยการแทนทั้งก้อนพร้อมวงเล็บ แล้วจึงกระจาย
- $f(a + 1)$ กับ $f(a) + 1$ ต่างกัน และ $f(a + h)$ มักไม่เท่ากับ $f(a) + f(h)$
