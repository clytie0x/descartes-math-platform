แอปแต่งรูปมีปุ่มหมุนภาพ $90^\circ$ ทวนเข็มนาฬิกา ถ้าจุดหนึ่งบนภาพอยู่ที่ $3 + 4i$ ลองคูณด้วย $i$ ได้ $i(3 + 4i) = 3i + 4i^2 = -4 + 3i$ จุดใหม่ยังห่างจากจุดกำเนิด $5$ หน่วยเท่าเดิม และถ้าวาดดูจะเห็นว่าลูกศรหมุนไปทวนเข็มนาฬิกาหนึ่งมุมฉากพอดี การคูณด้วย $i$ คือการหมุน

{/* check: expand(I*(3 + 4*I)) == -4 + 3*I and Abs(-4 + 3*I) == 5 */}

ถ้าคูณด้วยจำนวนอื่นล่ะ จะหมุนเท่าไรและยืดเท่าไร คำถามนี้ตอบง่ายมากเมื่อบอกจำนวนเชิงซ้อนด้วยระยะกับมุมแทนส่วนจริงกับส่วนจินตภาพ หน้านี้จะเปลี่ยนจำนวนเชิงซ้อนเป็นรูปนั้น แล้วใช้หาผลคูณ ผลหาร และกำลังสูงๆ ที่ถ้ากระจายตรงๆ จะยาวมาก

## ขนาดและอาร์กิวเมนต์

จุด $z = a + bi$ อยู่ห่างจากจุดกำเนิด $r = |z|$ และลูกศรจากจุดกำเนิดไปหา $z$ ทำมุม $\theta$ กับแกนจริงด้านบวก วัดทวนเข็มนาฬิกา มุมนี้เรียกว่า**อาร์กิวเมนต์**ของ $z$ จากนิยามของโคไซน์และไซน์บนวงกลมในหน้า 39.1 จะได้ $a = r\cos\theta$ และ $b = r\sin\theta$

<Thm>
$z=r(\cos\theta+i\sin\theta)$ โดย $r=|z|$ และ $r>0$ ให้ $a=r\cos\theta$ และ $b=r\sin\theta$ มุมต่างกันด้วยจำนวนเต็มเท่าของ $2\pi$ แทนจุดเดียวกัน
</Thm>

การเปลี่ยนจากรูป $a + bi$ เป็นรูปเชิงขั้วมีสามขั้น หา $r = \sqrt{a^2 + b^2}$ ก่อน แล้วดูเครื่องหมายของ $a$ กับ $b$ เพื่อรู้ว่าจุดอยู่จตุภาคไหน สุดท้ายหามุมอ้างอิงจาก $\tan\alpha = \left|\dfrac{b}{a}\right|$ แล้ววางมุมให้ตกในจตุภาคที่ถูก หน้านี้เลือก $\theta$ ในช่วง $0 \le \theta < 2\pi$ ถ้าโจทย์ถามเป็นองศาก็ใช้ช่วง $0^\circ$ ถึงน้อยกว่า $360^\circ$ จำนวนศูนย์ไม่มีอาร์กิวเมนต์ที่กำหนดเฉพาะ เพราะไม่มีลูกศรให้วัดมุม

<Example n={1}>

เขียน $1+\sqrt3i$ ในรูปเชิงขั้ว

<Steps reveal>
1. ขนาดคือ $\sqrt{1^2+(\sqrt{3})^2} = \sqrt{4} = 2$ ส่วนจริงและส่วนจินตภาพบวกทั้งคู่ จุดอยู่จตุภาคที่หนึ่ง
2. หารด้วยขนาดได้ $\cos\theta=\tfrac12$ และ $\sin\theta=\tfrac{\sqrt3}{2}$ มุมในจตุภาคที่หนึ่งที่ให้ค่านี้คือ $\theta=\pi/3$ หรือ $60^\circ$
3. ได้ $1 + \sqrt{3}i = 2\left(\cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}\right)$
</Steps>
</Example>

{/* check: expand(2*(cos(pi/3)+I*sin(pi/3)))==1+sqrt(3)*I and arg(1 + sqrt(3)*I) == pi/3 */}

<Think>

เพื่อนหาอาร์กิวเมนต์ของ $-1 - i$ จาก $\tan\theta = \dfrac{-1}{-1} = 1$ แล้วตอบ $\theta = \dfrac{\pi}{4}$ ถูกไหม

<Reveal>
ไม่ถูก มุม $\tfrac{\pi}{4}$ ชี้ไปที่จุด $1 + i$ ในจตุภาคที่หนึ่ง แต่ $-1 - i$ มีส่วนจริงและส่วนจินตภาพลบทั้งคู่ จึงอยู่จตุภาคที่สาม แทนเจนต์ของมุมในจตุภาคที่หนึ่งกับที่สามเท่ากัน ค่า $\tan\theta$ อย่างเดียวจึงแยกสองจุดนี้ไม่ออก มุมที่ถูกคือ $\pi + \tfrac{\pi}{4} = \tfrac{5\pi}{4}$ หรือ $225^\circ$ ต้องดูเครื่องหมายส่วนจริงกับส่วนจินตภาพก่อนเลือกมุมทุกครั้ง
</Reveal>
</Think>

{/* check: arg(-1 - I) + 2*pi == 5*pi/4 and expand(sqrt(2)*(cos(5*pi/4) + I*sin(5*pi/4))) == -1 - I */}

<Example n={2}>

เขียน $-2\sqrt{3} + 2i$ ในรูปเชิงขั้ว และบอกอาร์กิวเมนต์เป็นองศา

<Steps reveal>
1. ขนาด $r = \sqrt{12 + 4} = 4$
2. ส่วนจริงลบ ส่วนจินตภาพบวก จุดจึงอยู่จตุภาคที่สอง
3. มุมอ้างอิงจาก $\tan\alpha = \dfrac{2}{2\sqrt{3}} = \dfrac{1}{\sqrt{3}}$ ได้ $\alpha = \dfrac{\pi}{6}$ มุมในจตุภาคที่สองคือ $\theta = \pi - \dfrac{\pi}{6} = \dfrac{5\pi}{6}$ หรือ $150^\circ$
4. ได้ $-2\sqrt{3} + 2i = 4\left(\cos\dfrac{5\pi}{6} + i\sin\dfrac{5\pi}{6}\right)$ ตรวจ $4\cos\tfrac{5\pi}{6} = -2\sqrt{3}$ และ $4\sin\tfrac{5\pi}{6} = 2$ ถูกต้อง
</Steps>
</Example>

{/* check: Abs(-2*sqrt(3) + 2*I) == 4 and arg(-2*sqrt(3) + 2*I) == 5*pi/6 and expand(4*(cos(5*pi/6) + I*sin(5*pi/6))) == -2*sqrt(3) + 2*I */}

## คูณคือคูณขนาดแล้วบวกมุม

ให้ $z_1 = r_1(\cos\theta_1 + i\sin\theta_1)$ และ $z_2 = r_2(\cos\theta_2 + i\sin\theta_2)$ คูณกันแล้วกระจายวงเล็บ ส่วนจริงได้ $\cos\theta_1\cos\theta_2 - \sin\theta_1\sin\theta_2$ ส่วนจินตภาพได้ $\sin\theta_1\cos\theta_2 + \cos\theta_1\sin\theta_2$ ทั้งสองตัวคือสูตรผลบวกในหน้า 39.4 พอดี จึงได้

$$
z_1z_2 = r_1r_2\big(\cos(\theta_1 + \theta_2) + i\sin(\theta_1 + \theta_2)\big)
$$

ขนาดของผลคูณคือผลคูณของขนาด ซึ่งตรงกับ $|z_1z_2| = |z_1||z_2|$ ในหน้า 42.2 ส่วนมุมของผลคูณคือผลบวกของมุม การคูณด้วย $z_2$ จึงเป็นการยืดด้วย $r_2$ แล้วหมุนด้วยมุม $\theta_2$ ตัวอย่างตอนต้นหน้า $i = 1\left(\cos\tfrac{\pi}{2} + i\sin\tfrac{\pi}{2}\right)$ มีขนาด $1$ จึงไม่ยืด แต่หมุน $90^\circ$

<Example n={3}>

ให้ $z_1 = 2(\cos 30^\circ + i\sin 30^\circ)$ และ $z_2 = 3(\cos 60^\circ + i\sin 60^\circ)$ หา $z_1z_2$

<Steps reveal>
1. ขนาดคูณกัน $2 \times 3 = 6$
2. มุมบวกกัน $30^\circ + 60^\circ = 90^\circ$ ได้ $z_1z_2 = 6(\cos 90^\circ + i\sin 90^\circ)$
3. $\cos 90^\circ = 0$ และ $\sin 90^\circ = 1$ จึงได้ $z_1z_2 = 6i$
4. ตรวจด้วยรูปพิกัด $z_1 = \sqrt{3} + i$ และ $z_2 = \tfrac{3}{2} + \tfrac{3\sqrt{3}}{2}i$ กระจายแล้วส่วนจริงเป็น $\tfrac{3\sqrt{3}}{2} - \tfrac{3\sqrt{3}}{2} = 0$ และส่วนจินตภาพเป็น $\tfrac{9}{2} + \tfrac{3}{2} = 6$ ตรงกัน แต่ใช้แรงมากกว่า
</Steps>
</Example>

{/* check: expand((sqrt(3) + I)*(Rational(3, 2) + 3*sqrt(3)/2*I)) == 6*I */}

## การหารในรูปเชิงขั้ว

การคูณบวกมุมจึงทำให้การหารลบมุม เพราะต้องย้อนการหมุนของตัวส่วน ขนาดของผลหารเป็นอัตราส่วนขนาด

$$
\frac{z_1}{z_2} = \frac{r_1}{r_2}\big(\cos(\theta_1 - \theta_2) + i\sin(\theta_1 - \theta_2)\big)
$$

เมื่อมุมติดลบสามารถเติมสองพายเพื่อเขียนเป็นมุมบวกที่แทนจุดเดียวกันได้ แต่ไม่ควรเปลี่ยนมุมโดยเติมจำนวนที่ไม่ใช่จำนวนเต็มเท่าของสองพาย

<Example n={4}>

ให้ $z_1=4(\cos(2\pi/3)+i\sin(2\pi/3))$ และ $z_2=2(\cos(\pi/3)+i\sin(\pi/3))$ หา $z_1/z_2$

<Steps reveal>
1. ขนาดหารได้ $4/2=2$ และมุมลบกันได้ $\dfrac{2\pi}{3} - \dfrac{\pi}{3} = \dfrac{\pi}{3}$
2. ผลหารคือ $2(\cos(\pi/3)+i\sin(\pi/3))$
3. เปลี่ยนเป็นพิกัดได้ $1+\sqrt3i$ ตรวจขนาดยังเป็น $2$
</Steps>
</Example>

{/* check: expand(2*(cos(pi/3)+I*sin(pi/3)))==1+sqrt(3)*I and simplify(4*(cos(2*pi/3)+I*sin(2*pi/3))/(2*(cos(pi/3)+I*sin(pi/3))) - (1+sqrt(3)*I)) == 0 */}

## ทฤษฎีบทเดอมัวฟวร์

ยกกำลัง $n$ คือคูณตัวเองซ้ำ $n$ ครั้ง ขนาดจึงคูณกัน $n$ ครั้งเป็น $r^n$ และมุมบวกกัน $n$ ครั้งเป็น $n\theta$ ได้ผลที่เรียกว่าทฤษฎีบทเดอมัวฟวร์

<Thm label="ทฤษฎีบทเดอมัวฟวร์">
สำหรับจำนวนเต็มบวก $n$ ถ้า $z = r(\cos\theta + i\sin\theta)$ แล้ว $z^n=r^n(\cos n\theta+i\sin n\theta)$
</Thm>

ถ้าไม่มีทฤษฎีบทนี้ $(1 + i)^8$ ต้องกระจายด้วยทวินามแปดชั้น แต่ในรูปเชิงขั้วใช้แค่ยกกำลังขนาดหนึ่งครั้งกับคูณมุมหนึ่งครั้ง

<Example n={5}>

หา $(1+i)^4$ และ $(1 + i)^8$

<Steps reveal>
1. $1 + i$ มีขนาด $\sqrt{2}$ อยู่จตุภาคที่หนึ่ง มุม $\tfrac{\pi}{4}$ จึงเขียน $1+i=\sqrt2(\cos(\pi/4)+i\sin(\pi/4))$
2. ยกกำลังสี่ ขนาดเป็น $(\sqrt{2})^4 = 4$ มุมเป็น $4 \cdot \tfrac{\pi}{4} = \pi$ ได้ $4(\cos\pi+i\sin\pi)=-4$
3. ยกกำลังแปด ขนาดเป็น $(\sqrt{2})^8 = 16$ มุมเป็น $2\pi$ ซึ่งชี้ไปทางเดียวกับมุม $0$ ได้ $16(\cos 2\pi + i\sin 2\pi) = 16$
4. ตรวจข้อสองด้วยข้อแรก $(1 + i)^8 = \big((1 + i)^4\big)^2 = (-4)^2 = 16$ ตรงกัน
</Steps>
</Example>

{/* check: expand((1+I)**4)==-4 and expand((1 + I)**8) == 16 */}

<Example n={6}>

หา $(\sqrt{3} + i)^6$

<Steps reveal>
1. ขนาด $\sqrt{3 + 1} = 2$ จุดอยู่จตุภาคที่หนึ่ง $\cos\theta = \tfrac{\sqrt{3}}{2}$ และ $\sin\theta = \tfrac{1}{2}$ จึงได้มุม $\tfrac{\pi}{6}$
2. ใช้ทฤษฎีบทเดอมัวฟวร์ ขนาดเป็น $2^6 = 64$ มุมเป็น $6 \cdot \tfrac{\pi}{6} = \pi$
3. ได้ $64(\cos\pi + i\sin\pi) = 64(-1 + 0i) = -64$
</Steps>
</Example>

{/* check: expand((sqrt(3) + I)**6) == -64 */}

<Think>

เพื่อนตอบ $(\sqrt{3} + i)^6 = 64$ เพราะ $|\sqrt{3} + i| = 2$ และ $2^6 = 64$ ผิดตรงไหน

<Reveal>
เพื่อนหาแค่ขนาดของคำตอบ ซึ่งถูกแล้วว่าเป็น $64$ แต่ลืมว่ามุมก็ถูกคูณด้วย $6$ ด้วย มุม $\tfrac{\pi}{6}$ กลายเป็น $\pi$ ลูกศรชี้ไปทางแกนจริงด้านลบ คำตอบจึงเป็น $-64$ ตัวเลขที่ได้จาก $r^n$ เป็นแค่ความยาว ต้องคูณกับ $\cos n\theta + i\sin n\theta$ ทุกครั้ง
</Reveal>
</Think>

<Note title="ตรวจวิธีคิด">
รูปเชิงขั้วมีข้อได้เปรียบเมื่อคูณ หาร หรือยกกำลัง แต่บวกมักสะดวกกว่าในรูปพิกัด อย่าบวกขนาดและบวกมุมเมื่อโจทย์ให้บวกจำนวนเชิงซ้อน
</Note>

## สรุป

- $z = r(\cos\theta + i\sin\theta)$ โดย $r = |z|$ และมุมต้องสอดคล้องกับจตุภาคของ $(a, b)$
- ค่า $\tan\theta$ อย่างเดียวแยกจตุภาคที่หนึ่งกับสามไม่ออก ดูเครื่องหมายของ $a$ และ $b$ เสมอ
- คูณเชิงซ้อนคูณขนาดและบวกมุม หารคือหารขนาดและลบมุม
- ยกกำลังยกขนาดและคูณมุมด้วยเลขชี้กำลัง ตามทฤษฎีบทเดอมัวฟวร์

ทฤษฎีบทเดอมัวฟวร์บอกว่ายกกำลังแล้วได้อะไร หน้าถัดไปจะถามย้อนกลับ ถ้ารู้ผลของการยกกำลัง จะหาจำนวนตั้งต้นได้กี่ตัว
