ถ้าถามว่าจำนวนใดยกกำลังสามได้ $8$ เกือบทุกคนตอบ $2$ ทันที แต่ลองกระจาย $(-1 + \sqrt{3}i)^3$ ดู จะได้ $8$ เหมือนกัน สมการ $z^3 = 8$ จึงมีคำตอบมากกว่าหนึ่งตัว คำตอบที่ซ่อนอยู่ไม่ได้อยู่บนแกนจริง คนที่หาแค่ในจำนวนจริงจึงมองไม่เห็น

{/* check: expand((-1 + sqrt(3)*I)**3) == 8 */}

จำนวนหนึ่งมักมีรากหลายตัว เมื่อยกกำลัง มุมที่ต่างกันอาจหมุนมาทับกัน การหารากจึงต้องย้อนกลับให้ครบทุกทิศ ไม่หยุดที่รากจริงตัวเดียว หน้านี้จะย้อนทฤษฎีบทเดอมัวฟวร์จากหน้า 42.3 เพื่อหารากทั้งหมด แล้วดูว่ารากเหล่านั้นเรียงตัวบนระนาบเป็นรูปที่สวยงามเสมอ

## ย้อนทฤษฎีบทเดอมัวฟวร์

ต้องการแก้ $z^n = w$ เมื่อ $w = r(\cos\theta + i\sin\theta)$ ไม่เป็นศูนย์ ให้คำตอบมีรูป $z = s(\cos\varphi + i\sin\varphi)$ ทฤษฎีบทเดอมัวฟวร์ให้ $z^n = s^n(\cos n\varphi + i\sin n\varphi)$ ต้องเท่ากับ $w$ จึงเทียบได้สองเรื่อง

ขนาดต้องเท่ากัน $s^n = r$ และ $s$ เป็นจำนวนจริงบวก จึงได้ $s = r^{1/n}$ ค่าเดียว ส่วนมุมไม่จำเป็นต้องเท่ากันเป๊ะ เพราะมุมที่ต่างกันเป็นจำนวนเต็มเท่าของ $2\pi$ ชี้ไปทางเดียวกัน จึงได้ $n\varphi = \theta + 2k\pi$ เมื่อ $k$ เป็นจำนวนเต็ม หารด้วย $n$ ได้ $\varphi = \dfrac{\theta + 2k\pi}{n}$ ตรงนี้คือที่มาของรากหลายตัว รอบเต็มที่เติมเข้าไปก่อนหาร เมื่อหารด้วย $n$ แล้วกลายเป็นมุมที่ไม่ใช่รอบเต็มอีกต่อไป จึงได้จุดใหม่

<Thm>
ถ้า $w=r(\cos\theta+i\sin\theta)\ne0$ รากที่ $n$ คือ $r^{1/n}(\cos\frac{\theta+2k\pi}{n}+i\sin\frac{\theta+2k\pi}{n})$ เมื่อ $k=0,1,\ldots,n-1$
</Thm>

รากอยู่บนวงกลมรัศมี $r^{1/n}$ และห่างกันมุม $2\pi/n$ การเติมรอบเต็มก่อนหารด้วย $n$ คือเหตุผลที่ได้หลายราก ถ้าใส่ $k=n$ จะย้อนมาซ้ำตัวแรก เพราะมุมเพิ่มขึ้น $\tfrac{2n\pi}{n} = 2\pi$ พอดี จำนวนไม่เป็นศูนย์ทุกตัวจึงมีรากที่ $n$ ต่างกันพอดี $n$ ตัว

<Example n={1}>

หารากที่สองของ $-9$

<Steps reveal>
1. $-9$ อยู่บนแกนจริงด้านลบ ขนาด $9$ มุม $\pi$ เขียน $-9=9(\cos\pi+i\sin\pi)$
2. รากมีขนาด $\sqrt{9} = 3$ มุมคือ $\dfrac{\pi + 2k\pi}{2}$ เมื่อ $k = 0, 1$ ได้ $\pi/2$ และ $3\pi/2$
3. มุม $\pi/2$ ชี้ขึ้น มุม $3\pi/2$ ชี้ลง ได้ $3i$ และ $-3i$ ตรงกับที่หน้า 42.1 เขียน $\sqrt{-9} = 3i$ ซึ่งเป็นแค่หนึ่งในสองราก
</Steps>
</Example>

{/* check: (3*I)**2==(-3*I)**2==-9 */}

<Example n={2}>

หารากที่สามของ $8$

<Steps reveal>
1. $8 = 8(\cos 0 + i\sin 0)$ ขนาดของรากเป็น $\sqrt[3]{8} = 2$
2. มุมคือ $\dfrac{0 + 2k\pi}{3}$ เมื่อ $k = 0, 1, 2$ ได้ $0, 2\pi/3, 4\pi/3$
3. แปลงกลับ $2(\cos\tfrac{2\pi}{3} + i\sin\tfrac{2\pi}{3}) = 2\left(-\tfrac{1}{2} + \tfrac{\sqrt{3}}{2}i\right) = -1 + \sqrt{3}i$ และมุม $\tfrac{4\pi}{3}$ ให้สังยุคของมัน
4. ได้ $2,-1+\sqrt3i,-1-\sqrt3i$ ทุกรากยกกำลังสามได้ $8$ รวมถึงตัวที่ตอนต้นหน้าบอกว่าซ่อนอยู่
</Steps>
</Example>

{/* check: all(expand(z**3)==8 for z in [2,-1+sqrt(3)*I,-1-sqrt(3)*I]) */}

<Example n={3}>

หารากที่สามทั้งหมดของ $8i$

<Steps reveal>
1. $8i$ อยู่บนแกนจินตภาพด้านบวก ขนาด $8$ มุม $\tfrac{\pi}{2}$ เขียน $8i = 8\left(\cos\tfrac{\pi}{2} + i\sin\tfrac{\pi}{2}\right)$
2. ขนาดของรากเป็น $\sqrt[3]{8} = 2$ มุมคือ $\dfrac{\pi/2 + 2k\pi}{3}$ เมื่อ $k = 0, 1, 2$
3. $k = 0$ ได้ $\tfrac{\pi}{6}$ จากนั้นเพิ่มทีละ $\tfrac{2\pi}{3}$ ได้ $\tfrac{5\pi}{6}$ และ $\tfrac{3\pi}{2}$
4. แปลงกลับ $2\left(\tfrac{\sqrt{3}}{2} + \tfrac{1}{2}i\right) = \sqrt{3} + i$ และ $2\left(-\tfrac{\sqrt{3}}{2} + \tfrac{1}{2}i\right) = -\sqrt{3} + i$ และ $2(0 - i) = -2i$
5. ตรวจตัวสุดท้าย $(-2i)^3 = -8i^3 = -8(-i) = 8i$ ถูกต้อง
</Steps>
</Example>

{/* check: all(expand(z**3) == 8*I for z in [sqrt(3) + I, -sqrt(3) + I, -2*I]) */}

<Think>

เพื่อนบอกว่ารากที่สามของ $8i$ ตัวหนึ่งคือ $2i$ เพราะ $\sqrt[3]{8} = 2$ แล้วติด $i$ ไว้เหมือนเดิม ถูกไหม

<Reveal>
ไม่ถูก ยกกำลังสามตรวจดู $(2i)^3 = 8i^3 = -8i$ ไม่ใช่ $8i$ การดึง $i$ ออกมาแบบนี้ใช้ไม่ได้ เพราะ $i^3 \ne i$ มุมของ $2i$ คือ $\tfrac{\pi}{2}$ พอคูณสามได้ $\tfrac{3\pi}{2}$ ชี้ลง ต้องหารมุมของ $8i$ ด้วยสาม ไม่ใช่คงมุมไว้ จึงได้รากแรกที่มุม $\tfrac{\pi}{6}$ ตามตัวอย่าง 3
</Reveal>
</Think>

{/* check: expand((2*I)**3) == -8*I */}

<Example n={4}>

หารากที่สี่ทั้งหมดของ $-16$

<Steps reveal>
1. $-16 = 16(\cos\pi + i\sin\pi)$ ขนาดของรากเป็น $\sqrt[4]{16} = 2$
2. มุมคือ $\dfrac{\pi + 2k\pi}{4}$ เมื่อ $k = 0, 1, 2, 3$ ได้ $\tfrac{\pi}{4}, \tfrac{3\pi}{4}, \tfrac{5\pi}{4}, \tfrac{7\pi}{4}$ ห่างกันทีละ $\tfrac{\pi}{2}$
3. ทุกมุมมี $|\cos|$ และ $|\sin|$ เท่ากับ $\tfrac{\sqrt{2}}{2}$ คูณด้วย $2$ ได้ $\sqrt{2}$ เครื่องหมายเปลี่ยนตามจตุภาค
4. รากทั้งสี่คือ $\sqrt{2} + \sqrt{2}i$ และ $-\sqrt{2} + \sqrt{2}i$ และ $-\sqrt{2} - \sqrt{2}i$ และ $\sqrt{2} - \sqrt{2}i$ ไม่มีรากจริงเลย สอดคล้องกับที่ไม่มีจำนวนจริงใดยกกำลังสี่แล้วติดลบ
</Steps>
</Example>

{/* check: all(expand(z**4) == -16 for z in [sqrt(2) + sqrt(2)*I, -sqrt(2) + sqrt(2)*I, -sqrt(2) - sqrt(2)*I, sqrt(2) - sqrt(2)*I]) */}

## รากเรียงเป็นรูปหลายเหลี่ยมด้านเท่า

รากทุกตัวมีขนาดเท่ากัน จึงอยู่บนวงกลมเดียวกัน และมุมห่างกันทีละ $\tfrac{2\pi}{n}$ เท่ากันหมด จุดทั้ง $n$ จุดจึงแบ่งวงกลมเป็น $n$ ส่วนเท่ากัน ลากเส้นเชื่อมแล้วได้รูป $n$ เหลี่ยมด้านเท่ามุมเท่าเสมอ รากที่สามเป็นสามเหลี่ยมด้านเท่า รากที่สี่เป็นสี่เหลี่ยมจัตุรัส ตัวอย่าง 4 เป็นสี่เหลี่ยมจัตุรัสที่มุมอยู่บนเส้นทแยง $y = x$ และ $y = -x$

<Board name="c42-nth-roots" label="รากที่ n ของจำนวนเชิงซ้อน w เรียงบนวงกลมเป็นรูปหลายเหลี่ยมด้านเท่า ปรับ n ขนาดและมุมของ w ได้">
เริ่มที่ $w = 8i$ และ $n = 3$ ตรงกับตัวอย่าง 3 ลองเพิ่ม $n$ แล้วดูว่ารัศมีกับระยะห่างของมุมเปลี่ยนอย่างไร แล้วลองหมุนมุมของ $w$ รูปหลายเหลี่ยมหมุนตามช้ากว่า $w$ กี่เท่า
</Board>

ข้อสังเกตจากกราฟ เมื่อ $n$ มากขึ้นรัศมี $r^{1/n}$ เข้าใกล้ $1$ เสมอ ไม่ว่า $|w|$ เป็นเท่าไร และเมื่อมุมของ $w$ เพิ่มขึ้น $\Delta$ รากแรกหมุนเพิ่มแค่ $\tfrac{\Delta}{n}$ เพราะมุมถูกหารด้วย $n$

<Think>

ใช้สูตรรากด้วย $k=0,1,2,3$ เมื่อ $n=3$ จะได้สี่คำตอบหรือไม่

<Reveal>
ได้เพียงสามคำตอบที่ต่างกัน เพราะตัวที่ $k=3$ มีมุมมากกว่าตัวแรกหนึ่งรอบพอดีและเป็นจุดเดียวกัน ในกราฟข้างบนจะเห็นว่าสามเหลี่ยมมีแค่สามมุม ใส่ $k$ เพิ่มก็วนทับมุมเดิม
</Reveal>
</Think>

## รากของหนึ่ง

รากของหนึ่งแสดงโครงสร้างที่เห็นง่าย ทุกจุดอยู่บนวงกลมหนึ่งหน่วยและเว้นมุมเท่ากัน หนึ่งในนั้นคือ $1$ เองเสมอ จุดที่อยู่ตรงข้ามอาจจับคู่หักล้างกัน เมื่อทราบรากหนึ่งแล้ว การหมุนเพิ่มสองพายหารด้วย n จะพาไปหารากถัดไป การตรวจว่าครบทุกตัวต้องนับจุดต่างกันให้ครบ n ไม่ใช่นับจำนวนครั้งที่เขียนสูตร

<Example n={5}>

หารากที่สี่ทั้งหมดของ $1$

<Steps reveal>
1. $1 = 1(\cos 0 + i\sin 0)$ ขนาดเป็น $1$ มุมคือ $\tfrac{2k\pi}{4}$ ได้ $0,\pi/2,\pi,3\pi/2$
2. รากคือ $1,i,-1,-i$ ทุกตัวมีกำลังสี่เท่ากับหนึ่ง ตรงกับที่กำลังของ $i$ วนทุกสี่ขั้นในหน้า 42.1
3. ผลรวมรากเท่ากับศูนย์เพราะจับคู่ $1$ กับ $-1$ และ $i$ กับ $-i$ ที่อยู่ตรงข้ามกันบนวงกลม
</Steps>
</Example>

{/* check: all(z**4==1 for z in [1,I,-1,-I]) and 1+I-1-I==0 */}

<Note title="ตรวจวิธีคิด">
เครื่องหมายรากที่สองหลักกับคำว่าหารากทั้งหมดไม่เหมือนกัน เช่นรากที่สองหลักของเก้าคือสาม แต่สมการยกกำลังสองเท่ากับเก้ามีคำตอบทั้งสามกับลบสาม ให้ดูว่าคำถามต้องการค่าหลักหรือชุดราก
</Note>

## สรุป

- แก้ $z^n = w$ โดยเทียบขนาด $s^n = r$ และมุม $n\varphi = \theta + 2k\pi$
- จำนวนไม่เป็นศูนย์มีรากที่ n ต่างกัน n ตัว ใช้ $k = 0, 1, \ldots, n - 1$
- เติมมุมรอบเต็มก่อนหาร ห้ามคงมุมเดิมไว้แล้วถอดรากแค่ขนาด
- รากทั้งหมดอยู่บนวงกลมรัศมี $r^{1/n}$ ห่างกันทีละ $\tfrac{2\pi}{n}$ เป็นรูป $n$ เหลี่ยมด้านเท่า
- ตรวจด้วยการยกกำลังกลับและตรวจว่าไม่ซ้ำ

สมการ $z^n = w$ เป็นพหุนามแบบที่ง่ายที่สุด หน้าถัดไปจะดูพหุนามทั่วไปที่มีสัมประสิทธิ์จริง แล้วจะเห็นว่ารากที่ไม่จริงมาเป็นคู่เสมอ
