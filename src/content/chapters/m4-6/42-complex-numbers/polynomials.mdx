วาดกราฟ $y = x^3 - x^2 + 4x - 4$ จะเห็นว่ากราฟตัดแกน $x$ แค่จุดเดียวที่ $x = 1$ แล้วพุ่งขึ้นไปเลย ไม่วกกลับมาตัดอีก แต่พหุนามดีกรีสามควรมีรากได้ถึงสามตัว อีกสองตัวหายไปไหน

{/* check: roots(x**3 - x**2 + 4*x - 4) == [1] */}

คำตอบคือรากอีกสองตัวไม่ใช่จำนวนจริง กราฟบนระนาบ $xy$ แสดงได้เฉพาะรากจริง พหุนามสัมประสิทธิ์จริงอาจไม่มีจุดตัดแกนจริงครบตามดีกรี แต่เมื่อยอมรับจำนวนเชิงซ้อน เราจะแยกตัวประกอบต่อได้จนครบ หน้านี้จะหารากที่หายไปด้วยเครื่องมือเดิมจากบทที่ 34 คือสูตรสมการกำลังสองและทฤษฎีบทตัวประกอบ แล้วใช้ข้อเท็จจริงสำคัญข้อหนึ่ง คือรากที่ไม่จริงของพหุนามสัมประสิทธิ์จริงมาเป็นคู่เสมอ

## สูตรกำลังสองยังใช้ได้

สูตร $x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$ ได้มาจากการทำกำลังสองสมบูรณ์ ซึ่งไม่ได้ใช้ข้อใดที่ต้องเป็นจำนวนจริงเลย เมื่อ $b^2-4ac$ ลบ ให้เขียนรากของจำนวนลบเป็น $i$ คูณรากบวก แล้วคำนวณตามเดิม ตามที่ทำในหน้า 42.1 ผลที่ได้คือรากสองตัวที่เป็นสังยุคกัน เพราะเครื่องหมาย $\pm$ อยู่หน้าส่วนจินตภาพพอดี

<Example n={1}>

แก้ $x^2-2x+5=0$ ในจำนวนเชิงซ้อน

<Steps reveal>
1. ทำกำลังสองสมบูรณ์ ครึ่งหนึ่งของ $-2$ คือ $-1$ จึงเขียน $x^2 - 2x + 1 = -4$ ได้ $(x-1)^2=-4$
2. ข้างขวาติดลบ ไม่มีคำตอบจริง แต่ในจำนวนเชิงซ้อน $x - 1 = \pm\sqrt{-4} = \pm 2i$
3. จึงได้ $x=1\pm2i$ ทั้งสองค่า ตรวจผลบวกของราก $2$ และผลคูณ $1 + 4 = 5$ ตรงกับ $-\tfrac{b}{a}$ และ $\tfrac{c}{a}$
</Steps>
</Example>

{/* check: expand((x-(1+2*I))*(x-(1-2*I)))==x**2-2*x+5 */}

<Example n={2}>

วงจรจำลองมีสมการ $s^2+4s+13=0$ หารากทั้งคู่

<Steps reveal>
1. ดิสคริมิแนนต์คือ $b^2 - 4ac = 16-52=-36$ ติดลบ จึงรู้ก่อนว่าได้รากเชิงซ้อนคู่สังยุค
2. $\sqrt{-36} = 6i$ สูตรกำลังสองให้ $s=\dfrac{-4\pm6i}{2}=-2\pm3i$
3. ตรวจ $(-2 + 3i)^2 + 4(-2 + 3i) + 13 = (-5 - 12i) + (-8 + 12i) + 13 = 0$ ถูกต้อง
</Steps>
</Example>

{/* check: expand((x-(-2+3*I))*(x-(-2-3*I)))==x**2+4*x+13 and expand((-2 + 3*I)**2) == -5 - 12*I */}

## รากเชิงซ้อนของสัมประสิทธิ์จริง

<Thm>
ถ้าพหุนามมีสัมประสิทธิ์จริงและ $a+bi$ เป็นรากแล้ว $a-bi$ เป็นรากด้วย พหุนามดีกรี $n$ มีรากเชิงซ้อนรวมพหุคูณ $n$ ราก
</Thm>

ข้อแรกมีเหตุผลสั้นๆ สังยุคของผลบวกเท่ากับผลบวกของสังยุค และสังยุคของผลคูณเท่ากับผลคูณของสังยุค ส่วนจำนวนจริงเป็นสังยุคของตัวเอง ถ้า $P(z) = 0$ แล้วใส่สังยุคทั้งสองข้าง ทุกพจน์ $a_k z^k$ กลายเป็น $a_k \bar z^{\,k}$ โดยสัมประสิทธิ์ $a_k$ ไม่เปลี่ยนเพราะเป็นจำนวนจริง จึงได้ $P(\bar z) = \bar 0 = 0$ ข้อที่สองเรียกว่าทฤษฎีบทหลักมูลของพีชคณิต ระดับนี้ใช้ผลได้เลยโดยไม่ต้องพิสูจน์

คู่สังยุคคูณกลับให้ตัวประกอบกำลังสองสัมประสิทธิ์จริง

$$
(x-(a+bi))(x-(a-bi))=(x-a)^2+b^2 = x^2 - 2ax + (a^2 + b^2)
$$

สัมประสิทธิ์ของ $x$ คือลบสองเท่าของส่วนจริง และพจน์คงตัวคือ $|a + bi|^2$ ใช้สร้างตัวประกอบจากรากได้เร็ว สมบัตินี้ต้องมีเงื่อนไขสัมประสิทธิ์จริง ไม่ได้ใช้กับพหุนามเชิงซ้อนทั่วไป

{/* check: expand((x - (a + b*I))*(x - (a - b*I))) == expand(x**2 - 2*a*x + a**2 + b**2) */}

<Think>

รู้ว่ารากหนึ่งเป็น $2+i$ จะสรุปว่าอีกตัวเป็น $2-i$ ได้ทุกสมการหรือไม่

<Reveal>
ต้องรู้ก่อนว่าสัมประสิทธิ์พหุนามเป็นจำนวนจริง เช่นสมการ $x - (2 + i) = 0$ มีสัมประสิทธิ์เชิงซ้อนและมีรากเพียง $2+i$ ตัวเดียว เหตุผลข้างบนใช้ว่า $\bar a_k = a_k$ ซึ่งไม่จริงเมื่อ $a_k$ มี $i$
</Reveal>
</Think>

## ใช้ทฤษฎีบทตัวประกอบหารากทั้งหมด

เมื่อพหุนามมีดีกรีมากกว่าสอง ให้หารากจริงสักตัวก่อนด้วยทฤษฎีบทตัวประกอบในหน้า 34.5 ลองแทนตัวหารของพจน์คงตัว ถ้า $P(c) = 0$ แล้ว $x - c$ เป็นตัวประกอบ หารออกด้วยการหารสังเคราะห์ ได้พหุนามดีกรีต่ำลงหนึ่ง ทำซ้ำจนเหลือกำลังสองแล้วใช้สูตรกำลังสอง

<Example n={3}>

หารากทั้งหมดของ $x^3 - x^2 + 4x - 4 = 0$ ซึ่งเป็นกราฟตอนต้นหน้า

<Steps reveal>
1. ลองแทนตัวหารของ $-4$ เริ่มที่ $x = 1$ ได้ $P(1) = 1 - 1 + 4 - 4 = 0$ จึงมี $x - 1$ เป็นตัวประกอบ
2. หารสังเคราะห์ด้วย $1$ สัมประสิทธิ์ $1, -1, 4, -4$ ได้ผลหาร $x^2 + 0x + 4$ เศษ $0$ จึงได้ $P(x) = (x - 1)(x^2 + 4)$
3. จับกลุ่มก็ได้ผลเดียวกัน $x^2(x - 1) + 4(x - 1) = (x - 1)(x^2 + 4)$
4. $x^2 + 4 = 0$ ให้ $x^2 = -4$ จึงได้ $x = \pm 2i$
5. รากทั้งหมดคือ $1, 2i, -2i$ มีครบสามตัวตามดีกรี รากจริงตัวเดียวคือจุดที่กราฟตัดแกน ส่วนอีกสองตัวเป็นคู่สังยุคที่กราฟไม่แสดง
</Steps>
</Example>

{/* check: expand((x - 1)*(x**2 + 4)) == x**3 - x**2 + 4*x - 4 and expand((x - 1)*(x - 2*I)*(x + 2*I)) == x**3 - x**2 + 4*x - 4 */}

<Example n={4}>

กำหนดว่า $2 - i$ เป็นรากของ $x^3 - 3x^2 + x + 5 = 0$ หารากที่เหลือ

<Steps reveal>
1. สัมประสิทธิ์ทุกตัวเป็นจำนวนจริง สังยุค $2 + i$ จึงเป็นรากด้วย
2. คู่สังยุครวมเป็นตัวประกอบจริง ส่วนจริงเป็น $2$ และขนาดกำลังสองเป็น $4 + 1 = 5$ ได้ $x^2 - 4x + 5$
3. หารพหุนามเดิมด้วย $x^2 - 4x + 5$ ได้ผลหาร $x + 1$ เศษ $0$ ตรวจโดยคูณกลับ $(x^2 - 4x + 5)(x + 1) = x^3 - 3x^2 + x + 5$
4. รากที่เหลือคือ $x = -1$ ตรวจ $P(-1) = -1 - 3 - 1 + 5 = 0$ รากทั้งหมดจึงเป็น $2 - i, 2 + i, -1$
</Steps>
</Example>

{/* check: expand((x**2 - 4*x + 5)*(x + 1)) == x**3 - 3*x**2 + x + 5 and expand((2 - I)**3 - 3*(2 - I)**2 + (2 - I) + 5) == 0 */}

<Think>

พหุนามดีกรีสามที่มีสัมประสิทธิ์จริง อาจมีรากที่ไม่จริงทั้งสามตัวได้ไหม

<Reveal>
ไม่ได้ รากที่ไม่จริงต้องมาเป็นคู่สังยุค จำนวนรากที่ไม่จริงจึงเป็นจำนวนคู่เสมอ ดีกรีสามมีรากสามตัว ถ้าเป็นคู่ไปสองตัว ตัวที่สามต้องเป็นจำนวนจริง พหุนามดีกรีคี่ที่มีสัมประสิทธิ์จริงจึงมีรากจริงอย่างน้อยหนึ่งตัวเสมอ ตรงกับกราฟที่ปลายข้างหนึ่งลงไปลบและอีกข้างขึ้นไปบวก จึงต้องตัดแกน $x$
</Reveal>
</Think>

## สร้างพหุนามจากราก

เมื่อรู้รากจะสร้างตัวประกอบเชิงเส้นได้โดยใช้ x ลบราก ถ้าต้องการสัมประสิทธิ์จริงให้รวมคู่สังยุคก่อนเพื่อลดการคำนวณ พหุนามที่มีรากชุดเดียวกันอาจคูณด้วยค่าคงที่ไม่เป็นศูนย์ได้ ถ้าโจทย์กำหนดให้สัมประสิทธิ์นำเป็นหนึ่งจึงเลือกได้แน่นอน

ตัวอย่างสั้นๆ พหุนามกำลังสองสัมประสิทธิ์จริงที่มีราก $3 - 2i$ ต้องมีราก $3 + 2i$ ด้วย ใช้สูตรคู่สังยุค ส่วนจริง $3$ ให้ $-6x$ และ $3^2 + 2^2 = 13$ ได้ $x^2 - 6x + 13$

{/* check: expand((x - (3 - 2*I))*(x - (3 + 2*I))) == x**2 - 6*x + 13 */}

<Example n={5}>

สร้างพหุนามดีกรีสามสัมประสิทธิ์นำหนึ่ง มีราก $2$ และ $1+i$ โดยสัมประสิทธิ์เป็นจริง

<Steps reveal>
1. สัมประสิทธิ์ต้องเป็นจริง จึงต้องมีราก $1-i$ ด้วย ได้ครบสามรากพอดีกับดีกรีสาม พหุนามคือ $(x-2)(x-(1+i))(x-(1-i))$
2. คู่สังยุคคูณเป็น $(x-1)^2+1=x^2-2x+2$
3. คูณกับ $x-2$ ได้ $x^3 - 2x^2 + 2x - 2x^2 + 4x - 4 = x^3-4x^2+6x-4$
4. ตรวจ $P(2) = 8 - 16 + 12 - 4 = 0$ ถูกต้อง ถ้าลืมใส่ $1 - i$ จะได้ตัวประกอบ $(x - 2)(x - 1 - i)$ ซึ่งมี $i$ อยู่ในสัมประสิทธิ์ ผิดเงื่อนไขของโจทย์
</Steps>
</Example>

{/* check: expand((x-2)*(x-(1+I))*(x-(1-I)))==x**3-4*x**2+6*x-4 */}

<Note title="ตรวจวิธีคิด">
การมีรากเดียวกันไม่บอกพหุคูณเสมอ ถ้ารากซ้ำต้องมีตัวประกอบซ้ำตามจำนวน การนับดีกรีหลังคูณกลับช่วยตรวจว่ารากที่ใส่ครบตามเงื่อนไขหรือไม่
</Note>

## สรุป

- ใช้สูตรกำลังสองต่อได้เมื่อดิสคริมิแนนต์ลบ ได้รากคู่สังยุค
- รากที่ไม่จริงของพหุนามสัมประสิทธิ์จริงจับคู่สังยุค และคู่นั้นรวมเป็น $x^2 - 2ax + (a^2 + b^2)$
- ดีกรีสูงกว่าสอง หารากจริงด้วยทฤษฎีบทตัวประกอบ หารออก แล้วแก้ส่วนที่เหลือ
- พหุนามดีกรีคี่สัมประสิทธิ์จริงมีรากจริงอย่างน้อยหนึ่งตัว
- นับรากรวมพหุคูณและตรวจแทนกลับ

ถึงตรงนี้ใช้จำนวนเชิงซ้อนได้ครบทั้งคำนวณ วาดบนระนาบ หมุนด้วยรูปเชิงขั้ว และหารากของพหุนาม ลองทำแบบฝึกหัดท้ายบทเพื่อตรวจว่าแต่ละเรื่องคล่องแล้ว
