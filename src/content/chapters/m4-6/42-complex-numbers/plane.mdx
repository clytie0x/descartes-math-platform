ในเกมบนมือถือเกมหนึ่ง ตัวละครยืนอยู่ที่ช่อง $(1, 2)$ ของแผนที่ ผู้เล่นสั่งให้เดินไปทางขวา $3$ ช่องและลงล่าง $1$ ช่อง ตัวละครจึงไปอยู่ที่ $(4, 1)$ ถ้าเขียนตำแหน่งเริ่มเป็น $1 + 2i$ และการเดินเป็น $3 - i$ ผลบวก $(1 + 2i) + (3 - i) = 4 + i$ ก็คือตำแหน่งใหม่พอดี

{/* check: (1 + 2*I) + (3 - I) == 4 + I */}

ความบังเอิญนี้ไม่ใช่เรื่องบังเอิญ จำนวนเชิงซ้อนหนึ่งตัวมีจำนวนจริงสองตัว จึงวางเป็นจุดบนระนาบได้ตรงๆ หน้านี้จะดูว่าการบวก การลบ และค่าสัมบูรณ์มีความหมายอะไรบนระนาบ แล้วใช้ภาพนั้นแปลสมการเชิงซ้อนให้เป็นวงกลมและเส้นตรง

## จุดบนระนาบเชิงซ้อน

ให้แกนนอนแทนส่วนจริงและแกนตั้งแทนส่วนจินตภาพ จำนวน $a + bi$ จะเป็นจุด $(a, b)$ ระนาบที่ใช้แบบนี้เรียกว่า**ระนาบเชิงซ้อน** แกนนอนเรียกว่าแกนจริง แกนตั้งเรียกว่าแกนจินตภาพ เช่น $3 + 2i$ อยู่ที่ $(3, 2)$ จำนวนจริง $4$ อยู่ที่ $(4, 0)$ บนแกนจริง และ $-2i$ อยู่ที่ $(0, -2)$ บนแกนจินตภาพ

ภาพนี้ทำให้เห็นว่าทำไมสองจำนวนเท่ากันเมื่อส่วนจริงและส่วนจินตภาพเท่ากันแยกกัน จุดสองจุดทับกันได้ก็ต่อเมื่อพิกัดทั้งสองตัวตรงกัน และยังบอกว่าทำไมไม่มีการเรียงว่าจำนวนเชิงซ้อนตัวไหนมากกว่า จุดบนระนาบไม่ได้เรียงเป็นแถวเดียวแบบเส้นจำนวน ประโยคอย่าง $2 + i > 1 + 3i$ จึงไม่มีความหมาย

สังยุค $\bar z = a - bi$ อยู่ที่ $(a, -b)$ คือภาพสะท้อนของ $z$ ข้ามแกนจริง ลองเลื่อนค่าในกราฟข้างล่าง

<Board name="c42-complex-plane" label="จุดเชิงซ้อนและสังยุคบนระนาบ" caption="แกนนอนแทนส่วนจริง แกนตั้งแทนส่วนจินตภาพ" />

ปรับให้ส่วนจินตภาพเป็นศูนย์ จุดกับสังยุคจะทับกันบนแกนจริง เพราะจำนวนจริงเป็นสังยุคของตัวเอง จากนั้นเปลี่ยนเครื่องหมายส่วนจินตภาพแล้วดูว่าขนาดยังคงเดิม

การลบก็อ่านได้แบบเดียวกัน $z_1 - z_2$ คือลูกศรที่ชี้จากจุด $z_2$ ไปหาจุด $z_1$ เพราะ $z_2 + (z_1 - z_2) = z_1$ ข้อนี้คือกุญแจของการหาระยะในหัวข้อถัดไป

<Example n={1}>

ตัวละครในเกมตอนต้นหน้าอยู่ที่ $4 + i$ ต้องเดินด้วยจำนวนเชิงซ้อนใดจึงจะไปถึงจุดเก็บของที่ $-2 + 5i$

<Steps reveal>
1. การเดินคือลูกศรจากตำแหน่งปัจจุบันไปหาเป้าหมาย จึงเป็นผลต่าง เป้าหมายลบตำแหน่งปัจจุบัน
2. $(-2 + 5i) - (4 + i) = -6 + 4i$ คือเดินไปทางซ้าย $6$ ช่องและขึ้น $4$ ช่อง
3. ตรวจ $(4 + i) + (-6 + 4i) = -2 + 5i$ ถึงเป้าหมายจริง ถ้าลบสลับข้างจะได้ $6 - 4i$ ซึ่งพาเดินออกไปทางตรงข้าม
</Steps>
</Example>

{/* check: (-2 + 5*I) - (4 + I) == -6 + 4*I and (4 + I) + (-6 + 4*I) == -2 + 5*I */}

## ขนาดคือระยะจากจุดกำเนิด

<Thm>
ถ้า $z=a+bi$ แล้ว $|z|=\sqrt{a^2+b^2}$ และระยะระหว่าง $z_1,z_2$ คือ $|z_1-z_2|$ สังยุคสะท้อนจุดข้ามแกนจริง
</Thm>

สูตรนี้มาจากทฤษฎีบทพีทาโกรัส ลากเส้นจากจุดกำเนิดไปจุด $(a, b)$ จะได้ด้านตรงข้ามมุมฉากของสามเหลี่ยมที่มีด้านประกอบมุมฉากยาว $|a|$ และ $|b|$ ค่าสัมบูรณ์ของจำนวนจริงในหน้า 34.4 คือระยะบนเส้นจำนวน ค่าสัมบูรณ์ของจำนวนเชิงซ้อนก็คือระยะเหมือนกัน แต่เป็นระยะบนระนาบ ส่วนระยะระหว่างสองจุดใช้ขนาดของลูกศร $z_1 - z_2$ ซึ่งให้สูตรเดียวกับระยะระหว่างจุดในหน้า 38.1

ระยะเป็นจำนวนจริงไม่ติดลบเสมอ สมการ $|z-z_0|=r$ เมื่อ $r>0$ จึงแทนวงกลมที่มีจุดศูนย์กลาง $z_0$ และรัศมี $r$ อย่าคิดว่าค่าสัมบูรณ์เชิงซ้อนเพียงเปลี่ยนเครื่องหมายลบเป็นบวก เช่น $|-3 + 4i|$ ไม่ใช่ $3 + 4i$

<Example n={2}>

หา $|-3+4i|$ และตำแหน่งสังยุค

<Steps reveal>
1. ส่วนจริง $-3$ และส่วนจินตภาพ $4$ ยกกำลังสองแล้วเป็นบวกทั้งคู่ เครื่องหมายลบจึงไม่มีผลต่อระยะ
2. ระยะคือ $\sqrt{(-3)^2+4^2}=\sqrt{25}=5$
3. สังยุคคือ $-3-4i$ จุดสะท้อนอยู่ที่ $(-3,-4)$ ซึ่งห่างจากจุดกำเนิด $5$ หน่วยเท่ากัน
</Steps>
</Example>

{/* check: Abs(-3+4*I)==5 and Abs(-3-4*I)==5 */}

<Example n={3}>

หาระยะจาก $1+2i$ ถึง $4+6i$

<Steps reveal>
1. ระยะระหว่างจุดคือขนาดของผลต่าง ลบกันได้ $(4+6i)-(1+2i)=3+4i$
2. ขนาดของผลต่างคือ $\sqrt{3^2 + 4^2} = 5$ จึงห่างกัน $5$ หน่วย
3. ลบสลับลำดับได้ $-3 - 4i$ ซึ่งมีขนาด $5$ เท่ากัน ระยะจึงไม่ขึ้นกับว่าลบตัวไหนก่อน
</Steps>
</Example>

{/* check: Abs((4+6*I)-(1+2*I))==5 and Abs((1+2*I)-(4+6*I))==5 */}

ค่าสัมบูรณ์เข้ากับการคูณได้ดี มีสมบัติที่ใช้บ่อยสี่ข้อ คือ $|\bar z| = |z|$ และ $z\bar z = |z|^2$ และ $|z_1 z_2| = |z_1|\,|z_2|$ และ $\left|\dfrac{z_1}{z_2}\right| = \dfrac{|z_1|}{|z_2|}$ เมื่อ $z_2 \ne 0$ ข้อที่สองตามมาจาก $z\bar z = a^2 + b^2$ ในหน้า 42.1 ส่วนข้อสามตรวจได้โดยกระจาย แล้วจะเห็นเหตุผลชัดขึ้นในหน้า 42.3 สมบัติเหล่านี้ไม่มีคู่สำหรับการบวก $|z_1 + z_2|$ ไม่จำเป็นต้องเท่ากับ $|z_1| + |z_2|$

<Example n={4}>

หา $|(3 + 4i)(1 - i)|$ และ $\left|\dfrac{3 + 4i}{1 - i}\right|$ โดยไม่ต้องคูณหรือหารก่อน

<Steps reveal>
1. หาขนาดของแต่ละตัว $|3 + 4i| = 5$ และ $|1 - i| = \sqrt{1 + 1} = \sqrt{2}$
2. ขนาดของผลคูณคือผลคูณของขนาด ได้ $5\sqrt{2}$
3. ขนาดของผลหารคือผลหารของขนาด ได้ $\dfrac{5}{\sqrt{2}} = \dfrac{5\sqrt{2}}{2}$
4. ตรวจข้อแรกโดยกระจาย $(3 + 4i)(1 - i) = 3 - 3i + 4i - 4i^2 = 7 + i$ ขนาดคือ $\sqrt{49 + 1} = \sqrt{50} = 5\sqrt{2}$ ตรงกัน
</Steps>
</Example>

{/* check: Abs((3 + 4*I)*(1 - I)) == 5*sqrt(2) and expand((3 + 4*I)*(1 - I)) == 7 + I and simplify(Abs((3 + 4*I)/(1 - I)) - 5*sqrt(2)/2) == 0 */}

<Think>

ทุกจำนวนที่ค่าสัมบูรณ์เท่ากับ $5$ ต้องเท่ากันหรือไม่

<Reveal>
ไม่เท่ากัน จุดเหล่านี้อยู่บนวงกลมรัศมี $5$ รอบจุดกำเนิดวงเดียวกัน แต่มีทิศต่างกัน เช่น $5$ กับ $5i$ และ $3 + 4i$ มีขนาดเท่ากันแต่เป็นคนละจำนวน ค่าสัมบูรณ์บอกแค่ระยะ ไม่บอกทิศ
</Reveal>
</Think>

## วงกลมจากสมการค่าสัมบูรณ์

สมการระยะช่วยแปลจำนวนเชิงซ้อนกลับเป็นเรขาคณิตได้ เมื่อเขียน $z=a+bi$ สมการค่าสัมบูรณ์ของผลต่างจะกลายเป็นผลรวมกำลังสองของความต่างพิกัด ระวังว่าสิ่งที่อยู่ในค่าสัมบูรณ์เป็นผลต่างทั้งจำนวน ไม่ใช่ลบเฉพาะส่วนจริงหรือเฉพาะส่วนจินตภาพ

วิธีอ่านที่เร็วที่สุดคือทำให้ข้างในอยู่ในรูป $z - z_0$ ก่อน แล้วอ่านออกเสียงว่า ระยะจาก $z$ ถึง $z_0$ เท่ากับ $r$ ได้วงกลมที่มีศูนย์กลางที่ $z_0$ ตามนิยามวงกลมในหน้า 38.4

<Example n={5}>

อธิบายเซตของจุดที่ $|z-(2-i)|=3$ และตรวจจุด $5-i$

<Steps reveal>
1. ข้างในอยู่ในรูป $z - z_0$ แล้ว โดย $z_0 = 2 - i$ สมการจึงบอกว่าระยะจาก $z$ ถึงจุด $(2, -1)$ เท่ากับ $3$
2. ยืนยันด้วยพีชคณิต ให้ $z=a+bi$ ผลต่างคือ $(a - 2) + (b + 1)i$ ยกกำลังสองทั้งสองข้างได้ $(a-2)^2+(b+1)^2=9$
3. เป็นวงกลมศูนย์กลาง $(2,-1)$ รัศมี $3$
4. แทน $5-i$ ได้ผลต่าง $(5 - i) - (2 - i) = 3$ จึงมีขนาด $3$ และอยู่บนวงกลม
</Steps>
</Example>

{/* check: Abs((5-I)-(2-I))==3 and expand(Abs((a - 2) + (b + 1)*I)**2) == expand((a - 2)**2 + (b + 1)**2) */}

<Think>

วงกลม $|z + 3 - i| = 2$ มีจุดศูนย์กลางที่ $(3, -1)$ ใช่ไหม

<Reveal>
ไม่ใช่ ต้องเขียนข้างในเป็นรูป $z - z_0$ ก่อน $z + 3 - i = z - (-3 + i)$ จุดศูนย์กลางจึงเป็น $-3 + i$ คือจุด $(-3, 1)$ เครื่องหมายสลับเหมือนกรณี $(x - h)^2$ ในบทที่ 25 ตรวจได้โดยแทน $z = -3 + i$ ข้างในจะเป็นศูนย์ ซึ่งต้องเกิดที่จุดศูนย์กลางเท่านั้น
</Reveal>
</Think>

{/* check: (-3 + I) + 3 - I == 0 */}

<Example n={6}>

หาเซตของจุด $z$ ที่ $|z - 1| = |z + i|$

<Steps reveal>
1. เขียน $z + i = z - (-i)$ สมการจึงบอกว่าระยะจาก $z$ ถึง $1$ เท่ากับระยะจาก $z$ ถึง $-i$ คือจุดที่ห่างจาก $(1, 0)$ และ $(0, -1)$ เท่ากัน เซตนี้ควรเป็นเส้นแบ่งครึ่งตั้งฉากของส่วนของเส้นตรงที่เชื่อมสองจุด
2. ยืนยันด้วยพีชคณิต ให้ $z = a + bi$ ยกกำลังสองทั้งสองข้างได้ $(a - 1)^2 + b^2 = a^2 + (b + 1)^2$
3. กระจายแล้ว $a^2$ กับ $b^2$ หักล้างกัน เหลือ $-2a + 1 = 2b + 1$ จึงได้ $b = -a$
4. เซตนี้คือเส้นตรง $y = -x$ บนระนาบ ตรวจจุด $2 - 2i$ ที่อยู่บนเส้น $|1 - 2i| = \sqrt{5}$ และ $|2 - i| = \sqrt{5}$ เท่ากันจริง
</Steps>
</Example>

{/* check: expand((a - 1)**2 + b**2 - (a**2 + (b + 1)**2)) == -2*a - 2*b and Abs(2 - 2*I - 1) == Abs(2 - 2*I + I) == sqrt(5) */}

สังเกตว่าเส้น $y = -x$ ผ่านจุดกึ่งกลาง $\left(\tfrac{1}{2}, -\tfrac{1}{2}\right)$ ของสองจุดนั้น และมีความชัน $-1$ ตั้งฉากกับส่วนของเส้นตรงจาก $(0, -1)$ ไป $(1, 0)$ ที่มีความชัน $1$ ตรงกับที่คาดจากภาพในขั้นแรก

<Note title="ตรวจวิธีคิด">
จุดภายในวงกลมจะมีระยะน้อยกว่าสาม จุดภายนอกมีระยะมากกว่าสาม การเปลี่ยนเครื่องหมายเป็นไม่เท่ากันจึงเปลี่ยนจากเส้นขอบไปเป็นบริเวณ ต้องแยกให้ชัดว่าโจทย์ต้องการรูปใด
</Note>

## สรุป

- $a + bi$ คือจุด $(a, b)$ แกนนอนเป็นส่วนจริง แกนตั้งเป็นส่วนจินตภาพ
- บวกคือเลื่อนตามลูกศร $z_1 - z_2$ คือลูกศรจาก $z_2$ ไป $z_1$
- ค่าสัมบูรณ์เป็นระยะ $|z| = \sqrt{a^2 + b^2}$ และระยะระหว่างจุดคือ $|z_1 - z_2|$
- สังยุคสะท้อนข้ามแกนจริง คงแกนนอนและกลับเครื่องหมายแกนตั้ง
- $|z_1z_2| = |z_1||z_2|$ แต่ไม่มีสูตรแบบนี้สำหรับผลบวก
- $|z - z_0| = r$ เป็นวงกลม $|z - z_1| = |z - z_2|$ เป็นเส้นแบ่งครึ่งตั้งฉาก
