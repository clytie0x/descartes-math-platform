มุม $75^\circ$ ไม่อยู่ในตารางมุมพิเศษ เครื่องคิดเลขบอกว่า $\sin 75^\circ$ ประมาณ $0.9659$ แต่ตัวเลขนี้เป็นค่าประมาณ ถ้าต้องการค่าแม่นตรงแบบ $\tfrac{\sqrt{3}}{2}$ ต้องหาทางอื่น สังเกตว่า $75^\circ = 45^\circ + 30^\circ$ ซึ่งเป็นมุมพิเศษทั้งคู่ คำถามจึงกลายเป็นว่า ถ้ารู้ไซน์และโคไซน์ของสองมุม จะหาไซน์ของผลบวกได้อย่างไร

ความคิดแรกของหลายคนคือ $\sin 75^\circ = \sin 45^\circ + \sin 30^\circ$ แต่ $\tfrac{\sqrt{2}}{2} + \tfrac{1}{2}$ ประมาณ $1.21$ ซึ่งมากกว่า $1$ เป็นไซน์ของมุมใดไม่ได้เลย หน้านี้จะสร้างสูตรที่ถูกต้องจากวงกลมหนึ่งหน่วย แล้วใช้สูตรนั้นหาค่าแม่นตรงของมุมอย่าง $75^\circ$ และ $15^\circ$

## ที่มาของสูตรโคไซน์ของผลต่าง

วาดมุม $A$ และมุม $B$ บนวงกลมหนึ่งหน่วย จุดปลายคือ $P = (\cos A, \sin A)$ และ $Q = (\cos B, \sin B)$ มุมระหว่างรัศมีสองเส้นนี้คือ $A - B$ ลองหาระยะ $PQ$ สองวิธี

**วิธีแรก** ใช้สูตรระยะทางระหว่างจุดจากบทที่ 38 ตรงๆ

$$PQ^2 = (\cos A - \cos B)^2 + (\sin A - \sin B)^2$$

กระจายแล้วจัดกลุ่ม $\cos^2 A + \sin^2 A = 1$ และ $\cos^2 B + \sin^2 B = 1$ จะเหลือ

$$PQ^2 = 2 - 2(\cos A\cos B + \sin A\sin B)$$

**วิธีที่สอง** หมุนรูปทั้งรูปจนจุด $Q$ ไปอยู่ที่ $(1, 0)$ การหมุนไม่เปลี่ยนระยะ จุด $P$ ที่ห่างจาก $Q$ เป็นมุม $A - B$ จึงย้ายไปอยู่ที่ $(\cos(A - B), \sin(A - B))$ ระยะเดิมจึงเท่ากับ

$$PQ^2 = (\cos(A - B) - 1)^2 + \sin^2(A - B) = 2 - 2\cos(A - B)$$

ระยะเดียวกันวัดได้สองแบบ นำมาเท่ากันแล้วตัด $2$ กับ $-2$ ออก ได้สูตรแรกของหน้านี้

<Thm label="สูตรโคไซน์ของผลต่าง">

$$\cos(A - B) = \cos A\cos B + \sin A\sin B$$

</Thm>

{/* check: expand(expand_trig(cos(a - b)) - (cos(a)*cos(b) + sin(a)*sin(b))) == 0 */}
{/* check: simplify((cos(a) - cos(b))**2 + (sin(a) - sin(b))**2 - (2 - 2*(cos(a)*cos(b) + sin(a)*sin(b)))) == 0 */}

สูตรที่เหลือทั้งหมดมาจากสูตรนี้ แทน $B$ ด้วย $-B$ และใช้ $\cos(-B) = \cos B$ กับ $\sin(-B) = -\sin B$ จะได้สูตรของผลบวก ส่วนสูตรของไซน์มาจากการแทน $A = \tfrac{\pi}{2}$ ก่อน ได้ $\cos\left(\tfrac{\pi}{2} - B\right) = 0 \cdot \cos B + 1 \cdot \sin B = \sin B$ แปลว่าไซน์ของมุมหนึ่งคือโคไซน์ของมุมที่รวมกับมันได้มุมฉาก แล้วใช้ความจริงนี้แปลง $\sin(A + B) = \cos\left(\left(\tfrac{\pi}{2} - A\right) - B\right)$ จะได้สูตรไซน์ตามมา

<Thm label="สูตรมุมรวม">

$$\sin(A \pm B) = \sin A\cos B \pm \cos A\sin B$$
$$\cos(A \pm B) = \cos A\cos B \mp \sin A\sin B$$
$$\tan(A \pm B) = \frac{\tan A \pm \tan B}{1 \mp \tan A\tan B}$$

</Thm>

{/* check: expand(expand_trig(sin(a + b)) - (sin(a)*cos(b) + cos(a)*sin(b))) == 0 and expand(expand_trig(cos(a + b)) - (cos(a)*cos(b) - sin(a)*sin(b))) == 0 */}
{/* check: simplify(expand_trig(tan(a + b)) - (tan(a) + tan(b))/(1 - tan(a)*tan(b))) == 0 */}

วิธีจำเครื่องหมาย สูตรไซน์ใช้เครื่องหมายเดียวกับในวงเล็บ และไขว้ไซน์กับโคไซน์ สูตรโคไซน์เครื่องหมายกลับกัน และจับโคไซน์คู่โคไซน์ ไซน์คู่ไซน์ สูตรแทนเจนต์ใช้ได้เมื่อทุกพจน์นิยามและตัวส่วนไม่เป็นศูนย์

<Think>

เพื่อนจำสูตรเป็น $\sin(A + B) = \sin A + \sin B$ เพราะคิดว่าไซน์กระจายเข้าวงเล็บได้เหมือนการคูณ ลองหาตัวอย่างที่แสดงว่าผิด

<Reveal>
ลอง $A = B = \tfrac{\pi}{2}$ ข้างซ้ายเป็น $\sin\pi = 0$ แต่ข้างขวาเป็น $1 + 1 = 2$ ไซน์เป็นฟังก์ชัน ไม่ใช่ตัวเลขที่คูณเข้าวงเล็บได้ เหมือนกับที่ $\sqrt{9 + 16}$ ไม่เท่ากับ $\sqrt{9} + \sqrt{16}$ สูตรที่ถูกต้องมีผลคูณไขว้ $\sin A\cos B + \cos A\sin B$ ซึ่งให้ $1 \cdot 0 + 0 \cdot 1 = 0$ ตรงกับข้างซ้าย
</Reveal>
</Think>

{/* check: sin(pi) == 0 and sin(pi/2)*cos(pi/2) + cos(pi/2)*sin(pi/2) == 0 and sqrt(9 + 16) != sqrt(9) + sqrt(16) */}

## หาค่าแม่นตรงของมุมที่ไม่อยู่ในตาราง

<Example n={1}>

หา $\sin 75^\circ$ แบบค่าแม่นตรง

<Steps reveal>
1. แยก $75^\circ = 45^\circ + 30^\circ$ เพราะรู้ค่าของทั้งสองมุม แล้วใช้สูตรไซน์ของผลบวก $\sin 45^\circ\cos 30^\circ + \cos 45^\circ\sin 30^\circ$
2. แทนค่า $\tfrac{\sqrt{2}}{2} \cdot \tfrac{\sqrt{3}}{2} + \tfrac{\sqrt{2}}{2} \cdot \tfrac{1}{2} = \tfrac{\sqrt{6}}{4} + \tfrac{\sqrt{2}}{4}$
3. จึงได้ $\sin 75^\circ = \tfrac{\sqrt{6} + \sqrt{2}}{4}$ ตรวจด้วยเครื่องคิดเลข $\tfrac{2.449 + 1.414}{4}$ ประมาณ $0.9659$ ตรงกับค่าต้นหน้า
</Steps>
</Example>

{/* check: simplify(sin(5*pi/12)-(sqrt(6)+sqrt(2))/4)==0 */}

<Example n={2}>

หา $\cos 15^\circ$ และ $\tan 15^\circ$ แบบค่าแม่นตรง

<Steps reveal>
1. $15^\circ = 45^\circ - 30^\circ$ ใช้สูตรโคไซน์ของผลต่าง เครื่องหมายกลายเป็นบวก $\cos 45^\circ\cos 30^\circ + \sin 45^\circ\sin 30^\circ = \tfrac{\sqrt{6}}{4} + \tfrac{\sqrt{2}}{4} = \tfrac{\sqrt{6} + \sqrt{2}}{4}$
2. ผลนี้เท่ากับ $\sin 75^\circ$ พอดี ไม่ใช่เรื่องบังเอิญ เพราะ $15^\circ + 75^\circ = 90^\circ$ และไซน์ของมุมหนึ่งคือโคไซน์ของมุมที่รวมกันได้มุมฉาก
3. สำหรับแทนเจนต์ใช้สูตรผลต่าง $\tan 15^\circ = \dfrac{\tan 45^\circ - \tan 30^\circ}{1 + \tan 45^\circ\tan 30^\circ} = \dfrac{1 - \tfrac{1}{\sqrt{3}}}{1 + \tfrac{1}{\sqrt{3}}}$
4. คูณทั้งเศษและส่วนด้วย $\sqrt{3}$ ได้ $\dfrac{\sqrt{3} - 1}{\sqrt{3} + 1}$ แล้วคูณด้วย $\sqrt{3} - 1$ ทั้งเศษและส่วนเพื่อกำจัดรากที่ตัวส่วน ได้ $\dfrac{(\sqrt{3} - 1)^2}{3 - 1} = \dfrac{4 - 2\sqrt{3}}{2} = 2 - \sqrt{3}$
</Steps>
</Example>

{/* check: simplify(cos(pi/12) - (sqrt(6) + sqrt(2))/4) == 0 and simplify(tan(pi/12) - (2 - sqrt(3))) == 0 */}
{/* check: simplify((1 - 1/sqrt(3))/(1 + 1/sqrt(3)) - (2 - sqrt(3))) == 0 */}

สูตรมุมรวมไม่ได้ใช้แค่กับมุมพิเศษ ถ้าโจทย์ให้ค่าของมุมมาเป็นอัตราส่วน ก็ใช้วิธีจากหน้า 39.2 หาฟังก์ชันที่เหลือก่อน แล้วแทนในสูตร

<Example n={3}>

ให้ $\sin A = \tfrac{3}{5}$ และ $\cos B = \tfrac{5}{13}$ โดย $A$ และ $B$ อยู่จตุภาคที่ 1 ทั้งคู่ หา $\sin(A + B)$ และ $\cos(A + B)$

<Steps reveal>
1. สูตรต้องใช้ทั้ง $\cos A$ และ $\sin B$ จึงหาก่อน $\cos A = \sqrt{1 - \tfrac{9}{25}} = \tfrac{4}{5}$ และ $\sin B = \sqrt{1 - \tfrac{25}{169}} = \tfrac{12}{13}$ ทั้งสองเลือกรากบวกเพราะอยู่จตุภาคที่ 1
2. $\sin(A + B) = \tfrac{3}{5} \cdot \tfrac{5}{13} + \tfrac{4}{5} \cdot \tfrac{12}{13} = \tfrac{15 + 48}{65} = \tfrac{63}{65}$
3. $\cos(A + B) = \tfrac{4}{5} \cdot \tfrac{5}{13} - \tfrac{3}{5} \cdot \tfrac{12}{13} = \tfrac{20 - 36}{65} = -\tfrac{16}{65}$
4. โคไซน์ติดลบแปลว่า $A + B$ เกินมุมฉาก อยู่จตุภาคที่ 2 ทั้งที่ $A$ และ $B$ เป็นมุมแหลม ตรวจ $\left(\tfrac{63}{65}\right)^2 + \left(\tfrac{16}{65}\right)^2 = \tfrac{3969 + 256}{4225} = 1$ ตรงกับเอกลักษณ์
</Steps>
</Example>

{/* check: Rational(3,5)*Rational(5,13) + Rational(4,5)*Rational(12,13) == Rational(63,65) and Rational(4,5)*Rational(5,13) - Rational(3,5)*Rational(12,13) == Rational(-16,65) */}
{/* check: Rational(63, 65)**2 + Rational(16, 65)**2 == 1 and sqrt(1 - Rational(25, 169)) == Rational(12, 13) */}

## สูตรมุมสองเท่า

ถ้าให้ $B = A$ ในสูตรผลบวก จะได้สูตรของมุมสองเท่าทันที ไม่ต้องจำแยก

$$\sin 2A = 2\sin A\cos A$$
$$\cos 2A = \cos^2 A - \sin^2 A$$
$$\tan 2A = \frac{2\tan A}{1 - \tan^2 A}$$

สูตรโคไซน์มีอีกสองรูปที่ได้จากการแทน $\cos^2 A = 1 - \sin^2 A$ หรือ $\sin^2 A = 1 - \cos^2 A$ คือ $\cos 2A = 1 - 2\sin^2 A$ และ $\cos 2A = 2\cos^2 A - 1$ เลือกใช้รูปที่มีฟังก์ชันที่โจทย์ให้มา

{/* check: simplify(expand_trig(cos(2*a)) - (1 - 2*sin(a)**2)) == 0 and simplify(expand_trig(cos(2*a)) - (2*cos(a)**2 - 1)) == 0 and expand(expand_trig(sin(2*a)) - 2*sin(a)*cos(a)) == 0 */}

<Example n={4}>

ให้ $\sin u = \tfrac{3}{5}$ และ $u$ อยู่จตุภาคที่ 1 หา $\sin 2u$ และ $\cos 2u$

<Steps reveal>
1. สูตร $\sin 2u$ ต้องใช้ $\cos u$ จตุภาคที่ 1 โคไซน์บวก จึงได้ $\cos u = \tfrac{4}{5}$
2. $\sin 2u = 2\sin u\cos u = 2 \cdot \tfrac{3}{5} \cdot \tfrac{4}{5} = \tfrac{24}{25}$
3. สำหรับ $\cos 2u$ เลือกรูป $1 - 2\sin^2 u$ เพราะโจทย์ให้ไซน์มา $1 - 2 \cdot \tfrac{9}{25} = 1 - \tfrac{18}{25} = \tfrac{7}{25}$
4. ตรวจ $\left(\tfrac{24}{25}\right)^2 + \left(\tfrac{7}{25}\right)^2 = \tfrac{576 + 49}{625} = 1$
</Steps>
</Example>

{/* check: 2*Rational(3,5)*Rational(4,5)==Rational(24,25) and 1-2*Rational(3,5)**2==Rational(7,25) and Rational(24, 25)**2 + Rational(7, 25)**2 == 1 */}

จตุภาคของ $u$ ไม่จำเป็นต้องตรงกับจตุภาคของ $2u$ ในตัวอย่างนี้ $u$ ประมาณ $37^\circ$ มุม $2u$ ประมาณ $74^\circ$ ยังอยู่จตุภาคที่ 1 แต่ถ้า $u$ เป็น $60^\circ$ มุม $2u$ จะเป็น $120^\circ$ ข้ามไปจตุภาคที่ 2 จึงอย่าเติมเครื่องหมายของมุมสองเท่าจากมุมเดิม ให้คำนวณจากสูตร แล้วเครื่องหมายจะออกมาเอง

<Example n={5}>

ใช้สูตรมุมสองเท่าหา $\sin 15^\circ$ แล้วเทียบกับผลจากสูตรผลต่าง

<Steps reveal>
1. ใช้ $\cos 2A = 1 - 2\sin^2 A$ กับ $A = 15^\circ$ ได้ $\cos 30^\circ = 1 - 2\sin^2 15^\circ$ จึงได้ $\sin^2 15^\circ = \dfrac{1 - \tfrac{\sqrt{3}}{2}}{2} = \dfrac{2 - \sqrt{3}}{4}$
2. $15^\circ$ อยู่จตุภาคที่ 1 ไซน์บวก ถอดรากเลือกค่าบวก $\sin 15^\circ = \dfrac{\sqrt{2 - \sqrt{3}}}{2}$
3. จากสูตรผลต่าง $\sin 15^\circ = \sin(45^\circ - 30^\circ) = \tfrac{\sqrt{6} - \sqrt{2}}{4}$ หน้าตาต่างกัน ลองยกกำลังสองค่านี้ได้ $\tfrac{6 + 2 - 2\sqrt{12}}{16} = \tfrac{8 - 4\sqrt{3}}{16} = \tfrac{2 - \sqrt{3}}{4}$ เท่ากับขั้นที่ 1 ทั้งสองค่าเป็นบวก จึงเป็นจำนวนเดียวกันที่เขียนต่างรูป
</Steps>
</Example>

{/* check: simplify(sin(pi/12)**2 - (2 - sqrt(3))/4) == 0 and simplify(sin(pi/12) - (sqrt(6) - sqrt(2))/4) == 0 and expand(((sqrt(6) - sqrt(2))/4)**2) == expand((2 - sqrt(3))/4) */}

<Think>

$\sin 2A = 2\sin A$ ใช่ไหม เพราะมุมเพิ่มเป็นสองเท่า ไซน์ก็น่าจะเพิ่มเป็นสองเท่า

<Reveal>
ไม่ใช่ ลอง $A = 60^\circ$ ข้างซ้ายเป็น $\sin 120^\circ = \tfrac{\sqrt{3}}{2}$ แต่ข้างขวาเป็น $2 \cdot \tfrac{\sqrt{3}}{2} = \sqrt{3}$ ซึ่งเกิน $1$ ไปแล้ว ไซน์คือความสูงบนวงกลม ไม่ได้โตตามมุมเป็นสัดส่วน สูตรที่ถูกคือ $2\sin A\cos A$ ตัวคูณ $\cos A$ ที่ไม่เกิน $1$ ทำให้ผลไม่เคยเกิน $1$
</Reveal>
</Think>

{/* check: sin(2*pi/3) == sqrt(3)/2 and 2*sin(pi/3) == sqrt(3) and 2*sin(pi/3)*cos(pi/3) == sqrt(3)/2 */}

ทั้งหน้านี้เราเริ่มจากมุมแล้วหาค่า หน้าถัดไปจะถามกลับ ถ้ารู้ค่าไซน์ว่าเป็น $\tfrac{3}{5}$ มุมคือเท่าไร คำถามนี้นำไปสู่ฟังก์ชันตรีโกณมิติผกผัน

## สรุป

- $\cos(A - B) = \cos A\cos B + \sin A\sin B$ มาจากการวัดระยะระหว่างสองจุดบนวงกลมหนึ่งหน่วยสองวิธี
- สูตรไซน์ใช้เครื่องหมายเดียวกับในวงเล็บ สูตรโคไซน์เครื่องหมายกลับกัน
- แยกมุมเป็นผลบวกหรือผลต่างของมุมพิเศษเพื่อหาค่าแม่นตรง
- สูตรมุมสองเท่ามาจากการให้สองมุมเท่ากัน $\cos 2A$ มีสามรูปให้เลือกตามข้อมูลที่มี
- ไซน์ไม่กระจายเข้าวงเล็บ และไม่โตเป็นสัดส่วนกับมุม
