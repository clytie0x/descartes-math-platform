นักเรียนกลุ่มหนึ่งอยากรู้ว่าแม่น้ำหน้าโรงเรียนกว้างเท่าไร แต่ไม่มีเรือข้ามไปขึงเทปวัด ฝั่งตรงข้ามมีต้นไม้ใหญ่ต้นหนึ่ง พวกเขาจึงปักหลักสองหลักบนฝั่งตัวเองห่างกัน $100$ เมตร แล้วใช้ไม้โปรแทรกเตอร์วัดมุมจากแนวฝั่งไปยังต้นไม้ที่หลักทั้งสอง ได้ $75^\circ$ กับ $60^\circ$ ข้อมูลเท่านี้พอหาความกว้างของแม่น้ำได้ไหม

หลักสองหลักกับต้นไม้เป็นสามเหลี่ยม แต่ไม่ใช่สามเหลี่ยมมุมฉาก อัตราส่วนตรีโกณมิติแบบบทที่ 31 จึงใช้ตรงๆ ไม่ได้ หน้านี้จะสร้างกฎสองข้อที่ใช้กับสามเหลี่ยมทุกรูป แล้วกลับมาตอบคำถามนี้

## ตั้งชื่อด้านให้ตรงมุม

ในสามเหลี่ยม $ABC$ เขียนมุมด้วยอักษรตัวใหญ่ และให้ด้านที่อยู่ตรงข้ามมุมใช้อักษรตัวเล็กตัวเดียวกัน ด้าน $a$ อยู่ตรงข้ามมุม $A$ ด้าน $b$ อยู่ตรงข้ามมุม $B$ และด้าน $c$ อยู่ตรงข้ามมุม $C$ การตั้งชื่อแบบนี้ทำให้สูตรจำง่าย และบอกได้ทันทีว่าด้านไหนคู่กับมุมไหน

## กฎของโคไซน์มาจากพีทาโกรัส

วางสามเหลี่ยมบนระนาบพิกัดให้ $C$ อยู่ที่จุดกำเนิดและ $B$ อยู่บนแกน $x$ ที่ $(a, 0)$ จุด $A$ อยู่ห่างจาก $C$ เป็นระยะ $b$ ในทิศมุม $C$ ตามหน้า 39.1 พิกัดของ $A$ คือ $(b\cos C, b\sin C)$

ด้าน $c$ คือระยะระหว่าง $A$ กับ $B$ ใช้สูตรระยะทาง (ซึ่งก็คือพีทาโกรัสของสามเหลี่ยมมุมฉากที่มีเส้นประเป็นด้านหนึ่ง)

$$c^2 = (b\cos C - a)^2 + (b\sin C)^2 = b^2\cos^2 C - 2ab\cos C + a^2 + b^2\sin^2 C$$

รวม $b^2\cos^2 C + b^2\sin^2 C = b^2$ ด้วยเอกลักษณ์จากหน้า 39.2 ได้กฎของโคไซน์ การพิสูจน์นี้ไม่ได้สมมุติว่า $C$ เป็นมุมแหลม ถ้า $C$ เป็นมุมป้าน $\cos C$ ติดลบ จุด $A$ แค่ไปอยู่ทางซ้ายของแกน $y$ สูตรยังเหมือนเดิม

{/* check: simplify(expand((b*cos(c) - a)**2 + (b*sin(c))**2 - (a**2 + b**2 - 2*a*b*cos(c)))) == 0 */}

<Thm label="กฎของโคไซน์">

$$c^2 = a^2 + b^2 - 2ab\cos C$$

และในทำนองเดียวกัน $a^2 = b^2 + c^2 - 2bc\cos A$ และ $b^2 = a^2 + c^2 - 2ac\cos B$
</Thm>

ถ้า $C = 90^\circ$ จะได้ $\cos C = 0$ เหลือ $c^2 = a^2 + b^2$ ซึ่งคือทฤษฎีบทพีทาโกรัส พจน์ $-2ab\cos C$ จึงเป็นตัวปรับเมื่อมุมไม่ฉาก มุมแหลมทำให้ $c$ สั้นกว่ากรณีมุมฉาก มุมป้านทำให้ยาวกว่า กฎนี้เหมาะเมื่อรู้**สองด้านกับมุมระหว่างด้าน** (ด.ม.ด.) หรือรู้**สามด้าน** (ด.ด.ด.) แล้วจะหามุม

จากรูปเดียวกัน ความสูงของสามเหลี่ยมเมื่อใช้ $a$ เป็นฐานคือ $b\sin C$ จึงได้พื้นที่เท่ากับ $\tfrac{1}{2}$ คูณฐานคูณสูง คือ $\tfrac{1}{2}ab\sin C$ มุมในสูตรต้องเป็นมุมที่อยู่ระหว่างสองด้านที่ใช้

<Example n={1}>

แปลงผักรูปสามเหลี่ยมมีด้านยาว $5$ เมตรและ $7$ เมตร มุมระหว่างสองด้านนี้ $60^\circ$ หาด้านที่สามและพื้นที่ของแปลง

<Steps reveal>
1. ข้อมูลเป็นสองด้านกับมุมระหว่าง (ด.ม.ด.) จึงใช้กฎของโคไซน์ ให้ $a = 5$ $b = 7$ และ $C = 60^\circ$
2. $c^2 = 5^2 + 7^2 - 2(5)(7)\cos 60^\circ = 25 + 49 - 70 \cdot \tfrac{1}{2} = 39$
3. ความยาวต้องเป็นบวก จึงเลือกรากบวก $c = \sqrt{39}$ ประมาณ $6.24$ เมตร ตรวจว่าสมเหตุสมผล ถ้ามุมเป็นมุมฉากด้านที่สามจะยาว $\sqrt{74}$ ประมาณ $8.6$ เมตร มุม $60^\circ$ แคบกว่ามุมฉาก ด้านที่สามจึงควรสั้นกว่า
4. พื้นที่ $\tfrac{1}{2}(5)(7)\sin 60^\circ = \tfrac{35}{2} \cdot \tfrac{\sqrt{3}}{2} = \tfrac{35\sqrt{3}}{4}$ ประมาณ $15.2$ ตารางเมตร
</Steps>
</Example>

<Example n={2}>

สามเหลี่ยมมีด้านยาว $5$ $7$ และ $8$ หน่วย หามุมที่อยู่ตรงข้ามด้านที่ยาว $7$ และบอกว่าสามเหลี่ยมนี้มีมุมป้านหรือไม่

<Steps reveal>
1. รู้สามด้าน (ด.ด.ด.) ให้ $b = 7$ เป็นด้านตรงข้ามมุม $B$ ที่ต้องการ แล้วจัดกฎของโคไซน์ใหม่ให้ $\cos B$ อยู่ข้างเดียว $\cos B = \dfrac{a^2 + c^2 - b^2}{2ac}$
2. แทนค่า $\cos B = \dfrac{25 + 64 - 49}{2(5)(8)} = \dfrac{40}{80} = \dfrac{1}{2}$ จึงได้ $B = 60^\circ$
3. มุมที่ใหญ่ที่สุดอยู่ตรงข้ามด้านที่ยาวที่สุด $8$ คำนวณ $\cos C = \dfrac{25 + 49 - 64}{2(5)(7)} = \dfrac{10}{70} = \dfrac{1}{7}$ เป็นบวก มุม $C$ จึงเป็นมุมแหลม และเพราะเป็นมุมใหญ่ที่สุด สามเหลี่ยมนี้ไม่มีมุมป้าน
</Steps>
</Example>

{/* check: Rational(25 + 64 - 49, 80) == Rational(1, 2) and acos(Rational(1, 2)) == pi/3 and Rational(25 + 49 - 64, 70) == Rational(1, 7) */}

## กฎของไซน์มาจากความสูง

ลากความสูง $h$ จากจุด $C$ ลงด้าน $c$ ความสูงนี้เป็นด้านของสามเหลี่ยมมุมฉากสองรูป รูปที่มีมุม $A$ ให้ $h = b\sin A$ และรูปที่มีมุม $B$ ให้ $h = a\sin B$ ความสูงเส้นเดียวกันจึงได้ $b\sin A = a\sin B$ หารด้วย $\sin A\sin B$ จะได้ $\dfrac{a}{\sin A} = \dfrac{b}{\sin B}$ ทำแบบเดียวกันกับความสูงเส้นอื่นจะได้ครบสามคู่

<Thm label="กฎของไซน์">

$$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C}$$

</Thm>

กฎนี้เหมาะเมื่อรู้ด้านหนึ่งพร้อมมุมตรงข้ามของมันเป็นคู่ แล้วมีข้อมูลอีกหนึ่งอย่าง เช่นรู้สองมุมกับหนึ่งด้าน (ม.ม.ด.) ถ้ารู้สองมุม มุมที่สามหาได้จากผลรวม $180^\circ$ เสมอ

<Example n={3}>

ให้ $A = 30^\circ$ $B = 45^\circ$ และ $a = 6$ หา $b$

<Steps reveal>
1. คู่ $a$ กับ $A$ รู้ครบทั้งด้านและมุม จึงตั้ง $\dfrac{b}{\sin 45^\circ} = \dfrac{6}{\sin 30^\circ}$
2. คูณด้วย $\sin 45^\circ$ ได้ $b = \dfrac{6 \cdot \tfrac{\sqrt{2}}{2}}{\tfrac{1}{2}} = 6\sqrt{2}$ ประมาณ $8.49$ หน่วย
3. ตรวจ มุมที่เหลือ $C = 180^\circ - 30^\circ - 45^\circ = 105^\circ$ เป็นสามเหลี่ยมได้จริง และ $b \gt a$ สอดคล้องกับ $B \gt A$ เพราะด้านยาวกว่าอยู่ตรงข้ามมุมใหญ่กว่า
</Steps>
</Example>

{/* check: simplify(6*sin(pi/4)/sin(pi/6))==6*sqrt(2) and 180 - 30 - 45 == 105 */}

<Example n={4}>

กลับไปที่แม่น้ำ หลัก $A$ และ $B$ อยู่บนฝั่งเดียวกันห่างกัน $100$ เมตร ต้นไม้ $C$ อยู่อีกฝั่ง วัดมุม $CAB = 75^\circ$ และมุม $CBA = 60^\circ$ แม่น้ำกว้างเท่าไร (ถือว่าฝั่งเป็นเส้นตรงขนานกัน)

<Steps reveal>
1. มุมที่ต้นไม้ $C = 180^\circ - 75^\circ - 60^\circ = 45^\circ$ ตอนนี้รู้คู่ด้านกับมุมตรงข้าม คือ $c = AB = 100$ กับ $C = 45^\circ$ จึงใช้กฎของไซน์ได้
2. หาด้าน $a = BC$ ซึ่งอยู่ตรงข้ามมุม $A = 75^\circ$ $\dfrac{a}{\sin 75^\circ} = \dfrac{100}{\sin 45^\circ}$ ใช้ $\sin 75^\circ = \tfrac{\sqrt{6} + \sqrt{2}}{4}$ จากหน้า 39.5 ได้ $a = \dfrac{100 \cdot \tfrac{\sqrt{6} + \sqrt{2}}{4}}{\tfrac{\sqrt{2}}{2}} = 50(\sqrt{3} + 1)$ ประมาณ $136.6$ เมตร
3. ความกว้างของแม่น้ำคือระยะตั้งฉากจาก $C$ ถึงแนวฝั่ง $AB$ ในสามเหลี่ยมมุมฉากที่มีมุม $B = 60^\circ$ ระยะนี้คือ $a\sin 60^\circ = 50(\sqrt{3} + 1) \cdot \tfrac{\sqrt{3}}{2} = 25(3 + \sqrt{3})$
4. แม่น้ำกว้างประมาณ $118.3$ เมตร โดยไม่ต้องข้ามไปวัดเลย
</Steps>
</Example>

## กรณีคลุมเครือ ด.ด.ม.

ถ้ารู้สองด้านกับมุมที่**ไม่อยู่**ระหว่างสองด้านนั้น กฎของไซน์จะให้ค่า $\sin B$ มาก่อน แต่หน้า 39.4 สอนแล้วว่าค่าไซน์บวกหนึ่งค่ามาจากสองมุมในช่วง $0^\circ$ ถึง $180^\circ$ คือ $B$ กับ $180^\circ - B$ เพราะ $\sin\theta = \sin(180^\circ - \theta)$ ทั้งสองมุมอาจใช้ได้ หรือใช้ได้มุมเดียว หรือไม่มีสามเหลี่ยมเลย

ลองเลื่อนแถบในกราฟข้างล่าง ด้าน $b = 6$ ยึดไว้ที่มุม $A$ ด้าน $a$ คือรัศมีของวงกลมรอบ $C$ ที่ต้องยื่นไปแตะฐาน ถ้า $a$ สั้นกว่าความสูง $h = b\sin A$ จะแตะไม่ถึง ถ้ายาวระหว่าง $h$ กับ $b$ วงกลมตัดฐานสองจุดทางขวาของ $A$ ได้สองรูป ถ้ายาวตั้งแต่ $b$ ขึ้นไป จุดตัดหนึ่งไปอยู่หลัง $A$ เหลือรูปเดียว

<Board name="c39-ssa" label="สามเหลี่ยมที่รู้มุม A ด้าน b และด้าน a ที่ไม่อยู่ระหว่าง วงกลมรัศมี a รอบจุด C ตัดฐานได้ศูนย์ หนึ่ง หรือสองจุด" caption="เลื่อนด้าน a ดูว่าเมื่อไรได้สองรูป (ส้มและม่วง) รูปเดียว หรือไม่มีเลย" />

<Example n={5}>

ให้ $A = 30^\circ$ $a = 6$ และ $b = 6\sqrt{2}$ หาค่าที่เป็นไปได้ทั้งหมดของมุม $B$ แล้วเทียบกับกรณี $a = 10$

<Steps reveal>
1. กฎของไซน์ให้ $\sin B = \dfrac{b\sin A}{a} = \dfrac{6\sqrt{2} \cdot \tfrac{1}{2}}{6} = \dfrac{\sqrt{2}}{2}$
2. มุมในสามเหลี่ยมอยู่ระหว่าง $0^\circ$ ถึง $180^\circ$ จึงมี $B = 45^\circ$ หรือ $B = 135^\circ$
3. ตรวจผลรวมมุมทีละกรณี $30^\circ + 45^\circ = 75^\circ$ และ $30^\circ + 135^\circ = 165^\circ$ น้อยกว่า $180^\circ$ ทั้งคู่ จึงได้สองรูป ตรงกับเงื่อนไข $h = 3\sqrt{2}$ ประมาณ $4.24$ น้อยกว่า $a = 6$ ซึ่งน้อยกว่า $b$ ประมาณ $8.49$
4. ถ้า $a = 10$ จะได้ $\sin B = \dfrac{3\sqrt{2}}{10}$ ประมาณ $0.424$ ค่าหลักคือ $B$ ประมาณ $25.1^\circ$ อีกค่าคือ $154.9^\circ$ แต่ $30^\circ + 154.9^\circ$ เกิน $180^\circ$ ต้องตัดทิ้ง เหลือรูปเดียว ตรงกับ $a \ge b$
</Steps>
</Example>

## เลือกกฎให้ตรงข้อมูล

| ข้อมูลที่รู้ | ใช้ | ข้อควรระวัง |
|---|---|---|
| สองด้านกับมุมระหว่าง (ด.ม.ด.) | กฎของโคไซน์ | มุมต้องอยู่ตรงจุดที่สองด้านพบกัน |
| สามด้าน (ด.ด.ด.) | กฎของโคไซน์ในรูปหามุม | ผลรวมสองด้านต้องยาวกว่าด้านที่สาม |
| สองมุมกับหนึ่งด้าน (ม.ม.ด.) | กฎของไซน์ | หามุมที่สามจากผลรวม $180^\circ$ ก่อน |
| สองด้านกับมุมที่ไม่อยู่ระหว่าง (ด.ด.ม.) | กฎของไซน์ | อาจมีศูนย์ หนึ่ง หรือสองรูป ต้องตรวจทุกครั้ง |

บทนี้เริ่มจากคำถามว่า $\sin 150^\circ$ คืออะไร และจบที่การวัดแม่น้ำโดยไม่ต้องข้ามไป ทั้งหมดใช้เพียงความคิดเดียว คือจุดบนวงกลมหนึ่งหน่วยมีพิกัด $(\cos\theta, \sin\theta)$ ลองทำแบบฝึกหัดท้ายบทเพื่อตรวจว่าใช้เครื่องมือแต่ละชิ้นได้คล่องแล้ว

## สรุป

- กฎของโคไซน์ $c^2 = a^2 + b^2 - 2ab\cos C$ มาจากสูตรระยะทาง เมื่อ $C = 90^\circ$ กลายเป็นพีทาโกรัส
- กฎของไซน์ $\dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C}$ มาจากความสูงเส้นเดียวกันคำนวณสองทาง
- พื้นที่ $\tfrac{1}{2}ab\sin C$ ใช้มุมระหว่างสองด้าน
- ด.ม.ด. และ ด.ด.ด. ใช้กฎของโคไซน์ ม.ม.ด. ใช้กฎของไซน์
- ด.ด.ม. อาจได้หลายรูป ลองทั้ง $B$ และ $180^\circ - B$ แล้วตรวจผลรวมมุม
