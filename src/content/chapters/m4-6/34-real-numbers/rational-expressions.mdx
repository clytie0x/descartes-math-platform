ห้องเรียนจะสั่งทำเสื้อรุ่น ร้านคิดค่าทำบล็อกสกรีน $3000$ บาทครั้งเดียว และค่าเสื้อตัวละ $150$ บาท ถ้าสั่ง $x$ ตัว ราคาเฉลี่ยต่อตัวคือ $\frac{3000 + 150x}{x}$ บาท ห้องอยากให้ราคาเฉลี่ยไม่เกิน $200$ บาท ต้องสั่งอย่างน้อยกี่ตัว

ตัวแปรไปอยู่ในตัวส่วน นิพจน์แบบนี้เรียกว่า **เศษส่วนของพหุนาม** คือพหุนามหารด้วยพหุนาม เช่น $\frac{x-1}{x+2}$ ทุกอย่างที่ทำในหน้า 34.2 ยังใช้ได้เกือบหมด แต่มีกฎเพิ่มหนึ่งข้อที่ห้ามลืม ตัวส่วนเป็นศูนย์ไม่ได้

## ค่าที่ห้ามใช้

ก่อนแก้อะไรทั้งนั้น ให้หาค่าของ $x$ ที่ทำให้ตัวส่วนเป็นศูนย์ แล้วเขียนไว้ข้างโจทย์ ค่าพวกนี้ไม่มีวันเป็นคำตอบได้ เพราะที่ค่านั้นนิพจน์ไม่มีความหมาย ตามเหตุผลเรื่องการหารด้วยศูนย์ในหน้า 34.1

เช่น $\frac{x+1}{x-3}$ ห้าม $x = 3$ ส่วน $\frac{5}{x^2 - 4}$ ห้ามทั้ง $x = 2$ และ $x = -2$ เพราะ $x^2 - 4 = (x-2)(x+2)$ เป็นศูนย์ได้สองที่ การเขียนค่าต้องห้ามไว้ตั้งแต่แรกสำคัญ เพราะระหว่างแก้สมการ ตัวส่วนจะหายไป แล้วเราจะลืมว่ามันเคยมีอยู่

## สมการเศษส่วน

สำหรับ **สมการ** วิธีที่ตรงที่สุดคือคูณทั้งสองข้างด้วยตัวส่วน ให้เศษส่วนหายไป แล้วแก้สมการพหุนามที่เหลือ การคูณด้วยนิพจน์ทำได้ในสมการ เพราะเราได้ตัดค่าที่ทำให้ตัวคูณเป็นศูนย์ไว้แล้ว สมการไม่มีทิศให้กลับ ปัญหาเดียวคือคำตอบที่ได้อาจเป็นค่าต้องห้าม ต้องตรวจทุกครั้ง

<Example n={1}>

แก้สมการ $\frac{x+1}{x-3} = 2$

<Steps reveal>
1. ตัวส่วน $x - 3$ เป็นศูนย์ที่ $x = 3$ จดไว้ก่อนว่า $x \ne 3$
2. คูณ $x - 3$ ทั้งสองข้าง ทำได้เพราะ $x \ne 3$ ทำให้ตัวคูณไม่เป็นศูนย์ ได้ $x + 1 = 2(x - 3) = 2x - 6$
3. ย้ายข้างได้ $x = 7$ ซึ่งไม่ใช่ค่าต้องห้าม
4. ตรวจในสมการเดิม $\frac{7+1}{7-3} = \frac{8}{4} = 2$ จริง คำตอบคือ $x = 7$
</Steps>
</Example>

{/* check: solve((x+1)/(x-3) - 2, x) == [7] and Rational(8, 4) == 2 */}

<Example n={2}>

แก้สมการ $\frac{x^2}{x-1} = \frac{1}{x-1}$

<Steps reveal>
1. ค่าต้องห้ามคือ $x = 1$
2. ตัวส่วนเท่ากัน คูณ $x - 1$ ทั้งสองข้างได้ $x^2 = 1$ จึงได้ $x = 1$ หรือ $x = -1$
3. $x = 1$ เป็นค่าต้องห้าม แทนแล้วได้ $\frac{1}{0}$ ซึ่งไม่มีความหมาย ต้องตัดทิ้ง ค่านี้โผล่มาเพราะสมการ $x^2 = 1$ ไม่รู้จักตัวส่วนที่หายไปแล้ว
4. ตรวจ $x = -1$ ได้ $\frac{1}{-2} = \frac{1}{-2}$ จริง คำตอบมีตัวเดียวคือ $x = -1$
</Steps>
</Example>

{/* check: solve(x**2/(x-1) - 1/(x-1), x) == [-1] and roots(x**2 - 1) == [-1, 1] */}

ค่าอย่าง $x = 1$ ในตัวอย่างนี้เรียกว่า **คำตอบแปลกปลอม** เป็นคำตอบของสมการพหุนามหลังคูณ แต่ไม่ใช่คำตอบของสมการเดิม ถ้าไม่ได้จดค่าต้องห้ามไว้ จะส่งคำตอบผิดไปโดยไม่รู้ตัว

<Example n={3}>

ก๊อกน้ำ ก เติมถังเก็บน้ำจนเต็มใช้เวลา $x$ ชั่วโมง ก๊อก ข ช้ากว่า ใช้ $x + 2$ ชั่วโมง ถ้าเปิดพร้อมกัน ถังเต็มใน $80$ นาที ก๊อก ก ใช้เวลากี่ชั่วโมง

<Steps reveal>
1. ใน $1$ ชั่วโมง ก๊อก ก เติมได้ $\frac{1}{x}$ ถัง ก๊อก ข เติมได้ $\frac{1}{x+2}$ ถัง เปิดพร้อมกัน $80$ นาทีหรือ $\frac43$ ชั่วโมงได้ $1$ ถัง จึงเติมได้ชั่วโมงละ $\frac34$ ถัง
2. ตั้งสมการ $\frac1x + \frac{1}{x+2} = \frac34$ ค่าต้องห้ามคือ $0$ กับ $-2$ และในโจทย์นี้ $x$ เป็นเวลา จึงต้องเป็นบวกด้วย
3. คูณทั้งสองข้างด้วย $4x(x+2)$ ซึ่งเป็น ค.ร.น. ของตัวส่วน ได้ $4(x+2) + 4x = 3x(x+2)$ จัดรูปได้ $3x^2 - 2x - 8 = 0$ หรือ $(3x + 4)(x - 2) = 0$
4. ได้ $x = 2$ หรือ $x = -\frac43$ ทั้งคู่ไม่ใช่ค่าต้องห้ามและทำให้สมการเป็นจริง แต่เวลาติดลบไม่มีความหมาย จึงตอบ $x = 2$ ก๊อก ก ใช้ $2$ ชั่วโมง ตรวจ $\frac12 + \frac14 = \frac34$ จริง
</Steps>
</Example>

{/* check: solve(1/x + 1/(x+2) - Rational(3, 4), x) == [Rational(-4, 3), 2] and expand((3*x + 4)*(x - 2)) == 3*x**2 - 2*x - 8 */}

## อสมการเศษส่วน

อสมการต่างจากสมการตรงนี้ การคูณทั้งสองข้างด้วยตัวส่วนอย่าง $x + 2$ ใช้ไม่ได้ทันที เพราะ $x + 2$ เป็นบวกเมื่อ $x > -2$ แต่เป็นลบเมื่อ $x < -2$ ถ้าเป็นลบ ทิศอสมการต้องกลับ เราไม่รู้ว่า $x$ อยู่ฝั่งไหน จึงไม่รู้ว่าต้องกลับทิศหรือไม่

<Think>

เพื่อนแก้ $\frac{x-1}{x+2}\ge0$ โดยคูณ $x + 2$ ทั้งสองข้าง ได้ $x - 1 \ge 0$ ตอบ $[1, \infty)$ ลองแทน $x = -5$ ในโจทย์ แล้วบอกว่าเพื่อนพลาดตรงไหน

<Reveal>
แทน $x = -5$ ได้ $\frac{-6}{-3} = 2$ ซึ่งมากกว่าศูนย์ จึงเป็นคำตอบ แต่ไม่อยู่ในคำตอบของเพื่อน เพื่อนพลาดตอนคูณ $x + 2$ เพราะเมื่อ $x < -2$ ตัวคูณนี้ติดลบ ทิศอสมการต้องกลับ เพื่อนจึงทำช่วง $(-\infty, -2)$ หายไปทั้งก้อน
</Reveal>
</Think>

{/* check: Rational(-5 - 1, -5 + 2) == 2 */}

วิธีที่ปลอดภัยคือไม่คูณ แต่ใช้ตารางเครื่องหมายแบบหน้า 34.2 ได้เลย เพราะกฎเครื่องหมายของการหารเหมือนการคูณ ลบหารลบได้บวก บวกหารลบได้ลบ ขั้นตอนคือ

1. ย้ายทุกอย่างมาข้างเดียวให้อีกข้างเป็นศูนย์
2. รวมเป็นเศษส่วนก้อนเดียว แล้วแยกตัวประกอบทั้งตัวเศษและตัวส่วน
3. ใช้รากของตัวเศษและรากของตัวส่วนแบ่งเส้นจำนวน หาเครื่องหมายแต่ละช่วง
4. รากของตัวเศษรวมได้ถ้าอสมการมีเครื่องหมายเท่ากับ แต่รากของตัวส่วนเป็นจุดโปร่งเสมอ ไม่ว่าอสมการจะเป็นแบบไหน

<Example n={4}>

แก้ $\frac{x-1}{x+2}\ge0$

<Steps reveal>
1. จุดแบ่งช่วงคือ $-2$ จากตัวส่วนและ $1$ จากตัวเศษ ทั้งสองจุดใช้แบ่งช่วงได้ เพราะเป็นจุดที่ตัวเศษหรือตัวส่วนเปลี่ยนเครื่องหมาย
2. ทดสอบ $x = -3$ ได้ $\frac{-4}{-1} = 4$ บวก $x = 0$ ได้ $\frac{-1}{2}$ ลบ $x = 2$ ได้ $\frac{1}{4}$ บวก จึงเป็นบวกบน $(-\infty,-2)$ กับ $(1,\infty)$ และเป็นลบบนช่วงกลาง
3. รวม $1$ เพราะทำให้ตัวเศษเป็นศูนย์ ผลหารเป็น $0$ ซึ่งผ่าน $\ge 0$ แต่ไม่รวม $-2$ เพราะตัวส่วนเป็นศูนย์ ได้ $(-\infty,-2)\cup[1,\infty)$
</Steps>
</Example>

<Example n={5}>

แก้ $\frac{x+1}{x-3} \le 2$

<Steps reveal>
1. ข้างขวาเป็น $2$ ไม่ใช่ศูนย์ และห้ามคูณ $x - 3$ ข้ามไป เพราะไม่รู้เครื่องหมาย จึงลบ $2$ ทั้งสองข้าง ได้ $\frac{x+1}{x-3} - 2 \le 0$
2. รวมเป็นเศษส่วนเดียวด้วยตัวส่วนร่วม $\frac{(x+1) - 2(x-3)}{x-3} = \frac{7 - x}{x - 3} \le 0$ ระวังเครื่องหมายลบที่ต้องคูณเข้าไปทั้งวงเล็บ
3. ตัวเศษ $7 - x$ มี $x$ ติดลบ เขียนเป็น $-(x - 7)$ แล้วคูณ $-1$ ทั้งสองข้าง ทิศกลับ ได้ $\frac{x - 7}{x - 3} \ge 0$ การคูณ $-1$ ทำได้เพราะรู้แน่ว่าเป็นลบ
4. จุดแบ่งคือ $3$ จากตัวส่วนและ $7$ จากตัวเศษ ทดสอบ $x = 0$ ได้ $\frac{-7}{-3}$ บวก $x = 5$ ได้ $\frac{-2}{2}$ ลบ $x = 8$ ได้ $\frac{1}{5}$ บวก
5. เลือกช่วงบวก รวม $7$ แต่ไม่รวม $3$ ได้ $(-\infty, 3) \cup [7, \infty)$ ตรวจในโจทย์เดิมที่ $x = 5$ ได้ $\frac{6}{2} = 3$ มากกว่า $2$ จริง ช่วงกลางจึงไม่ใช่คำตอบ
</Steps>
</Example>

{/* check: simplify((x+1)/(x-3) - 2 - (7 - x)/(x - 3)) == 0 */}

<Think>

$\frac{x-1}{x+2} \ge 0$ กับ $(x-1)(x+2) \ge 0$ มีคำตอบเหมือนกันไหม

<Reveal>
เกือบเหมือน ผลหารกับผลคูณมีเครื่องหมายเดียวกันทุกที่ที่ $x \ne -2$ เพราะกฎเครื่องหมายเหมือนกัน ต่างกันจุดเดียวคือ $x = -2$ ซึ่งทำให้ผลคูณเป็น $0$ จึงผ่าน $\ge 0$ แต่ทำให้ผลหารไม่มีความหมาย คำตอบของผลคูณคือ $(-\infty, -2] \cup [1, \infty)$ ส่วนของผลหารต้องเปิดที่ $-2$
</Reveal>
</Think>

## เมื่อรู้เครื่องหมายของตัวส่วน

กฎห้ามคูณตัวส่วนมีไว้เพราะไม่รู้เครื่องหมาย ถ้าโจทย์บอกเครื่องหมายมาแล้ว ก็คูณได้ตามสมบัติการไม่เท่ากัน กลับไปที่เสื้อรุ่นตอนต้นหน้า

<Example n={6}>

ราคาเฉลี่ยต่อตัว $\frac{3000 + 150x}{x}$ บาท ต้องสั่งอย่างน้อยกี่ตัว ราคาเฉลี่ยจึงไม่เกิน $200$ บาท

<Steps reveal>
1. ตั้งอสมการ $\frac{3000 + 150x}{x} \le 200$ โดย $x$ เป็นจำนวนเสื้อ จึงเป็นจำนวนนับ $x > 0$ แน่นอน
2. เพราะรู้ว่า $x$ เป็นบวก คูณ $x$ ทั้งสองข้างได้โดยทิศไม่เปลี่ยน ได้ $3000 + 150x \le 200x$
3. ลบ $150x$ ทั้งสองข้าง ได้ $3000 \le 50x$ หาร $50$ ได้ $x \ge 60$
4. ต้องสั่งอย่างน้อย $60$ ตัว ตรวจที่ $60$ ตัว ราคาเฉลี่ย $\frac{3000 + 9000}{60} = 200$ บาทพอดี ที่ $50$ ตัวได้ $\frac{10500}{50} = 210$ บาท เกินจริง
</Steps>
</Example>

{/* check: solve_univariate_inequality((3000 + 150*x)/x <= 200, x, relational=False).intersect(Interval.open(0, oo)) == Interval(60, oo) and Rational(3000 + 150*60, 60) == 200 and Rational(3000 + 150*50, 50) == 210 */}

ตัวอย่างนี้ไม่ได้ขัดกับที่เตือนไว้ ความผิดพลาดในกล่องลองคิดก่อนเกิดจากการคูณด้วยนิพจน์ที่เป็นลบได้ ส่วนในโจทย์เสื้อรุ่น ความหมายของ $x$ รับประกันว่าเป็นบวก ก่อนคูณทุกครั้งให้ถามตัวเองว่ารู้เครื่องหมายของตัวคูณแน่หรือยัง

หน้าถัดไปเปลี่ยนจากตัวส่วนมาเป็นค่าสัมบูรณ์ ซึ่งก็ต้องแยกกรณีตามเครื่องหมายเหมือนกัน แต่มีภาพของระยะบนเส้นจำนวนช่วยให้คิดเร็วขึ้น

## สรุป

- หาค่าที่ทำให้ตัวส่วนเป็นศูนย์ก่อนลงมือ ค่าเหล่านี้ไม่เป็นคำตอบเด็ดขาด
- สมการเศษส่วน คูณด้วยตัวส่วนได้ แล้วตัดคำตอบแปลกปลอมที่เป็นค่าต้องห้าม
- อสมการเศษส่วน ห้ามคูณด้วยตัวส่วนที่ไม่รู้เครื่องหมาย ให้ย้ายข้าง รวมเป็นเศษส่วนเดียว แล้วใช้ตารางเครื่องหมาย
- รากของตัวส่วนเป็นจุดโปร่งเสมอ รากของตัวเศษรวมได้เมื่ออสมการมีเครื่องหมายเท่ากับ
- ถ้ารู้แน่ว่าตัวส่วนเป็นบวก คูณได้โดยทิศไม่เปลี่ยน
