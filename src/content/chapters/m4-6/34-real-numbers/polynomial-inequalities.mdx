ร้านน้ำผลไม้หน้าโรงเรียนประเมินว่า ถ้าตั้งราคาแก้วละ $x$ สิบบาท กำไรต่อวันเป็น $P(x)=(x-2)(8-x)$ ร้อยบาท ตั้งราคาถูกไปก็ขาดทุนเพราะไม่คุ้มต้นทุน ตั้งแพงไปก็ขาดทุนเพราะไม่มีคนซื้อ ถ้าต้องการกำไรเป็นบวก เราต้องหาทั้งช่วงของ $x$ ไม่ใช่หาเพียงค่าที่ทำให้กำไรศูนย์

สมการ $P(x) = 0$ ตอบแค่จุดเปลี่ยน คือ $x = 2$ กับ $x = 8$ แต่อสมการ $P(x) > 0$ ถามว่าระหว่างจุดเปลี่ยนเหล่านั้น ส่วนไหนที่กำไรเป็นบวก หน้านี้ใช้รากของสมการเป็นหลักไมล์แบ่งเส้นจำนวน แล้วดูเครื่องหมายในแต่ละช่วง

## ทบทวนสมบัติการไม่เท่ากัน

ในบทที่ 21 เราแก้อสมการเชิงเส้นด้วยสมบัติสามข้อ บวกหรือลบจำนวนเดียวกันทั้งสองข้าง ทิศไม่เปลี่ยน คูณหรือหารด้วยจำนวนบวก ทิศไม่เปลี่ยน แต่คูณหรือหารด้วยจำนวนลบ ทิศกลับ

ทำไมจำนวนลบจึงกลับทิศ ลองดู $2 < 5$ คูณ $-1$ ได้ $-2$ กับ $-5$ บนเส้นจำนวน การคูณ $-1$ คือการพลิกทุกจุดข้ามศูนย์เหมือนส่องกระจก จุดที่เคยอยู่ซ้ายกลายเป็นอยู่ขวา จึงได้ $-2 > -5$

ปัญหาของอสมการพหุนามคือ บ่อยครั้งเราอยากคูณหรือหารด้วยนิพจน์อย่าง $x - 2$ ซึ่งเป็นบวกบ้างลบบ้างแล้วแต่ค่า $x$ เราจึงไม่รู้ว่าทิศต้องกลับหรือไม่ ทางที่ปลอดภัยคือไม่หารเลย แต่ย้ายทุกอย่างมาข้างเดียว แยกตัวประกอบ แล้วดูเครื่องหมายของผลคูณ

## เขียนคำตอบเป็นช่วง

คำตอบของอสมการมักเป็นจำนวนจริงไม่รู้จบทั้งก้อน เขียนเป็นเซตแบบแจกแจงไม่ได้ จึงใช้สัญลักษณ์ **ช่วง** วงเล็บเหลี่ยมแปลว่ารวมจุดปลาย วงเล็บโค้งแปลว่าไม่รวม

| อสมการ | ช่วง | จุดปลาย |
|---|---|---|
| $a < x < b$ | $(a, b)$ | ไม่รวมทั้งสองข้าง |
| $a \le x \le b$ | $[a, b]$ | รวมทั้งสองข้าง |
| $a \le x < b$ | $[a, b)$ | รวมเฉพาะ $a$ |
| $x > a$ | $(a, \infty)$ | ไม่รวม $a$ |
| $x \le b$ | $(-\infty, b]$ | รวม $b$ |
| จำนวนจริงทุกตัว | $(-\infty, \infty)$ | |

ฝั่งที่เป็น $\infty$ ใช้วงเล็บโค้งเสมอ เพราะ $\infty$ ไม่ใช่จำนวน ไม่มีทางรวมไว้ในช่วงได้ ถ้าคำตอบมีสองก้อนแยกกัน ใช้ยูเนียน $\cup$ จากบทที่ 32 เชื่อม เช่น $x < -1$ หรือ $x > 3$ เขียนเป็น $(-\infty, -1) \cup (3, \infty)$

## รากแบ่งเส้นจำนวน

เริ่มจากตัวประกอบตัวเดียว $x - 1$ เป็นลบเมื่อ $x < 1$ เป็นศูนย์ที่ $x = 1$ และเป็นบวกเมื่อ $x > 1$ ตัวประกอบเชิงเส้นเปลี่ยนเครื่องหมายได้ที่รากของมันจุดเดียวเท่านั้น

ทีนี้คูณกันหลายตัว เครื่องหมายของผลคูณขึ้นกับจำนวนตัวประกอบที่เป็นลบ ลบเป็นจำนวนคู่ได้บวก ลบเป็นจำนวนคี่ได้ลบ ระหว่างรากสองตัวที่ติดกัน ไม่มีตัวประกอบไหนเปลี่ยนเครื่องหมาย ผลคูณจึงมีเครื่องหมายเดียวตลอดช่วง เลือกค่าทดสอบหนึ่งค่าก็รู้เครื่องหมายของทั้งช่วงได้

สำหรับกำลังคู่ เครื่องหมายสองฝั่งรากไม่เปลี่ยน เช่น $(x-1)^2$ เป็นบวกทั้งสองข้าง และเป็นศูนย์ที่ $x = 1$ จุดเดียว กำลังคี่ทำให้เครื่องหมายสลับ การลากเครื่องหมายสลับทุกครั้งโดยไม่ดูเลขชี้กำลังจึงผิดได้

## ขั้นตอนแก้อสมการพหุนาม

1. ย้ายทุกพจน์มาไว้ข้างเดียว ให้อีกข้างเป็นศูนย์ โดยรักษาทิศอสมการ
2. แยกตัวประกอบ ด้วยวิธีจากบทที่ 20 และ 22 หรือทฤษฎีบทตัวประกอบในหน้า 34.5 และทำให้สัมประสิทธิ์ของ $x$ ในทุกตัวประกอบเป็นบวก
3. ทำตารางเครื่องหมาย หาเครื่องหมายแต่ละช่วงด้วยค่าทดสอบ
4. เลือกช่วงตามเครื่องหมายที่ถาม แล้วพิจารณาจุดปลาย ถ้าเป็น $\le$ หรือ $\ge$ รวมรากได้

ห้ามหารอสมการด้วยนิพจน์ที่ยังไม่รู้เครื่องหมาย เช่นหารด้วย $x-2$ ทันที เพราะถ้ามันติดลบต้องกลับทิศอสมการ การคงผลคูณแล้วใช้ตารางเครื่องหมายปลอดภัยกว่า

## แก้อสมการด้วยตารางเครื่องหมาย

<Example n={1}>

แก้ $(x-1)(x-4)\le0$

<Steps reveal>
1. รากคือ $1$ และ $4$ แบ่งเส้นจำนวนเป็นสามช่วง คือ ซ้ายของ $1$ ระหว่าง $1$ กับ $4$ และขวาของ $4$
2. เลือกค่าทดสอบช่วงละหนึ่งค่า เลือกเลขที่คิดง่ายอย่าง $0, 2, 5$ ได้ $(0-1)(0-4) = 4$ บวก $(2-1)(2-4) = -2$ ลบ และ $(5-1)(5-4) = 4$ บวก
3. อสมการถามว่าผลคูณไม่มากกว่าศูนย์ คือเป็นลบหรือเป็นศูนย์ ช่วงที่เป็นลบคือช่วงกลาง
4. เครื่องหมาย $\le$ ยอมให้เป็นศูนย์ จึงรวมราก $1$ และ $4$ ได้ $x\in[1,4]$ ตรงกับช่วงที่ระบายในรูป
</Steps>
</Example>

{/* check: solve_univariate_inequality((x-1)*(x-4)<=0,x,relational=False) == Interval(1,4) */}
{/* check: [((x-1)*(x-4)).subs(x, v) for v in (0, 2, 5)] == [4, -2, 4] */}

<Example n={2}>

แก้ $x^2 > 2x + 3$

<Steps reveal>
1. ข้างขวายังไม่เป็นศูนย์ ตารางเครื่องหมายยังใช้ไม่ได้ ย้าย $2x + 3$ มาข้างซ้ายได้ $x^2 - 2x - 3 > 0$ การลบทั้งสองข้างไม่เปลี่ยนทิศ
2. แยกตัวประกอบ หาสองจำนวนที่คูณกันได้ $-3$ บวกกันได้ $-2$ คือ $-3$ กับ $1$ ได้ $(x - 3)(x + 1) > 0$
3. รากคือ $-1$ และ $3$ ทดสอบ $x = -2$ ได้ $(-5)(-1) = 5$ บวก $x = 0$ ได้ $(-3)(1) = -3$ ลบ $x = 4$ ได้ $(1)(5) = 5$ บวก
4. ต้องการบวกอย่างเดียว เครื่องหมาย $>$ ไม่รวมราก ได้ $x < -1$ หรือ $x > 3$ เขียนเป็น $(-\infty, -1) \cup (3, \infty)$
</Steps>
</Example>

{/* check: solve_univariate_inequality(x**2 > 2*x + 3, x, relational=False) == Union(Interval.open(-oo, -1), Interval.open(3, oo)) */}

<Example n={3}>

แก้ $(x+2)(x-1)^2>0$

<Steps reveal>
1. รากคือ $-2$ และ $1$ ตัว $(x - 1)^2$ เป็นกำลังสอง จึงเป็นบวกทุกที่ยกเว้นที่ $x = 1$ ซึ่งเป็นศูนย์
2. เมื่อ $x\ne1$ การคูณด้วยจำนวนบวกไม่เปลี่ยนเครื่องหมาย เครื่องหมายผลคูณจึงเหมือน $x+2$ คือบวกเมื่อ $x > -2$
3. แต่ที่ $x = 1$ ผลคูณเป็นศูนย์ ซึ่งไม่มากกว่าศูนย์ ต้องเจาะจุดนี้ออก
4. ได้ $x>-2$ แต่ $x\ne1$ เขียน $(-2,1)\cup(1,\infty)$ ถ้าทำตารางแบบสลับเครื่องหมายทุกราก จะได้ช่วงขวาของ $1$ เป็นลบ ซึ่งผิด
</Steps>
</Example>

{/* check: solve_univariate_inequality((x+2)*(x-1)**2>0,x,relational=False) == Union(Interval.open(-2,1),Interval.open(1,oo)) */}

## กลับไปที่ร้านน้ำผลไม้

<Example n={4}>

ร้านในตอนต้นหน้ามีกำไร $P(x)=(x-2)(8-x)$ ร้อยบาทเมื่อตั้งราคาแก้วละ $x$ สิบบาท ต้องตั้งราคาช่วงไหนจึงได้กำไรเป็นบวก

<Steps reveal>
1. ตัวประกอบ $8 - x$ มี $x$ ติดลบ ถ้าทำตารางตรงๆ ง่ายที่จะใส่เครื่องหมายผิด จึงเขียน $8 - x = -(x - 8)$ ได้ $P(x) = -(x - 2)(x - 8)$
2. อสมการ $-(x-2)(x-8) > 0$ คูณ $-1$ ทั้งสองข้าง ทิศต้องกลับ ได้ $(x - 2)(x - 8) < 0$
3. รากคือ $2$ กับ $8$ ผลคูณเป็นลบในช่วงกลางแบบเดียวกับตัวอย่าง 1 จึงได้ $2 < x < 8$ ไม่รวมราก เพราะที่รากกำไรเป็นศูนย์
4. แปลกลับเป็นราคา ร้านต้องตั้งราคามากกว่า $20$ บาทแต่น้อยกว่า $80$ บาทต่อแก้ว ตรวจที่ $x = 5$ ได้ $P = 3 \times 3 = 9$ คือกำไร $900$ บาท เป็นบวกจริง
</Steps>
</Example>

{/* check: solve_univariate_inequality((x-2)*(8-x) > 0, x, relational=False) == Interval.open(2, 8) and ((x-2)*(8-x)).subs(x, 5) == 9 */}

ถ้าตัวแปรไปอยู่ในตัวส่วน เช่น ต้นทุนเฉลี่ยต่อชิ้น ตารางเครื่องหมายยังใช้ได้ แต่มีจุดต้องห้ามเพิ่มขึ้นมา หน้าถัดไปจะดูเรื่องนี้

## สรุป

- คูณหรือหารด้วยจำนวนลบ ทิศอสมการกลับ จึงห้ามหารด้วยนิพจน์ที่ไม่รู้เครื่องหมาย
- เขียนคำตอบเป็นช่วง วงเล็บเหลี่ยมรวมจุดปลาย วงเล็บโค้งไม่รวม $\infty$ ใช้วงเล็บโค้งเสมอ
- รากแบ่งช่วงสำหรับตารางเครื่องหมาย ค่าทดสอบหนึ่งค่าบอกเครื่องหมายทั้งช่วง
- รากกำลังคู่ไม่ทำให้เครื่องหมายสลับ
- ตรวจว่าเครื่องหมายอสมการยอมให้รวมรากหรือไม่ แล้วแปลคำตอบกลับเป็นความหมายของโจทย์
