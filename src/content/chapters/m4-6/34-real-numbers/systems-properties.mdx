วัดเส้นทแยงมุมของกระดาษจัตุรัสด้านหนึ่งหน่วยได้ $\sqrt2$ หน่วย ตามทฤษฎีบทพีทาโกรัสในบทที่ 10 ลองวัดด้วยไม้บรรทัดจะได้ราว $1.41$ ใช้เครื่องคิดเลขได้ $1.41421356\ldots$ ไม่ว่าเพิ่มตำแหน่งทศนิยมไปเท่าไรก็ไม่จบ และไม่วนซ้ำ ตัวเลขนี้มีตำแหน่งชัดเจนบนเส้นจำนวน แต่เขียนเป็นเศษส่วนของจำนวนเต็มไม่ได้ จำนวนจริงจึงกว้างกว่าจำนวนที่เคยใช้ซื้อขายหรือนับของ

หน้านี้ทบทวนว่าจำนวนจริงประกอบด้วยอะไรบ้าง แล้วดูสมบัติที่เราใช้ทุกครั้งที่แก้สมการ โดยเฉพาะข้อที่มีเงื่อนไขซ่อนอยู่ ถ้าลืมเงื่อนไขนั้น คำตอบจะหายไปเงียบๆ โดยไม่มีใครเตือน

## แผนผังของระบบจำนวน

แต่ละชุดจำนวนเกิดขึ้นเพราะชุดเดิมทำบางอย่างไม่ได้ จำนวนนับใช้นับของ แต่ $3 - 5$ ไม่มีคำตอบในจำนวนนับ จึงต้องมีจำนวนเต็มลบ จำนวนเต็มลบกันได้เสมอ แต่ $3 \div 4$ ไม่ได้จำนวนเต็ม จึงต้องมีเศษส่วน แล้วพอวัดความยาวอย่างเส้นทแยงมุมข้างบน เศษส่วนก็ยังไม่พอ จึงต้องมีจำนวนอตรรกยะมาเติมช่องว่างบนเส้นจำนวน

<Def>
**จำนวนตรรกยะ** คือจำนวนที่เขียนในรูป $\frac{p}{q}$ ได้ เมื่อ $p, q$ เป็นจำนวนเต็มและ $q \ne 0$ จำนวนจริงที่ไม่เป็นจำนวนตรรกยะเรียกว่า **จำนวนอตรรกยะ** จำนวนตรรกยะกับจำนวนอตรรกยะรวมกันเป็นจำนวนจริง $\mathbb R$
</Def>

เงื่อนไข $q \ne 0$ ไม่ได้ใส่ไว้ให้ดูเป็นทางการ ถ้า $\frac{6}{0}$ มีค่าเป็นจำนวน $k$ สักตัว ก็ต้องได้ $0 \times k = 6$ แต่ศูนย์คูณอะไรก็ได้ศูนย์ จึงไม่มี $k$ ตัวไหนใช้ได้เลย การหารด้วยศูนย์จึงไม่มีความหมาย

## ดูจากทศนิยม

ในบทที่ 4 และบทที่ 11 เราเปลี่ยนทศนิยมซ้ำเป็นเศษส่วนได้ทุกตัว ทศนิยมสิ้นสุดก็เขียนเป็นเศษส่วนที่ตัวส่วนเป็น $10$ $100$ $1000$ ได้ทันที ทั้งสองแบบจึงเป็นจำนวนตรรกยะ แม้ทศนิยมซ้ำจะเขียนได้ไม่รู้จบ ส่วนทศนิยมที่ไม่รู้จบและไม่ซ้ำเป็นจำนวนอตรรกยะ

ทศนิยมซ้ำที่มีส่วนไม่ซ้ำนำหน้า เช่น $1.2333\ldots$ ทำให้หลายคนสะดุด ต้องคูณสองครั้งเพื่อให้หางที่ซ้ำตรงกันพอดี

<Example n={1}>

เขียน $N = 1.2333\ldots$ เป็นเศษส่วนอย่างต่ำ

<Steps reveal>
1. ส่วนที่ซ้ำคือเลข $3$ ซึ่งเริ่มที่ตำแหน่งที่สอง คูณ $10$ ก่อนเพื่อดันส่วนไม่ซ้ำไปอยู่หน้าจุด ได้ $10N = 12.333\ldots$
2. คูณ $10$ อีกครั้งให้ได้หางซ้ำชุดเดียวกัน $100N = 123.333\ldots$ ทำไมต้องสองครั้ง เพราะต้องการสองจำนวนที่หลังจุดเหมือนกันทุกหลัก
3. ลบกัน $100N - 10N = 123.333\ldots - 12.333\ldots = 111$ หางที่ไม่รู้จบหักล้างกันหมด เหลือ $90N = 111$
4. ได้ $N = \frac{111}{90} = \frac{37}{30}$ ตรวจด้วยการหาร $37 \div 30 = 1.2333\ldots$ ตรงกัน
</Steps>
</Example>

{/* check: 100*Rational(37, 30) - 10*Rational(37, 30) == 111 and Rational(111, 90) == Rational(37, 30) */}
{/* check: Rational(37, 30) == Rational(12, 10) + Rational(1, 30) */}

<Example n={2}>

จัดประเภท $\sqrt{36}$ $0.125$ และ $\sqrt3$

<Steps reveal>
1. อย่าตัดสินจากเครื่องหมายราก ให้หาค่าก่อน $\sqrt{36} = 6$ เพราะ $6^2 = 36$ จึงเป็นจำนวนนับ จำนวนเต็ม และจำนวนตรรกยะพร้อมกัน ตามกรอบซ้อนในแผนผัง
2. $0.125$ เป็นทศนิยมสิ้นสุด เขียนได้ $\frac{125}{1000} = \frac{1}{8}$ จึงเป็นจำนวนตรรกยะ แต่ไม่เป็นจำนวนเต็ม
3. $3$ ไม่ใช่กำลังสองของจำนวนเต็มใด เพราะ $1^2 = 1$ และ $2^2 = 4$ ข้ามไปแล้ว $\sqrt3$ จึงเป็นอตรรกยะ ทั้งสามจำนวนเป็นจำนวนจริง
</Steps>
</Example>

{/* check: sqrt(36)==6 and Rational("0.125")==Rational(1,8) */}
{/* check: sqrt(3).is_rational is False */}

<Reveal summary="ทำไม √2 จึงเขียนเป็นเศษส่วนไม่ได้">

ใช้การพิสูจน์โดยข้อขัดแย้งจากบทที่ 33 สมมติว่า $\sqrt2 = \frac{p}{q}$ เป็นเศษส่วนอย่างต่ำ ยกกำลังสองได้ $p^2 = 2q^2$ ดังนั้น $p^2$ เป็นเลขคู่ และ $p$ ต้องเป็นเลขคู่ด้วย เพราะเลขคี่ยกกำลังสองได้เลขคี่ เขียน $p = 2m$ แทนกลับได้ $4m^2 = 2q^2$ หรือ $q^2 = 2m^2$ จึงได้ว่า $q$ เป็นเลขคู่ด้วย ทั้ง $p$ และ $q$ หารด้วย $2$ ลงตัว ขัดกับที่บอกว่าเป็นเศษส่วนอย่างต่ำ ข้อสมมติจึงผิด $\sqrt2$ เป็นอตรรกยะ

</Reveal>

<Think>

ผลบวกของอตรรกยะสองจำนวนต้องเป็นอตรรกยะไหม

<Reveal>
ไม่จำเป็น เช่น $\sqrt2+(-\sqrt2)=0$ เป็นตรรกยะ แต่ $\sqrt2+\sqrt2=2\sqrt2$ เป็นอตรรกยะ ต้องพิจารณาค่าจริงของผลรวม ผลคูณก็เหมือนกัน $\sqrt2 \times \sqrt2 = 2$ เป็นตรรกยะ เซตของจำนวนอตรรกยะจึงไม่มีสมบัติปิดของการบวกและการคูณ
</Reveal>
</Think>

<Think>

เพื่อนบอกว่า $\pi = \frac{22}{7}$ ดังนั้น $\pi$ เป็นจำนวนตรรกยะ ถูกไหม

<Reveal>
ไม่ถูก $\frac{22}{7} = 3.142857\ldots$ เป็นแค่ค่าประมาณที่ใกล้ $\pi = 3.141592\ldots$ สองตัวต่างกันตั้งแต่ทศนิยมตำแหน่งที่สาม $\pi$ เป็นอตรรกยะ ค่าประมาณที่เป็นเศษส่วนใช้คำนวณได้ แต่ไม่ได้เปลี่ยนชนิดของจำนวน
</Reveal>
</Think>

## สมบัติที่ใช้ย้ายและจัดรูป

<Thm label="สมบัติของจำนวนจริง">

เมื่อ $a, b, c$ เป็นจำนวนจริงใดๆ

- **ปิด** $a + b$ และ $ab$ เป็นจำนวนจริง
- **สลับที่** $a + b = b + a$ และ $ab = ba$
- **เปลี่ยนหมู่** $(a + b) + c = a + (b + c)$ และ $(ab)c = a(bc)$
- **เอกลักษณ์** $a + 0 = a$ และ $a \times 1 = a$
- **ตัวผกผัน** ทุก $a$ มี $-a$ ที่ $a + (-a) = 0$ และทุก $a \ne 0$ มี $\frac{1}{a}$ ที่ $a \times \frac{1}{a} = 1$
- **แจกแจง** $a(b + c) = ab + ac$

</Thm>

สมบัติเหล่านี้ดูธรรมดา แต่ทุกขั้นของการแก้สมการคือการใช้มันโดยไม่รู้ตัว คำว่า ย้ายข้าง ที่ใช้กันจริงๆ คือการบวกตัวผกผันการบวกเข้าทั้งสองข้าง ส่วน ย้ายไปหาร คือการคูณด้วยตัวผกผันการคูณทั้งสองข้าง

ข้อที่ต้องจับตาคือตัวผกผันการคูณ ทุกจำนวนมีตัวตรงข้าม แต่ $0$ ไม่มีตัวผกผันการคูณ เพราะไม่มีจำนวนไหนคูณ $0$ แล้วได้ $1$ การ ย้ายไปหาร จึงทำได้เฉพาะเมื่อแน่ใจว่าตัวที่ย้ายไม่เป็นศูนย์ ส่วนการลบและการหารไม่มีสมบัติสลับที่ $5 - 2 \ne 2 - 5$ จึงห้ามสลับลำดับเวลาเจอเครื่องหมายลบ

<Example n={3}>

แก้สมการ $3x + 5 = 20$ แล้วบอกว่าแต่ละขั้นใช้สมบัติอะไร

<Steps reveal>
1. บวก $-5$ ซึ่งเป็นตัวผกผันการบวกของ $5$ ทั้งสองข้าง ได้ $3x + 5 + (-5) = 20 + (-5)$ ฝั่งซ้ายเหลือ $3x + 0$
2. ใช้สมบัติเอกลักษณ์การบวก $3x + 0 = 3x$ จึงได้ $3x = 15$
3. คูณ $\frac13$ ทั้งสองข้าง ทำได้เพราะ $3 \ne 0$ จึงมีตัวผกผัน ได้ $\frac13 \cdot 3x = 1 \cdot x = x$ และ $\frac13 \cdot 15 = 5$
4. ได้ $x = 5$ ตรวจ $3(5) + 5 = 20$ จริง
</Steps>
</Example>

{/* check: roots(3*x + 5 - 20) == [5] and 3*5 + 5 == 20 */}

## การหารทำให้คำตอบหายอย่างไร

การตัดตัวประกอบจากสองข้างของสมการคือการคูณด้วยตัวผกผันของตัวนั้น จึงทำได้เมื่อตัวนั้นไม่เป็นศูนย์ ถ้าตัวประกอบมีตัวแปร เราไม่รู้ล่วงหน้าว่ามันเป็นศูนย์หรือไม่ ต้องแยกกรณีศูนย์ก่อน ไม่เช่นนั้นอาจทำคำตอบหาย เครื่องมือที่ปลอดภัยกว่าคือสมบัติผลคูณเป็นศูนย์ ถ้า $ab = 0$ แล้ว $a = 0$ หรือ $b = 0$

<Example n={4}>

แก้ $x^2=3x$ โดยไม่สูญเสียคำตอบ

<Steps reveal>
1. ย้าย $3x$ มาฝั่งซ้ายให้อีกข้างเป็นศูนย์ ได้ $x^2-3x=0$ ทำไมต้องให้ข้างหนึ่งเป็นศูนย์ เพราะสมบัติผลคูณเป็นศูนย์ใช้ได้กับศูนย์เท่านั้น
2. ดึงตัวร่วม $x$ ได้ $x(x-3)=0$ ผลคูณเป็นศูนย์จึงได้ $x=0$ หรือ $x-3=0$
3. ได้ $x=0$ หรือ $x=3$ ตรวจ $0^2 = 3(0)$ และ $3^2 = 3(3)$ จริงทั้งคู่
4. ถ้าหารด้วย $x$ ตั้งแต่แรกจะเหลือเพียง $x=3$ เพราะการหารแอบตั้งเงื่อนไข $x \ne 0$ ไว้ คำตอบ $x = 0$ จึงถูกตัดทิ้งโดยไม่รู้ตัว
</Steps>
</Example>

{/* check: roots(x**2-3*x)==[0,3] */}

<Example n={5}>

แก้ $(x - 2)(x + 1) = 4(x - 2)$

<Steps reveal>
1. ทั้งสองข้างมี $x - 2$ น่าตัดทิ้ง แต่ $x - 2$ เป็นศูนย์ได้เมื่อ $x = 2$ จึงยังไม่ตัด
2. ย้ายทุกอย่างมาฝั่งซ้าย $(x - 2)(x + 1) - 4(x - 2) = 0$ แล้วดึง $x - 2$ เป็นตัวร่วมด้วยสมบัติการแจกแจง ได้ $(x - 2)\big[(x + 1) - 4\big] = 0$
3. จัดในวงเล็บใหญ่ได้ $(x - 2)(x - 3) = 0$ จึงได้ $x = 2$ หรือ $x = 3$
4. ตรวจ $x = 2$ ข้างซ้าย $0 \times 3 = 0$ ข้างขวา $4 \times 0 = 0$ จริง ถ้าตัด $x - 2$ ตั้งแต่ขั้นแรกจะได้ $x + 1 = 4$ เหลือแค่ $x = 3$
</Steps>
</Example>

{/* check: roots((x - 2)*(x + 1) - 4*(x - 2)) == [2, 3] */}

การหารด้วยตัวแปรทำได้ถ้าตั้งกรณี $x\ne0$ ก่อน แล้วกลับไปตรวจกรณี $x=0$ แยกต่างหาก วิธีแยกตัวประกอบมักทำให้เงื่อนไขอยู่ในคำตอบโดยไม่ต้องแยกหลายย่อหน้า

<Think>

ให้ $a = b$ แล้วทำต่อแบบนี้ $a^2 = ab$ จึงได้ $a^2 - b^2 = ab - b^2$ แยกตัวประกอบได้ $(a + b)(a - b) = b(a - b)$ ตัด $a - b$ ได้ $a + b = b$ แทน $a = b$ ได้ $2b = b$ สรุปว่า $2 = 1$ ผิดที่ขั้นไหน

<Reveal>
ผิดตอนตัด $a - b$ เพราะ $a = b$ ทำให้ $a - b = 0$ การตัดคือการคูณด้วยตัวผกผันของศูนย์ ซึ่งไม่มีอยู่จริง ทุกขั้นก่อนหน้านั้นถูกหมด ข้อผิดพลาดนี้เป็นตัวเดียวกับที่ทำให้คำตอบ $x = 0$ หายในตัวอย่าง 4

## สรุป

- ตรรกยะเขียนเป็นเศษส่วนจำนวนเต็มที่ตัวส่วนไม่เป็นศูนย์ได้ ทศนิยมสิ้นสุดและทศนิยมซ้ำเป็นตรรกยะ
- รากบางค่าเป็นจำนวนเต็ม ต้องหาค่าก่อนจัดประเภท
- ย้ายข้างคือการบวกตัวผกผัน ย้ายไปหารคือการคูณตัวผกผัน ซึ่งศูนย์ไม่มี
- ห้ามหารด้วยตัวแปรโดยไม่ตรวจศูนย์ ใช้สมบัติผลคูณเป็นศูนย์แทน
