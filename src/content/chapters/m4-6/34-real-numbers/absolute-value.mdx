น้ำหนักสินค้าอาจคลาดจากเป้าหมาย $500$ กรัมได้ไม่เกิน $4$ กรัม ทั้งน้ำหนักต่ำกว่าและสูงกว่ายอมรับได้ เงื่อนไขนี้ใช้ระยะจากเป้าหมาย ซึ่งค่าสัมบูรณ์บันทึกได้ด้วยนิพจน์เดียว ถ้าไม่ใช้ค่าสัมบูรณ์ ต้องเขียนเป็นสองเงื่อนไข คือ หนักเกินได้ไม่เกิน $4$ กรัม และ เบากว่าได้ไม่เกิน $4$ กรัม

ในบทที่ 1 เราใช้ค่าสัมบูรณ์บอกว่าจำนวนหนึ่งอยู่ห่างจากศูนย์เท่าไร หน้านี้ขยายไปเป็นระยะระหว่างสองจุดใดๆ บนเส้นจำนวน แล้วใช้ภาพของระยะแก้สมการและอสมการ

## ระยะไม่มีเครื่องหมายลบ

<Def>
$|x|=x$ เมื่อ $x\ge0$ และ $|x|=-x$ เมื่อ $x<0$ ดังนั้น $|x-a|$ คือระยะระหว่าง $x$ กับ $a$ บนเส้นจำนวน มีค่าไม่ติดลบเสมอ
</Def>

นิยามบรรทัดที่สองทำให้หลายคนงง $-x$ ดูเหมือนเป็นลบ แต่บรรทัดนี้ใช้เฉพาะเมื่อ $x$ เป็นลบอยู่แล้ว เช่น $x = -6$ ได้ $-x = -(-6) = 6$ การใส่เครื่องหมายลบหน้าจำนวนลบคือการกลับให้เป็นบวก นิยามจึงพูดว่า ถ้าเป็นบวกหรือศูนย์ก็ใช้ตามเดิม ถ้าเป็นลบก็กลับเครื่องหมาย

ทำไม $|x - a|$ จึงเป็นระยะ ระยะระหว่าง $3$ กับ $7$ คือ $4$ ลบทางไหนก็ได้ $7 - 3 = 4$ แต่ $3 - 7 = -4$ ค่าสัมบูรณ์ตัดเครื่องหมายทิ้ง ทำให้ $|7 - 3| = |3 - 7| = 4$ เหมือนกัน เราจึงไม่ต้องสนว่าจุดไหนอยู่ซ้ายจุดไหนอยู่ขวา

เมื่อ $r>0$ สมการ $|x-a|=r$ มีจุดสองด้านคือ $x=a-r$ และ $x=a+r$ ถ้า $r=0$ มีจุดเดียว ส่วนถ้า $r<0$ ไม่มีคำตอบ เพราะระยะติดลบไม่ได้

<Example n={1}>

แก้ $|2x-3|=5$

<Steps reveal>
1. ค่าสัมบูรณ์เป็น $5$ แปลว่าข้างในอยู่ห่างศูนย์ $5$ หน่วย ข้างในจึงเป็นได้ทั้ง $5$ และ $-5$
2. จาก $2x-3=5$ ได้ $2x = 8$ จึงได้ $x=4$
3. จาก $2x-3=-5$ ได้ $2x = -2$ จึงได้ $x=-1$
4. แทนกลับ $|2(4) - 3| = |5| = 5$ และ $|2(-1) - 3| = |-5| = 5$ จริงทั้งคู่ คำตอบคือ $-1$ และ $4$
</Steps>
</Example>

{/* check: solve(Abs(2*x-3)-5,x) == [-1,4] */}

<Example n={2}>

แก้ $|x - 4| = 2x - 5$

<Steps reveal>
1. ข้างขวามีตัวแปร จึงไม่รู้ว่าเป็นบวกหรือลบ ใช้นิยามแยกกรณีตามเครื่องหมายของข้างใน $x - 4$
2. กรณี $x \ge 4$ ได้ $|x - 4| = x - 4$ สมการเป็น $x - 4 = 2x - 5$ ได้ $x = 1$ แต่ $1$ ไม่อยู่ในกรณี $x \ge 4$ ต้องทิ้ง
3. กรณี $x < 4$ ได้ $|x - 4| = -(x - 4) = 4 - x$ สมการเป็น $4 - x = 2x - 5$ ได้ $3x = 9$ จึงได้ $x = 3$ ซึ่งอยู่ในกรณี $x < 4$ จริง
4. ตรวจ $|3 - 4| = 1$ และ $2(3) - 5 = 1$ เท่ากัน คำตอบมีตัวเดียวคือ $x = 3$ ถ้าลองแทน $x = 1$ จะได้ $|1 - 4| = 3$ แต่ $2(1) - 5 = -3$ ไม่เท่ากัน ยืนยันว่าต้องทิ้งจริง
</Steps>
</Example>

{/* check: solve(Abs(x - 4) - (2*x - 5), x) == [3] and abs(1 - 4) != 2*1 - 5 */}

<Think>

เพื่อนแก้ $|x + 1| = -2$ ได้ $x + 1 = 2$ หรือ $x + 1 = -2$ ตอบ $x = 1$ และ $x = -3$ ถูกไหม

<Reveal>
ไม่ถูก ค่าสัมบูรณ์เป็นระยะ ไม่มีทางเท่ากับ $-2$ สมการนี้ไม่มีคำตอบ แทน $x = 1$ ได้ $|2| = 2$ ไม่ใช่ $-2$ ก่อนแยกกรณี ให้ดูข้างขวาก่อนทุกครั้งว่าติดลบได้หรือไม่
</Reveal>
</Think>

<Example n={3}>

น้ำหนัก $w$ ต้องอยู่ห่าง $500$ กรัมไม่เกิน $4$ กรัม เขียนช่วงที่ยอมรับได้

<Steps reveal>
1. ระยะจาก $w$ ถึง $500$ คือ $|w-500|$ ไม่เกิน $4$ แปลเป็น $|w-500|\le4$
2. ระยะไม่เกิน $4$ แปลว่า $w - 500$ อยู่ระหว่าง $-4$ ถึง $4$ ได้ $-4\le w-500\le4$
3. บวก $500$ ทุกส่วน ทิศไม่เปลี่ยน ได้ $496\le w\le504$ กรัม รวมจุดปลาย เพราะ ไม่เกิน ยอมให้เท่ากับ
4. เขียนเป็นช่วง $[496, 504]$ สังเกตว่า $500$ คือจุดกลางช่วง และ $4$ คือครึ่งหนึ่งของความกว้างช่วง
</Steps>
</Example>

{/* check: (500-4,500+4)==(496,504) */}

<Example n={4}>

แก้ $|2x + 1| > 5$

<Steps reveal>
1. ค่าสัมบูรณ์มากกว่า $5$ คือข้างในอยู่ภายนอกช่วง $[-5, 5]$ ได้ $2x + 1 > 5$ หรือ $2x + 1 < -5$
2. จาก $2x + 1 > 5$ ได้ $x > 2$
3. จาก $2x + 1 < -5$ ได้ $2x < -6$ จึงได้ $x < -3$
4. เชื่อมด้วย หรือ ได้ $(-\infty, -3) \cup (2, \infty)$ ไม่รวมจุดปลายเพราะเป็น $>$ ตรวจ $x = 0$ ซึ่งไม่อยู่ในคำตอบ ได้ $|1| = 1$ ไม่มากกว่า $5$ จริง
</Steps>
</Example>

{/* check: solve_univariate_inequality(Abs(2*x + 1) > 5, x, relational=False) == Union(Interval.open(-oo, -3), Interval.open(2, oo)) */}

ข้อผิดพลาดที่พบบ่อยคือเขียน $-5 > 2x + 1 > 5$ ซึ่งไม่มีจำนวนไหนทำให้จริงได้ เพราะไม่มีจำนวนที่ทั้งน้อยกว่า $-5$ และมากกว่า $5$ พร้อมกัน ภายนอกต้องแยกเป็นสองอสมการเสมอ

<Think>

$|x+y|=|x|+|y|$ เสมอหรือไม่

<Reveal>
ไม่เสมอ เช่น $x=3$ $y=-3$ ข้างซ้ายเป็น $0$ ข้างขวาเป็น $6$ สมบัติทั่วไปคือ $|x+y|\le|x|+|y|$ เท่ากันเมื่อ $x$ กับ $y$ ไม่มีเครื่องหมายตรงข้ามกัน
</Reveal>
</Think>

## ระยะเท่ากันจากสองจุด

เมื่อค่าสัมบูรณ์สองข้างเป็นระยะ ลองหาความหมายทางเรขาคณิตก่อนแยกกรณียาว จุดที่อยู่ห่างจากปลายสองด้านเท่ากันบนเส้นจำนวนคือจุดกึ่งกลาง

<Example n={5}>

แก้ $|x-2|=|x-8|$

<Steps reveal>
1. ข้างซ้ายคือระยะจาก $x$ ถึง $2$ ข้างขวาคือระยะจาก $x$ ถึง $8$ โจทย์ถามจุดที่ห่างสองจุดนี้เท่ากัน
2. จุดเดียวบนเส้นจำนวนที่ทำได้คือจุดกึ่งกลาง $(2+8)/2=5$ ถ้าเลื่อนไปทางไหน จะใกล้จุดหนึ่งมากขึ้นและไกลอีกจุดหนึ่ง
3. ตรวจที่ $5$ ได้ $|5-2|=|5-8|=3$ จึงเป็นคำตอบ
</Steps>
</Example>

{/* check: solve(Abs(x-2)-Abs(x-8),x)==[5] */}

ถ้าจะทำพีชคณิต ยกกำลังสองทั้งสองข้างได้เพราะทั้งสองข้างไม่ติดลบ จะได้ $(x-2)^2=(x-8)^2$ แล้วแก้สมการเชิงเส้นหลังตัดพจน์กำลังสอง วิธีระยะให้ภาพก่อนและวิธีพีชคณิตใช้ตรวจได้

## ค่าสัมบูรณ์หลายชุด

กรณีมีค่าสัมบูรณ์หลายชุด แบ่งช่วงที่แต่ละวงเล็บเปลี่ยนเครื่องหมายก่อน แล้วแทนนิยามในแต่ละช่วง หลีกเลี่ยงการถอดขีดโดยเปลี่ยนเป็นเครื่องหมายบวกทั้งหมด หลักคิดเหมือนตารางเครื่องหมายในหน้า 34.2

<Example n={6}>

แก้ $|x - 1| + |x + 2| = 5$

<Steps reveal>
1. ข้างในเป็นศูนย์ที่ $x = 1$ และ $x = -2$ แบ่งเส้นจำนวนเป็นสามช่วง
2. ช่วง $x < -2$ ข้างในทั้งสองติดลบ ได้ $(1 - x) + (-x - 2) = -2x - 1 = 5$ จึงได้ $x = -3$ อยู่ในช่วงนี้จริง
3. ช่วง $-2 \le x < 1$ ได้ $(1 - x) + (x + 2) = 3$ ซึ่งไม่เท่ากับ $5$ ช่วงนี้จึงไม่มีคำตอบ
4. ช่วง $x \ge 1$ ได้ $(x - 1) + (x + 2) = 2x + 1 = 5$ จึงได้ $x = 2$ อยู่ในช่วงนี้จริง คำตอบคือ $-3$ และ $2$
</Steps>
</Example>

{/* check: solve(Abs(x - 1) + Abs(x + 2) - 5, x) == [-3, 2] */}

ภาพระยะอธิบายขั้นที่ 3 ได้ทันที โจทย์ถามจุดที่ระยะถึง $1$ บวกระยะถึง $-2$ ได้ $5$ ถ้าจุดอยู่ระหว่าง $-2$ กับ $1$ ผลรวมเท่ากับระยะระหว่างสองจุดนั้นพอดีคือ $3$ เสมอ จึงต้องออกไปข้างนอกฝั่งละ $1$ หน่วย ได้ $-3$ และ $2$

หน้าถัดไปกลับไปที่พหุนามดีกรีสูง ซึ่งต้องแยกตัวประกอบให้ได้ก่อนจึงจะใช้ตารางเครื่องหมายในหน้า 34.2 ได้

## สรุป

- ค่าสัมบูรณ์แทนระยะและไม่ติดลบ $|x - a|$ คือระยะจาก $x$ ถึง $a$
- ถ้าข้างขวามีตัวแปร แยกกรณีตามนิยาม แล้วทิ้งคำตอบที่ไม่อยู่ในกรณีของตัวเอง
- อยู่ภายในช่วงใช้ และ ภายนอกใช้ หรือ
- ค่าสัมบูรณ์หลายชุด แบ่งช่วงตามจุดที่ข้างในเป็นศูนย์ แล้วแทนนิยามทีละช่วง
