แผนที่โรงเรียนแทนอาคารสองหลังด้วยจุดบนตาราง การนับช่องแนวนอนบวกแนวตั้งเป็นระยะเดินตามทางฉาก แต่ระยะตรงต้องใช้พีทาโกรัส

ถ้าโรงอาหารอยู่ที่จุด $(1, 2)$ และห้องสมุดอยู่ที่ $(7, 10)$ บนแผนที่ที่หนึ่งช่องยาว $10$ เมตร นักเรียนที่เดินตามถนนแนวนอนแล้วเลี้ยวขึ้นแนวตั้งต้องเดิน $6 + 8 = 14$ ช่อง แต่คนที่เดินตัดสนามตรงไปเดินแค่ $10$ ช่อง หน้านี้จะหาระยะตรงแบบนี้จากพิกัดอย่างเดียว โดยไม่ต้องวาดรูปให้ตรงมาตราส่วน และหาจุดที่อยู่ตรงกลางทางพอดี เช่นตำแหน่งตั้งจุดพักระหว่างสองอาคาร

{/* check: 6 + 8 == 14 and sqrt(6**2 + 8**2) == 10 */}

แนวคิดนี้คือหัวใจของ**เรขาคณิตวิเคราะห์** เราแทนรูปเรขาคณิตด้วยพิกัดและสมการ แล้วใช้พีชคณิตตอบคำถามเรื่องรูป ทั้งบทนี้จะใช้สูตรระยะในหน้านี้ซ้ำแล้วซ้ำอีก ตั้งแต่ระยะจากจุดถึงเส้นตรงไปจนถึงวงกลม พาราโบลา วงรี และไฮเพอร์โบลา

## จากสามเหลี่ยมมุมฉากสู่สูตร

ในบทที่ 10 เราหาระยะระหว่างจุดสองจุดบนตารางด้วยการวาดสามเหลี่ยมมุมฉาก ตอนนี้ทำแบบเดียวกันแต่ใช้ตัวแปรแทนตัวเลข จะได้สูตรที่ใช้กับจุดคู่ไหนก็ได้

ให้จุด $A(x_1, y_1)$ กับ $B(x_2, y_2)$ ลากเส้นแนวนอนผ่าน $A$ และเส้นแนวตั้งผ่าน $B$ มาพบกันที่มุมฉาก ขาแนวนอนยาวเท่ากับ $|x_2 - x_1|$ และขาแนวตั้งยาวเท่ากับ $|y_2 - y_1|$ ต้องใช้ค่าสัมบูรณ์เพราะความยาวไม่ติดลบ เมื่อยกกำลังสอง ค่าสัมบูรณ์กับผลต่างมีค่ากำลังสองเท่ากัน ทฤษฎีบทพีทาโกรัสจึงให้

$$AB=\sqrt{(x_2-x_1)^2+(y_2-y_1)^2}$$

ผลต่างอาจติดลบแต่กำลังสองไม่ติดลบ ระยะสุดท้ายเลือกค่ารากบวก การสลับจุดไม่เปลี่ยนระยะ เพราะผลต่างเปลี่ยนเครื่องหมายพร้อมกัน เช่น $(5 - 2)^2$ กับ $(2 - 5)^2$ ได้ $9$ เท่ากัน จึงไม่ต้องกังวลว่าจุดไหนคือจุดแรก

ทำไมต้องยกกำลังสองก่อนแล้วค่อยถอดราก ไม่บวกผลต่างตรงๆ ผลบวก $|x_2 - x_1| + |y_2 - y_1|$ คือระยะเดินตามขาสองข้างของสามเหลี่ยม ซึ่งยาวกว่าด้านตรงข้ามมุมฉากเสมอ ยกเว้นเมื่อจุดสองจุดอยู่บนเส้นแนวนอนหรือแนวตั้งเดียวกัน ขาข้างหนึ่งจะยาวศูนย์ และสองระยะนี้เท่ากันพอดี

## ตัวอย่างระยะทาง

<Example n={1}>

หา $AB$ และจุดกึ่งกลางเมื่อ $A=(-1,2)$ $B=(5,10)$

<Steps reveal>
1. ผลต่างพิกัด $x$ คือ $5 - (-1) = 6$ ผลต่างพิกัด $y$ คือ $10 - 2 = 8$ ระวังการลบจำนวนลบ $5 - (-1)$ เท่ากับ $5 + 1$ ไม่ใช่ $4$
2. ระยะ $\sqrt{6^2+8^2}=\sqrt{36 + 64} = \sqrt{100} = 10$ ได้ตัวเลขลงตัวเพราะ $6, 8, 10$ เป็นสามจำนวนพีทาโกรัส
3. จุดกึ่งกลางเฉลี่ยพิกัดแยกกัน $(({-1}+5)/2,(2+10)/2)=(2,6)$ ที่มาของวิธีนี้อธิบายในหัวข้อถัดไป
</Steps>
</Example>

{/* check: sqrt(6**2+8**2)==10 and ((-1+5)/2,(2+10)/2)==(2,6) */}

ระยะส่วนใหญ่ไม่ลงตัว ให้ตอบในรูปกรณฑ์ที่ทำให้อย่างง่ายแล้ว ตามที่เรียนในบทที่ 11 ถ้าโจทย์เป็นเรื่องจริงที่ต้องใช้ตัวเลข ค่อยประมาณเป็นทศนิยม

<Example n={2}>

บนแผนที่ที่หนึ่งหน่วยยาว $100$ เมตร บ้านอยู่ที่ $P(1, -2)$ ร้านสะดวกซื้ออยู่ที่ $Q(4, 7)$ ระยะตรงจากบ้านถึงร้านกี่เมตร

<Steps reveal>
1. ผลต่างพิกัด $x$ คือ $4 - 1 = 3$ ผลต่างพิกัด $y$ คือ $7 - (-2) = 9$
2. $PQ = \sqrt{3^2 + 9^2} = \sqrt{9 + 81} = \sqrt{90}$
3. ทำให้อย่างง่าย $\sqrt{90} = \sqrt{9 \times 10} = 3\sqrt{10}$ หน่วย ดึงตัวประกอบที่เป็นกำลังสองสมบูรณ์ออกมาก่อน คำตอบจึงอ่านง่ายขึ้น
4. แปลงเป็นเมตร $3\sqrt{10} \approx 3 \times 3.162 = 9.49$ หน่วย คูณ $100$ ได้ประมาณ $949$ เมตร
</Steps>
</Example>

{/* check: sqrt(3**2 + 9**2) == 3*sqrt(10) and abs(300*sqrt(10) - 949) < 1 */}

<Reveal>
ระยะตรงเท่ากับ $5$ จากพีทาโกรัส ส่วน $7$ เป็นระยะตามเส้นทางฉากสองช่วง ต้องอ่านว่าถามระยะชนิดใด
</Reveal>

## จุดกึ่งกลาง

เริ่มจากเส้นจำนวนก่อน จุดกึ่งกลางระหว่าง $2$ กับ $8$ คือ $5$ ซึ่งได้จากเดินจาก $2$ ไปครึ่งหนึ่งของระยะ $6$ คือ $2 + 3 = 5$ หรือคิดอีกแบบคือค่าเฉลี่ย $\tfrac{2 + 8}{2} = 5$ สองวิธีให้ค่าเดียวกันเสมอ เพราะ $x_1 + \tfrac{x_2 - x_1}{2} = \tfrac{x_1 + x_2}{2}$

{/* check: 2 + Rational(8 - 2, 2) == Rational(2 + 8, 2) == 5 */}

บนระนาบก็ทำแบบเดียวกัน ถ้าเดินจาก $A$ ไป $B$ ครึ่งทาง พิกัดแต่ละแกนเพิ่มครึ่งหนึ่งของผลต่าง ในรูปข้างบน เส้นประจาก $M$ ลงมาแบ่งขาแนวนอนเป็นสองส่วนเท่ากัน เพราะสามเหลี่ยมเล็กคล้ายกับสามเหลี่ยมใหญ่ด้วยอัตราส่วน $1 : 2$ ตามบทที่ 24 จึงได้

$$M\left(\frac{x_1+x_2}{2},\ \frac{y_1+y_2}{2}\right)$$

สูตรนี้ใช้ได้กับเส้นเอียง แนวนอน และแนวตั้ง ไม่จำเป็นต้องวาดกราฟตรงมาตราส่วน

ถ้าทราบจุดกึ่งกลางและปลายหนึ่งด้าน สามารถแก้สมการพิกัดหาปลายอีกด้านได้ ตรวจด้วยการเฉลี่ยกลับ และตรวจว่าระยะ $AM=MB$ จริง

<Example n={3}>

จุดกึ่งกลางคือ $(3,-1)$ และปลายหนึ่งคือ $(1,4)$ หาปลายอีกด้าน

<Steps reveal>
1. ให้ปลายอีกด้านเป็น $(u,v)$ เงื่อนไขจุดกึ่งกลางให้สองสมการแยกกันตามแกน $(1+u)/2=3$ และ $(4+v)/2=-1$
2. คูณสองทั้งสองข้าง ได้ $1 + u = 6$ และ $4 + v = -2$ จึงได้ $u=5$ และ $v=-6$ ปลายอีกด้านคือ $(5,-6)$
3. มองอีกแบบ จาก $(1, 4)$ ไป $(3, -1)$ พิกัด $x$ เพิ่ม $2$ พิกัด $y$ ลด $5$ ปลายอีกด้านต้องห่างจากจุดกึ่งกลางเท่าเดิมในทิศเดิม จึงเป็น $(3 + 2, -1 - 5) = (5, -6)$ ตรงกัน
4. ตรวจด้วยการเฉลี่ยกลับ $\left(\tfrac{1 + 5}{2}, \tfrac{4 - 6}{2}\right) = (3, -1)$ ถูกต้อง
</Steps>
</Example>

{/* check: ((1+5)/2,(4-6)/2)==(3,-1) */}

<Think>

เพื่อนหาจุดกึ่งกลางของ $(2, 1)$ กับ $(8, 5)$ ได้ $(3, 2)$ โดยคิดว่า $\tfrac{8 - 2}{2} = 3$ และ $\tfrac{5 - 1}{2} = 2$ ผิดตรงไหน

<Reveal>
เพื่อนเอาผลต่างหารสอง ซึ่งได้ครึ่งหนึ่งของระยะที่ต้องเดิน ไม่ใช่ตำแหน่ง ต้องบวกกับจุดเริ่มต้นด้วย $2 + 3 = 5$ และ $1 + 2 = 3$ หรือใช้สูตรเฉลี่ย $\left(\tfrac{2 + 8}{2}, \tfrac{1 + 5}{2}\right) = (5, 3)$ ตรวจได้ทันทีด้วยการเทียบระยะ จาก $(2, 1)$ ไป $(3, 2)$ ห่างแค่ $\sqrt{2}$ แต่จาก $(3, 2)$ ไป $(8, 5)$ ห่าง $\sqrt{34}$ สองช่วงไม่เท่ากัน จุดนั้นจึงไม่ใช่จุดกึ่งกลาง
</Reveal>
</Think>

## หาระยะเมื่อมีตัวแปร

สูตรระยะให้สมการกำลังสองเมื่อพิกัดหนึ่งยังไม่รู้ ต้องหาทุกค่าที่ทำให้ระยะตรงตามกำหนด และตรวจความเป็นไปได้ทางรูปด้วย

<Example n={4}>

จุด $P=(x,3)$ อยู่ห่างจากจุดกำเนิด $5$ หน่วย หา $x$

<Steps reveal>
1. $\sqrt{x^2+3^2}=5$ ทั้งสองข้างไม่ติดลบ จึงยกกำลังสองได้ $x^2+9=25$ การยกกำลังสองปลอดภัยเมื่อทั้งสองข้างไม่ติดลบ เพราะจะไม่เกิดคำตอบเกินมา
2. ได้ $x^2=16$ จึงมี $x=-4$ หรือ $x=4$
3. จุดสองจุดอยู่ซ้ายขวาของแกนตั้งและมีระยะเท่ากัน เพราะทุกจุดที่อยู่ห่างจุดกำเนิด $5$ หน่วยเรียงกันเป็นวงกลม และเส้น $y = 3$ ตัดวงกลมนี้สองจุด
</Steps>
</Example>

{/* check: roots(x**2+9-25)==[-4,4] */}

การได้สองคำตอบไม่ได้เป็นความผิดพลาดเสมอ สมมาตรของรูปอธิบายว่าทั้งสองจุดเป็นไปได้ หากโจทย์เพิ่มเงื่อนไขว่าอยู่ขวาของแกนตั้ง จึงค่อยเลือก $x=4$ เพียงค่าเดียว

โจทย์อีกแบบที่พบบ่อยคือหาจุดที่ห่างจากสองจุดเท่ากัน เช่นหาตำแหน่งตั้งเสาไฟให้ห่างจากบ้านสองหลังเท่ากัน ตั้งสมการระยะเท่ากันแล้วยกกำลังสองทั้งสองข้าง พจน์กำลังสองของตัวแปรจะตัดกันหมด เหลือสมการเชิงเส้นที่แก้ง่าย

<Example n={5}>

ถนนเลียบคลองอยู่บนแกน $x$ บ้านสองหลังอยู่ที่ $A(1, 3)$ และ $B(5, 1)$ จะตั้งศาลาริมถนนให้ห่างจากบ้านทั้งสองเท่ากัน ศาลาอยู่ที่จุดใด

<Steps reveal>
1. ศาลาอยู่บนแกน $x$ จึงมีพิกัด $(x, 0)$ ตัวแปรเหลือตัวเดียว
2. ตั้งเงื่อนไข $PA = PB$ แล้วยกกำลังสองทั้งสองข้างเพื่อกำจัดเครื่องหมายราก $(x - 1)^2 + 3^2 = (x - 5)^2 + 1^2$
3. กระจาย $x^2 - 2x + 1 + 9 = x^2 - 10x + 25 + 1$ พจน์ $x^2$ อยู่ทั้งสองข้าง จึงตัดกันได้ เหลือ $-2x + 10 = -10x + 26$
4. ย้ายข้าง $8x = 16$ ได้ $x = 2$ ศาลาอยู่ที่ $(2, 0)$
5. ตรวจ $PA = \sqrt{1 + 9} = \sqrt{10}$ และ $PB = \sqrt{9 + 1} = \sqrt{10}$ เท่ากันจริง
</Steps>
</Example>

{/* check: solve(Eq((x-1)**2 + 9, (x-5)**2 + 1), x) == [2] and (2-1)**2 + 9 == (2-5)**2 + 1 == 10 */}

จุดทุกจุดที่ห่างจาก $A$ และ $B$ เท่ากันเรียงกันเป็นเส้นตรงเส้นหนึ่ง คือเส้นแบ่งครึ่งและตั้งฉากกับ $AB$ ซึ่งเคยสร้างด้วยวงเวียนในบทที่ 2 ศาลาในตัวอย่างนี้คือจุดที่เส้นนั้นตัดแกน $x$ หน้าถัดไปจะเขียนสมการของเส้นแบบนี้ได้โดยตรง

## ใช้ระยะตรวจชนิดของรูปสามเหลี่ยม

เมื่อรู้ความยาวทุกด้าน ก็บอกได้ว่าสามเหลี่ยมเป็นหน้าจั่วหรือไม่ และใช้บทกลับของทฤษฎีบทพีทาโกรัสในหน้า 10.3 ตรวจมุมฉากได้ เทียบกำลังสองของด้านตรงๆ จะสะดวกกว่า เพราะไม่ต้องถอดราก

<Example n={6}>

สามเหลี่ยมที่มีจุดยอด $A(1, 2)$ $B(4, 6)$ $C(5, -1)$ เป็นสามเหลี่ยมชนิดใด

<Steps reveal>
1. $AB^2 = 3^2 + 4^2 = 25$ $AC^2 = 4^2 + (-3)^2 = 25$ $BC^2 = 1^2 + (-7)^2 = 50$
2. $AB = AC = 5$ สองด้านยาวเท่ากัน จึงเป็นสามเหลี่ยมหน้าจั่ว
3. $AB^2 + AC^2 = 25 + 25 = 50 = BC^2$ ตามบทกลับของทฤษฎีบทพีทาโกรัส มุมตรงข้ามด้าน $BC$ ซึ่งคือมุม $A$ เป็นมุมฉาก
4. สรุปว่าเป็นสามเหลี่ยมมุมฉากหน้าจั่ว มุมฉากอยู่ที่ $A$
</Steps>
</Example>

{/* check: (3**2+4**2, 4**2+(-3)**2, 1**2+(-7)**2) == (25, 25, 50) and 25 + 25 == 50 */}

## สรุป
