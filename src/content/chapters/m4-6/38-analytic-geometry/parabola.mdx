จานรับสัญญาณดาวเทียมบนหลังคาบ้านมีหัวรับสัญญาณยื่นออกมาตรงกลาง คลื่นจากดาวเทียมที่อยู่ไกลมากเดินทางมาเป็นแนวขนานกัน กระทบผิวจานแล้วสะท้อนไปรวมที่หัวรับจุดเดียว ไฟหน้ารถทำกลับกัน หลอดไฟอยู่ที่จุดพิเศษจุดนั้น แสงสะท้อนผิวโคมออกไปเป็นลำขนาน รูปตัดของจานและโคมไฟทั้งสองแบบคือพาราโบลา และจุดพิเศษที่แสงรวมกันเรียกว่า**โฟกัส**

บทที่ 25 เรียกกราฟของ $y = ax^2 + bx + c$ ว่าพาราโบลา แต่ยังไม่ได้บอกว่าโฟกัสอยู่ที่ไหน หน้านี้จะนิยามพาราโบลาด้วยระยะ แล้วจะเห็นว่ากราฟในบทที่ 25 ทุกเส้นมีโฟกัสของตัวเอง

## นิยามด้วยโฟกัสและไดเรกตริกซ์

ทำไมต้องใช้เส้นตรงคู่กับจุด ถ้าใช้แค่จุดเดียวจะได้วงกลมแบบหน้าที่แล้ว การมีเส้นตรงเป็นตัวเทียบทำให้รูปเปิดออกไม่มีที่สิ้นสุด เพราะยิ่งจุดอยู่ไกล ระยะถึงโฟกัสกับระยะถึงเส้นตรงก็โตไปพร้อมกัน

**จุดยอด**อยู่บนเส้นที่ลากผ่านโฟกัสตั้งฉากกับไดเรกตริกซ์ เส้นนี้คือ**แกนสมมาตร** จุดยอดต้องห่างจากโฟกัสเท่ากับห่างจากไดเรกตริกซ์ จึงอยู่กึ่งกลางระหว่างสองสิ่งนี้พอดี ให้ $p$ แทนระยะจากจุดยอดถึงโฟกัสพร้อมเครื่องหมายบอกทิศ

## หาสมการรูปมาตรฐาน

วางจุดยอดที่จุดกำเนิด โฟกัส $F(0, p)$ ไดเรกตริกซ์ $y = -p$ จุด $P(x, y)$ ห่างจากโฟกัส $\sqrt{x^2 + (y - p)^2}$ และห่างจากไดเรกตริกซ์ $|y + p|$ เพราะระยะจากจุดถึงเส้นแนวนอนคือผลต่างของพิกัด $y$ ตั้งให้เท่ากันแล้วยกกำลังสอง

$$x^2 + (y - p)^2 = (y + p)^2$$

กระจายได้ $x^2 + y^2 - 2py + p^2 = y^2 + 2py + p^2$ พจน์ $y^2$ และ $p^2$ ตัดกัน เหลือ

$$x^2 = 4py$$

{/* check: expand(x**2 + (y - symbols('p'))**2 - (y + symbols('p'))**2) == expand(x**2 - 4*symbols('p')*y) */}

ถ้าเขียนเป็น $y = \tfrac{1}{4p}x^2$ ก็คือ $y = ax^2$ ในหน้า 25.2 โดย $a = \tfrac{1}{4p}$ ดังนั้นกราฟ $y = x^2$ มีโฟกัสที่ $\left(0, \tfrac14\right)$ ยิ่ง $p$ ใหญ่ $a$ ยิ่งเล็ก พาราโบลายิ่งบาน ลองเลื่อน $p$ ในกราฟข้างล่าง แล้วเลื่อนจุด $P$ ไปตามเส้น สังเกตว่าความยาวสองเส้นเท่ากันตลอด

<Board name="c38-parabola" label="พาราโบลา x กำลังสองเท่ากับ 4py ปรับ p และตำแหน่งจุด P ระยะจาก P ถึงโฟกัสเท่ากับระยะจาก P ถึงไดเรกตริกซ์" caption="เส้นสีเขียวคือ PF เส้นสีม่วงคือระยะจาก P ถึงไดเรกตริกซ์" />

ถ้าเลื่อนจุดยอดไปที่ $(h, k)$ ทุกอย่างเลื่อนตามไปด้วย แบบเดียวกับการเลื่อนกราฟในหน้า 25.3

<Thm>

- $(x-h)^2=4p(y-k)$ มีจุดยอด $(h,k)$ โฟกัส $(h,k+p)$ ไดเรกตริกซ์ $y=k-p$ แกนสมมาตร $x = h$ ถ้า $p>0$ เปิดขึ้น ถ้า $p<0$ เปิดลง
- $(y-k)^2=4p(x-h)$ มีจุดยอด $(h,k)$ โฟกัส $(h+p,k)$ ไดเรกตริกซ์ $x=h-p$ แกนสมมาตร $y = k$ ถ้า $p>0$ เปิดขวา ถ้า $p<0$ เปิดซ้าย

</Thm>

ตัวแปรที่ไม่ยกกำลังสองบอกแกนของรูป ถ้า $y$ ไม่ยกกำลังสอง รูปเปิดขึ้นหรือลงตามแกน $y$ ถ้า $x$ ไม่ยกกำลังสอง รูปเปิดซ้ายหรือขวา

เพื่อวาดให้ได้ความกว้างที่ถูก ให้ดูเส้นที่ผ่านโฟกัสขนานกับไดเรกตริกซ์ แทน $y = p$ ใน $x^2 = 4py$ ได้ $x = \pm 2p$ พาราโบลาจึงกว้าง $|4p|$ ที่ระดับโฟกัส ส่วนของเส้นตรงนี้เรียกว่า**เลตัสเรกตัม** ได้จุดเพิ่มอีกสองจุดสำหรับวาดกราฟโดยไม่ต้องแทนค่าเพิ่ม

## อ่านค่าจากสมการ

<Example n={1}>

หาโฟกัสและไดเรกตริกซ์ของ $(x-1)^2=8(y+2)$ แล้ววาดกราฟคร่าวๆ

<Steps reveal>
1. เทียบกับ $(x - h)^2 = 4p(y - k)$ ได้ $h=1$ และ $k=-2$ เพราะ $y + 2 = y - (-2)$
2. $4p=8$ จึงได้ $p=2$ เป็นบวก และ $x$ ยกกำลังสอง กราฟจึงเปิดขึ้น
3. โฟกัสอยู่เหนือจุดยอด $2$ หน่วย คือ $(1,0)$ ไดเรกตริกซ์อยู่ใต้จุดยอด $2$ หน่วย คือ $y=-4$
4. ความกว้างที่ระดับโฟกัสคือ $|4p| = 8$ จึงได้จุด $(1 - 4, 0) = (-3, 0)$ และ $(5, 0)$ บนกราฟ ลากโค้งจากสองจุดนี้ผ่านจุดยอด $(1, -2)$
</Steps>
</Example>

{/* check: (-2+2,-2-2)==(0,-4) and (5-1)**2 == 8*(0+2) and (-3-1)**2 == 8*(0+2) */}

<Think>

ถ้า $4p=12$ ระยะจุดยอดถึงโฟกัสเท่ากับ $12$ หรือไม่

<Reveal>
ไม่ใช่ $p=3$ จึงห่าง $3$ หน่วย สัมประสิทธิ์ในสมการเป็น $4p$ ต้องหารด้วยสี่ก่อน
</Reveal>
</Think>

พาราโบลาไม่จำเป็นต้องเป็นฟังก์ชันของ $x$ ทั้งเส้น ถ้าตัวแปร $y$ ถูกยกกำลังสอง กราฟเปิดซ้ายหรือขวาและอาจมีสองค่า $y$ สำหรับ $x$ เดียว

<Example n={2}>

อ่านจุดยอด โฟกัส และไดเรกตริกซ์ของ $(y-1)^2=-12(x+2)$

<Steps reveal>
1. $y$ ยกกำลังสอง จึงเทียบกับ $(y-k)^2=4p(x-h)$ ได้ $h=-2$ $k=1$ และ $4p = -12$ จึงได้ $p=-3$
2. จุดยอด $(-2,1)$ โฟกัสเลื่อนไปตามแกน $x$ คือ $(h+p,k)=(-5,1)$
3. ไดเรกตริกซ์ $x=h-p=-2 + 3 = 1$ กราฟเปิดซ้ายเพราะ $p<0$
</Steps>
</Example>

{/* check: (-2-3,1)==(-5,1) and -2-(-3)==1 */}

ตรวจด้วยจุดยอดซึ่งอยู่ห่างโฟกัสสามหน่วยและห่างไดเรกตริกซ์สามหน่วยเท่ากัน โฟกัสกับเส้นไดเรกตริกซ์อยู่คนละด้านของจุดยอดตามนิยามระยะ และพาราโบลาเปิดไปทางโฟกัสเสมอ ไม่เคยเปิดเข้าหาไดเรกตริกซ์

## หาสมการจากโฟกัสและไดเรกตริกซ์

<Example n={3}>

หาสมการพาราโบลาที่มีโฟกัส $(2, 3)$ และไดเรกตริกซ์ $y = -1$

<Steps reveal>
1. ไดเรกตริกซ์เป็นเส้นนอน แกนสมมาตรจึงเป็นเส้นตั้ง $x = 2$ ที่ผ่านโฟกัส รูปจึงเป็น $(x - h)^2 = 4p(y - k)$
2. จุดยอดอยู่กึ่งกลางระหว่างโฟกัสกับไดเรกตริกซ์บนแกนสมมาตร พิกัด $y$ คือ $\tfrac{3 + (-1)}{2} = 1$ จุดยอดจึงเป็น $(2, 1)$
3. โฟกัสอยู่เหนือจุดยอด $2$ หน่วย จึงได้ $p = 2$ สมการคือ $(x - 2)^2 = 8(y - 1)$
4. ตรวจกับนิยาม จุด $(6, 3)$ อยู่บนกราฟเพราะ $16 = 8(2)$ ห่างโฟกัส $4$ หน่วยและห่างเส้น $y = -1$ อีก $4$ หน่วย เท่ากันจริง
</Steps>
</Example>

{/* check: Rational(3 + (-1), 2) == 1 and (6-2)**2 == 8*(3-1) and sqrt((6-2)**2 + (3-3)**2) == 3 - (-1) */}

## ทำกำลังสองสมบูรณ์

ถ้าสมการกระจายมาแล้ว ให้ดูว่าตัวแปรไหนยกกำลังสอง เก็บพจน์ของตัวแปรนั้นไว้ข้างหนึ่ง ย้ายทุกอย่างที่เหลือไปอีกข้าง ทำกำลังสองสมบูรณ์ แล้วดึงสัมประสิทธิ์ของอีกตัวแปรออกมาเป็น $4p$

<Example n={4}>

หาจุดยอด โฟกัส และไดเรกตริกซ์ของ $y^2 - 4y - 8x - 12 = 0$

<Steps reveal>
1. มีแค่ $y$ ที่ยกกำลังสอง เก็บพจน์ $y$ ไว้ซ้าย $y^2 - 4y = 8x + 12$
2. ครึ่งหนึ่งของ $-4$ คือ $-2$ เติม $4$ ทั้งสองข้าง $(y - 2)^2 = 8x + 16$
3. ดึง $8$ ออกจากขวามือให้ $x$ อยู่ลำพังในวงเล็บ $(y - 2)^2 = 8(x + 2)$ ขั้นนี้สำคัญ ถ้าไม่ดึงจะอ่าน $h$ ผิดเป็น $-16$
4. จุดยอด $(-2, 2)$ และ $4p = 8$ ได้ $p = 2$ เปิดขวา โฟกัส $(0, 2)$ ไดเรกตริกซ์ $x = -4$
</Steps>
</Example>

{/* check: expand((y - 2)**2 - 8*(x + 2)) == y**2 - 4*y - 8*x - 12 and (-2 + 2, 2) == (0, 2) and -2 - 2 == -4 */}

<Example n={5}>

กราฟของ $y = x^2 - 4x + 3$ จากหน้า 25.3 มีโฟกัสอยู่ที่ใด

<Steps reveal>
1. ย้ายค่าคงตัว $x^2 - 4x = y - 3$ แล้วเติม $4$ ทั้งสองข้าง $(x - 2)^2 = y + 1$
2. เทียบกับ $(x - h)^2 = 4p(y - k)$ ได้จุดยอด $(2, -1)$ ตรงกับที่หาไว้ในบทที่ 25 และ $4p = 1$ จึงได้ $p = \tfrac14$
3. โฟกัส $\left(2, -1 + \tfrac14\right) = \left(2, -\tfrac34\right)$ ไดเรกตริกซ์ $y = -1 - \tfrac14 = -\tfrac54$
</Steps>
</Example>

{/* check: expand((x - 2)**2 - (y + 1)) == expand(x**2 - 4*x - (y - 3)) and vertex(x**2 - 4*x + 3) == (2, -1) and -1 + Rational(1, 4) == Rational(-3, 4) */}

<Think>

เพื่อนบอกว่า $y = 2x^2$ มีโฟกัสที่ $\left(0, \tfrac12\right)$ เพราะ $4p = 2$ ถูกไหม

<Reveal>
ไม่ถูก สมการยังไม่อยู่ในรูป $x^2 = 4py$ ต้องให้ $x^2$ อยู่ลำพังก่อน หารสองได้ $x^2 = \tfrac12 y$ จึงได้ $4p = \tfrac12$ และ $p = \tfrac18$ โฟกัสอยู่ที่ $\left(0, \tfrac18\right)$ ตรวจด้วย $a = \tfrac{1}{4p} = \tfrac{1}{1/2} = 2$ ตรงกับสมการเดิม
</Reveal>
</Think>

{/* check: Rational(1, 2)/4 == Rational(1, 8) and 1/(4*Rational(1, 8)) == 2 */}

## จานรับสัญญาณ

<Example n={6}>

จานรับสัญญาณดาวเทียมกว้าง $60$ เซนติเมตร ลึก $10$ เซนติเมตร ต้องติดหัวรับสัญญาณห่างจากก้นจานเท่าไร

<Steps reveal>
1. วางจุดยอดของจานไว้ที่จุดกำเนิด เปิดขึ้น สมการจึงเป็น $x^2 = 4py$ เลือกแบบนี้เพราะสมการสั้นที่สุด
2. ขอบจานอยู่ห่างแกน $30$ เซนติเมตร (ครึ่งหนึ่งของความกว้าง) และสูงจากก้น $10$ เซนติเมตร จุด $(30, 10)$ จึงอยู่บนพาราโบลา
3. แทนค่า $900 = 4p(10) = 40p$ ได้ $p = 22.5$
4. หัวรับสัญญาณต้องอยู่ที่โฟกัส ห่างจากก้นจาน $22.5$ เซนติเมตร ซึ่งอยู่สูงกว่าขอบจาน เพราะจานนี้ตื้น
</Steps>
</Example>

{/* check: Rational(30**2, 40) == Rational('22.5') */}

หน้าถัดไปจะใช้จุดคงที่สองจุดแทนจุดกับเส้น ผลบวกระยะถึงสองโฟกัสคงที่ให้วงรี ซึ่งเป็นรูปของวงโคจรดาวเคราะห์

## สรุป

- พาราโบลาคือจุดที่ห่างจากโฟกัสเท่ากับห่างจากไดเรกตริกซ์ จุดยอดอยู่กึ่งกลางระหว่างสองสิ่งนี้
- $(x - h)^2 = 4p(y - k)$ เปิดขึ้นลง $(y - k)^2 = 4p(x - h)$ เปิดซ้ายขวา ตามเครื่องหมายของ $p$
- พาราโบลาต้องแยก $p$ ออกจาก $4p$ และให้ตัวแปรกำลังสองอยู่ลำพังก่อนอ่านค่า
- กว้าง $|4p|$ ที่ระดับโฟกัส ใช้หาจุดเพิ่มตอนวาดกราฟ
- กราฟ $y = ax^2$ ในบทที่ 25 คือพาราโบลาที่มี $p = \tfrac{1}{4a}$
