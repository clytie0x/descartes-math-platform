สปริงเกลอร์รดน้ำตั้งอยู่กลางสนาม พ่นน้ำได้ไกล $5$ เมตรทุกทิศ ขอบของบริเวณที่เปียกคือจุดทุกจุดที่อยู่ห่างจากสปริงเกลอร์ $5$ เมตรพอดี เสาสัญญาณโทรศัพท์ก็เช่นกัน บริเวณที่รับสัญญาณได้ถึงขอบพอดีคือจุดที่อยู่ห่างจากเสาเท่ากันทุกทิศ รูปที่ได้คือวงกลม

บทที่ 28 ศึกษาวงกลมด้วยเรขาคณิตล้วน เช่นมุมในวงกลมและเส้นสัมผัส หน้านี้มองวงกลมด้วยพิกัด แปลงเงื่อนไขห่างจากจุดศูนย์กลางเท่ากันให้เป็นสมการด้วยสูตรระยะของหน้า 38.1 แล้วเรียนวิธีอ่านศูนย์กลางและรัศมีจากสมการที่ถูกกระจายจนดูไม่ออก

## ภาคตัดกรวยคืออะไร

วงกลม พาราโบลา วงรี และไฮเพอร์โบลา ที่จะเรียนในหน้านี้และสามหน้าถัดไป เรียกรวมกันว่า**ภาคตัดกรวย** เพราะได้จากการเอาระนาบไปตัดกรวยกลมสองอันที่ต่อยอดกัน ระนาบที่ตั้งฉากกับแกนกรวยได้วงกลม เอียงระนาบเล็กน้อยได้วงรี เอียงจนขนานกับเส้นข้างของกรวยได้พาราโบลา เอียงมากกว่านั้นจนตัดกรวยทั้งสองอันได้ไฮเพอร์โบลาสองกิ่ง

แต่ในบทนี้เราจะไม่นิยามรูปเหล่านี้ด้วยกรวย เราจะนิยามด้วย**ระยะ** เพราะระยะแปลงเป็นสมการได้ทันทีด้วยสูตรที่มีอยู่แล้ว ทุกรูปจะใช้ขั้นตอนเดียวกัน คือเขียนเงื่อนไขเป็นคำพูด แปลงเป็นสมการระยะ แล้วจัดรูปให้อ่านง่าย

## จากนิยามสู่สมการ

<Def>
**วงกลม** คือเซตของจุดทุกจุดบนระนาบที่อยู่ห่างจากจุดคงที่จุดหนึ่งเป็นระยะเท่ากัน จุดคงที่เรียกว่า**จุดศูนย์กลาง** ระยะที่เท่ากันเรียกว่า**รัศมี**
</Def>

ให้ศูนย์กลางเป็น $C(h, k)$ และรัศมี $r > 0$ จุด $P(x, y)$ อยู่บนวงกลมก็ต่อเมื่อ $PC = r$ ใช้สูตรระยะได้

$$\sqrt{(x - h)^2 + (y - k)^2} = r$$

ทั้งสองข้างไม่ติดลบ ยกกำลังสองได้โดยไม่เปลี่ยนเซตคำตอบ จึงได้**สมการรูปมาตรฐาน**ของวงกลม

$$(x-h)^2+(y-k)^2=r^2$$

ที่นิยมยกกำลังสองเพราะสมการที่ไม่มีเครื่องหมายรากจัดรูปและแทนค่าได้ง่ายกว่ามาก ถ้าศูนย์กลางอยู่ที่จุดกำเนิด สมการเหลือ $x^2 + y^2 = r^2$

การอ่านศูนย์กลางใช้หลักเดียวกับการเลื่อนกราฟในหน้า 25.3 ถามว่า $x$ เท่าไรทำให้วงเล็บเป็นศูนย์ เช่น $(x + 3)^2$ ให้ $h = -3$ ไม่ใช่ $3$

<Example n={1}>

บนแผนที่สนามที่หนึ่งหน่วยยาวหนึ่งเมตร สปริงเกลอร์อยู่ที่ $(1, -2)$ และน้ำพ่นไปถึงต้นไม้ที่ $(4, 2)$ พอดี เขียนสมการขอบบริเวณที่น้ำพ่นถึง

<Steps reveal>
1. ศูนย์กลางคือตำแหน่งสปริงเกลอร์ $(h, k) = (1, -2)$
2. ต้นไม้อยู่บนขอบพอดี รัศมีจึงเท่ากับระยะจากสปริงเกลอร์ถึงต้นไม้ $r = \sqrt{(4 - 1)^2 + (2 + 2)^2} = \sqrt{9 + 16} = 5$ เมตร
3. แทนในรูปมาตรฐาน $(x - 1)^2 + (y - (-2))^2 = 5^2$ จัดเครื่องหมายได้ $(x - 1)^2 + (y + 2)^2 = 25$
4. ตรวจ แทนจุดต้นไม้ $(4 - 1)^2 + (2 + 2)^2 = 9 + 16 = 25$ ถูกต้อง
</Steps>
</Example>

{/* check: sqrt((4-1)**2 + (2+2)**2) == 5 and (4-1)**2 + (2+2)**2 == 25 */}

<Example n={2}>

เขียนสมการวงกลมที่มีส่วนของเส้นตรง $AB$ เป็นเส้นผ่านศูนย์กลาง เมื่อ $A(-1, 3)$ และ $B(5, -5)$

<Steps reveal>
1. ศูนย์กลางของวงกลมอยู่กึ่งกลางเส้นผ่านศูนย์กลางพอดี จึงใช้สูตรจุดกึ่งกลาง $\left(\tfrac{-1 + 5}{2}, \tfrac{3 - 5}{2}\right) = (2, -1)$
2. เส้นผ่านศูนย์กลางยาว $AB = \sqrt{6^2 + 8^2} = 10$ รัศมีเป็นครึ่งหนึ่ง คือ $5$
3. สมการคือ $(x - 2)^2 + (y + 1)^2 = 25$
4. ตรวจด้วยจุด $A$ $(-1 - 2)^2 + (3 + 1)^2 = 9 + 16 = 25$ ถูกต้อง
</Steps>
</Example>

{/* check: ((-1+5)/2, (3-5)/2) == (2, -1) and sqrt(6**2 + 8**2) == 10 and (-1-2)**2 + (3+1)**2 == 25 */}

## รูปทั่วไปและการทำกำลังสองสมบูรณ์

ถ้ากระจายรูปมาตรฐานแล้วย้ายทุกพจน์ไปข้างเดียว จะได้**รูปทั่วไป**

$$x^2 + y^2 + Dx + Ey + F = 0$$

สังเกตลักษณะของรูปนี้ สัมประสิทธิ์ของ $x^2$ กับ $y^2$ เท่ากัน และไม่มีพจน์ $xy$ สมการกำลังสองที่มีลักษณะนี้มีโอกาสเป็นวงกลม ส่วนที่สัมประสิทธิ์ของ $x^2$ กับ $y^2$ ต่างกันจะเป็นรูปอื่น ซึ่งจะพบในหน้าวงรีและไฮเพอร์โบลา

โจทย์มักให้รูปทั่วไปมา ซึ่งอ่านศูนย์กลางตรงๆ ไม่ได้ ต้องย้อนกลับเป็นรูปมาตรฐานด้วยการทำกำลังสองสมบูรณ์จากหน้า 23.2 แยกทีละตัวแปร หลักเดิมคือ $x^2 + 2px$ ต้องเติม $p^2$ จึงเป็น $(x + p)^2$ หรือพูดสั้นๆ ว่าเติมกำลังสองของครึ่งหนึ่งของสัมประสิทธิ์ $x$

<Example n={3}>

หาศูนย์กลางและรัศมีของ $x^2+y^2-6x+4y-12=0$

<Steps reveal>
1. จับกลุ่มตามตัวแปรและย้ายค่าคงตัวไปขวามือ $(x^2-6x)+(y^2+4y)=12$ ทำแบบนี้เพราะแต่ละกลุ่มจะกลายเป็นกำลังสองสมบูรณ์ของตัวเอง
2. ครึ่งหนึ่งของ $-6$ คือ $-3$ ต้องเติม $9$ ครึ่งหนึ่งของ $4$ คือ $2$ ต้องเติม $4$ เติมทั้งสองข้างของสมการ สมการจึงยังเท่าเดิม $(x^2 - 6x + 9) + (y^2 + 4y + 4) = 12 + 9 + 4$
3. เขียนเป็นกำลังสอง $(x-3)^2+(y+2)^2=25$
4. ศูนย์กลาง $(3,-2)$ รัศมี $\sqrt{25} = 5$
</Steps>
</Example>

{/* check: expand((x-3)**2+(y+2)**2-25)==x**2+y**2-6*x+4*y-12 */}

ทางลัดที่ใช้ตรวจได้ จากรูปทั่วไป ศูนย์กลางคือ $\left(-\tfrac{D}{2}, -\tfrac{E}{2}\right)$ ตัวอย่างนี้ $D = -6$ และ $E = 4$ ได้ $(3, -2)$ ตรงกัน แต่ทางลัดนี้ใช้ได้เมื่อสัมประสิทธิ์ของ $x^2$ และ $y^2$ เป็น $1$ เท่านั้น

<Example n={4}>

หาศูนย์กลางและรัศมีของ $2x^2 + 2y^2 - 8x + 12y + 8 = 0$

<Steps reveal>
1. สัมประสิทธิ์ของ $x^2$ และ $y^2$ เป็น $2$ ทั้งคู่ หารทั้งสมการด้วย $2$ ก่อน ได้ $x^2 + y^2 - 4x + 6y + 4 = 0$ ถ้าไม่หารก่อน การเติมกำลังสองจะซับซ้อนขึ้นมาก
2. จับกลุ่ม $(x^2 - 4x) + (y^2 + 6y) = -4$
3. เติม $4$ และ $9$ ทั้งสองข้าง $(x - 2)^2 + (y + 3)^2 = -4 + 4 + 9 = 9$
4. ศูนย์กลาง $(2, -3)$ รัศมี $3$
</Steps>
</Example>

{/* check: expand(2*((x - 2)**2 + (y + 3)**2 - 9)) == 2*x**2 + 2*y**2 - 8*x + 12*y + 8 */}

<Think>

สมการ $x^2 + y^2 + 2x - 4y + 9 = 0$ เป็นวงกลมรัศมีเท่าไร

<Reveal>
จัดรูปได้ $(x + 1)^2 + (y - 2)^2 = -9 + 1 + 4 = -4$ ซ้ายมือเป็นผลบวกของกำลังสองจึงไม่มีวันติดลบ ไม่มีจุดใดบนระนาบที่ทำให้สมการเป็นจริง สมการนี้จึงไม่ใช่วงกลม กราฟเป็นเซตว่าง ถ้าขวามือออกมาเป็น $0$ จะเหลือแค่จุดเดียวคือ $(-1, 2)$ สรุปว่ารูปทั่วไปไม่ได้เป็นวงกลมเสมอ ต้องตรวจว่าขวามือเป็นบวกก่อน
</Reveal>
</Think>

{/* check: expand((x + 1)**2 + (y - 2)**2 + 4) == x**2 + y**2 + 2*x - 4*y + 9 */}

<Note kind="warning" title="อย่าสับสน r กับ r²">
ขวามือของรูปมาตรฐานคือ $r^2$ ไม่ใช่ $r$ ถ้าได้ $(x - 2)^2 + (y + 3)^2 = 9$ รัศมีคือ $3$ และถ้าขวามือเป็น $20$ รัศมีคือ $\sqrt{20} = 2\sqrt5$ ไม่ใช่ $20$
</Note>

## วงกลมกับเส้นตรง

บทที่ 28 พิสูจน์แล้วว่าเส้นสัมผัสวงกลมตั้งฉากกับรัศมีที่จุดสัมผัส ดังนั้นระยะจากศูนย์กลางถึงเส้นสัมผัสเท่ากับรัศมีพอดี เมื่อรวมกับสูตรระยะจากหน้า 38.3 จะบอกได้ทันทีว่าเส้นตรงเส้นหนึ่งตัดวงกลม สัมผัสวงกลม หรืออยู่นอกวงกลม โดยเทียบระยะ $d$ จากศูนย์กลางถึงเส้นกับรัศมี $r$ ถ้า $d$ น้อยกว่า $r$ เส้นตัดวงกลมสองจุด ถ้า $d = r$ เส้นสัมผัส ถ้า $d$ มากกว่า $r$ เส้นไม่พบวงกลมเลย

<Example n={5}>

เราเตอร์ไวไฟตั้งที่ $(1, 1)$ บนผังบ้าน ผนังห้องเป็นเส้นตรง $3x + 4y + 3 = 0$ ถ้าวาดวงกลมศูนย์กลางที่เราเตอร์ให้แตะผนังพอดี วงกลมนี้มีสมการอะไร

<Steps reveal>
1. วงกลมแตะผนังพอดีแปลว่าผนังเป็นเส้นสัมผัส รัศมีจึงเท่ากับระยะจากศูนย์กลางถึงเส้น
2. $r = \tfrac{|3(1) + 4(1) + 3|}{\sqrt{9 + 16}} = \tfrac{10}{5} = 2$
3. สมการคือ $(x - 1)^2 + (y - 1)^2 = 4$
</Steps>
</Example>

{/* check: abs(3*1 + 4*1 + 3)/sqrt(3**2 + 4**2) == 2 */}

วงกลมนิยามด้วยระยะถึงจุดคงที่จุดเดียว หน้าถัดไปจะเปลี่ยนเงื่อนไขเป็นระยะถึงจุดคงที่เท่ากับระยะถึงเส้นตรงคงที่ ผลที่ได้คือพาราโบลา รูปเดียวกับกราฟของฟังก์ชันกำลังสองในบทที่ 25

## สรุป

- วงกลมคือจุดที่ห่างจากศูนย์กลางเท่ากัน แปลงด้วยสูตรระยะได้ $(x - h)^2 + (y - k)^2 = r^2$
- อ่านศูนย์กลางด้วยคำถามว่าค่าใดทำให้วงเล็บเป็นศูนย์ และถอดรากขวามือเพื่อหารัศมี
- รูปทั่วไป หารให้สัมประสิทธิ์กำลังสองเป็น $1$ จับกลุ่มทีละตัวแปร แล้วเติมกำลังสองทั้งสองข้าง
- ขวามือเป็นศูนย์ได้จุดเดียว ติดลบไม่มีจุดจริง
- เส้นสัมผัสวงกลมเมื่อระยะจากศูนย์กลางถึงเส้นเท่ากับรัศมี
