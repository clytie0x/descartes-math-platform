ต้องลากสายจากจุดติดตั้งไปถึงถนนเส้นตรงให้สั้นที่สุด สายต้องตั้งฉากกับถนน ระยะถึงจุดใดบนถนนก็ไม่สั้นเท่าระยะตั้งฉาก

คำถามแบบนี้มีอยู่รอบตัว นักเรียนยืนกลางสนามแล้วอยากเดินไปถึงรั้วที่เป็นเส้นตรงให้เร็วที่สุด หรือเรือที่ลอยกลางทะเลอยากรู้ว่าอยู่ห่างชายฝั่งแค่ไหน ระยะที่ถามหาคือระยะสั้นที่สุด ไม่ใช่ระยะถึงจุดใดจุดหนึ่งบนเส้น หน้านี้จะหาระยะนั้นด้วยสองวิธี วิธีแรกใช้แค่ความรู้จากสองหน้าที่แล้ว วิธีที่สองเป็นสูตรสำเร็จที่เร็วกว่ามาก

ให้ $H$ เป็นเท้าฉากจาก $P$ ลงเส้นตรงและ $Q$ เป็นจุดอื่นบนเส้น สามเหลี่ยม $PHQ$ เป็นมุมฉาก จึงมี $PQ^2=PH^2+HQ^2\ge PH^2$ แสดงว่า $PH$ สั้นที่สุด และจะเท่ากันก็ต่อเมื่อ $HQ = 0$ คือ $Q$ เป็นจุดเดียวกับ $H$ ระยะ $PH$ นี้เองที่เรียกว่า**ระยะจากจุดถึงเส้นตรง**

## วิธีแรก หาเท้าฉากก่อน

ข้อดีของวิธีนี้คือไม่ต้องจำสูตรใหม่ ใช้แค่สามอย่างที่รู้แล้ว ความชันของเส้นตั้งฉาก การแก้ระบบสมการจากบทที่ 27 และสูตรระยะจากหน้า 38.1

<Example n={1}>

หาระยะจาก $P(2,-1)$ ถึงเส้น $3x+4y-12=0$ โดยหาเท้าฉากก่อน

<Steps reveal>
1. เส้นที่กำหนดมีความชัน $-\tfrac{A}{B} = -\tfrac34$ เส้นที่ตั้งฉากจึงมีความชัน $\tfrac43$ เพราะผลคูณต้องเป็น $-1$
2. เส้นตั้งฉากผ่าน $P$ คือ $y + 1 = \tfrac43(x - 2)$ คูณสามได้ $3y + 3 = 4x - 8$ หรือ $4x - 3y - 11 = 0$
3. เท้าฉาก $H$ คือจุดที่สองเส้นตัดกัน แก้ระบบ $3x + 4y = 12$ กับ $4x - 3y = 11$ คูณสมการแรกด้วย $3$ สมการที่สองด้วย $4$ แล้วบวกกันเพื่อกำจัด $y$ ได้ $25x = 80$ จึงได้ $x = \tfrac{16}{5}$ แทนกลับได้ $y = \tfrac35$
4. ระยะ $PH = \sqrt{\left(\tfrac{16}{5} - 2\right)^2 + \left(\tfrac35 + 1\right)^2} = \sqrt{\tfrac{36}{25} + \tfrac{64}{25}} = \sqrt{4} = 2$ หน่วย
</Steps>
</Example>

{/* check: solve([3*x + 4*y - 12, 4*x - 3*y - 11], [x, y])[x] == Rational(16, 5) and solve([3*x + 4*y - 12, 4*x - 3*y - 11], [x, y])[y] == Rational(3, 5) and sqrt((Rational(16,5) - 2)**2 + (Rational(3,5) + 1)**2) == 2 */}

วิธีนี้ถูกต้องและได้เท้าฉากมาด้วย แต่ยาวถึงสี่ขั้น และเศษส่วนทำให้พลาดง่าย ถ้าโจทย์ต้องการแค่ระยะ มีทางที่สั้นกว่ามาก

## สูตรระยะ

<Thm>
ระยะจาก $P(x_0,y_0)$ ถึงเส้น $Ax+By+C=0$ คือ
$$d=\frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}$$
เมื่อ $A,B$ ไม่เป็นศูนย์พร้อมกัน
</Thm>

อ่านสูตรนี้ทีละส่วน ตัวเศษคือการแทนพิกัดของจุดลงในซ้ายมือของสมการเส้น ถ้าจุดอยู่บนเส้น ค่านี้เป็นศูนย์ ระยะก็เป็นศูนย์ ตรงกับความรู้สึก ยิ่งจุดอยู่ไกลเส้น ค่านี้ยิ่งห่างจากศูนย์ ค่าสัมบูรณ์ทำให้ได้ระยะไม่ติดลบ ตัวหารปรับความยาวตามเวกเตอร์ตั้งฉาก $(A,B)$ ถ้าคูณสมการทั้งเส้นด้วยค่าคงตัวที่ไม่เป็นศูนย์ ตัวเศษและตัวส่วนถูกคูณด้วยค่าสัมบูรณ์เดียวกัน ระยะจึงคงเดิม

<Reveal summary="ดูที่มาของสูตร">

ทิศที่ไป $A$ หน่วยตามแกน $x$ และ $B$ หน่วยตามแกน $y$ มีความชัน $\tfrac{B}{A}$ ซึ่งคูณกับความชันของเส้น $-\tfrac{A}{B}$ ได้ $-1$ ทิศนี้จึงตั้งฉากกับเส้น เท้าฉากจึงเขียนได้เป็น $H(x_0 - tA,\ y_0 - tB)$ สำหรับจำนวน $t$ บางค่า

$H$ อยู่บนเส้น แทนลงในสมการได้ $A(x_0 - tA) + B(y_0 - tB) + C = 0$ จัดได้ $t = \dfrac{Ax_0 + By_0 + C}{A^2 + B^2}$

ระยะ $PH = \sqrt{(tA)^2 + (tB)^2} = |t|\sqrt{A^2 + B^2}$ แทนค่า $t$ แล้วตัด $\sqrt{A^2 + B^2}$ หนึ่งตัวได้สูตรข้างบน กรณีเส้นตั้งหรือเส้นนอนก็ใช้เหตุผลเดียวกันได้

</Reveal>

{/* check: simplify(solve(a*(h - t*a) + b*(k - t*b) + c, t)[0] - (a*h + b*k + c)/(a**2 + b**2)) == 0 and (2 - Rational(-10, 25)*3, -1 - Rational(-10, 25)*4) == (Rational(16, 5), Rational(3, 5)) */}

<Example n={2}>

หาระยะจาก $(2,-1)$ ถึงเส้น $3x+4y-12=0$ ด้วยสูตร

<Steps reveal>
1. ตัวเศษ $|3(2)+4(-1)-12|=|-10|=10$ แทนพิกัดลงไปตรงตำแหน่งของ $x$ และ $y$ ทั้งหมด รวมค่าคงตัว $-12$ ด้วย
2. ตัวส่วน $\sqrt{9+16}=5$
3. ระยะเท่ากับ $10/5=2$ หน่วย ตรงกับตัวอย่างที่ 1 แต่ใช้แค่สามบรรทัด
</Steps>
</Example>

{/* check: abs(3*2+4*(-1)-12)/sqrt(3**2+4**2)==2 */}

<Think>

แทนจุดในสมการแล้วได้ $-10$ จะตอบระยะ $-2$ ได้ไหม

<Reveal>
ไม่ได้ เครื่องหมายบอกด้านของเส้นตามการเลือกสัมประสิทธิ์ แต่ระยะต้องไม่ติดลบ จึงใช้ค่าสัมบูรณ์
</Reveal>
</Think>

สูตรต้องการเส้นในรูป $Ax + By + C = 0$ ถ้าโจทย์ให้รูป $y = mx + b$ ต้องย้ายทุกพจน์ไปข้างเดียวก่อน

<Example n={3}>

หาระยะจาก $(-1, 3)$ ถึงเส้น $y = 2x + 1$

<Steps reveal>
1. ย้ายทุกพจน์ไปข้างเดียว $2x - y + 1 = 0$ จึงได้ $A = 2$ $B = -1$ $C = 1$ สังเกตว่า $B$ เป็น $-1$ ไม่ใช่ $1$
2. ตัวเศษ $|2(-1) - 3 + 1| = |-4| = 4$
3. ตัวส่วน $\sqrt{2^2 + (-1)^2} = \sqrt5$
4. ระยะ $\tfrac{4}{\sqrt5} = \tfrac{4\sqrt5}{5} \approx 1.79$ หน่วย คูณทั้งเศษและส่วนด้วย $\sqrt5$ เพื่อไม่ให้มีกรณฑ์ที่ตัวส่วน
</Steps>
</Example>

{/* check: abs(2*(-1) - 3 + 1)/sqrt(5) == 4*sqrt(5)/5 and abs(4*sqrt(5)/5 - Rational('1.79')) < Rational('0.01') */}

<Think>

เพื่อนหาระยะจาก $(-1, 3)$ ถึง $y = 2x + 1$ โดยใช้ $A = 2$ $B = 1$ $C = 1$ ได้ $\tfrac{|{-2} + 3 + 1|}{\sqrt5} = \tfrac{2}{\sqrt5}$ ผิดตรงไหน

<Reveal>
เพื่อนอ่านสัมประสิทธิ์จาก $y = 2x + 1$ ตรงๆ โดยไม่ย้าย $y$ ไปข้างเดียวกัน เมื่อย้ายแล้วพจน์ $y$ มีเครื่องหมายลบ $B$ จึงเป็น $-1$ ทุกครั้งที่ใช้สูตรนี้ ให้เขียนสมการในรูปที่ขวามือเป็นศูนย์ให้เห็นก่อน
</Reveal>
</Think>

## เส้นขนาน

ระยะระหว่างเส้นขนานสองเส้นคือระยะจากจุดใดก็ได้บนเส้นหนึ่งไปถึงอีกเส้น ค่านี้เท่ากันทุกจุดเพราะเส้นขนานห่างกันเท่าเดิมตลอด ถ้าเลือกจุด $(x_0, y_0)$ บนเส้น $Ax+By+C_1=0$ จะได้ $Ax_0 + By_0 = -C_1$ แทนในสูตรระยะถึง $Ax+By+C_2=0$ ตัวเศษจึงเป็น $|C_2 - C_1|$

ถ้าเส้นขนานเขียนสัมประสิทธิ์ $A,B$ ให้ตรงกันได้ ระยะระหว่างเส้น $Ax+By+C_1=0$ และ $Ax+By+C_2=0$ คือ $|C_1-C_2|/\sqrt{A^2+B^2}$ ต้องปรับสัมประสิทธิ์ก่อนหาผลต่างค่าคงตัว

<Example n={4}>

หาระยะระหว่าง $3x+4y-5=0$ กับ $6x+8y+10=0$

<Steps reveal>
1. สัมประสิทธิ์ยังไม่ตรงกัน หารสมการที่สองด้วย $2$ ได้ $3x+4y+5=0$ การหารทั้งสมการไม่เปลี่ยนเส้น
2. สัมประสิทธิ์ตรงกันแล้ว ระยะ $|-5-5|/5=2$ หน่วย
3. ตรวจด้วยจุด $(0, \tfrac54)$ ซึ่งอยู่บนเส้นแรก ระยะถึงเส้นที่สองคือ $\tfrac{|0 + 5 + 5|}{5} = 2$ ตรงกัน
</Steps>
</Example>

{/* check: abs(-5-5)/sqrt(3**2+4**2)==2 and 3*0 + 4*Rational(5,4) - 5 == 0 and abs(3*0 + 4*Rational(5,4) + 5)/5 == 2 */}

ถ้าลืมหารสองแล้วคิด $|-5 - 10|/5 = 3$ จะได้คำตอบผิด เพราะ $C$ ของสองสมการวัดด้วยหน่วยคนละขนาด

## สองเส้นที่อยู่ห่างเท่ากัน

จุดที่ห่างจากเส้นตรงด้วยระยะคงที่อยู่ได้สองด้าน ค่าสัมบูรณ์ในสูตรระยะเก็บสองกรณีนี้ไว้ ถ้าแก้สมการควรแยกบวกและลบครบ

<Example n={5}>

เส้นขนานกับ $3x+4y-2=0$ อยู่ห่าง $2$ หน่วย มีสมการใดบ้าง

<Steps reveal>
1. เขียนเส้นใหม่ $3x+4y+C=0$ เพื่อให้ความชันเดิม
2. ระยะคือ $|C-(-2)|/5=2$ จึงได้ $|C+2|=10$
3. ค่าสัมบูรณ์เท่ากับ $10$ ได้สองกรณี $C + 2 = 10$ หรือ $C + 2 = -10$ จึงได้ $C=8$ หรือ $C=-12$ เป็นสองเส้นที่อยู่คนละด้าน
</Steps>
</Example>

{/* check: abs(8+2)/5==2 and abs(-12+2)/5==2 */}

การตอบเพียงเส้นเดียวจะขาดอีกด้าน เว้นแต่โจทย์ระบุว่าต้องอยู่ด้านใดของเส้นเดิม ถ้าโจทย์ให้ผ่านจุดเพิ่ม สามารถแทนจุดในสองสมการเพื่อเลือกเส้นที่ตรงเงื่อนไข

## ใช้ระยะเป็นความสูงของสามเหลี่ยม

พื้นที่สามเหลี่ยมคือครึ่งหนึ่งของฐานคูณสูง เมื่อรู้พิกัดจุดยอดทั้งสาม ฐานหาได้จากสูตรระยะสองจุด ส่วนความสูงคือระยะจากจุดยอดที่เหลือถึงเส้นที่เป็นฐาน

<Example n={6}>

แปลงดอกไม้รูปสามเหลี่ยมมีมุมอยู่ที่ $A(1, 1)$ $B(5, 4)$ $C(2, 6)$ หน่วยเป็นเมตร มีพื้นที่กี่ตารางเมตร

<Steps reveal>
1. เลือก $AB$ เป็นฐาน ยาว $\sqrt{4^2 + 3^2} = 5$ เมตร
2. เส้น $AB$ มีความชัน $\tfrac34$ เขียน $y - 1 = \tfrac34(x - 1)$ คูณสี่แล้วจัดได้ $3x - 4y + 1 = 0$ ตรวจ $B$ ได้ $15 - 16 + 1 = 0$
3. ความสูงคือระยะจาก $C$ ถึงเส้นนี้ $\tfrac{|3(2) - 4(6) + 1|}{\sqrt{9 + 16}} = \tfrac{17}{5}$ เมตร
4. พื้นที่ $\tfrac12 \times 5 \times \tfrac{17}{5} = \tfrac{17}{2} = 8.5$ ตารางเมตร
</Steps>
</Example>

{/* check: sqrt(4**2+3**2) == 5 and 3*5 - 4*4 + 1 == 0 and Rational(abs(3*2 - 4*6 + 1), 5) == Rational(17, 5) and Rational(1, 2)*5*Rational(17, 5) == Rational(17, 2) */}
{/* check: Rational(abs(1*(4 - 6) + 5*(6 - 1) + 2*(1 - 4)), 2) == Rational(17, 2) */}

หน้าถัดไปจะกลับคำถาม แทนที่จะวัดระยะจากจุดหนึ่ง เราจะรวบรวมทุกจุดที่อยู่ห่างจากจุดคงที่จุดหนึ่งเป็นระยะเท่ากัน ผลที่ได้คือวงกลม ซึ่งเป็นภาคตัดกรวยชนิดแรกของบทนี้

## สรุป

- ระยะสั้นที่สุดตั้งฉากกับเส้น เพราะด้านตรงข้ามมุมฉากยาวกว่าขาเสมอ
- หาได้สองวิธี หาเท้าฉากด้วยระบบสมการแล้ววัดระยะ หรือใช้สูตร $d = \tfrac{|Ax_0 + By_0 + C|}{\sqrt{A^2 + B^2}}$
- ก่อนใช้สูตร จัดเส้นให้ขวามือเป็นศูนย์ ตัวเศษต้องมีค่าสัมบูรณ์
- เทียบเส้นขนานต้องทำสัมประสิทธิ์ให้ตรงกัน และเส้นที่ห่างระยะหนึ่งมีสองด้าน
