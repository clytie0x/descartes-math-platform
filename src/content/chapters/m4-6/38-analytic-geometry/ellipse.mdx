ช่างจัดสวนอยากทำแปลงดอกไม้รูปวงรี เขาตอกหมุดสองตัวลงดิน ผูกเชือกเส้นหนึ่งไว้กับหมุดทั้งสอง เอาไม้ดึงเชือกให้ตึงแล้วลากไปรอบๆ รอยที่ไม้ขีดบนดินคือวงรี ทุกจุดบนรอยนั้นมีสมบัติเดียวกัน ระยะจากจุดนั้นถึงหมุดตัวแรกบวกระยะถึงหมุดตัวที่สองเท่ากับความยาวเชือกเสมอ

วงรีพบได้ในธรรมชาติด้วย ดาวเคราะห์ทุกดวงโคจรรอบดวงอาทิตย์เป็นวงรีที่มีดวงอาทิตย์อยู่ที่โฟกัสหนึ่ง และห้องที่มีเพดานโค้งเป็นวงรี ถ้าคนหนึ่งกระซิบที่โฟกัสหนึ่ง อีกคนที่ยืนอยู่ที่โฟกัสอีกจุดจะได้ยินชัด เพราะเสียงที่สะท้อนผนังทุกทิศเดินทางไปรวมที่โฟกัสอีกจุดในเวลาเท่ากัน ห้องแบบนี้เรียกว่าห้องกระซิบ

## นิยามด้วยผลบวกระยะ

<Def>
**วงรี** คือเซตของจุดทุกจุดบนระนาบที่ผลบวกของระยะจากจุดนั้นไปยังจุดคงที่สองจุดมีค่าคงตัว จุดคงที่สองจุดเรียกว่า**โฟกัส** และค่าคงตัวต้องมากกว่าระยะระหว่างโฟกัส
</Def>

ทำไมค่าคงตัวต้องมากกว่าระยะระหว่างโฟกัส ลองนึกถึงเชือก ถ้าเชือกยาวเท่ากับระยะระหว่างหมุดพอดี เชือกจะตึงเป็นเส้นตรงระหว่างหมุด ลากไปไหนไม่ได้ ถ้าเชือกสั้นกว่านั้นก็ผูกไม่ถึงด้วยซ้ำ นี่คืออสมการสามเหลี่ยม ผลบวกของสองด้านต้องยาวกว่าด้านที่สาม

วางศูนย์กลางวงรีที่จุดกำเนิด โฟกัสที่ $F_1(-c, 0)$ และ $F_2(c, 0)$ และเรียกค่าคงตัวว่า $2a$ ทำไมเลือกเขียนเป็น $2a$ ให้จุดที่วงรีตัดแกน $x$ ทางขวาเป็น $(v, 0)$ ระยะถึง $F_1$ คือ $v + c$ ระยะถึง $F_2$ คือ $v - c$ ผลบวกคือ $2v$ แต่ผลบวกนี้ต้องเท่ากับ $2a$ จึงได้ $v = a$ จุดยอดจึงอยู่ที่ $(\pm a, 0)$ และความยาวเชือกเท่ากับความยาวของวงรีตามแนวยาวพอดี ส่วนนี้เรียกว่า**แกนเอก** ยาว $2a$

ต่อไปดูจุด $B(0, b)$ ที่วงรีตัดแกน $y$ จุดนี้อยู่ห่างโฟกัสทั้งสองเท่ากันเพราะสมมาตร ผลบวกเป็น $2a$ แต่ละระยะจึงเท่ากับ $a$ สามเหลี่ยม $OBF_2$ เป็นสามเหลี่ยมมุมฉาก มีขา $b$ กับ $c$ และด้านตรงข้ามมุมฉาก $a$ จากพีทาโกรัส

$$c^2 = a^2 - b^2$$

ส่วนของเส้นตรงจาก $(0, -b)$ ถึง $(0, b)$ เรียกว่า**แกนโท** ยาว $2b$ และสั้นกว่าแกนเอก เพราะ $a$ เป็นด้านตรงข้ามมุมฉาก จึงยาวกว่าทั้ง $b$ และ $c$ โฟกัสจึงอยู่ภายในวงรีเสมอ

## สมการรูปมาตรฐาน

แปลงนิยาม $PF_1 + PF_2 = 2a$ เป็นสมการด้วยสูตรระยะ แล้วกำจัดเครื่องหมายรากทีละตัว จะได้

$$\frac{x^2}{a^2}+\frac{y^2}{b^2}=1 \qquad a > b > 0$$

<Reveal summary="ดูการจัดรูปทีละขั้น">

1. เริ่มจาก $\sqrt{(x + c)^2 + y^2} + \sqrt{(x - c)^2 + y^2} = 2a$ ย้ายรากตัวที่สองไปขวามือ ก่อนยกกำลังสอง เพื่อไม่ให้เกิดพจน์ที่มีรากคูณกันสองตัว
2. ยกกำลังสอง $(x + c)^2 + y^2 = 4a^2 - 4a\sqrt{(x - c)^2 + y^2} + (x - c)^2 + y^2$
3. พจน์ $x^2$ $y^2$ $c^2$ ตัดกัน เหลือ $4cx = 4a^2 - 4a\sqrt{(x - c)^2 + y^2}$ หารสี่แล้วจัดได้ $a\sqrt{(x - c)^2 + y^2} = a^2 - cx$
4. ยกกำลังสองอีกครั้ง $a^2(x^2 - 2cx + c^2 + y^2) = a^4 - 2a^2cx + c^2x^2$ พจน์ $-2a^2cx$ ตัดกัน
5. จัดได้ $(a^2 - c^2)x^2 + a^2y^2 = a^2(a^2 - c^2)$ แทน $a^2 - c^2 = b^2$ แล้วหารด้วย $a^2b^2$ ได้รูปมาตรฐาน

</Reveal>

{/* check: expand(a**2*((x - c)**2 + y**2) - (a**2 - c*x)**2) == expand((a**2 - c**2)*x**2 + a**2*y**2 - a**2*(a**2 - c**2)) */}

ถ้าแกนเอกเป็นแนวตั้ง โฟกัสอยู่บนแกน $y$ สมการเป็น $\tfrac{x^2}{b^2} + \tfrac{y^2}{a^2} = 1$ คือ $a^2$ ย้ายไปอยู่ใต้ $y^2$ วิธีดูง่ายที่สุดคือ**ตัวส่วนที่ใหญ่กว่าบอกทิศของแกนเอก** และตัวส่วนที่ใหญ่กว่าคือ $a^2$ เสมอ

ถ้าเลื่อนศูนย์กลางไปที่ $(h, k)$ ใช้ $(x - h)$ และ $(y - k)$ แทน $x$ และ $y$ แบบเดียวกับวงกลมและพาราโบลา จุดยอดและโฟกัสทั้งหมดเลื่อนไปพร้อมศูนย์กลาง

<Board name="c38-ellipse" label="วงรีกึ่งแกนเอกสี่หน่วย ปรับระยะโฟกัสและสังเกตกึ่งแกนโท" caption="เลื่อนโฟกัสออกทีละน้อย แล้วตรวจความสัมพันธ์ c² เท่ากับ a² ลบ b²" />

เมื่อ $c = 0$ โฟกัสทั้งสองซ้อนกันที่ศูนย์กลาง $b = a$ และวงรีกลายเป็นวงกลม ยิ่ง $c$ เข้าใกล้ $a$ วงรียิ่งแบน อัตราส่วน $\tfrac{c}{a}$ จึงใช้บอกว่าวงรีแบนแค่ไหน วงโคจรของโลกมีอัตราส่วนนี้น้อยมาก จึงเกือบเป็นวงกลม

## อ่านค่าจากสมการ

<Example n={1}>

หาจุดยอด จุดปลายแกนโท และโฟกัสของ $x^2/25+y^2/9=1$

<Steps reveal>
1. ตัวส่วนที่ใหญ่กว่าคือ $25$ อยู่ใต้ $x^2$ จึงเป็นวงรีแกนเอกแนวนอน $a=5$ $b=3$
2. จุดยอด $(\pm 5, 0)$ จุดปลายแกนโท $(0, \pm 3)$ ได้จากแทน $y = 0$ และ $x = 0$ ในสมการ
3. $c^2=25-9=16$ จึงได้ $c=4$ โฟกัสคือ $(-4,0)$ และ $(4,0)$
4. ตรวจกับนิยามที่จุด $(0, 3)$ ระยะถึงโฟกัสแต่ละตัวคือ $\sqrt{16 + 9} = 5$ ผลบวก $10 = 2a$ ถูกต้อง
</Steps>
</Example>

{/* check: sqrt(25-9)==4 and 2*sqrt(4**2 + 3**2) == 2*5 */}

<Example n={2}>

หาโฟกัสของ $\frac{(x-2)^2}{9}+\frac{(y+1)^2}{25}=1$

<Steps reveal>
1. ศูนย์กลาง $(2,-1)$ ตัวส่วนใหญ่ใต้พจน์ $y$ จึงเป็นวงรีแกนเอกแนวตั้ง
2. $a=5$ $b=3$ และ $c=\sqrt{25-9}=4$
3. โฟกัสเลื่อนจากศูนย์กลางไปตามแกนตั้ง $(2,-1\pm4)$ คือ $(2,3)$ และ $(2,-5)$ จุดยอดคือ $(2, -1 \pm 5)$ คือ $(2, 4)$ และ $(2, -6)$
</Steps>
</Example>

{/* check: sqrt(25-9)==4 and (-1+4,-1-4)==(3,-5) and (-1+5, -1-5) == (4, -6) */}

ถ้าส่งระยะโฟกัสไปตามแกน $x$ จะได้คนละวงรี แม้คำนวณ $c$ ถูก ต้องตรวจทั้งตำแหน่งศูนย์กลางและทิศของแกนเอกก่อนเขียนคู่อันดับ

<Think>

วงรีใช้ $c^2=a^2+b^2$ ได้ไหม

<Reveal>
ไม่ได้ วงรีใช้ผลต่างเพื่อให้โฟกัสอยู่ภายใน ส่วนไฮเพอร์โบลาใช้ผลบวก ต้องดูชนิดรูปก่อนเลือกสูตร จำจากสามเหลี่ยม $OBF_2$ ในรูปก็ได้ $a$ เป็นด้านตรงข้ามมุมฉาก จึงยาวที่สุด
</Reveal>
</Think>

<Think>

เพื่อนอ่าน $\tfrac{x^2}{9} + \tfrac{y^2}{25} = 1$ ว่า $a = 3$ เพราะ $a$ อยู่คู่กับ $x$ เสมอ ถูกไหม

<Reveal>
ไม่ถูก สำหรับวงรี $a$ คือกึ่งแกนเอก ซึ่งยาวกว่ากึ่งแกนโทเสมอ จึงต้องเป็นรากของตัวส่วนที่ใหญ่กว่า ข้อนี้ $a = 5$ และแกนเอกเป็นแนวตั้ง ถ้าใช้ $a = 3$ จะได้ $c^2 = 9 - 25$ ติดลบ ซึ่งเป็นไปไม่ได้ เป็นสัญญาณว่าอ่านผิด
</Reveal>
</Think>

## หาสมการจากสถานการณ์

<Example n={3}>

ช่างจัดสวนตอกหมุดสองตัวห่างกัน $6$ เมตร ใช้เชือกยาว $10$ เมตร แปลงดอกไม้ที่ได้ยาวและกว้างเท่าไร และมีสมการอะไรถ้าวางศูนย์กลางที่จุดกำเนิด

<Steps reveal>
1. ความยาวเชือกคือผลบวกระยะ $2a = 10$ จึงได้ $a = 5$ หมุดคือโฟกัส ห่างกัน $2c = 6$ จึงได้ $c = 3$
2. $b^2 = a^2 - c^2 = 25 - 9 = 16$ จึงได้ $b = 4$
3. แปลงยาวตามแกนเอก $2a = 10$ เมตร กว้างตามแกนโท $2b = 8$ เมตร
4. วางหมุดบนแกน $x$ สมการคือ $\tfrac{x^2}{25} + \tfrac{y^2}{16} = 1$
</Steps>
</Example>

{/* check: 25 - 9 == 16 and sqrt(16) == 4 */}

## ทำกำลังสองสมบูรณ์

เมื่อสมการถูกกระจายมา ให้ดูก่อนว่าสัมประสิทธิ์ของ $x^2$ กับ $y^2$ เป็นบวกทั้งคู่แต่ไม่เท่ากัน นั่นคือลักษณะของวงรี จากนั้นทำกำลังสองสมบูรณ์ทีละตัวแปร ต่างจากวงกลมตรงที่ต้องดึงสัมประสิทธิ์ออกก่อน และสุดท้ายต้องหารให้ขวามือเป็น $1$

<Example n={4}>

หาศูนย์กลาง จุดยอด และโฟกัสของ $9x^2 + 4y^2 - 36x + 8y + 4 = 0$

<Steps reveal>
1. จับกลุ่มและย้ายค่าคงตัว $(9x^2 - 36x) + (4y^2 + 8y) = -4$
2. ดึงสัมประสิทธิ์ออกจากแต่ละกลุ่ม $9(x^2 - 4x) + 4(y^2 + 2y) = -4$ ต้องทำก่อน เพราะสูตรเติมกำลังสองใช้ได้เมื่อสัมประสิทธิ์ของกำลังสองเป็น $1$
3. เติม $4$ ในวงเล็บแรก ซึ่งจริงๆ คือเติม $9 \times 4 = 36$ และเติม $1$ ในวงเล็บที่สอง ซึ่งคือเติม $4 \times 1 = 4$ ต้องบวกขวามือด้วยค่าที่เติมจริง $9(x - 2)^2 + 4(y + 1)^2 = -4 + 36 + 4 = 36$
4. หารด้วย $36$ ให้ขวามือเป็น $1$ ได้ $\tfrac{(x - 2)^2}{4} + \tfrac{(y + 1)^2}{9} = 1$
5. ศูนย์กลาง $(2, -1)$ ตัวส่วนใหญ่ $9$ อยู่ใต้ $y$ แกนเอกแนวตั้ง $a = 3$ $b = 2$ $c = \sqrt{9 - 4} = \sqrt5$
6. จุดยอด $(2, -1 \pm 3)$ คือ $(2, 2)$ และ $(2, -4)$ โฟกัส $(2, -1 \pm \sqrt5)$
</Steps>
</Example>

{/* check: expand(36*((x - 2)**2/4 + (y + 1)**2/9 - 1)) == 9*x**2 + 4*y**2 - 36*x + 8*y + 4 and sqrt(9 - 4) == sqrt(5) */}

<Note kind="warning" title="บวกขวามือด้วยค่าที่เติมจริง">
ในตัวอย่างที่ 4 ถ้าบวกขวามือแค่ $4 + 1$ จะได้ $9(x - 2)^2 + 4(y + 1)^2 = 1$ ซึ่งผิด เพราะเลข $4$ ที่เติมในวงเล็บถูกคูณด้วย $9$ ข้อผิดพลาดนี้เหมือนกับหน้า 25.3 ที่ $-9$ ในวงเล็บถูกคูณด้วย $2$
</Note>

หน้าถัดไปจะเปลี่ยนผลบวกเป็นผลต่าง ได้ไฮเพอร์โบลา ซึ่งหน้าตาต่างจากวงรีมาก แต่สมการต่างกันแค่เครื่องหมายเดียว

## สรุป

- วงรีคือจุดที่ผลบวกระยะถึงสองโฟกัสเท่ากับ $2a$ ซึ่งเป็นความยาวแกนเอก
- รูปมาตรฐาน $\tfrac{(x - h)^2}{a^2} + \tfrac{(y - k)^2}{b^2} = 1$ ตัวส่วนที่ใหญ่กว่าคือ $a^2$ และบอกทิศของแกนเอก
- วงรีมีสองพจน์บวกและใช้ $c^2=a^2-b^2$ โฟกัสอยู่ภายใน
- รูปทั่วไป ดึงสัมประสิทธิ์ออกก่อนเติมกำลังสอง บวกขวามือด้วยค่าที่เติมจริง แล้วหารให้ขวามือเป็น $1$
