ในหน้า 46.1 รถที่วิ่งได้ $s(t) = 5t^2$ เมตร มีความเร็วเฉลี่ยในช่วงสั้นลงเรื่อยๆ เข้าใกล้ $20$ เมตรต่อวินาที ตัวเลข $20$ นี้คือความเร็วขณะหนึ่งที่วินาทีที่ $2$ ถ้าวาดกราฟระยะทางเทียบเวลา ความเร็วเฉลี่ยคือความชันของเส้นที่ลากผ่านสองจุดบนกราฟ ส่วนความเร็วขณะหนึ่งคือความชันของกราฟตรงจุดเดียว

ความคิดเดียวกันใช้ได้กับปริมาณอื่นทุกอย่างที่เปลี่ยนตามกัน เช่นค่าไฟที่เปลี่ยนตามจำนวนหน่วย หรืออุณหภูมิที่เปลี่ยนตามเวลา หน้านี้จะนิยามความชันที่จุดเดียวด้วยลิมิต แล้วคำนวณจากนิยามจนเห็นแบบแผนที่จะกลายเป็นสูตรในหน้าถัดไป

## ความชันเส้นตัดคืออัตราการเปลี่ยนแปลงเฉลี่ย

เส้นตรงที่ลากผ่านสองจุดบนกราฟเรียกว่า**เส้นตัด** ถ้าจุดแรกอยู่ที่ $x = a$ และจุดที่สองห่างออกไป $h$ จุดทั้งสองคือ $(a, f(a))$ และ $(a + h, f(a + h))$ ความชันของเส้นตัดคือผลต่างของค่า $y$ หารผลต่างของค่า $x$

$$\text{ความชันเส้นตัด} = \frac{f(a+h) - f(a)}{h}$$

ปริมาณนี้คืออัตราการเปลี่ยนแปลงเฉลี่ยของ $f$ บนช่วงจาก $a$ ถึง $a + h$ เมื่อเลื่อนจุดที่สองเข้าหาจุดแรก คือให้ $h$ เข้าใกล้ศูนย์ เส้นตัดจะหมุนเข้าหาเส้นที่แตะกราฟพอดีที่จุดแรก เส้นนั้นคือ**เส้นสัมผัส** ลองเลื่อน $h$ ในกราฟข้างล่างให้เข้าใกล้ศูนย์ทั้งจากด้านบวกและด้านลบ

<Board name="c46-secant" label="กราฟ y เท่ากับ x กำลังสอง กับเส้นตัดผ่านจุด 1 1 และจุดที่ห่างออกไป h เลื่อน h ได้" caption="เมื่อ h เข้าใกล้ศูนย์ เส้นตัดสีเขียวหมุนเข้าหาเส้นสัมผัสที่มีความชัน 2" />

<Example n={1}>

หาความชันเส้นตัดของกราฟ $y = x^2$ จากจุด $(1, 1)$ ไปยังจุดที่ $x = 3$ $2$ $1.5$ $1.1$ แล้วคาดความชันของเส้นสัมผัสที่ $x = 1$

<Steps reveal>
1. ไป $x = 3$ ความชันคือ $\dfrac{9 - 1}{3 - 1} = 4$ ไป $x = 2$ ได้ $\dfrac{4-1}{1} = 3$
2. ไป $x = 1.5$ ได้ $\dfrac{2.25 - 1}{0.5} = 2.5$ ไป $x = 1.1$ ได้ $\dfrac{1.21 - 1}{0.1} = 2.1$
3. ตัวเลขลดลงเข้าหา $2$ ดูให้เป็นสูตร ความชันเส้นตัดคือ $\dfrac{(1+h)^2 - 1}{h} = \dfrac{2h + h^2}{h} = 2 + h$ เมื่อ $h \ne 0$
4. เมื่อ $h$ เข้าใกล้ศูนย์ $2 + h$ เข้าใกล้ $2$ ความชันของเส้นสัมผัสที่ $x = 1$ จึงเท่ากับ $2$
</Steps>
</Example>

## นิยามของอนุพันธ์

<Def>
อนุพันธ์ของ $f$ ที่ $x = a$ คือ $f'(a)=\lim_{h\to0}\dfrac{f(a+h)-f(a)}h$ เมื่อลิมิตนี้มีค่า ถ้ามีค่าจะกล่าวว่า $f$ หาอนุพันธ์ได้ที่ $a$
</Def>

อนุพันธ์ที่ $a$ มีสองความหมายพร้อมกัน ในทางกราฟคือความชันของเส้นสัมผัสที่จุด $(a, f(a))$ ในทางปริมาณคืออัตราการเปลี่ยนแปลงขณะหนึ่งของ $f$ เทียบกับ $x$ หน่วยของอนุพันธ์จึงเป็นหน่วยของผลลัพธ์ต่อหน่วยของตัวแปรต้น ระยะทางเป็นเมตร เวลาเป็นวินาที อนุพันธ์ก็เป็นเมตรต่อวินาที

ถ้าเปลี่ยน $a$ เป็นตัวแปร $x$ เราได้ฟังก์ชันใหม่ $f'(x)$ ที่บอกความชันของกราฟที่ทุกจุด เรียกว่า**ฟังก์ชันอนุพันธ์** เขียนได้หลายแบบ คือ $f'(x)$ หรือ $y'$ หรือ $\dfrac{dy}{dx}$ แบบสุดท้ายอ่านว่า ดีวายดีเอกซ์ เตือนให้นึกถึงผลต่างของ $y$ หารผลต่างของ $x$ ที่เล็กลงเรื่อยๆ ไม่ใช่เศษส่วนธรรมดาที่ตัด $d$ ทิ้งได้

ขั้นตอนหาอนุพันธ์จากนิยามมีสามขั้นเสมอ คือ เขียนผลต่าง $f(x + h) - f(x)$ แล้วจัดรูปให้ทุกพจน์มี $h$ เป็นตัวประกอบ หารด้วย $h$ ให้หมดเมื่อ $h \ne 0$ แล้วจึงให้ $h$ เข้าใกล้ศูนย์ ถ้าแทน $h = 0$ ก่อนตัด จะได้ $\tfrac{0}{0}$ เหมือนในหน้า 46.1

<Example n={2}>

ใช้นิยามหาอนุพันธ์ของ $f(x)=x^2$ ที่ $x=a$ แล้วใช้ผลนี้หาความเร็วของรถ $s(t) = 5t^2$ ที่วินาทีที่ $2$

<Steps reveal>
1. ผลต่าง $(a+h)^2 - a^2 = a^2 + 2ah + h^2 - a^2 = 2ah + h^2$ ทุกพจน์มี $h$ แล้ว
2. หารด้วย $h$ ได้ $2a + h$ เมื่อ $h\ne0$
3. ให้ $h\to0$ ได้ $f'(a)=2a$ ความชันที่ $x = 1$ จึงเป็น $2$ ตรงกับตัวอย่างที่ 1
4. รถมี $s(t) = 5t^2$ ทำแบบเดียวกันได้ผลต่างหาร $h$ เป็น $10t + 5h$ จึงได้ $s'(t) = 10t$ และ $s'(2) = 20$ เมตรต่อวินาที ตรงกับตารางในหน้า 46.1
</Steps>
</Example>

{/* check: limit(((a+h)**2-a**2)/h,h,0)==2*a and limit((5*(t + h)**2 - 5*t**2)/h, h, 0) == 10*t and (10*t).subs(t, 2) == 20 */}

<Example n={3}>

ใช้นิยามหา $f'(x)$ เมื่อ $f(x) = x^3$ แล้วหาความชันที่ $x = -1$

<Steps reveal>
1. กระจาย $(x + h)^3 = x^3 + 3x^2h + 3xh^2 + h^3$ ลบ $x^3$ ออก เหลือ $3x^2h + 3xh^2 + h^3$
2. หารด้วย $h$ ได้ $3x^2 + 3xh + h^2$ เมื่อ $h \ne 0$
3. ให้ $h\to0$ สองพจน์หลังมี $h$ จึงหายไป ได้ $f'(x) = 3x^2$
4. ที่ $x = -1$ ความชันคือ $3(-1)^2 = 3$ เป็นบวก แม้จุดนั้นอยู่ใต้แกน $x$ ความชันบอกทิศที่กราฟกำลังไป ไม่ได้บอกว่ากราฟอยู่สูงหรือต่ำ
</Steps>
</Example>

{/* check: limit(((x + h)**3 - x**3)/h, h, 0) == 3*x**2 and (3*x**2).subs(x, -1) == 3 */}

ผลสองตัวอย่างนี้มีแบบแผน $x^2$ ได้ $2x$ และ $x^3$ ได้ $3x^2$ คือดึงเลขชี้กำลังลงมาคูณแล้วลดกำลังลงหนึ่ง หน้า 46.3 จะใช้แบบแผนนี้เป็นสูตร แต่ก่อนจะเชื่อสูตร ลองดูฟังก์ชันที่มีรากที่สองว่ายังเข้ากับแบบแผนหรือไม่

<Example n={4}>

ใช้นิยามหาอนุพันธ์ของ $f(x) = \sqrt{x}$ เมื่อ $x$ มากกว่าศูนย์ แล้วหา $f'(4)$

<Steps reveal>
1. ตั้ง $\dfrac{\sqrt{x+h} - \sqrt{x}}{h}$ แทน $h = 0$ ได้ $\tfrac{0}{0}$ และแยกตัวประกอบไม่ได้ จึงคูณสังยุค $\sqrt{x+h} + \sqrt{x}$ ทั้งเศษและส่วนแบบหน้า 46.1
2. เศษกลายเป็น $(x + h) - x = h$ ได้ $\dfrac{h}{h(\sqrt{x+h} + \sqrt{x})} = \dfrac{1}{\sqrt{x+h} + \sqrt{x}}$ เมื่อ $h \ne 0$
3. ให้ $h\to0$ ได้ $f'(x) = \dfrac{1}{2\sqrt{x}}$ ซึ่งเขียนได้เป็น $\tfrac{1}{2}x^{-1/2}$ เข้ากับแบบแผนดึงเลขชี้กำลัง $\tfrac{1}{2}$ ลงมาแล้วลดกำลังลงหนึ่ง
4. $f'(4) = \dfrac{1}{2 \cdot 2} = \dfrac{1}{4}$ ตรงกับลิมิตในตัวอย่างที่ 4 ของหน้า 46.1 เพราะลิมิตนั้นคือนิยามของอนุพันธ์ที่ $4$ ในอีกรูปหนึ่ง
</Steps>
</Example>

{/* check: simplify(limit((sqrt(x + h) - sqrt(x))/h, h, 0) - 1/(2*sqrt(x))) == 0 and (1/(2*sqrt(x))).subs(x, 4) == Rational(1, 4) */}

## เส้นสัมผัสบอกทิศของกราฟ

<Board name="c46-tangent" label="เส้นสัมผัสกราฟ y เท่ากับ x กำลังสอง ที่เลื่อนจุดสัมผัสได้" caption="ความชันของเส้นสัมผัสเท่ากับสองเท่าของพิกัด x ของจุดสัมผัส" />

เลื่อนจุดสัมผัสจากด้านลบผ่านศูนย์ไปด้านบวก ความชันเปลี่ยนจากลบเป็นศูนย์แล้วเป็นบวกตาม $f'(x) = 2x$ ช่วงที่ความชันเป็นลบ กราฟกำลังลง ช่วงที่เป็นบวก กราฟกำลังขึ้น จุดต่ำสุดจึงตรงกับตำแหน่งที่เส้นสัมผัสขนานแกนนอน ข้อสังเกตนี้คือหัวใจของการหาค่าสูงสุดต่ำสุดในหน้า 46.4

<Think>

เพื่อนบอกว่าเส้นสัมผัสต้องแตะกราฟเพียงจุดเดียว เหมือนเส้นสัมผัสวงกลม เส้นสัมผัสกราฟ $y = x^3$ ที่ $x = 1$ แตะกราฟจุดเดียวหรือไม่

<Reveal>
ไม่ใช่ ความชันที่ $x = 1$ คือ $3$ เส้นสัมผัสคือ $y = 3x - 2$ ตั้ง $x^3 = 3x - 2$ ได้ $x^3 - 3x + 2 = (x - 1)^2(x + 2) = 0$ เส้นนี้จึงพบกราฟอีกครั้งที่ $x = -2$ เส้นสัมผัสของกราฟทั่วไปนิยามจากความชันที่จุดนั้น ไม่ได้นิยามจากจำนวนจุดที่แตะ คำนิยามแบบวงกลมใช้ได้เฉพาะวงกลมและภาคตัดกรวย
</Reveal>
</Think>

{/* check: factor(x**3 - 3*x + 2) == (x - 1)**2*(x + 2) and diff(x**3, x).subs(x, 1) == 3 */}

<Think>

ฟังก์ชัน $f(x) = |x|$ ต่อเนื่องที่ศูนย์ จึงต้องหาอนุพันธ์ที่ศูนย์ได้ ถูกไหม

<Reveal>
ไม่ถูก ผลหาร $\dfrac{|0 + h| - 0}{h} = \dfrac{|h|}{h}$ เป็นฟังก์ชันในตัวอย่างที่ 2 ของหน้า 46.1 ซึ่งลิมิตขวาเป็น $1$ ลิมิตซ้ายเป็น $-1$ ไม่มีลิมิตสองด้าน จึงหาอนุพันธ์ที่ศูนย์ไม่ได้ กราฟเป็นมุมแหลมที่ศูนย์ ไม่มีเส้นสัมผัสเส้นเดียว ฟังก์ชันที่หาอนุพันธ์ได้ต้องต่อเนื่อง แต่ฟังก์ชันต่อเนื่องไม่จำเป็นต้องหาอนุพันธ์ได้
</Reveal>
</Think>

## สรุป

- ความชันเส้นตัดคืออัตราการเปลี่ยนแปลงเฉลี่ย อนุพันธ์คือลิมิตของความชันนี้เมื่อ $h$ เข้าใกล้ศูนย์
- $f'(a)$ เป็นทั้งความชันเส้นสัมผัสและอัตราการเปลี่ยนแปลงขณะหนึ่ง มีหน่วยเป็นหน่วยผลลัพธ์ต่อหน่วยตัวแปรต้น
- หาจากนิยามโดยจัดผลต่างให้มี $h$ เป็นตัวประกอบ หาร $h$ ก่อน แล้วจึงให้ $h$ เข้าใกล้ศูนย์
- $x^2$ ได้ $2x$ $x^3$ ได้ $3x^2$ $\sqrt{x}$ ได้ $\dfrac{1}{2\sqrt{x}}$ ส่วน $|x|$ หาอนุพันธ์ที่ศูนย์ไม่ได้

การหาอนุพันธ์จากนิยามทุกครั้งยาวเกินไป หน้าถัดไปจะสรุปแบบแผนที่เห็นเป็นกฎ แล้วใช้กับผลบวก ผลคูณ ผลหาร และฟังก์ชันประกอบ
