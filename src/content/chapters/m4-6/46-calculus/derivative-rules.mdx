หน้า 46.2 ใช้นิยามหาอนุพันธ์ของ $x^2$ $x^3$ และ $\sqrt{x}$ แต่ละข้อต้องกระจาย จัดรูป และหาลิมิต ถ้าโจทย์ให้ $(x^2 + 1)(3x - 2)$ หรือ $\sqrt{x^2 + 9}$ การทำจากนิยามจะยาวและพลาดง่าย นักคณิตศาสตร์จึงพิสูจน์กฎไว้ครั้งเดียวจากนิยาม แล้วใช้กฎแทนนิยามตลอดไป หน้านี้รวบรวมกฎเหล่านั้นพร้อมเหตุผลว่าทำไมจึงเป็นแบบนั้น

## กฎกำลัง ค่าคงตัว และผลบวก

<Thm label="กฎพื้นฐาน">

- $\dfrac{d}{dx}c = 0$ เมื่อ $c$ เป็นค่าคงตัว
- $\dfrac{d}{dx}x^n = nx^{n-1}$ เมื่อ $n$ เป็นจำนวนจริง และ $x^n$ นิยามบนช่วงที่พิจารณา
- $\dfrac{d}{dx}\big(c\,f(x)\big) = c\,f'(x)$ และ $\dfrac{d}{dx}\big(f(x) \pm g(x)\big) = f'(x) \pm g'(x)$

</Thm>

แต่ละข้อมีเหตุผลที่เห็นได้จากกราฟ กราฟของค่าคงตัวเป็นเส้นแนวนอน ความชันจึงเป็นศูนย์ทุกจุด กฎกำลังคือแบบแผนที่เห็นในหน้า 46.2 ส่วนการคูณด้วยค่าคงตัวทำให้กราฟยืดในแนวตั้ง ความชันจึงคูณด้วยค่าเดียวกัน และผลบวกของสองฟังก์ชันเปลี่ยนเร็วเท่ากับผลรวมของความเร็วในการเปลี่ยนของแต่ละตัว

กฎกำลังใช้กับรากและเศษส่วนได้ด้วย แต่ต้องเขียนให้อยู่ในรูป $x^n$ ก่อน เช่น $\sqrt{x} = x^{1/2}$ และ $\dfrac{1}{x^2} = x^{-2}$

<Example n={1}>

(1) หา $f'(x)$ เมื่อ $f(x) = 4x^3 - 5x^2 + 7x - 2$ แล้วหา $f'(1)$

(2) หา $\dfrac{dy}{dx}$ เมื่อ $y = 6\sqrt{x} - \dfrac{2}{x^2}$ แล้วหาค่าที่ $x = 1$

<Steps reveal>
1. ข้อ (1) หาแยกทีละพจน์ $4x^3$ ได้ $12x^2$ ส่วน $-5x^2$ ได้ $-10x$ ส่วน $7x$ ได้ $7$ และค่าคงตัว $-2$ ได้ $0$
2. รวมเป็น $f'(x) = 12x^2 - 10x + 7$ จึงได้ $f'(1) = 12 - 10 + 7 = 9$
3. ข้อ (2) เขียนเป็นเลขยกกำลังก่อน $y = 6x^{1/2} - 2x^{-2}$
4. กฎกำลังให้ $6 \cdot \tfrac{1}{2}x^{-1/2} - 2(-2)x^{-3} = 3x^{-1/2} + 4x^{-3}$ หรือ $\dfrac{3}{\sqrt{x}} + \dfrac{4}{x^3}$ สังเกตว่าลบคูณลบกลายเป็นบวก
5. ที่ $x = 1$ ได้ $3 + 4 = 7$
</Steps>
</Example>

{/* check: diff(4*x**3 - 5*x**2 + 7*x - 2, x) == 12*x**2 - 10*x + 7 and diff(4*x**3 - 5*x**2 + 7*x - 2, x).subs(x, 1) == 9 and simplify(diff(6*sqrt(x) - 2/x**2, x) - (3/sqrt(x) + 4/x**3)) == 0 and diff(6*sqrt(x) - 2/x**2, x).subs(x, 1) == 7 */}

<Think>

เพื่อนหาอนุพันธ์ของ $\dfrac{1}{x^2}$ โดยหาอนุพันธ์ของตัวส่วนแล้วกลับเศษส่วน ได้ $\dfrac{1}{2x}$ ถูกไหม

<Reveal>
ไม่ถูก ไม่มีกฎที่ให้หาอนุพันธ์เฉพาะตัวส่วน ต้องเขียน $\dfrac{1}{x^2} = x^{-2}$ แล้วใช้กฎกำลังได้ $-2x^{-3} = -\dfrac{2}{x^3}$ ตรวจด้วยความหมายก็ได้ กราฟ $y = \dfrac{1}{x^2}$ เมื่อ $x$ เป็นบวกลดลงตลอด ความชันจึงต้องเป็นลบ แต่ $\dfrac{1}{2x}$ เป็นบวก
</Reveal>
</Think>

{/* check: diff(1/x**2, x) == -2/x**3 */}

## กฎผลคูณ

<Thm label="กฎผลคูณ">
$\dfrac{d}{dx}\big(u v\big) = u'v + uv'$ เมื่อ $u$ และ $v$ เป็นฟังก์ชันของ $x$ ที่หาอนุพันธ์ได้
</Thm>

นึกถึงรูปสี่เหลี่ยมผืนผ้าด้านยาว $u$ ด้านกว้าง $v$ พื้นที่คือ $uv$ เมื่อ $x$ เพิ่มเล็กน้อย ด้านยาวเพิ่ม $\Delta u$ ด้านกว้างเพิ่ม $\Delta v$ พื้นที่ที่งอกออกมามีสามส่วน คือแถบยาว $\Delta u \cdot v$ แถบกว้าง $u \cdot \Delta v$ และสี่เหลี่ยมเล็กที่มุม $\Delta u \cdot \Delta v$ หารทั้งหมดด้วย $\Delta x$ แล้วให้ $\Delta x$ เข้าใกล้ศูนย์ สองส่วนแรกกลายเป็น $u'v$ กับ $uv'$ ส่วนมุมหายไป เพราะ $\Delta u$ เข้าใกล้ศูนย์ ผลคูณของอนุพันธ์ $u'v'$ จึงไม่อยู่ในสูตรเลย

<Example n={2}>

หาอนุพันธ์ของ $f(x) = (x^2 + 1)(3x - 2)$ ด้วยกฎผลคูณ แล้วตรวจด้วยการกระจาย

<Steps reveal>
1. ให้ $u = x^2 + 1$ และ $v = 3x - 2$ ได้ $u' = 2x$ และ $v' = 3$
2. กฎผลคูณให้ $f'(x) = 2x(3x - 2) + (x^2 + 1)(3) = 6x^2 - 4x + 3x^2 + 3 = 9x^2 - 4x + 3$
3. ตรวจ กระจายก่อนได้ $f(x) = 3x^3 - 2x^2 + 3x - 2$ หาอนุพันธ์ทีละพจน์ได้ $9x^2 - 4x + 3$ ตรงกัน
4. ถ้าคำตอบสองวิธีหน้าตาต่างกัน ให้กระจายทั้งคู่ก่อนเทียบ การแทนค่าจุดเดียวแล้วตรงกันยังไม่พิสูจน์ว่าเท่ากันทุกจุด
</Steps>
</Example>

{/* check: expand(2*x*(3*x - 2) + 3*(x**2 + 1)) == 9*x**2 - 4*x + 3 and diff(expand((x**2 + 1)*(3*x - 2)), x) == 9*x**2 - 4*x + 3 */}

<Think>

อนุพันธ์ของ $x^2(x+1)$ เท่ากับ $(2x)(1) = 2x$ หรือไม่ เพราะอนุพันธ์ของ $x^2$ คือ $2x$ และของ $x + 1$ คือ $1$

<Reveal>
ไม่ใช่ อนุพันธ์ของผลคูณไม่ใช่ผลคูณของอนุพันธ์ กฎผลคูณให้ $2x(x+1)+x^2(1) = 3x^2 + 2x$ หรือกระจายก่อนเป็น $x^3+x^2$ แล้วหาอนุพันธ์ ได้ผลเดียวกัน ที่ $x = 1$ ความชันจริงคือ $5$ แต่คำตอบผิดให้ $2$
</Reveal>
</Think>

{/* check: expand(2*x*(x+1)+x**2)==3*x**2+2*x and diff(x**2*(x+1),x).subs(x,1)==5 */}

## กฎผลหาร

<Thm label="กฎผลหาร">
$\dfrac{d}{dx}\left(\dfrac{u}{v}\right) = \dfrac{u'v - uv'}{v^2}$ เมื่อ $v \ne 0$
</Thm>

ลำดับในตัวเศษสำคัญ เพราะมีเครื่องหมายลบ วิธีจำคือเริ่มจากอนุพันธ์ของตัวบนเสมอ คือ $u'v$ ก่อน แล้วจึงลบ $uv'$ ถ้าสลับลำดับ คำตอบจะผิดเครื่องหมายทั้งหมด และต้องเก็บเงื่อนไขตัวส่วนไม่เป็นศูนย์ไว้แม้จัดรูปแล้วดูเรียบง่าย

<Example n={3}>

หา $f'(x)$ เมื่อ $f(x) = \dfrac{2x + 1}{x - 3}$ และ $x \ne 3$ แล้วหาความชันที่ $x = 4$

<Steps reveal>
1. ให้ $u = 2x + 1$ และ $v = x - 3$ ได้ $u' = 2$ และ $v' = 1$
2. ตัวเศษ $u'v - uv' = 2(x - 3) - (2x + 1)(1) = 2x - 6 - 2x - 1 = -7$
3. จึงได้ $f'(x) = \dfrac{-7}{(x-3)^2}$ ตัวส่วนเป็นกำลังสองจึงบวกเสมอ ความชันเป็นลบทุกจุดในโดเมน กราฟลดลงทั้งสองฝั่งของ $x = 3$
4. ที่ $x = 4$ ได้ $f'(4) = \dfrac{-7}{1} = -7$
</Steps>
</Example>

{/* check: simplify(diff((2*x + 1)/(x - 3), x) + 7/(x - 3)**2) == 0 and diff((2*x + 1)/(x - 3), x).subs(x, 4) == -7 */}

## กฎลูกโซ่สำหรับฟังก์ชันประกอบ

ฟังก์ชัน $y = (3x + 1)^4$ ประกอบจากสองชั้น ชั้นในคือ $u = 3x + 1$ และชั้นนอกคือ $y = u^4$ ลองนึกถึงเฟืองสามตัวที่ขบกัน ถ้าเฟือง $y$ หมุนเร็วเป็นสามเท่าของเฟือง $u$ และเฟือง $u$ หมุนเร็วเป็นสองเท่าของเฟือง $x$ เฟือง $y$ ก็หมุนเร็วเป็น $3 \times 2 = 6$ เท่าของเฟือง $x$ อัตราการเปลี่ยนแปลงจึงคูณต่อกันเป็นลูกโซ่

<Thm label="กฎลูกโซ่">
ถ้า $y = f(u)$ และ $u = g(x)$ แล้ว $\dfrac{dy}{dx} = \dfrac{dy}{du}\cdot\dfrac{du}{dx}$ หรือเขียนอีกแบบว่า $\dfrac{d}{dx}f(g(x)) = f'(g(x))\,g'(x)$
</Thm>

ใช้เป็นขั้นได้ว่า หาอนุพันธ์ชั้นนอกโดยปล่อยชั้นในไว้ตามเดิม แล้วคูณด้วยอนุพันธ์ชั้นใน ข้อที่ลืมบ่อยที่สุดคือขั้นคูณอนุพันธ์ชั้นใน

<Example n={4}>

(1) หาอนุพันธ์ของ $(3x+1)^4$

(2) หาอนุพันธ์ของ $y = \sqrt{x^2 + 9}$ แล้วหาค่าที่ $x = 4$

<Steps reveal>
1. ข้อ (1) ชั้นนอกคือกำลังสี่ อนุพันธ์ชั้นนอกคือ $4(3x+1)^3$ โดยปล่อย $3x + 1$ ไว้ในวงเล็บ
2. คูณอนุพันธ์ชั้นในคือ $3$ ได้ $12(3x+1)^3$ ถ้ากระจาย $(3x+1)^4$ ก่อนจะได้พหุนามห้าพจน์ ซึ่งยาวกว่ามาก
3. ข้อ (2) เขียน $y = (x^2 + 9)^{1/2}$ ชั้นนอกให้ $\tfrac{1}{2}(x^2 + 9)^{-1/2}$ ชั้นในคือ $x^2 + 9$ มีอนุพันธ์ $2x$
4. คูณกันได้ $\dfrac{dy}{dx} = \dfrac{2x}{2\sqrt{x^2 + 9}} = \dfrac{x}{\sqrt{x^2+9}}$ ที่ $x = 4$ ได้ $\dfrac{4}{\sqrt{25}} = \dfrac{4}{5}$
</Steps>
</Example>

{/* check: expand(diff((3*x+1)**4,x))==expand(12*(3*x+1)**3) and simplify(diff(sqrt(x**2 + 9), x) - x/sqrt(x**2 + 9)) == 0 and diff(sqrt(x**2 + 9), x).subs(x, 4) == Rational(4, 5) */}

## อนุพันธ์อันดับสอง

อนุพันธ์ของ $f'$ เรียกว่า**อนุพันธ์อันดับสอง** เขียน $f''(x)$ หรือ $\dfrac{d^2y}{dx^2}$ ถ้า $f'$ บอกว่ากราฟชันเท่าไร $f''$ ก็บอกว่าความชันนั้นเปลี่ยนเร็วแค่ไหน ในการเคลื่อนที่ อนุพันธ์ของตำแหน่งคือความเร็ว และอนุพันธ์ของความเร็วคือความเร่ง ความเร่งจึงเป็นอนุพันธ์อันดับสองของตำแหน่ง

<Example n={5}>

ลิฟต์เคลื่อนที่ตามแนวดิ่ง ตำแหน่งเหนือชั้นล่างเป็น $s(t) = t^3 - 6t^2 + 9t$ เมตร เมื่อ $t$ เป็นวินาที หาความเร็วและความเร่งที่ $t = 1$

<Steps reveal>
1. ความเร็ว $v(t) = s'(t) = 3t^2 - 12t + 9$ ที่ $t = 1$ ได้ $3 - 12 + 9 = 0$ เมตรต่อวินาที
2. ความเร่ง $a(t) = s''(t) = 6t - 12$ ที่ $t = 1$ ได้ $-6$ เมตรต่อวินาทีกำลังสอง
3. แปลความหมาย ขณะนั้นลิฟต์หยุดนิ่งชั่วขณะ แต่ความเร่งไม่เป็นศูนย์และติดลบ ความเร็วจึงกำลังลดลงต่ำกว่าศูนย์ ลิฟต์กำลังจะเปลี่ยนทิศเป็นเคลื่อนลง ความเร็วเป็นศูนย์ไม่ได้แปลว่าความเร่งเป็นศูนย์
</Steps>
</Example>

{/* check: diff(t**3 - 6*t**2 + 9*t, t).subs(t, 1) == 0 and diff(t**3 - 6*t**2 + 9*t, t, 2).subs(t, 1) == -6 */}

## สรุป

- ค่าคงตัวได้ศูนย์ $x^n$ ได้ $nx^{n-1}$ เขียนรากและเศษส่วนเป็นเลขยกกำลังก่อน ผลบวกหาแยกพจน์ได้
- ผลคูณ $(uv)' = u'v + uv'$ ไม่ใช่ $u'v'$ ผลหาร $\left(\dfrac{u}{v}\right)' = \dfrac{u'v - uv'}{v^2}$ เริ่มจากอนุพันธ์ตัวบน
- กฎลูกโซ่ หาอนุพันธ์ชั้นนอกโดยปล่อยชั้นในไว้ แล้วคูณอนุพันธ์ชั้นใน
- อนุพันธ์อันดับสองของตำแหน่งคือความเร่ง

เมื่อหาอนุพันธ์ได้คล่องแล้ว หน้าถัดไปจะใช้อนุพันธ์ตอบคำถามที่มีความหมาย เช่นสมการเส้นสัมผัส จุดสูงสุดของลูกบอล และขนาดกล่องที่จุของได้มากที่สุด
