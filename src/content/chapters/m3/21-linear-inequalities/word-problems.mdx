มีเงิน 250 บาท จะซื้อสมุดเล่มละ 18 บาทให้ได้มากที่สุด ถ้าตั้งเป็นสมการ $18x = 250$ จะได้ $x = 13.88\ldots$ ซึ่งซื้อจริงไม่ได้ และโจทย์ก็ไม่ได้บอกว่าต้องใช้เงินหมดพอดี เงื่อนไขจริงคือราคารวมต้อง**ไม่เกิน** 250 บาท ซึ่งเป็นอสมการ

โจทย์ปัญหาอสมการต่างจากโจทย์สมการตรงขั้นสุดท้าย คำตอบของอสมการมีมากมาย แต่คำถามมักต้องการจำนวนเดียว เช่น มากที่สุดกี่เล่ม หรืออย่างน้อยกี่คะแนน ต้องเลือกจำนวนนั้นออกมาจากคำตอบให้ถูก

## ขั้นตอนทำโจทย์

1. ตั้งตัวแปรแทนสิ่งที่ไม่รู้ บอกให้ชัดว่าหมายถึงอะไรและหน่วยอะไร
2. หาคำที่บอกเครื่องหมาย เช่น ไม่เกิน อย่างน้อย เกิน ไม่ถึง แล้วเขียนอสมการ
3. แก้อสมการ
4. ตีความคำตอบ ถ้าสิ่งที่ถามต้องเป็นจำนวนเต็ม เช่น จำนวนเล่ม จำนวนแผ่น คะแนน ให้เลือกจำนวนเต็มในคำตอบที่ตรงกับคำถาม แล้วแทนกลับในโจทย์เพื่อตรวจ

## มากที่สุดเท่าไร

<Example n={1}>
มีเงิน 250 บาท ซื้อสมุดเล่มละ 18 บาทได้มากที่สุดกี่เล่ม

<Steps reveal>
1. ให้ซื้อสมุด $x$ เล่ม ราคารวม $18x$ บาท ต้องไม่เกิน $250$ บาท ได้ $18x \le 250$
2. หารด้วย $18$ ได้ $x \le 13.88\ldots$
3. $x$ เป็นจำนวนเล่ม ต้องเป็นจำนวนเต็ม จำนวนเต็มที่มากที่สุดที่ไม่เกิน $13.88\ldots$ คือ $13$
4. ตรวจ $13$ เล่มราคา $234$ บาท ไม่เกิน $250$ ส่วน $14$ เล่มราคา $252$ บาท เกินเงินที่มี ซื้อได้มากที่สุด 13 เล่ม
</Steps>
</Example>

{/* check: max([v for v in range(0, 100) if 18*v <= 250]) == 13 and (18*13, 18*14) == (234, 252) */}

<Note kind="warning" title="ปัดลงหรือปัดขึ้น ดูจากโจทย์">
$13.88\ldots$ ปัดเศษตามปกติได้ $14$ แต่ซื้อ 14 เล่มเงินไม่พอ ข้อนี้คำตอบต้องไม่เกิน $13.88\ldots$ จึงต้องปัดลง ถ้าโจทย์ใช้คำว่าอย่างน้อย คำตอบต้องไม่น้อยกว่าจุดปลาย จึงต้องปัดขึ้น อย่าปัดตามความเคยชิน ให้แทนกลับในโจทย์ตรวจทุกครั้ง
</Note>

<Example n={2}>
จำนวนคู่สามจำนวนเรียงติดกันมีผลบวกไม่เกิน 100 จำนวนที่มากที่สุดในสามจำนวนนี้เป็นได้มากที่สุดเท่าใด

<Steps reveal>
1. ให้จำนวนที่น้อยที่สุดเป็น $x$ จำนวนคู่ที่ถัดไปคือ $x + 2$ และ $x + 4$
2. ผลบวกไม่เกิน 100 ได้ $x + (x + 2) + (x + 4) \le 100$ หรือ $3x + 6 \le 100$
3. บวก $-6$ ได้ $3x \le 94$ หารด้วย $3$ ได้ $x \le 31.33\ldots$
4. $x$ ต้องเป็นจำนวนคู่ จำนวนคู่ที่มากที่สุดที่ไม่เกิน $31.33\ldots$ คือ $30$ สามจำนวนจึงเป็น $30$ $32$ $34$ ผลบวก $96$ ไม่เกิน 100
5. คำถามถามจำนวนที่มากที่สุดในสามจำนวน จึงตอบ $34$ ถ้าเลื่อนขึ้นไปเป็น $32$ $34$ $36$ ผลบวกเป็น $102$ เกิน 100
</Steps>
</Example>

{/* check: max([v for v in range(0, 100, 2) if 3*v + 6 <= 100]) + 4 == 34 and 32 + 34 + 36 == 102 */}

<Think>

ลิฟต์ขนของรับน้ำหนักได้ไม่เกิน 600 กิโลกรัม พนักงานหนัก 80 กิโลกรัมเข็นกล่องกล่องละ 25 กิโลกรัมเข้าไปพร้อมตัวเอง เพื่อนคิดว่า $600 \div 25 = 24$ จึงตอบว่าขนได้เที่ยวละ 24 กล่อง ผิดตรงไหน

<Reveal>
ลืมน้ำหนักของพนักงานที่อยู่ในลิฟต์ด้วย ถ้าขน $n$ กล่อง น้ำหนักรวมคือ $80 + 25n$ ต้องไม่เกิน 600 ได้ $25n \le 520$ หรือ $n \le 20.8$ ขนได้มากที่สุดเที่ยวละ 20 กล่อง ตรวจ $80 + 500 = 580$ ไม่เกิน 600 ส่วน 21 กล่องหนักรวม $605$ กิโลกรัม เกิน
</Reveal>
</Think>

{/* check: max([n for n in range(0, 100) if 80 + 25*n <= 600]) == 20 and 80 + 25*21 == 605 */}

## อย่างน้อยเท่าไร

<Example n={3}>
วิชาคณิตศาสตร์ของปิยะ คะแนนเก็บระหว่างภาคได้ 42 คะแนน ส่วนข้อสอบปลายภาคมีคะแนนเต็ม 50 คะแนน แต่นำมาคิดเป็น 40 คะแนนในคะแนนรวม ปิยะต้องได้คะแนนรวมอย่างน้อย 80 คะแนนจึงได้เกรด 4 ข้อสอบปลายภาคต้องได้อย่างน้อยกี่คะแนน ถ้าคะแนนสอบเป็นจำนวนเต็ม

<Steps reveal>
1. ให้ปิยะได้คะแนนสอบปลายภาค $x$ คะแนนจาก 50 คิดเป็นคะแนนรวม $\tfrac{40}{50}x = \tfrac{4}{5}x$ คะแนน
2. คะแนนรวมอย่างน้อย 80 ได้ $42 + \tfrac{4}{5}x \ge 80$
3. บวก $-42$ ได้ $\tfrac{4}{5}x \ge 38$ คูณด้วย $\tfrac{5}{4}$ ได้ $x \ge 47.5$
4. คะแนนเป็นจำนวนเต็ม จำนวนเต็มที่น้อยที่สุดที่ไม่น้อยกว่า $47.5$ คือ $48$ ข้อนี้จึงปัดขึ้น
5. ตรวจ ได้ 48 คะแนน คะแนนรวม $42 + \tfrac{4}{5}(48) = 80.4$ ถึง 80 ส่วนได้ 47 คะแนน คะแนนรวม $79.6$ ไม่ถึง ต้องได้อย่างน้อย 48 คะแนน
</Steps>
</Example>

{/* check: min([v for v in range(0, 51) if 42 + Rational(4, 5)*v >= 80]) == 48 */}
{/* check: (42 + Rational(4, 5)*48, 42 + Rational(4, 5)*47) == (Rational('80.4'), Rational('79.6')) */}

## เปรียบเทียบสองทางเลือก

โจทย์ที่ถามว่าเมื่อใดทางเลือกหนึ่งถูกกว่าหรือดีกว่าอีกทาง ให้เขียนค่าใช้จ่ายของทั้งสองทางเป็นนิพจน์ แล้วเทียบกันด้วยอสมการ

<Example n={4}>
ร้านถ่ายเอกสาร ก คิดแผ่นละ 0.50 บาท ร้าน ข ต้องสมัครสมาชิก 30 บาทก่อน แล้วคิดแผ่นละ 0.30 บาท กลุ่มของมะปรางจะถ่ายเอกสารรายงาน ต้องถ่ายกี่แผ่นขึ้นไปร้าน ข จึงถูกกว่า

<Steps reveal>
1. ให้ถ่าย $x$ แผ่น ร้าน ก คิด $0.5x$ บาท ร้าน ข คิด $30 + 0.3x$ บาท
2. ร้าน ข ถูกกว่าเมื่อ $30 + 0.3x < 0.5x$
3. คูณทั้งสองข้างด้วย $10$ ได้ $300 + 3x < 5x$ บวก $-3x$ ได้ $300 < 2x$ จึงได้ $x > 150$
4. จำนวนแผ่นเป็นจำนวนเต็ม และ $150$ ไม่เป็นคำตอบ ถ่ายตั้งแต่ 151 แผ่นขึ้นไปร้าน ข จึงถูกกว่า
5. ตรวจจุดปลาย ถ่าย 150 แผ่น ร้าน ก คิด $75$ บาท ร้าน ข คิด $30 + 45 = 75$ บาท เท่ากันพอดี
</Steps>
</Example>

{/* check: solve_univariate_inequality(30 + Rational(3, 10)*x < Rational(1, 2)*x, x, relational=False) == Interval.open(150, oo) */}
{/* check: (Rational(1, 2)*150, 30 + Rational(3, 10)*150) == (75, 75) */}

## สรุป

- อ่านหาคำที่บอกเครื่องหมาย แล้วเขียนอสมการ
- คำตอบของอสมการมีมากมาย ต้องเลือกจำนวนที่ตรงกับคำถาม เช่น จำนวนเต็มที่มากที่สุดหรือน้อยที่สุด
- ไม่เกินและมากที่สุด มักต้องปัดลง อย่างน้อยและน้อยที่สุด มักต้องปัดขึ้น ตรวจด้วยการแทนกลับทุกครั้ง
- เปรียบเทียบสองทางเลือก เขียนค่าใช้จ่ายของแต่ละทางแล้วเทียบด้วยอสมการ
