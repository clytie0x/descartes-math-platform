สนามหญ้ารูปสี่เหลี่ยมผืนผ้าแปลงหนึ่งมีพื้นที่ $x^2 + 7x + 12$ ตารางเมตร ถ้ารู้ว่าด้านกว้างและด้านยาวเขียนเป็นพหุนามดีกรีหนึ่งได้ ด้านทั้งสองยาวเท่าไร

คำถามนี้คือการถามกลับจากการคูณ ตอน ม.2 เราคูณ $(x + 3)(x + 4)$ ได้ $x^2 + 7x + 12$ ตอนนี้ได้ผลคูณมา ต้องหาตัวที่คูณกัน ด้านทั้งสองจึงยาว $x + 3$ และ $x + 4$ เมตร งานนี้เรียกว่า**การแยกตัวประกอบ**

{/* check: expand((x + 3)*(x + 4)) == x**2 + 7*x + 12 */}

ทั้งบทนี้ใช้เครื่องมือชุดเดียวกับบทที่ 20 แค่เอาไปใช้กับพหุนามที่ดีกรีสูงขึ้น หน้านี้จึงทบทวนเครื่องมือทั้งหมดก่อน

## แยกได้ครบหมายถึงอะไร

<Def>
**การแยกตัวประกอบ**ของพหุนาม คือการเขียนพหุนามนั้นให้อยู่ในรูปการคูณของพหุนามที่มีดีกรีต่ำกว่า

ในบทนี้ สัมประสิทธิ์ของตัวประกอบทุกตัวเป็นจำนวนเต็ม และแยก**ได้ครบ**เมื่อไม่มีตัวประกอบตัวไหนแยกต่อได้อีก
</Def>

เช่น $3x^2 - 12$ เขียนเป็น $3(x^2 - 4)$ ได้ แต่ $x^2 - 4$ ยังแยกต่อเป็น $(x + 2)(x - 2)$ ได้ คำตอบที่ครบจึงเป็น $3(x + 2)(x - 2)$ ทั้งสองแบบคูณกลับแล้วได้โจทย์เหมือนกัน แต่แบบแรกยังทำไม่เสร็จ

{/* check: expand(3*(x + 2)*(x - 2)) == 3*x**2 - 12 */}

## เครื่องมือสี่ชิ้นจากบทที่ 20

| แบบ | รูปทั่วไป | ตัวอย่าง |
|---|---|---|
| ดึงตัวร่วม | $ab + ac = a(b + c)$ | $6x^2 - 9x = 3x(2x - 3)$ |
| $ax^2 + bx + c$ | หาสองจำนวนที่คูณกันและบวกกันได้ตามต้องการ | $x^2 - x - 12 = (x - 4)(x + 3)$ |
| กำลังสองสมบูรณ์ | $A^2 + 2AB + B^2 = (A + B)^2$ และ $A^2 - 2AB + B^2 = (A - B)^2$ | $4x^2 + 12x + 9 = (2x + 3)^2$ |
| ผลต่างของกำลังสอง | $A^2 - B^2 = (A + B)(A - B)$ | $25x^2 - 1 = (5x + 1)(5x - 1)$ |

{/* check: expand(3*x*(2*x - 3)) == 6*x**2 - 9*x */}
{/* check: expand((x - 4)*(x + 3)) == x**2 - x - 12 */}
{/* check: expand((2*x + 3)**2) == 4*x**2 + 12*x + 9 */}
{/* check: expand((5*x + 1)*(5*x - 1)) == 25*x**2 - 1 */}

ในตาราง $A$ กับ $B$ เป็นอะไรก็ได้ เป็นตัวเลข เป็นเอกนามอย่าง $2x$ หรือเป็นพหุนามทั้งก้อนก็ได้ ข้อนี้สำคัญมากในหน้าถัดไป

<Example n={1}>

แยกตัวประกอบของ $2x^2 + 7x + 3$

<Steps reveal>
1. สัมประสิทธิ์ของ $x^2$ ไม่ใช่ $1$ หาสองจำนวนที่คูณกันได้ $2 \times 3 = 6$ และบวกกันได้ $7$ ได้ $1$ กับ $6$
2. แยกพจน์กลาง $7x = x + 6x$ ได้ $2x^2 + x + 6x + 3$
3. จับกลุ่มทีละสองพจน์ $x(2x + 1) + 3(2x + 1)$
4. ทั้งสองกลุ่มมี $(2x + 1)$ เป็นตัวร่วม ดึงออกได้ $(2x + 1)(x + 3)$
</Steps>
</Example>

{/* check: expand((2*x + 1)*(x + 3)) == 2*x**2 + 7*x + 3 */}

ขั้นที่ 4 ดึงตัวร่วมที่เป็นวงเล็บทั้งก้อนออก วิธีนี้เรียกว่า**การจับกลุ่ม** หน้า 22.2 จะใช้กับพหุนามสี่พจน์ที่ดีกรีสาม

<Example n={2}>

แยกตัวประกอบของ $9x^2 - 30x + 25$

<Steps reveal>
1. พจน์หน้า $9x^2 = (3x)^2$ พจน์หลัง $25 = 5^2$ ทั้งสองเป็นกำลังสอง จึงลองดูว่าเป็นกำลังสองสมบูรณ์หรือไม่ โดยให้ $A = 3x$ และ $B = 5$
2. ตรวจพจน์กลาง $2AB = 2(3x)(5) = 30x$ ตรงกับโจทย์ และมีเครื่องหมายลบ
3. ได้ $9x^2 - 30x + 25 = (3x - 5)^2$
</Steps>
</Example>

{/* check: expand((3*x - 5)**2) == 9*x**2 - 30*x + 25 */}

## ตรวจคำตอบด้วยการแทนค่า

คูณกลับเป็นวิธีตรวจที่แน่นอนที่สุด แต่ถ้าตัวประกอบมีหลายวงเล็บ คูณกลับจะช้า วิธีที่เร็วกว่าคือแทน $x$ ด้วยตัวเลขเล็กๆ สักตัวทั้งในโจทย์และในคำตอบ แล้วดูว่าได้เท่ากันไหม

<Example n={3}>

ตรวจว่า $x^2 - x - 12 = (x - 4)(x + 3)$ ถูกหรือไม่ โดยแทน $x = 2$

<Steps reveal>
1. แทนในโจทย์ $2^2 - 2 - 12 = 4 - 2 - 12 = -10$
2. แทนในคำตอบ $(2 - 4)(2 + 3) = (-2)(5) = -10$
3. ได้เท่ากัน คำตอบน่าจะถูก
</Steps>
</Example>

{/* check: (x**2 - x - 12).subs(x, 2) == -10 and ((x - 4)*(x + 3)).subs(x, 2) == -10 */}

<Note kind="tip" title="เลือกค่าที่แทนให้ดี">
ถ้าแทนแล้วได้ไม่เท่ากัน รู้ทันทีว่าผิด แต่ถ้าได้เท่ากันที่ค่าเดียว ยังมีโอกาสบังเอิญ ให้เลี่ยง $x = 0$ และ $x = 1$ เพราะตัวเลขพวกนี้ทำให้เลขยกกำลังทุกตัวหน้าตาเหมือนกัน จับเครื่องหมายผิดไม่ได้ ใช้ $x = 2$ หรือ $x = 3$ ดีกว่า
</Note>

## แบบที่แยกไม่ได้

ไม่ใช่ทุกพหุนามจะแยกตัวประกอบได้ รู้ว่าแบบไหนแยกไม่ได้ช่วยให้รู้ว่าเมื่อไรควรหยุด

<Think>

เพื่อนแยกตัวประกอบของ $x^2 + 9$ ได้ $(x + 3)(x - 3)$ ถูกไหม ถ้าไม่ถูก $x^2 + 9$ แยกเป็นอะไรได้

<Reveal>
ไม่ถูก $(x + 3)(x - 3) = x^2 - 9$ ไม่ใช่ $x^2 + 9$ ลองหาสองจำนวนที่คูณกันได้ $9$ และบวกกันได้ $0$ ถ้าคูณกันได้บวก สองจำนวนต้องเครื่องหมายเหมือนกัน บวกกันจึงเป็นศูนย์ไม่ได้ $x^2 + 9$ จึงแยกเป็นผลคูณของพหุนามดีกรีหนึ่งที่มีสัมประสิทธิ์เป็นจำนวนจริงไม่ได้ แต่ห้ามสรุปว่าผลบวก $A^2 + B^2$ ทุกแบบแยกไม่ได้ ถ้า $A$ หรือ $B$ เป็นพหุนามดีกรีสูง อาจใช้วิธีอื่นได้ เช่น $x^4 + 4 = (x^2 - 2x + 2)(x^2 + 2x + 2)$
</Reveal>
</Think>

{/* check: expand((x + 3)*(x - 3)) == x**2 - 9 and factor(x**2 + 9) == x**2 + 9 */}
{/* check: expand((x**2 - 2*x + 2)*(x**2 + 2*x + 2)) == x**4 + 4 */}

อีกแบบที่เจอบ่อยในบทนี้คือ $x^2 + 2x + 4$ ต้องหาสองจำนวนที่คูณกันได้ $4$ และบวกกันได้ $2$ คู่ที่คูณกันได้ $4$ คือ $1$ กับ $4$ หรือ $2$ กับ $2$ หรือคู่ที่ติดลบทั้งสองตัว บวกกันได้ $5$ $4$ $-5$ และ $-4$ ไม่มีคู่ไหนได้ $2$ จึงแยกไม่ได้ จำหน้าตาของมันไว้ จะได้เจออีกในหน้า 22.3

{/* check: factor(x**2 + 2*x + 4) == x**2 + 2*x + 4 */}

## สรุป

- แยกตัวประกอบคือเขียนพหุนามเป็นผลคูณ และต้องแยกจนไม่มีวงเล็บไหนแยกต่อได้
- เครื่องมือมีสี่ชิ้น ดึงตัวร่วม $ax^2 + bx + c$ กำลังสองสมบูรณ์ และผลต่างของกำลังสอง
- $A$ กับ $B$ ในสูตรเป็นตัวเลข เอกนาม หรือพหุนามทั้งก้อนก็ได้
- ตรวจคำตอบด้วยการแทน $x = 2$ หรือ $x = 3$ ทั้งในโจทย์และในคำตอบ
- $x^2 + 9$ และ $x^2 + 2x + 4$ แยกตัวประกอบไม่ได้
