ครูให้แยกตัวประกอบของ $2x^3 - 18x$ ต้นได้ $2(x^3 - 9x)$ ฝนได้ $2x(x^2 - 9)$ ส่วนบีได้ $2x(x + 3)(x - 3)$ ทั้งสามคนคูณกลับแล้วได้โจทย์เหมือนกันหมด ใครได้คะแนนเต็ม

{/* check: expand(2*(x**3 - 9*x)) == 2*x**3 - 18*x and expand(2*x*(x**2 - 9)) == 2*x**3 - 18*x and expand(2*x*(x + 3)*(x - 3)) == 2*x**3 - 18*x */}

คำตอบคือบีคนเดียว ของต้นยังดึง $x$ ออกได้อีก ของฝนยังแยก $x^2 - 9$ ได้อีก โจทย์ในบทนี้ส่วนใหญ่ต้องใช้เครื่องมือมากกว่าหนึ่งชิ้นต่อกัน หน้านี้คือการวางลำดับให้ไม่ตกหล่น

## ลำดับการคิด

<Thm label="ลำดับการแยกตัวประกอบ">

1. **ดึงตัวร่วมออกก่อนเสมอ** ใช้ ห.ร.ม. ของสัมประสิทธิ์ และตัวแปรที่มีในทุกพจน์
2. **นับพจน์ในวงเล็บที่เหลือ**
   - สองพจน์ ดูว่าเป็น $A^2 - B^2$ หรือ $A^3 + B^3$ หรือ $A^3 - B^3$ ส่วน $A^2 + B^2$ แยกไม่ได้
   - สามพจน์ ดูว่าเป็นกำลังสองสมบูรณ์ หรือแบบ $ax^2 + bx + c$ หรือมองเป็นดีกรีสองได้
   - สี่พจน์ ลองจับกลุ่ม
3. **ตรวจทุกวงเล็บที่ได้** ถ้าวงเล็บไหนแยกต่อได้ กลับไปทำข้อ 2 กับวงเล็บนั้น
4. **ตรวจคำตอบ** ด้วยการคูณกลับหรือแทนค่า

</Thm>

ที่ต้องดึงตัวร่วมก่อน เพราะตัวเลขในวงเล็บจะเล็กลง และรูปแบบอย่างกำลังสองหรือกำลังสามจะโผล่ออกมาให้เห็น เช่น $3x^3 + 24$ ไม่มีพจน์ไหนเป็นกำลังสาม แต่ดึง $3$ ออกแล้วได้ $x^3 + 8$ ทันที

## ตัวอย่างที่ใช้สองขั้น

<Example n={1}>

แยกตัวประกอบของ $2x^3 - 18x$

<Steps reveal>
1. ห.ร.ม. ของ $2$ กับ $18$ คือ $2$ และทั้งสองพจน์มี $x$ ดึง $2x$ ออกได้ $2x(x^2 - 9)$
2. $x^2 - 9$ มีสองพจน์ เป็นผลต่างของกำลังสอง ได้ $(x + 3)(x - 3)$
3. $2x$ $(x + 3)$ และ $(x - 3)$ แยกต่อไม่ได้แล้ว ตอบ $2x(x + 3)(x - 3)$
</Steps>
</Example>

{/* check: expand(2*x*(x + 3)*(x - 3)) == 2*x**3 - 18*x */}

<Example n={2}>

แยกตัวประกอบของ $3x^3 + 24$

<Steps reveal>
1. ดึง $3$ ออกได้ $3(x^3 + 8)$
2. $x^3 + 8 = x^3 + 2^3$ เป็นผลบวกของกำลังสาม ได้ $(x + 2)(x^2 - 2x + 4)$
3. วงเล็บที่สองของกำลังสามแยกต่อไม่ได้ ตอบ $3(x + 2)(x^2 - 2x + 4)$
</Steps>
</Example>

{/* check: expand(3*(x + 2)*(x**2 - 2*x + 4)) == 3*x**3 + 24 */}

<Example n={3}>

แยกตัวประกอบของ $x^4 - 16$

<Steps reveal>
1. ไม่มีตัวร่วม มีสองพจน์ $x^4 = (x^2)^2$ และ $16 = 4^2$ เป็นผลต่างของกำลังสอง ได้ $(x^2 + 4)(x^2 - 4)$
2. ตรวจทุกวงเล็บ $x^2 - 4$ เป็นผลต่างของกำลังสอง แยกต่อได้ $(x + 2)(x - 2)$
3. $x^2 + 4$ เป็นผลบวกของกำลังสอง แยกต่อไม่ได้
4. ตอบ $(x^2 + 4)(x + 2)(x - 2)$
</Steps>
</Example>

{/* check: expand((x**2 + 4)*(x + 2)*(x - 2)) == x**4 - 16 */}

## ตัวอย่างที่ใช้สามขั้น

<Example n={4}>

แยกตัวประกอบของ $2x^4 - 10x^2 + 8$

<Steps reveal>
1. ดึง $2$ ออกได้ $2(x^4 - 5x^2 + 4)$
2. ในวงเล็บมีสามพจน์ ให้ $A = x^2$ ได้ $A^2 - 5A + 4 = (A - 1)(A - 4)$ จึงได้ $2(x^2 - 1)(x^2 - 4)$
3. ตรวจทุกวงเล็บ ทั้ง $x^2 - 1$ และ $x^2 - 4$ เป็นผลต่างของกำลังสอง
4. ได้ $2(x + 1)(x - 1)(x + 2)(x - 2)$
5. ตรวจด้วย $x = 3$ โจทย์ได้ $2(81) - 10(9) + 8 = 80$ คำตอบได้ $2 \times 4 \times 2 \times 5 \times 1 = 80$
</Steps>
</Example>

{/* check: expand(2*(x + 1)*(x - 1)*(x + 2)*(x - 2)) == 2*x**4 - 10*x**2 + 8 */}
{/* check: (2*x**4 - 10*x**2 + 8).subs(x, 3) == 80 and 2*4*2*5*1 == 80 */}

<Note kind="warning" title="พจน์แรกติดลบ">
ถ้าพจน์ที่มีดีกรีสูงสุดติดลบ เช่น $-x^3 + 4x^2 + 5x$ ให้ดึงตัวร่วมที่ติดลบออก ได้ $-x(x^2 - 4x - 5)$ วงเล็บที่เหลือมี $x^2$ เป็นบวก แยกง่ายกว่า ได้ $-x(x - 5)(x + 1)$ ระวังว่าดึงลบออกแล้ว ทุกพจน์ในวงเล็บต้องเปลี่ยนเครื่องหมาย
</Note>

{/* check: expand(-x*(x - 5)*(x + 1)) == -x**3 + 4*x**2 + 5*x */}

<Think>

$x^6 - 64$ เป็นได้ทั้งผลต่างของกำลังสอง $(x^3)^2 - 8^2$ และผลต่างของกำลังสาม $(x^2)^3 - 4^3$ ควรเริ่มด้วยสูตรไหน

<Reveal>
เริ่มด้วยผลต่างของกำลังสองง่ายกว่า

- ใช้กำลังสองก่อน ได้ $(x^3 + 8)(x^3 - 8)$ แล้วใช้สูตรกำลังสามกับทั้งสองวงเล็บ ได้ $(x + 2)(x^2 - 2x + 4)(x - 2)(x^2 + 2x + 4)$ ครบแล้ว
- ใช้กำลังสามก่อน ได้ $(x^2 - 4)(x^4 + 4x^2 + 16)$ แยก $x^2 - 4$ ต่อได้ แต่ $x^4 + 4x^2 + 16$ ดูเหมือนแยกไม่ได้ ทั้งที่จริงเท่ากับ $(x^2 + 2x + 4)(x^2 - 2x + 4)$ ซึ่งมองไม่ออกง่ายๆ

เมื่อเลขชี้กำลังเป็นทั้งสองเท่าและสามเท่าของอะไรสักอย่าง ให้ใช้ผลต่างของกำลังสองก่อน
</Reveal>
</Think>

{/* check: expand((x + 2)*(x**2 - 2*x + 4)*(x - 2)*(x**2 + 2*x + 4)) == x**6 - 64 */}
{/* check: expand((x**2 + 2*x + 4)*(x**2 - 2*x + 4)) == x**4 + 4*x**2 + 16 */}

## ใช้แยกตัวประกอบตอบโจทย์

<Example n={5}>

กล่องเก็บของทรงสี่เหลี่ยมมุมฉากใบหนึ่งมีปริมาตร $x^3 + 6x^2 + 8x$ ลูกบาศก์เซนติเมตร ด้านที่สั้นที่สุดยาว $x$ เซนติเมตร และอีกสองด้านยาวกว่า $x$ เป็นจำนวนเต็มเซนติเมตร ถ้าด้านที่สั้นที่สุดยาว $10$ เซนติเมตร กล่องมีขนาดเท่าไร

<Steps reveal>
1. ปริมาตรคือกว้าง คูณ ยาว คูณ สูง จึงต้องเขียนปริมาตรเป็นผลคูณของสามวงเล็บ
2. ดึง $x$ ออกได้ $x(x^2 + 6x + 8)$
3. หาสองจำนวนที่คูณกันได้ $8$ และบวกกันได้ $6$ ได้ $2$ กับ $4$ จึงได้ $x(x + 2)(x + 4)$
4. ด้านทั้งสามยาว $x$ $x + 2$ และ $x + 4$ เซนติเมตร เมื่อ $x = 10$ กล่องมีขนาด $10 \times 12 \times 14$ เซนติเมตร
5. ตรวจ $10^3 + 6(10^2) + 8(10) = 1680$ และ $10 \times 12 \times 14 = 1680$ ตรงกัน
</Steps>
</Example>

{/* check: expand(x*(x + 2)*(x + 4)) == x**3 + 6*x**2 + 8*x */}
{/* check: (x**3 + 6*x**2 + 8*x).subs(x, 10) == 1680 and 10*12*14 == 1680 */}

<Example n={6}>

ให้ $n$ เป็นจำนวนเต็ม อธิบายว่าทำไม $n^3 - n$ หารด้วย $6$ ลงตัวเสมอ

<Steps reveal>
1. ดึง $n$ ออกได้ $n(n^2 - 1)$ แล้วแยกผลต่างของกำลังสองได้ $n(n + 1)(n - 1)$
2. เรียงใหม่เป็น $(n - 1) \times n \times (n + 1)$ คือผลคูณของจำนวนเต็มสามจำนวนที่เรียงติดกัน
3. จำนวนเต็มสองจำนวนที่ติดกันต้องมีจำนวนคู่หนึ่งตัว และสามจำนวนที่ติดกันต้องมีตัวหนึ่งที่หารด้วย $3$ ลงตัว ผลคูณจึงหารด้วย $2 \times 3 = 6$ ลงตัว
4. ลองดู $n = 5$ ได้ $125 - 5 = 120 = 4 \times 5 \times 6$ และ $120 \div 6 = 20$
</Steps>
</Example>

{/* check: expand((x - 1)*x*(x + 1)) == x**3 - x */}
{/* check: 5**3 - 5 == 120 and 4*5*6 == 120 and all((v**3 - v) % 6 == 0 for v in range(-20, 21)) */}

## สรุป

- ดึงตัวร่วมออกก่อนเสมอ ถ้าพจน์แรกติดลบให้ดึงลบออกด้วย
- นับพจน์ในวงเล็บ สองพจน์ดูผลต่างกำลังสองหรือกำลังสาม สามพจน์ดูกำลังสองสมบูรณ์หรือมองเป็นดีกรีสอง สี่พจน์ลองจับกลุ่ม
- ได้วงเล็บใหม่เมื่อไร ตรวจว่าแยกต่อได้ไหมทุกครั้ง
- เลขชี้กำลังเป็นได้ทั้งกำลังสองและกำลังสาม ให้ใช้ผลต่างของกำลังสองก่อน
- คำตอบที่คูณกลับได้โจทย์ ยังไม่แปลว่าแยกครบ
