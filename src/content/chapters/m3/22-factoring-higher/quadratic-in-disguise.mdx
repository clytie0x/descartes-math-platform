$x^4 - 13x^2 + 36$ ดูน่ากลัวเพราะมี $x^4$ ซึ่งไม่เคยแยกมาก่อน แต่ $x^4 = (x^2)^2$ ถ้าเขียนใหม่เป็น

$$
(x^2)^2 - 13(x^2) + 36
$$

แล้วลองปิด $x^2$ ไว้ด้วยตัวอักษร $A$ จะเหลือ $A^2 - 13A + 36$ ซึ่งเป็นพหุนามดีกรีสองแบบที่แยกได้ตั้งแต่บทที่ 20 หน้านี้คือการฝึกมองหาก้อนแบบนี้

## แทนก้อนที่ซ้ำด้วยตัวแปรใหม่

<Example n={1}>

แยกตัวประกอบของ $x^4 - 13x^2 + 36$

<Steps reveal>
1. ให้ $A = x^2$ ได้ $A^2 - 13A + 36$
2. หาสองจำนวนที่คูณกันได้ $36$ และบวกกันได้ $-13$ ได้ $-4$ กับ $-9$ จึงได้ $(A - 4)(A - 9)$
3. แทน $A$ กลับเป็น $x^2$ ได้ $(x^2 - 4)(x^2 - 9)$
4. ยังไม่จบ ทั้งสองวงเล็บเป็นผลต่างของกำลังสอง $x^2 - 4 = (x + 2)(x - 2)$ และ $x^2 - 9 = (x + 3)(x - 3)$
5. ได้ $x^4 - 13x^2 + 36 = (x + 2)(x - 2)(x + 3)(x - 3)$
</Steps>
</Example>

{/* check: expand((x + 2)*(x - 2)*(x + 3)*(x - 3)) == x**4 - 13*x**2 + 36 */}

ขั้นที่ 4 คือขั้นที่ลืมกันบ่อยที่สุด พอแทน $A$ กลับแล้ว ต้องตรวจทุกวงเล็บอีกรอบเสมอว่าแยกต่อได้ไหม

<Note kind="tip" title="ดูเลขชี้กำลัง">
พหุนามสามพจน์ที่เลขชี้กำลังของพจน์แรกเป็นสองเท่าของพจน์กลาง เช่น $x^4$ กับ $x^2$ หรือ $x^6$ กับ $x^3$ มองเป็นดีกรีสองได้เสมอ โดยให้ $A$ เป็นตัวที่อยู่ในพจน์กลาง
</Note>

<Example n={2}>

แยกตัวประกอบของ $x^4 + 8x^2 + 16$

<Steps reveal>
1. ให้ $A = x^2$ ได้ $A^2 + 8A + 16$
2. $16 = 4^2$ และ $8A = 2(A)(4)$ จึงเป็นกำลังสองสมบูรณ์ $(A + 4)^2$
3. แทนกลับได้ $(x^2 + 4)^2$
4. $x^2 + 4$ เป็นผลบวกของกำลังสอง แยกต่อไม่ได้ จึงตอบ $(x^2 + 4)^2$
</Steps>
</Example>

{/* check: expand((x**2 + 4)**2) == x**4 + 8*x**2 + 16 */}

<Example n={3}>

แยกตัวประกอบของ $16x^4 - 81$

<Steps reveal>
1. $16x^4 = (4x^2)^2$ และ $81 = 9^2$ เป็นผลต่างของกำลังสองโดย $A = 4x^2$ และ $B = 9$
2. ได้ $(4x^2 + 9)(4x^2 - 9)$
3. $4x^2 - 9 = (2x)^2 - 3^2$ ยังเป็นผลต่างของกำลังสอง แยกต่อได้ $(2x + 3)(2x - 3)$
4. $4x^2 + 9$ เป็นผลบวกของกำลังสอง แยกต่อไม่ได้
5. ได้ $16x^4 - 81 = (4x^2 + 9)(2x + 3)(2x - 3)$
</Steps>
</Example>

{/* check: expand((4*x**2 + 9)*(2*x + 3)*(2*x - 3)) == 16*x**4 - 81 */}

<Think>

เพื่อนแยกตัวประกอบของ $x^4 - 1$ ได้ $(x^2 - 1)^2$ เพราะคิดว่า $x^4 = (x^2)^2$ และ $1 = 1^2$ เพื่อนพูดถูกไหม

<Reveal>
ไม่ถูก กระจายดูจะเห็นว่า $(x^2 - 1)^2 = x^4 - 2x^2 + 1$ มีพจน์กลางเกินมา $x^4 - 1$ มีแค่สองพจน์และเป็นผลต่าง จึงต้องใช้ผลต่างของกำลังสอง $(x^2 + 1)(x^2 - 1)$ แล้วแยก $x^2 - 1$ ต่อ ได้ $(x^2 + 1)(x + 1)(x - 1)$ ลองตรวจด้วย $x = 2$ โจทย์ได้ $16 - 1 = 15$ คำตอบของเพื่อนได้ $3^2 = 9$ ส่วนคำตอบที่ถูกได้ $5 \times 3 \times 1 = 15$
</Reveal>
</Think>

{/* check: expand((x**2 - 1)**2) == x**4 - 2*x**2 + 1 and expand((x**2 + 1)*(x + 1)*(x - 1)) == x**4 - 1 */}
{/* check: ((x**2 - 1)**2).subs(x, 2) == 9 and ((x**2 + 1)*(x + 1)*(x - 1)).subs(x, 2) == 15 */}

## ก้อนที่เป็นวงเล็บทั้งก้อน

ตัวที่แทนด้วย $A$ ไม่จำเป็นต้องเป็น $x^2$ จะเป็นวงเล็บทั้งก้อนก็ได้

<Example n={4}>

แยกตัวประกอบของ $(x + 2)^2 - 9$

<Steps reveal>
1. ให้ $A = x + 2$ ได้ $A^2 - 3^2 = (A + 3)(A - 3)$
2. แทนกลับ $\big((x + 2) + 3\big)\big((x + 2) - 3\big)$
3. รวมพจน์ในแต่ละวงเล็บ ได้ $(x + 5)(x - 1)$
</Steps>
</Example>

{/* check: expand((x + 5)*(x - 1)) == expand((x + 2)**2 - 9) */}

ถ้ากระจายโจทย์ก่อนจะได้ $x^2 + 4x - 5$ แล้วแยกแบบบทที่ 20 ก็ได้คำตอบเดียวกัน แต่การมองเป็นก้อนเร็วกว่า และใช้ได้แม้โจทย์จะซับซ้อนจนกระจายไม่ไหว

<Example n={5}>

แยกตัวประกอบของ $(2x - 1)^2 - (x + 3)^2$

<Steps reveal>
1. ให้ $A = 2x - 1$ และ $B = x + 3$ ได้ $A^2 - B^2 = (A + B)(A - B)$
2. $A + B = (2x - 1) + (x + 3) = 3x + 2$
3. $A - B = (2x - 1) - (x + 3) = 2x - 1 - x - 3 = x - 4$
4. ได้ $(3x + 2)(x - 4)$
</Steps>
</Example>

{/* check: expand((3*x + 2)*(x - 4)) == expand((2*x - 1)**2 - (x + 3)**2) */}

<Note kind="warning" title="ลบวงเล็บทั้งก้อน">
ขั้นที่ 3 ต้องลบ $B$ ทั้งก้อน $-(x + 3) = -x - 3$ ถ้าเขียน $2x - 1 - x + 3$ จะได้ $x + 2$ ซึ่งผิด ใส่วงเล็บรอบ $A$ และ $B$ ไว้ก่อนทุกครั้ง แล้วค่อยถอดวงเล็บ
</Note>

## ตัวร่วมที่เป็นพหุนามและการจับกลุ่ม

ตัวร่วมไม่จำเป็นต้องเป็นตัวเลขหรือเอกนาม ใน $x(x + 3) + 5(x + 3)$ ทั้งสองพจน์มี $(x + 3)$ คูณอยู่ ดึงออกได้ $(x + 3)(x + 5)$ เหมือนดึง $A$ ออกจาก $xA + 5A$

{/* check: expand((x + 3)*(x + 5)) == expand(x*(x + 3) + 5*(x + 3)) */}

พหุนามดีกรีสามที่มีสี่พจน์ มักแยกได้ด้วยการจับกลุ่มทีละสองพจน์ให้เกิดวงเล็บที่เหมือนกัน

<Example n={6}>

แยกตัวประกอบของ $x^3 + 2x^2 - 9x - 18$

<Steps reveal>
1. จับกลุ่มสองพจน์แรกกับสองพจน์หลัง $(x^3 + 2x^2) + (-9x - 18)$
2. กลุ่มแรกดึง $x^2$ ออกได้ $x^2(x + 2)$ กลุ่มหลังดึง $-9$ ออกได้ $-9(x + 2)$
3. ทั้งสองกลุ่มมี $(x + 2)$ ดึงออกได้ $(x + 2)(x^2 - 9)$
4. $x^2 - 9$ เป็นผลต่างของกำลังสอง ได้ $(x + 2)(x + 3)(x - 3)$
</Steps>
</Example>

{/* check: expand((x + 2)*(x + 3)*(x - 3)) == x**3 + 2*x**2 - 9*x - 18 */}

ขั้นที่ 2 ต้องดึง $-9$ ไม่ใช่ $9$ เพราะต้องการให้ในวงเล็บเป็น $x + 2$ เหมือนกลุ่มแรก ตรวจได้โดยคูณกลับ $-9(x + 2) = -9x - 18$

<Think>

จับกลุ่ม $x^3 - 3x^2 + 4x - 12$ ได้ $(x - 3)(x^2 + 4)$ แยกต่อได้อีกไหม

<Reveal>
ไม่ได้ $x - 3$ เป็นดีกรีหนึ่ง แยกต่อไม่ได้อยู่แล้ว ส่วน $x^2 + 4$ เป็นผลบวกของกำลังสอง ไม่ใช่ผลต่าง จึงแยกไม่ได้ คำตอบ $(x - 3)(x^2 + 4)$ ครบแล้ว
</Reveal>
</Think>

{/* check: expand((x - 3)*(x**2 + 4)) == x**3 - 3*x**2 + 4*x - 12 */}

## สรุป

- $x^4 = (x^2)^2$ พหุนามที่มี $x^4$ $x^2$ และค่าคงตัว ให้ $A = x^2$ แล้วแยกแบบดีกรีสอง
- ตัวที่แทนด้วย $A$ เป็นวงเล็บทั้งก้อนได้ เช่น $(x + 2)^2 - 9$
- แทน $A$ กลับแล้ว ตรวจทุกวงเล็บอีกรอบว่าแยกต่อได้ไหม
- พหุนามสี่พจน์ ลองจับกลุ่มทีละสองพจน์ให้เกิดวงเล็บเหมือนกัน ระวังเครื่องหมายเมื่อดึงจำนวนลบออก
