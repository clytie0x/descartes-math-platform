ตะกร้าใบที่หนึ่งมีมะม่วง 2 ผลกับส้ม 3 ผล หนัก 1,300 กรัม ตะกร้าใบที่สองมีมะม่วง 2 ผลกับส้ม 1 ผล หนัก 900 กรัม ทั้งสองตะกร้ามีมะม่วงเท่ากัน ตะกร้าแรกหนักกว่า 400 กรัม เพราะมีส้มเกินมา 2 ผล ส้มจึงหนักผลละ 200 กรัม แล้วจากตะกร้าที่สอง มะม่วงสองผลหนัก $900 - 200 = 700$ กรัม จึงหนักผลละ 350 กรัม

{/* check: solve([2*x + 3*y - 1300, 2*x + y - 900], [x, y]) == {x: 350, y: 200} */}

ที่ทำไปคือเอาสองสมการมาลบกัน ส่วนที่เหมือนกันหักล้างไป เหลือตัวแปรเดียว วิธีนี้เรียกว่า**การกำจัดตัวแปร**

## บวกหรือลบสมการ

ถ้า $A = B$ และ $C = D$ จะได้ $A + C = B + D$ และ $A - C = B - D$ เพราะบวกหรือลบจำนวนที่เท่ากันทั้งสองข้าง สมการยังเป็นจริง จึงนำสมการในระบบมาบวกหรือลบกันได้ทั้งสมการ

- ถ้าตัวแปรตัวหนึ่งมีสัมประสิทธิ์**ตรงข้ามกัน** เช่น $2y$ กับ $-2y$ ให้**บวก**สมการ
- ถ้าตัวแปรตัวหนึ่งมีสัมประสิทธิ์**เท่ากัน** เช่น $2x$ กับ $2x$ ให้**ลบ**สมการ

<Example n={1}>
แก้ระบบสมการ

$$
\begin{aligned}
3x + 2y &= 16 \qquad (1) \\
5x - 2y &= 16 \qquad (2)
\end{aligned}
$$

<Steps reveal>
1. $2y$ กับ $-2y$ ตรงข้ามกัน นำ (1) บวก (2) ได้ $(3x + 5x) + (2y - 2y) = 16 + 16$
2. ได้ $8x = 32$ จึงได้ $x = 4$
3. แทน $x = 4$ ใน (1) ได้ $12 + 2y = 16$ จึงได้ $2y = 4$ และ $y = 2$
4. ตรวจกับ (2) $5(4) - 2(2) = 20 - 4 = 16$ เป็นจริง คำตอบคือ $(4, 2)$
</Steps>
</Example>

{/* check: solve([3*x + 2*y - 16, 5*x - 2*y - 16], [x, y]) == {x: 4, y: 2} */}

<Example n={2}>
แก้ระบบสมการ

$$
\begin{aligned}
2x + 5y &= 19 \qquad (1) \\
2x - y &= 1 \qquad (2)
\end{aligned}
$$

<Steps reveal>
1. $2x$ เท่ากันทั้งสองสมการ นำ (1) ลบ (2) ได้ $(2x - 2x) + (5y - (-y)) = 19 - 1$
2. $5y - (-y) = 5y + y = 6y$ จึงได้ $6y = 18$ และ $y = 3$
3. แทน $y = 3$ ใน (2) ได้ $2x - 3 = 1$ จึงได้ $2x = 4$ และ $x = 2$
4. ตรวจกับ (1) $2(2) + 5(3) = 4 + 15 = 19$ เป็นจริง คำตอบคือ $(2, 3)$
</Steps>
</Example>

{/* check: solve([2*x + 5*y - 19, 2*x - y - 1], [x, y]) == {x: 2, y: 3} */}

<Note kind="warning" title="ลบทั้งสมการ">
ตอนลบสมการ ต้องลบทุกพจน์ของสมการที่สอง ใส่วงเล็บให้ทั้งสมการก่อนจะไม่พลาด ในตัวอย่างนี้ $(2x + 5y) - (2x - y)$ ได้ $6y$ คนที่ลืมเปลี่ยนเครื่องหมายของ $-y$ จะได้ $4y = 18$ ซึ่งให้ $y = 4.5$ ผิดทันที
</Note>

{/* check: expand((2*x + 5*y) - (2*x - y)) == 6*y */}

## คูณสมการก่อนบวกหรือลบ

ถ้าไม่มีตัวแปรไหนที่สัมประสิทธิ์เท่ากันหรือตรงข้ามกัน ให้คูณสมการด้วยจำนวนที่เหมาะสมก่อน คูณจำนวนเดียวกันทั้งสองข้าง สมการยังเป็นจริงและมีกราฟเป็นเส้นเดิม

<Example n={3}>
แก้ระบบสมการ

$$
\begin{aligned}
3x + 2y &= 7 \qquad (1) \\
2x - 3y &= -4 \qquad (2)
\end{aligned}
$$

<Steps reveal>
1. เลือกกำจัด $y$ สัมประสิทธิ์คือ $2$ กับ $-3$ ทำให้เป็น $6$ กับ $-6$ ได้ โดยคูณ (1) ด้วย $3$ และคูณ (2) ด้วย $2$
2. (1) × 3 ได้ $9x + 6y = 21$ และ (2) × 2 ได้ $4x - 6y = -8$ คูณทั้งสองข้างของสมการ
3. บวกสองสมการใหม่ ได้ $13x = 13$ จึงได้ $x = 1$
4. แทน $x = 1$ ใน (1) ได้ $3 + 2y = 7$ จึงได้ $y = 2$
5. ตรวจกับ (2) $2(1) - 3(2) = 2 - 6 = -4$ เป็นจริง คำตอบคือ $(1, 2)$
</Steps>
</Example>

{/* check: solve([3*x + 2*y - 7, 2*x - 3*y + 4], [x, y]) == {x: 1, y: 2} */}

<Think>

ข้อเดียวกันนี้ เพื่อนคูณ (1) ด้วย $3$ แล้วเขียนว่า $9x + 6y = 7$ ต่อจากนั้นทำถูกทุกขั้น เพื่อนจะได้ $x$ เท่าไร และรู้ได้อย่างไรว่าผิด

<Reveal>
บวกกับ $4x - 6y = -8$ ได้ $13x = -1$ จึงได้ $x = -\tfrac{1}{13}$ ผิดเพราะคูณ $3$ แค่ข้างซ้าย ข้างขวาต้องเป็น $21$ ถ้าคูณข้างเดียว สมการใหม่ไม่เท่ากับสมการเดิมแล้ว ข้อนี้ตรวจคำตอบแล้วจะไม่เป็นจริง แต่ป้องกันได้ตั้งแต่แรกด้วยการเขียนการคูณครอบทั้งสองข้าง เช่น $3(3x + 2y) = 3(7)$
</Reveal>
</Think>

{/* check: solve(13*x + 1, x) == [Rational(-1, 13)] */}

### เลือกกำจัดตัวไหนก่อน

ตัวอย่างที่ 3 จะกำจัด $x$ ก่อนก็ได้ โดยคูณ (1) ด้วย $2$ และ (2) ด้วย $3$ ได้ $6x + 4y = 14$ กับ $6x - 9y = -12$ แล้วลบกัน ได้ $13y = 26$ จึงได้ $y = 2$ คำตอบเหมือนเดิม เลือกตัวที่คูณแล้วตัวเลขเล็กกว่า หรือตัวที่มีเครื่องหมายตรงข้ามกันอยู่แล้ว เพราะบวกพลาดยากกว่าลบ

{/* check: expand(2*(3*x + 2*y) - 3*(2*x - 3*y)) == 13*y and 2*7 - 3*(-4) == 26 */}

## เมื่อตัวแปรหายไปทั้งสองตัว

บางระบบกำจัดตัวหนึ่งแล้วอีกตัวหายไปด้วย สิ่งที่เหลือบอกได้ว่าระบบไม่มีคำตอบหรือมีคำตอบมากมาย ตรงกับกรณีเส้นขนานและเส้นทับกันในหน้า 27.2

<Example n={4}>
ระบบสมการแต่ละข้อมีคำตอบกี่คำตอบ

(ก) $2x - y = 3$ และ $4x - 2y = 5$   (ข) $x + 3y = 2$ และ $2x + 6y = 4$

<Steps reveal>
1. (ก) คูณสมการแรกด้วย $2$ ได้ $4x - 2y = 6$ ลบด้วยสมการที่สอง ได้ $0 = 1$ ซึ่งเป็นเท็จเสมอ ไม่ว่า $x$ และ $y$ เป็นอะไร ระบบนี้จึง**ไม่มีคำตอบ** เส้นตรงขนานกัน
2. (ข) คูณสมการแรกด้วย $2$ ได้ $2x + 6y = 4$ ลบด้วยสมการที่สอง ได้ $0 = 0$ ซึ่งเป็นจริงเสมอ สองสมการเป็นสมการเดียวกัน ระบบนี้จึงมี**คำตอบมากมายนับไม่ถ้วน** คือทุกคู่อันดับที่ทำให้ $x + 3y = 2$ เป็นจริง เช่น $(2, 0)$ และ $(-1, 1)$
</Steps>
</Example>

{/* check: solve([2*x - y - 3, 4*x - 2*y - 5], [x, y]) == [] */}
{/* check: expand(2*(x + 3*y) - (2*x + 6*y)) == 0 and [p + 3*q for p, q in [(2, 0), (-1, 1)]] == [2, 2] */}

## เลือกวิธีไหนดี

| ระบบมีลักษณะแบบนี้ | วิธีที่สะดวก |
|---|---|
| มีสมการที่บอก $x = \ldots$ หรือ $y = \ldots$ มาแล้ว หรือมีตัวแปรที่สัมประสิทธิ์เป็น $1$ | แทนค่า |
| มีตัวแปรที่สัมประสิทธิ์เท่ากันหรือตรงข้ามกัน | กำจัดตัวแปรด้วยการบวกหรือลบ |
| สัมประสิทธิ์ไม่สวยทั้งคู่ เช่น $3x + 2y = 7$ กับ $2x - 3y = -4$ | คูณแล้วกำจัดตัวแปร |

ทั้งสองวิธีให้คำตอบเดียวกันเสมอ ถ้าเลือกวิธีที่ยากกว่าก็แค่คิดเลขนานขึ้น ไม่ผิด

## สรุป

- บวกสมการเมื่อสัมประสิทธิ์ตรงข้ามกัน ลบสมการเมื่อสัมประสิทธิ์เท่ากัน
- ตอนลบ ใส่วงเล็บครอบสมการที่สองแล้วเปลี่ยนเครื่องหมายทุกพจน์
- ถ้าสัมประสิทธิ์ไม่ตรงกัน คูณสมการด้วยจำนวนที่เหมาะสมก่อน และต้องคูณทั้งสองข้าง
- ตัวแปรหายหมดแล้วเหลือข้อความเท็จ เช่น $0 = 1$ แปลว่าไม่มีคำตอบ ถ้าเหลือ $0 = 0$ แปลว่ามีคำตอบมากมายนับไม่ถ้วน
