จุดยอดคือจุดที่กราฟเลี้ยวกลับ จึงเป็นจุดที่ค่า $y$ มากที่สุดหรือน้อยที่สุดด้วย โจทย์ที่ถามว่า "มากที่สุดเท่าไร" หรือ "น้อยที่สุดเท่าไร" จึงกลายเป็นโจทย์หาจุดยอด ถ้าเขียนสิ่งที่ถามเป็นฟังก์ชันกำลังสองได้

<Thm>

ฟังก์ชัน $y = a(x - h)^2 + k$

- ถ้า $a > 0$ มี**ค่าต่ำสุด**เท่ากับ $k$ เมื่อ $x = h$ และไม่มีค่าสูงสุด
- ถ้า $a < 0$ มี**ค่าสูงสุด**เท่ากับ $k$ เมื่อ $x = h$ และไม่มีค่าต่ำสุด

</Thm>

เหตุผลคือ $(x - h)^2$ มีค่าน้อยที่สุดเป็น $0$ ที่ $x = h$ ค่าอื่นเป็นบวกทั้งหมด ถ้า $a > 0$ การบวกค่าบวกเข้าไปทำให้ $y$ โตขึ้นได้เรื่อยๆ จึงไม่มีค่าสูงสุด แต่ต่ำกว่า $k$ ไม่ได้

## ขั้นตอนทำโจทย์

1. ตั้งตัวแปรแทนสิ่งที่เปลี่ยนได้ เขียนให้ชัดว่าหมายถึงอะไรและหน่วยอะไร
2. เขียนสิ่งที่โจทย์ถามให้มากที่สุดหรือน้อยที่สุด เป็นฟังก์ชันของตัวแปรนั้น
3. หาจุดยอด ด้วยกำลังสองสมบูรณ์ หรือทางลัด $h = -\tfrac{b}{2a}$
4. ตอบให้ตรงคำถาม พร้อมหน่วย และตรวจว่าค่าที่ได้เป็นไปได้จริง เช่น ความยาวต้องไม่ติดลบ

## ลูกบอลขึ้นไปสูงสุดเท่าไร

<Example n={1}>

ลูกบอลจากหน้า 25.1 มีความสูง $h = 1 + 20t - 5t^2$ เมตร เมื่อเวลาผ่านไป $t$ วินาที ลูกบอลขึ้นไปสูงสุดกี่เมตร และถึงจุดสูงสุดเมื่อไร

<Steps reveal>
1. เรียงใหม่ $h = -5t^2 + 20t + 1$ มี $a = -5 < 0$ กราฟคว่ำลง จึงมีค่าสูงสุด
2. ดึง $-5$ ออก $h = -5(t^2 - 4t) + 1$ เติมให้ครบกำลังสอง $h = -5\big[(t - 2)^2 - 4\big] + 1$
3. คูณเข้าไป $h = -5(t - 2)^2 + 20 + 1 = -5(t - 2)^2 + 21$
4. จุดยอดคือ $(2, 21)$ ลูกบอลขึ้นไปสูงสุด 21 เมตร เมื่อเวลาผ่านไป 2 วินาที ตรงกับตารางในหน้า 25.1
</Steps>
</Example>

{/* check: expand(-5*(t - 2)**2 + 21) == expand(1 + 20*t - 5*t**2) */}

## ล้อมรั้วให้ได้พื้นที่มากที่สุด

มีรั้วยาว 40 เมตร จะล้อมแปลงผักรูปสี่เหลี่ยมผืนผ้าติดกำแพงบ้าน ด้านที่ติดกำแพงไม่ต้องใช้รั้ว ถ้าให้ด้านกว้างที่ตั้งฉากกับกำแพงยาว $x$ เมตร รั้วสองด้านนี้ใช้ไป $2x$ เมตร เหลือเป็นด้านยาว $40 - 2x$ เมตร

ก่อนคำนวณ ลองลากจุดบนกราฟของพื้นที่ข้างล่าง หาด้วยตาก่อนว่ากว้างเท่าไรได้พื้นที่มากที่สุด

<Board name="fence" label="กราฟพื้นที่แปลงผักเทียบกับความกว้าง ลากจุดไปตามเส้นได้">
แกนนอนคือความกว้าง $x$ เมตร แกนตั้งคือพื้นที่เป็นตารางเมตร
</Board>

<Example n={2}>

ด้านกว้างต้องยาวเท่าไรจึงได้พื้นที่มากที่สุด และพื้นที่มากที่สุดเป็นเท่าไร

<Steps reveal>
1. พื้นที่ $A = x(40 - 2x) = -2x^2 + 40x$ ตารางเมตร โดย $0 < x < 20$ เพราะด้านยาวต้องมากกว่าศูนย์
2. ดึง $-2$ ออก $A = -2(x^2 - 20x) = -2\big[(x - 10)^2 - 100\big]$
3. ได้ $A = -2(x - 10)^2 + 200$ มี $a = -2 < 0$ จึงมีค่าสูงสุด 200 เมื่อ $x = 10$
4. ด้านกว้าง 10 เมตร ด้านยาว $40 - 20 = 20$ เมตร ได้พื้นที่มากที่สุด 200 ตารางเมตร และ $x = 10$ อยู่ในช่วงที่เป็นไปได้
</Steps>
</Example>

{/* check: expand(-2*(x - 10)**2 + 200) == expand(x*(40 - 2*x)) */}

## ตั้งราคาให้ได้รายรับมากที่สุด

<Example n={3}>

ร้านชานมขายแก้วละ 40 บาท ขายได้วันละ 100 แก้ว เจ้าของร้านสังเกตว่าขึ้นราคาทุก 1 บาท จะขายได้น้อยลงวันละ 2 แก้ว ควรตั้งราคาแก้วละเท่าไรจึงได้รายรับมากที่สุด

<Steps reveal>
1. ให้ขึ้นราคา $x$ บาท ราคาแก้วละ $40 + x$ บาท ขายได้ $100 - 2x$ แก้ว
2. รายรับ $R = (40 + x)(100 - 2x) = 4000 + 20x - 2x^2$ บาท
3. จัดรูป $R = -2(x^2 - 10x) + 4000 = -2\big[(x - 5)^2 - 25\big] + 4000 = -2(x - 5)^2 + 4050$
4. รายรับมากที่สุด 4050 บาทเมื่อ $x = 5$ คำถามถามราคา จึงตอบว่าตั้งราคาแก้วละ $40 + 5 = 45$ บาท
</Steps>
</Example>

{/* check: expand((40 + x)*(100 - 2*x)) == expand(-2*(x - 5)**2 + 4050) */}

ขั้นสุดท้ายของตัวอย่างนี้คือจุดที่พลาดกันบ่อย หาจุดยอดได้ $x = 5$ แล้วตอบว่า 5 บาท ทั้งที่ $x$ คือราคาที่ขึ้น ไม่ใช่ราคาขาย ก่อนตอบให้กลับไปอ่านว่าตั้งตัวแปรไว้ว่าอะไร

<Think>

จำนวนสองจำนวนบวกกันได้ 20 ผลคูณของสองจำนวนนี้มากที่สุดเท่าไร

<Reveal>
ให้จำนวนหนึ่งเป็น $x$ อีกจำนวนเป็น $20 - x$ ผลคูณ $P = x(20 - x) = -(x - 10)^2 + 100$ มากที่สุด 100 เมื่อทั้งสองจำนวนเป็น 10
</Reveal>
</Think>

{/* check: expand(x*(20 - x)) == expand(-(x - 10)**2 + 100) */}

## สรุป

- ค่าสูงสุดหรือต่ำสุดของฟังก์ชันกำลังสองคือค่า $k$ ของจุดยอด
- $a > 0$ มีแต่ค่าต่ำสุด $a < 0$ มีแต่ค่าสูงสุด
- โจทย์ปัญหา ตั้งตัวแปร เขียนฟังก์ชัน หาจุดยอด แล้วตอบให้ตรงคำถามพร้อมหน่วย
