ขวดโหลบนโต๊ะครูมีลูกอมรสส้ม 3 เม็ด กับรสองุ่น 1 เม็ด ขนาดและห่อเหมือนกันหมด หลับตาหยิบมาหนึ่งเม็ด ใครก็บอกได้ว่าน่าจะได้รสส้มมากกว่า แต่ถ้าถามว่ามากกว่าแค่ไหน ต้องตอบเป็นตัวเลข หน้านี้คือวิธีหาตัวเลขนั้น

## ผลลัพธ์ที่มีโอกาสเกิดเท่ากัน

ตั้งชื่อลูกอมให้ต่างกัน เป็น ส้ม 1 ส้ม 2 ส้ม 3 และองุ่น หยิบหนึ่งเม็ดมีผลลัพธ์ $4$ แบบ ลูกอมทุกเม็ดเหมือนกันหมด จึงไม่มีเม็ดไหนถูกหยิบง่ายกว่าเม็ดอื่น เรียกว่าผลลัพธ์ทั้งสี่**มีโอกาสเกิดเท่าๆ กัน** ในสี่แบบนี้ เป็นรสส้ม $3$ แบบ จึงพูดได้ว่าโอกาสได้รสส้มเป็น $3$ ใน $4$

<Def label="ความน่าจะเป็น">
ถ้าผลลัพธ์ทุกแบบของการทดลองสุ่มมีโอกาสเกิดเท่าๆ กัน **ความน่าจะเป็น**ของเหตุการณ์ $E$ เขียนแทนด้วย $P(E)$ คือ

$$
P(E) = \frac{\text{จำนวนผลลัพธ์ของเหตุการณ์ } E}{\text{จำนวนผลลัพธ์ทั้งหมด}}
$$
</Def>

ลูกอมในขวดโหลจึงมี $P(\text{ได้รสส้ม}) = \tfrac{3}{4}$ และ $P(\text{ได้รสองุ่น}) = \tfrac{1}{4}$

{/* check: Rational(3, 4) + Rational(1, 4) == 1 */}

เหรียญที่ทำมาสม่ำเสมอ ลูกเต๋าที่ไม่ถ่วงน้ำหนัก ของที่ขนาดเท่ากันในถุงทึบ เป็นตัวอย่างที่ผลลัพธ์มีโอกาสเกิดเท่ากัน โจทย์ในบทนี้ถือแบบนี้ทั้งหมด ถ้าไม่ได้บอกเป็นอย่างอื่น

<Example n={1}>
ทอยลูกเต๋าหนึ่งลูก หาความน่าจะเป็นที่จะได้ (1) แต้มคู่ (2) แต้มมากกว่า 4 (3) แต้มที่เป็นจำนวนเฉพาะ

<Steps reveal>
1. ผลลัพธ์ทั้งหมดคือ 1 ถึง 6 มี $6$ ผลลัพธ์ ใช้เป็นตัวส่วนทุกข้อ
2. แต้มคู่คือ 2 4 6 มี $3$ ผลลัพธ์ ความน่าจะเป็นคือ $\tfrac{3}{6} = \tfrac{1}{2}$
3. แต้มมากกว่า 4 คือ 5 6 ความน่าจะเป็นคือ $\tfrac{2}{6} = \tfrac{1}{3}$
4. จำนวนเฉพาะคือ 2 3 5 ระวังว่า 1 ไม่ใช่จำนวนเฉพาะ ความน่าจะเป็นคือ $\tfrac{3}{6} = \tfrac{1}{2}$
</Steps>
</Example>

{/* check: Rational(len([v for v in range(1, 7) if v % 2 == 0]), 6) == Rational(1, 2) */}
{/* check: Rational(len([v for v in range(1, 7) if v > 4]), 6) == Rational(1, 3) */}
{/* check: Rational(len([v for v in range(1, 7) if isprime(v)]), 6) == Rational(1, 2) */}

## ความน่าจะเป็นอยู่ระหว่าง 0 ถึง 1

จำนวนผลลัพธ์ของเหตุการณ์ไม่มีทางติดลบ และไม่มีทางมากกว่าจำนวนผลลัพธ์ทั้งหมด เศษจึงอยู่ระหว่าง $0$ กับตัวส่วนเสมอ

<Thm>

สำหรับเหตุการณ์ $E$ ใดๆ $\;0 \le P(E) \le 1$

- เหตุการณ์ที่เป็นไปไม่ได้ ไม่มีผลลัพธ์เลย มีความน่าจะเป็น $0$ เช่นทอยลูกเต๋าได้แต้ม 7
- เหตุการณ์ที่เกิดขึ้นแน่นอน มีผลลัพธ์ครบทุกแบบ มีความน่าจะเป็น $1$ เช่นทอยลูกเต๋าได้แต้มน้อยกว่า 7
- ความน่าจะเป็นที่เหตุการณ์ $E$ **ไม่**เกิด เท่ากับ $1 - P(E)$

</Thm>

ข้อสุดท้ายมาจากการนับ ถ้ามีผลลัพธ์ทั้งหมด $n$ แบบ และเป็นของ $E$ อยู่ $m$ แบบ ผลลัพธ์ที่เหลือ $n - m$ แบบคือตอนที่ $E$ ไม่เกิด ได้ $\tfrac{n - m}{n} = 1 - \tfrac{m}{n}$ เมื่อนับตอนที่ไม่เกิดง่ายกว่า ให้หาความน่าจะเป็นที่เกิดก่อนแล้วลบออกจาก $1$

{/* check: simplify((symbols('n') - symbols('m'))/symbols('n') - (1 - symbols('m')/symbols('n'))) == 0 */}

<Example n={2}>
ห้อง ม.3/2 มีนักเรียน 40 คน ใส่แว่น 12 คน ครูสุ่มเรียกชื่อหนึ่งคนขึ้นมาทำโจทย์บนกระดาน ความน่าจะเป็นที่คนที่ถูกเรียกไม่ใส่แว่นเป็นเท่าไร

<Steps reveal>
1. นักเรียนทุกคนมีโอกาสถูกเรียกเท่ากัน ผลลัพธ์ทั้งหมด $40$ แบบ
2. ความน่าจะเป็นที่ได้คนใส่แว่นคือ $\tfrac{12}{40} = \tfrac{3}{10}$
3. ความน่าจะเป็นที่ไม่ใส่แว่นคือ $1 - \tfrac{3}{10} = \tfrac{7}{10}$
4. ตรวจด้วยการนับตรงๆ คนไม่ใส่แว่นมี $40 - 12 = 28$ คน ได้ $\tfrac{28}{40} = \tfrac{7}{10}$ ตรงกัน
</Steps>
</Example>

{/* check: 1 - Rational(12, 40) == Rational(28, 40) == Rational(7, 10) */}

## นับจากแผนภาพต้นไม้และตาราง

การทดลองหลายขั้น ต้องนับผลลัพธ์จากแผนภาพต้นไม้หรือตารางในหน้า 30.1 ไม่ใช่จากการนึกเอา

<Example n={3}>
โยนเหรียญสองเหรียญ หาความน่าจะเป็นที่จะได้หัวหนึ่งเหรียญและก้อยหนึ่งเหรียญ

<Steps reveal>
1. จากแผนภาพต้นไม้ ผลลัพธ์ทั้งหมดคือ HH HT TH TT มี $4$ แบบ และมีโอกาสเกิดเท่ากัน
2. หัวหนึ่งก้อยหนึ่งคือ HT กับ TH มี $2$ แบบ
3. ความน่าจะเป็นคือ $\tfrac{2}{4} = \tfrac{1}{2}$
</Steps>
</Example>

{/* check: Rational(len([p + q for p in 'HT' for q in 'HT' if p != q]), 4) == Rational(1, 2) */}

<Think>
เพื่อนนับว่าผลมีสามแบบ คือหัวทั้งคู่ ก้อยทั้งคู่ หัวหนึ่งก้อยหนึ่ง แล้วสรุปว่าความน่าจะเป็นที่ได้หัวทั้งคู่คือ $\tfrac{1}{3}$ ผิดตรงไหน

<Reveal>
สูตรความน่าจะเป็นใช้ได้เมื่อผลลัพธ์ทุกแบบมีโอกาสเกิดเท่ากัน สามแบบที่เพื่อนนับไม่เท่ากัน เพราะหัวหนึ่งก้อยหนึ่งเกิดได้สองทาง คือ HT กับ TH ต้องนับจากสี่ผลลัพธ์ HH HT TH TT ได้ความน่าจะเป็นที่ได้หัวทั้งคู่เป็น $\tfrac{1}{4}$ ลองโยนเหรียญสองเหรียญสัก 40 ครั้งดู จะได้หัวหนึ่งก้อยหนึ่งราวครึ่งหนึ่ง มากกว่าแบบอื่นชัดเจน
</Reveal>
</Think>

<Example n={4}>
ทอยลูกเต๋าสองลูก หาความน่าจะเป็นที่ (1) ผลบวกของแต้มเท่ากับ 8 (2) ผลบวกไม่เกิน 4 (3) ได้แต้มเหมือนกันทั้งสองลูก

<Steps reveal>
1. จากตารางในหน้า 30.1 ผลลัพธ์ทั้งหมด $36$ แบบ ใช้เป็นตัวส่วนทุกข้อ
2. ผลบวก 8 มี $5$ ช่อง ได้ $\tfrac{5}{36}$ ซึ่งทำให้เป็นเศษส่วนอย่างต่ำไม่ได้อีก
3. ผลบวกไม่เกิน 4 คือผลบวก 2 3 หรือ 4 นับได้ $1 + 2 + 3 = 6$ ช่อง ได้ $\tfrac{6}{36} = \tfrac{1}{6}$
4. แต้มเหมือนกันคือช่องแนวทแยง $(1, 1)$ $(2, 2)$ ไปจนถึง $(6, 6)$ มี $6$ ช่อง ได้ $\tfrac{6}{36} = \tfrac{1}{6}$
</Steps>
</Example>

{/* check: Rational(len([1 for i in range(1, 7) for j in range(1, 7) if i + j == 8]), 36) == Rational(5, 36) */}
{/* check: Rational(len([1 for i in range(1, 7) for j in range(1, 7) if i + j <= 4]), 36) == Rational(1, 6) */}
{/* check: Rational(len([1 for i in range(1, 7) for j in range(1, 7) if i == j]), 36) == Rational(1, 6) */}

<Note kind="warning" title="ผลบวก 2 ถึง 12 ไม่ได้มีโอกาสเท่ากัน">
ผลบวกของแต้มลูกเต๋าสองลูกมี 11 ค่า คือ 2 ถึง 12 แต่ห้ามตอบว่าความน่าจะเป็นของแต่ละค่าคือ $\tfrac{1}{11}$ เพราะผลบวก 7 มีหกช่องในตาราง ส่วนผลบวก 2 มีช่องเดียว ต้องนับจาก $36$ ผลลัพธ์เสมอ
</Note>

{/* check: [len([1 for i in range(1, 7) for j in range(1, 7) if i + j == s]) for s in (2, 7)] == [1, 6] */}

## เมื่อผลลัพธ์ไม่ได้มีโอกาสเท่ากันตั้งแต่แรก

<Think>
แป้นหมุนวงกลมระบายสีแดงครึ่งวง อีกครึ่งแบ่งเป็นสีน้ำเงินกับสีเขียวอย่างละเท่ากัน เข็มชี้ได้สามสี จึงมีความน่าจะเป็นที่ชี้สีแดงเป็น $\tfrac{1}{3}$ ใช่ไหม

<Reveal>
ไม่ใช่ สามสีนี้มีพื้นที่ไม่เท่ากัน จึงมีโอกาสเกิดไม่เท่ากัน ให้แบ่งแป้นเป็นสี่ส่วนเท่ากันก่อน สีแดงได้ $2$ ส่วน สีน้ำเงิน $1$ ส่วน สีเขียว $1$ ส่วน สี่ส่วนนี้มีโอกาสเท่ากันแล้ว ความน่าจะเป็นที่ชี้สีแดงจึงเป็น $\tfrac{2}{4} = \tfrac{1}{2}$
</Reveal>
</Think>

{/* check: Rational(2, 4) == Rational(1, 2) and Rational(2, 4) + Rational(1, 4) + Rational(1, 4) == 1 */}

## สรุป

- ใช้ $P(E) = \tfrac{\text{จำนวนผลลัพธ์ของ } E}{\text{จำนวนผลลัพธ์ทั้งหมด}}$ ได้เมื่อทุกผลลัพธ์มีโอกาสเกิดเท่ากัน
- $0 \le P(E) \le 1$ เป็นไปไม่ได้ได้ $0$ เกิดแน่นอนได้ $1$
- ความน่าจะเป็นที่ $E$ ไม่เกิดคือ $1 - P(E)$
- การทดลองหลายขั้น นับผลลัพธ์จากแผนภาพต้นไม้หรือตาราง อย่านับจากผลที่ดูเหมือนต่างกัน
- ตอบเป็นเศษส่วนอย่างต่ำ
