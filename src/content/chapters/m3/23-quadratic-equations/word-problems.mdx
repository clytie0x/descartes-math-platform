สามหน้าที่ผ่านมามีวิธีแก้สมการครบแล้ว หน้านี้ฝึกส่วนที่ยากกว่า คือการเขียนสมการจากเรื่องที่เล่ามา และการตัดสินว่าคำตอบที่ได้จากสมการใช้ได้จริงหรือไม่ สมการกำลังสองมักให้คำตอบสองตัว บางครั้งใช้ได้ทั้งคู่ บางครั้งใช้ได้ตัวเดียว และบางครั้งไม่มีคำตอบเลย ซึ่งก็เป็นคำตอบที่มีความหมาย

## ขั้นตอนทำโจทย์

1. ตั้งตัวแปรแทนสิ่งที่โจทย์ถาม เขียนให้ชัดว่าหมายถึงอะไรและหน่วยอะไร
2. เขียนปริมาณอื่นในโจทย์ด้วยตัวแปรนั้น แล้วตั้งสมการ
3. จัดให้อยู่ในรูปทั่วไปแล้วแก้ ด้วยวิธีที่เหมาะจากหน้า 23.3
4. ตรวจทุกคำตอบกับเรื่องในโจทย์ ตัดค่าที่เป็นไปไม่ได้ เช่น ความยาวติดลบ จำนวนคนเป็นเศษส่วน
5. ตอบให้ตรงคำถาม พร้อมหน่วย

## เลขหน้าหนังสือ

<Example n={1}>

เปิดหนังสือเรียนค้างไว้ เลขหน้าซ้ายกับเลขหน้าขวาคูณกันได้ $156$ เปิดอยู่ที่หน้าใด

<Steps reveal>
1. ให้หน้าซ้ายเป็นหน้า $n$ หน้าขวาเป็นหน้าถัดไปคือ $n + 1$
2. $n(n + 1) = 156$ จัดรูปได้ $n^2 + n - 156 = 0$
3. หาสองจำนวนที่คูณกันได้ $-156$ บวกกันได้ $1$ คือ $13$ กับ $-12$ ได้ $(n + 13)(n - 12) = 0$
4. $n = -13$ หรือ $n = 12$ เลขหน้าติดลบไม่ได้ จึงเหลือ $n = 12$
5. เปิดอยู่ที่หน้า 12 กับหน้า 13 ตรวจ $12 \times 13 = 156$
</Steps>
</Example>

{/* check: roots(x**2 + x - 156) == [-13, 12] */}
{/* check: 12*13 == 156 */}

## กรอบรูป

<Example n={2}>

รูปถ่ายกว้าง 10 เซนติเมตร ยาว 15 เซนติเมตร ใส่กรอบที่กว้างเท่ากันทุกด้าน วัดทั้งรูปรวมกรอบได้พื้นที่ 266 ตารางเซนติเมตร กรอบกว้างกี่เซนติเมตร

<Steps reveal>
1. ให้กรอบกว้าง $x$ เซนติเมตร กรอบอยู่ทั้งสองข้างของรูป ความกว้างรวมจึงเป็น $10 + 2x$ ความยาวรวมเป็น $15 + 2x$
2. $(10 + 2x)(15 + 2x) = 266$ กระจายได้ $4x^2 + 50x + 150 = 266$
3. ย้ายข้างได้ $4x^2 + 50x - 116 = 0$ หารด้วย $2$ ได้ $2x^2 + 25x - 58 = 0$
4. แยกตัวประกอบไม่เห็นทันที ใช้สูตร $b^2 - 4ac = 625 + 464 = 1089 = 33^2$
5. $x = \dfrac{-25 \pm 33}{4}$ ได้ $x = 2$ หรือ $x = -\dfrac{29}{2}$
6. ความกว้างของกรอบติดลบไม่ได้ กรอบกว้าง 2 เซนติเมตร ตรวจ $14 \times 19 = 266$
</Steps>
</Example>

{/* check: expand((10 + 2*x)*(15 + 2*x)) == 4*x**2 + 50*x + 150 */}
{/* check: 25**2 - 4*2*(-58) == 33**2 */}
{/* check: roots(2*x**2 + 25*x - 58) == [Rational(-29, 2), 2] */}
{/* check: 14*19 == 266 */}

<Think>

ข้อนี้ถ้าตั้งสมการเป็น $(10 + x)(15 + x) = 266$ จะได้คำตอบเท่าไร และผิดตรงไหน

<Reveal>
จะได้ $x^2 + 25x - 116 = 0$ ซึ่งมี $b^2 - 4ac = 1089$ เหมือนเดิม ได้ $x = 4$ หรือ $x = -29$ คำตอบ 4 ดูสมเหตุสมผลแต่ผิด เพราะกรอบอยู่ทั้งสองข้างของรูป ด้านกว้างจึงเพิ่ม $2x$ ไม่ใช่ $x$ วาดรูปก่อนตั้งสมการทุกครั้งจะเห็นเรื่องนี้ทันที
</Reveal>
</Think>

{/* check: roots((10 + x)*(15 + x) - 266) == [-29, 4] */}

## ทางเดินลัดแนวทแยง

<Example n={3}>

สนามหญ้ารูปสี่เหลี่ยมผืนผ้าด้านยาวยาวกว่าด้านกว้าง 14 เมตร มีทางเดินลัดตามแนวเส้นทแยงมุมยาว 26 เมตร สนามกว้างและยาวเท่าใด

<Steps reveal>
1. ให้สนามกว้าง $x$ เมตร ยาว $x + 14$ เมตร เส้นทแยงมุมกับสองด้านเป็นสามเหลี่ยมมุมฉาก
2. ทฤษฎีบทพีทาโกรัสจากบทที่ 10 ให้ $x^2 + (x + 14)^2 = 26^2$
3. กระจาย $x^2 + x^2 + 28x + 196 = 676$ ได้ $2x^2 + 28x - 480 = 0$ หารด้วย $2$ ได้ $x^2 + 14x - 240 = 0$
4. $(x + 24)(x - 10) = 0$ ได้ $x = -24$ หรือ $x = 10$ ตัด $-24$ ทิ้ง
5. สนามกว้าง 10 เมตร ยาว 24 เมตร ตรวจ $10^2 + 24^2 = 100 + 576 = 676 = 26^2$
</Steps>
</Example>

{/* check: expand(x**2 + (x + 14)**2 - 26**2) == 2*x**2 + 28*x - 480 */}
{/* check: roots(x**2 + 14*x - 240) == [-24, 10] */}
{/* check: 10**2 + 24**2 == 26**2 */}

## เมื่อคำตอบใช้ได้ทั้งสองตัว

<Example n={4}>

เตะลูกฟุตบอลโด่งขึ้นไป ความสูงของลูกบอลเมื่อเวลาผ่านไป $t$ วินาทีคือ $h = 1 + 14t - 5t^2$ เมตร ลูกบอลอยู่สูง 9 เมตรเมื่อใด

<Steps reveal>
1. ให้ $h = 9$ ได้ $1 + 14t - 5t^2 = 9$ ย้ายข้างแล้วคูณด้วย $-1$ ได้ $5t^2 - 14t + 8 = 0$
2. แยกพจน์กลาง สองจำนวนที่คูณกันได้ $5 \times 8 = 40$ บวกกันได้ $-14$ คือ $-10$ กับ $-4$
3. $5t^2 - 10t - 4t + 8 = 5t(t - 2) - 4(t - 2) = (5t - 4)(t - 2) = 0$
4. $t = \tfrac{4}{5} = 0.8$ หรือ $t = 2$
5. ทั้งสองค่าเป็นบวกและใช้ได้ ลูกบอลผ่านความสูง 9 เมตรสองครั้ง ตอนขาขึ้นที่ 0.8 วินาที และตอนขาลงที่ 2 วินาที
</Steps>
</Example>

{/* check: expand((5*t - 4)*(t - 2)) == 5*t**2 - 14*t + 8 */}
{/* check: roots(1 + 14*t - 5*t**2 - 9) == [Rational(4, 5), 2] */}

ตัวอย่างนี้ห้ามตัดคำตอบใดทิ้ง เพราะทั้งสองค่ามีความหมายในเรื่องจริง การตัดคำตอบต้องมีเหตุผลจากโจทย์เสมอ ไม่ใช่ตัดเพราะเคยชินว่าต้องเหลือตัวเดียว

<Think>

ลูกบอลลูกเดิมขึ้นไปถึงความสูง 12 เมตรได้ไหม

<Reveal>
ให้ $h = 12$ ได้ $5t^2 - 14t + 11 = 0$ ซึ่งมี $b^2 - 4ac = 196 - 220 = -24$ น้อยกว่าศูนย์ สมการไม่มีคำตอบที่เป็นจำนวนจริง แปลว่าไม่มีเวลาไหนที่ลูกบอลสูง 12 เมตร คือขึ้นไปไม่ถึง การที่สมการไม่มีคำตอบจึงตอบคำถามได้เหมือนกัน
</Reveal>
</Think>

## สรุป

- ตั้งตัวแปร เขียนปริมาณอื่นด้วยตัวแปรนั้น ตั้งสมการ แล้วแก้
- วาดรูปเมื่อโจทย์เกี่ยวกับความยาวหรือพื้นที่ จะเห็นว่าอะไรเพิ่มขึ้นกี่ด้าน
- ตรวจทุกคำตอบกับเรื่องในโจทย์ ตัดเฉพาะค่าที่มีเหตุผลว่าเป็นไปไม่ได้
- คำตอบสองตัวอาจใช้ได้ทั้งคู่ และสมการที่ไม่มีคำตอบก็บอกว่าสิ่งนั้นเกิดขึ้นไม่ได้
- แทนคำตอบกลับในเรื่องเดิมเพื่อตรวจทุกครั้ง
