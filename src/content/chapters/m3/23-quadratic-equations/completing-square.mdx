ลองแก้ $x^2 + 4x - 1 = 0$ ด้วยวิธีของหน้าที่แล้ว ต้องหาสองจำนวนเต็มที่คูณกันได้ $-1$ และบวกกันได้ $4$ จำนวนเต็มที่คูณกันได้ $-1$ มีแค่ $1$ กับ $-1$ ซึ่งบวกกันได้ $0$ จึงแยกตัวประกอบด้วยจำนวนเต็มไม่ได้ แต่สมการนี้มีคำตอบจริงๆ หน้านี้จะหาคำตอบนั้นด้วยรากที่สองจากบทที่ 11

## สมการ x² = k

สมการ $x^2 = 9$ ถามว่าจำนวนอะไรยกกำลังสองได้ $9$ คำตอบมีสองตัวคือ $3$ กับ $-3$ เพราะ $(-3)^2 = 9$ ด้วย ถ้าตอบแค่ $3$ จะได้คำตอบไม่ครบ

<Thm label="สมบัติของรากที่สอง">

สำหรับสมการ $x^2 = k$

- ถ้า $k > 0$ ได้ $x = \sqrt{k}$ หรือ $x = -\sqrt{k}$ เขียนย่อเป็น $x = \pm\sqrt{k}$
- ถ้า $k = 0$ ได้ $x = 0$ เพียงคำตอบเดียว
- ถ้า $k < 0$ สมการไม่มีคำตอบที่เป็นจำนวนจริง เพราะจำนวนจริงยกกำลังสองแล้วไม่มีทางติดลบ

</Thm>

<Example n={1}>

แก้สมการ (1) $x^2 = 16$   (2) $x^2 = 7$   (3) $2x^2 - 10 = 0$   (4) $x^2 + 4 = 0$

<Steps reveal>
1. $x^2 = 16$ ได้ $x = \pm 4$
2. $7$ ไม่ใช่กำลังสองของจำนวนเต็ม คำตอบจึงเขียนด้วยเครื่องหมายราก $x = \pm\sqrt{7}$ ไม่ต้องแปลงเป็นทศนิยม
3. จัดให้ $x^2$ อยู่ตัวเดียวก่อน $2x^2 = 10$ หารด้วย $2$ ได้ $x^2 = 5$ จึงได้ $x = \pm\sqrt{5}$
4. $x^2 = -4$ ไม่มีจำนวนจริงใดยกกำลังสองแล้วได้ $-4$ สมการนี้จึงไม่มีคำตอบที่เป็นจำนวนจริง
</Steps>
</Example>

{/* check: roots(x**2 - 16) == [-4, 4] */}
{/* check: roots(x**2 - 7) == [-sqrt(7), sqrt(7)] */}
{/* check: roots(2*x**2 - 10) == [-sqrt(5), sqrt(5)] */}
{/* check: roots(x**2 + 4) == [] */}

## สมการ (x + p)² = q

ใช้หลักเดียวกันได้ ถ้าสิ่งที่ยกกำลังสองเป็นวงเล็บทั้งก้อน ให้ถอดรากที่สองทั้งก้อนก่อน แล้วค่อยย้ายข้าง

<Example n={2}>

แก้สมการ (1) $(x - 3)^2 = 25$   (2) $(x + 2)^2 = 6$

<Steps reveal>
1. $(x - 3)^2 = 25$ ได้ $x - 3 = 5$ หรือ $x - 3 = -5$
2. จึงได้ $x = 8$ หรือ $x = -2$
3. $(x + 2)^2 = 6$ ได้ $x + 2 = \pm\sqrt{6}$
4. ย้าย $2$ ไปอีกข้าง $x = -2 + \sqrt{6}$ หรือ $x = -2 - \sqrt{6}$
</Steps>
</Example>

{/* check: roots((x - 3)**2 - 25) == [-2, 8] */}
{/* check: roots((x + 2)**2 - 6) == [-2 - sqrt(6), -2 + sqrt(6)] */}

<Note kind="warning" title="อย่าลืม ±">
ทุกครั้งที่ถอดรากที่สองเพื่อแก้สมการ ต้องเขียน $\pm$ เสมอ คำตอบที่หายบ่อยที่สุดในบทนี้คือคำตอบที่มาจากเครื่องหมายลบ
</Note>

## เติมให้เป็นกำลังสองสมบูรณ์

ถ้าเปลี่ยน $x^2 + 4x - 1 = 0$ ให้อยู่ในรูป $(x + p)^2 = q$ ได้ ก็แก้ได้ด้วยวิธีข้างบน เครื่องมือคือการเติม $x^2 + bx$ ให้เป็นกำลังสองสมบูรณ์จากหน้า 20.3

ดูรูปของ $x^2 + 6x$ เป็นพื้นที่ ตัด $6x$ เป็นสี่เหลี่ยมผืนผ้าขนาด $3 \times x$ สองแผ่น วางติดสองด้านของสี่เหลี่ยมจัตุรัส $x^2$ จะเหลือมุมที่ขาดไปขนาด $3 \times 3$

ค่าที่ต้องเติมคือครึ่งหนึ่งของสัมประสิทธิ์ของ $x$ แล้วยกกำลังสอง คือ $\left(\tfrac{b}{2}\right)^2$ สิ่งที่ต่างจากบทที่ 20 คือตอนนี้เป็นสมการ เติมอะไรข้างหนึ่งต้องเติมอีกข้างด้วย สมการจึงยังเป็นจริง

ขั้นตอนแก้ $x^2 + bx + c = 0$

1. ย้ายค่าคงตัว $c$ ไปอีกข้าง
2. เติม $\left(\tfrac{b}{2}\right)^2$ ทั้งสองข้าง
3. เขียนข้างซ้ายเป็น $\left(x + \tfrac{b}{2}\right)^2$
4. ถอดรากที่สอง อย่าลืม $\pm$ แล้วย้ายข้าง

<Example n={3}>

แก้สมการ $x^2 + 4x - 1 = 0$

<Steps reveal>
1. ย้าย $-1$ ไปข้างขวา $x^2 + 4x = 1$
2. ครึ่งหนึ่งของ $4$ คือ $2$ ยกกำลังสองได้ $4$ เติม $4$ ทั้งสองข้าง $x^2 + 4x + 4 = 1 + 4$
3. $(x + 2)^2 = 5$
4. $x + 2 = \pm\sqrt{5}$ จึงได้ $x = -2 + \sqrt{5}$ หรือ $x = -2 - \sqrt{5}$
</Steps>
</Example>

{/* check: roots(x**2 + 4*x - 1) == [-2 - sqrt(5), -2 + sqrt(5)] */}

ถ้าต้องการค่าประมาณ ใช้ $\sqrt{5} \approx 2.236$ จะได้ $x \approx 0.24$ หรือ $x \approx -4.24$ แต่ถ้าโจทย์ไม่ได้สั่ง ให้ตอบในรูปที่มีเครื่องหมายรากซึ่งเป็นค่าที่แท้จริง

{/* check: abs(float(-2 + sqrt(5)) - 0.236) < 0.001 */}

<Example n={4}>

แก้สมการ $x^2 - 8x + 13 = 0$

<Steps reveal>
1. ย้ายค่าคงตัว $x^2 - 8x = -13$
2. ครึ่งหนึ่งของ $-8$ คือ $-4$ ยกกำลังสองได้ $16$ เติมทั้งสองข้าง $x^2 - 8x + 16 = -13 + 16$
3. $(x - 4)^2 = 3$
4. $x - 4 = \pm\sqrt{3}$ จึงได้ $x = 4 \pm \sqrt{3}$
</Steps>
</Example>

{/* check: roots(x**2 - 8*x + 13) == [4 - sqrt(3), 4 + sqrt(3)] */}

<Think>

แก้ $x^2 + 8x = 5$ เพื่อนเติม $16$ ข้างซ้ายได้ $(x + 4)^2 = 5$ แล้วตอบ $x = -4 \pm \sqrt{5}$ ผิดตรงไหน

<Reveal>
เพื่อนเติม $16$ แค่ข้างซ้าย สมการจึงไม่เท่ากันแล้ว ต้องเติมทั้งสองข้าง $x^2 + 8x + 16 = 5 + 16$ ได้ $(x + 4)^2 = 21$ คำตอบที่ถูกคือ $x = -4 \pm \sqrt{21}$

ตรวจได้ด้วยการกระจาย $(x + 4)^2 = 5$ กลับ ได้ $x^2 + 8x + 16 = 5$ คือ $x^2 + 8x = -11$ ไม่ใช่สมการเดิม
</Reveal>
</Think>

{/* check: roots(x**2 + 8*x - 5) == [-4 - sqrt(21), -4 + sqrt(21)] */}
{/* check: expand((x + 4)**2 - 5) == x**2 + 8*x + 11 */}

## เมื่อ a ไม่เท่ากับ 1

การเติม $\left(\tfrac{b}{2}\right)^2$ ใช้ได้เมื่อสัมประสิทธิ์ของ $x^2$ เป็น $1$ ถ้าไม่ใช่ ให้หารทั้งสมการด้วย $a$ ก่อน หารได้เพราะ $a$ เป็นตัวเลขที่ไม่ใช่ศูนย์ ไม่ใช่ตัวแปร

<Example n={5}>

แก้สมการ $2x^2 + 12x + 8 = 0$

<Steps reveal>
1. หารทั้งสมการด้วย $2$ ได้ $x^2 + 6x + 4 = 0$
2. ย้ายค่าคงตัว $x^2 + 6x = -4$
3. เติม $9$ ทั้งสองข้าง ตามรูปข้างบน $x^2 + 6x + 9 = 5$
4. $(x + 3)^2 = 5$ ได้ $x = -3 \pm \sqrt{5}$
</Steps>
</Example>

{/* check: roots(2*x**2 + 12*x + 8) == [-3 - sqrt(5), -3 + sqrt(5)] */}

## เมื่อสมการไม่มีคำตอบ

<Example n={6}>

แก้สมการ $x^2 + 2x + 5 = 0$

<Steps reveal>
1. ย้ายค่าคงตัว $x^2 + 2x = -5$
2. เติม $1$ ทั้งสองข้าง $x^2 + 2x + 1 = -4$
3. $(x + 1)^2 = -4$ ข้างซ้ายเป็นกำลังสองซึ่งติดลบไม่ได้ แต่ข้างขวาเป็น $-4$
4. สมการนี้จึงไม่มีคำตอบที่เป็นจำนวนจริง
</Steps>
</Example>

{/* check: roots(x**2 + 2*x + 5) == [] */}
{/* check: expand((x + 1)**2 + 4) == x**2 + 2*x + 5 */}

## สรุป

- $x^2 = k$ ได้ $x = \pm\sqrt{k}$ เมื่อ $k > 0$ ได้ $x = 0$ เมื่อ $k = 0$ และไม่มีคำตอบเมื่อ $k < 0$
- ถอดรากที่สองเมื่อไร ต้องมี $\pm$ เสมอ
- ทำเป็นกำลังสองสมบูรณ์ ย้ายค่าคงตัว เติม $\left(\tfrac{b}{2}\right)^2$ ทั้งสองข้าง แล้วถอดราก
- ถ้า $a \neq 1$ หารทั้งสมการด้วย $a$ ก่อน
- ถ้าได้ $(x + p)^2$ เท่ากับจำนวนลบ สมการไม่มีคำตอบที่เป็นจำนวนจริง
