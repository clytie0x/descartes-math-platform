การทำเป็นกำลังสองสมบูรณ์ใช้ได้กับทุกสมการ แต่ถ้า $b$ เป็นเลขคี่หรือ $a$ หาร $b$ ไม่ลงตัว จะเจอเศษส่วนตลอดทาง เช่น $3x^2 + 5x - 1 = 0$ ต้องหารด้วย $3$ แล้วเติม $\tfrac{25}{36}$ ถ้าทำกำลังสองสมบูรณ์กับ $ax^2 + bx + c = 0$ ที่เป็นตัวอักษรไว้ครั้งเดียว จะได้สูตรที่แทนค่าได้ทันทีทุกครั้ง

## ที่มาของสูตร

ทำทีละขั้นเหมือนตัวอย่าง 5 ของหน้าที่แล้ว เพียงแต่ใช้ $a$ $b$ $c$ แทนตัวเลข โดย $a \neq 0$

<Steps reveal>
1. หารทั้งสมการด้วย $a$ ได้ $x^2 + \tfrac{b}{a}x + \tfrac{c}{a} = 0$
2. ย้ายค่าคงตัว $x^2 + \tfrac{b}{a}x = -\tfrac{c}{a}$
3. ครึ่งหนึ่งของ $\tfrac{b}{a}$ คือ $\tfrac{b}{2a}$ เติม $\tfrac{b^2}{4a^2}$ ทั้งสองข้าง $\left(x + \tfrac{b}{2a}\right)^2 = \tfrac{b^2}{4a^2} - \tfrac{c}{a}$
4. รวมข้างขวาเป็นเศษส่วนเดียว ตัวส่วน $4a^2$ ได้ $\left(x + \tfrac{b}{2a}\right)^2 = \tfrac{b^2 - 4ac}{4a^2}$
5. ถ้า $b^2 - 4ac \geq 0$ ถอดรากที่สองได้ $x + \tfrac{b}{2a} = \pm\tfrac{\sqrt{b^2 - 4ac}}{2a}$ (รากที่สองของ $4a^2$ คือ $2a$ หรือ $-2a$ แต่มี $\pm$ อยู่แล้วจึงครอบคลุมทั้งสองกรณี)
6. ย้าย $\tfrac{b}{2a}$ ไปข้างขวา รวมเป็นเศษส่วนเดียว ได้สูตรข้างล่าง
</Steps>

{/* check: simplify((x + b/(2*a))**2 - (b**2 - 4*a*c)/(4*a**2) - (x**2 + b/a*x + c/a)) == 0 */}
{/* check: simplify(a*((-b + sqrt(b**2 - 4*a*c))/(2*a))**2 + b*(-b + sqrt(b**2 - 4*a*c))/(2*a) + c) == 0 */}

<Thm label="สูตรสมการกำลังสอง">

คำตอบของสมการ $ax^2 + bx + c = 0$ เมื่อ $a \neq 0$ และ $b^2 - 4ac \geq 0$ คือ

$$
x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}
$$

</Thm>

ก่อนแทนค่า ต้องจัดสมการให้อยู่ในรูปทั่วไปที่ข้างหนึ่งเป็นศูนย์ แล้วเขียน $a$ $b$ $c$ พร้อมเครื่องหมายให้ชัด

<Example n={1}>

แก้สมการ $x^2 + 5x + 2 = 0$

<Steps reveal>
1. $a = 1$ $b = 5$ $c = 2$
2. $b^2 - 4ac = 25 - 4(1)(2) = 17$
3. $x = \dfrac{-5 \pm \sqrt{17}}{2(1)} = \dfrac{-5 \pm \sqrt{17}}{2}$
4. คำตอบคือ $\dfrac{-5 + \sqrt{17}}{2}$ และ $\dfrac{-5 - \sqrt{17}}{2}$ ประมาณ $-0.44$ และ $-4.56$
</Steps>
</Example>

{/* check: roots(x**2 + 5*x + 2) == [(-5 - sqrt(17))/2, (-5 + sqrt(17))/2] */}
{/* check: [round(float(r), 2) for r in roots(x**2 + 5*x + 2)] == [-4.56, -0.44] */}

<Example n={2}>

แก้สมการ $3x^2 - 2x - 8 = 0$

<Steps reveal>
1. $a = 3$ $b = -2$ $c = -8$
2. $b^2 - 4ac = (-2)^2 - 4(3)(-8) = 4 + 96 = 100$
3. $x = \dfrac{-(-2) \pm \sqrt{100}}{2(3)} = \dfrac{2 \pm 10}{6}$
4. $x = \dfrac{12}{6} = 2$ หรือ $x = \dfrac{-8}{6} = -\dfrac{4}{3}$
</Steps>
</Example>

{/* check: roots(3*x**2 - 2*x - 8) == [Rational(-4, 3), 2] */}

$b^2 - 4ac = 100$ เป็นกำลังสองของจำนวนเต็ม คำตอบจึงไม่มีเครื่องหมายราก แปลว่าสมการนี้แยกตัวประกอบได้ด้วย คือ $(3x + 4)(x - 2) = 0$ ถ้าเห็นตัวประกอบตั้งแต่แรก วิธีของหน้า 23.1 จะเร็วกว่า

{/* check: expand((3*x + 4)*(x - 2)) == 3*x**2 - 2*x - 8 */}

<Example n={3}>

แก้สมการ $x^2 = 3x + 5$

<Steps reveal>
1. จัดให้อยู่ในรูปทั่วไปก่อน $x^2 - 3x - 5 = 0$ จึงได้ $a = 1$ $b = -3$ $c = -5$
2. $b^2 - 4ac = (-3)^2 - 4(1)(-5) = 9 + 20 = 29$
3. $x = \dfrac{-(-3) \pm \sqrt{29}}{2} = \dfrac{3 \pm \sqrt{29}}{2}$
</Steps>
</Example>

{/* check: roots(x**2 - 3*x - 5) == [(3 - sqrt(29))/2, (3 + sqrt(29))/2] */}

<Think>

ในตัวอย่าง 3 นักเรียนคนหนึ่งคิด $b^2 - 4ac$ ได้ $-9 - 20 = -29$ แล้วสรุปว่าสมการไม่มีคำตอบ พลาดตรงไหนบ้าง

<Reveal>
พลาดสองที่ ที่แรก $b = -3$ ต้องยกกำลังทั้งก้อน $(-3)^2 = 9$ ไม่ใช่ $-3^2 = -9$ ที่สอง $c = -5$ ทำให้ $-4ac = -4(1)(-5) = +20$ ลบคูณลบเป็นบวก

ทางกันพลาดคือใส่วงเล็บรอบทุกค่าที่แทนลงไป $(-3)^2 - 4(1)(-5)$ แล้วค่อยคิดทีละพจน์
</Reveal>
</Think>

{/* check: (-3)**2 - 4*1*(-5) == 29 */}

## b² − 4ac บอกจำนวนคำตอบ

ค่า $b^2 - 4ac$ อยู่ใต้เครื่องหมายราก ค่านี้ค่าเดียวจึงบอกได้ว่าสมการมีคำตอบกี่คำตอบ โดยไม่ต้องแก้จนจบ ค่านี้มีชื่อเรียกว่า**ดิสคริมิแนนต์** (discriminant)

<Thm>

สำหรับสมการ $ax^2 + bx + c = 0$ เมื่อ $a \neq 0$

- ถ้า $b^2 - 4ac > 0$ สมการมีคำตอบที่เป็นจำนวนจริงสองคำตอบที่ไม่เท่ากัน เพราะ $+\sqrt{\phantom{x}}$ กับ $-\sqrt{\phantom{x}}$ ให้ค่าต่างกัน
- ถ้า $b^2 - 4ac = 0$ สมการมีคำตอบเดียว คือ $x = -\tfrac{b}{2a}$ เพราะ $\pm\sqrt{0}$ เป็นศูนย์ทั้งคู่
- ถ้า $b^2 - 4ac < 0$ สมการไม่มีคำตอบที่เป็นจำนวนจริง เพราะจำนวนลบไม่มีรากที่สองที่เป็นจำนวนจริง

</Thm>

กราฟข้างล่างคือกราฟของ $y = ax^2 + bx + c$ ซึ่งเป็นเส้นโค้งที่จะเรียนละเอียดในบทที่ 25 ตอนนี้ให้ดูแค่จุดที่เส้นโค้งตัดแกน $x$ ที่จุดนั้น $y = 0$ พิกัด $x$ ของจุดตัดจึงเป็นคำตอบของสมการ $ax^2 + bx + c = 0$ พอดี

<Board name="c23-roots" label="เส้นโค้ง y เท่ากับ a x กำลังสอง บวก b x บวก c ปรับ a b c ด้วยแถบเลื่อน จุดที่ตัดแกน x คือคำตอบของสมการ">
ตั้ง $a = 1$ $b = 4$ $c = 4$ แล้วดูว่าเส้นโค้งแตะแกน $x$ กี่จุด จากนั้นเลื่อน $c$ ขึ้นเป็น $6$ จุดตัดหายไปไหน
</Board>

<Example n={4}>

ไม่ต้องแก้สมการ บอกว่าแต่ละสมการมีคำตอบที่เป็นจำนวนจริงกี่คำตอบ

(1) $x^2 - 6x + 9 = 0$   (2) $2x^2 + 3x + 5 = 0$   (3) $x^2 + x - 1 = 0$

<Steps reveal>
1. $(-6)^2 - 4(1)(9) = 36 - 36 = 0$ มีคำตอบเดียว
2. $3^2 - 4(2)(5) = 9 - 40 = -31$ น้อยกว่าศูนย์ ไม่มีคำตอบที่เป็นจำนวนจริง
3. $1^2 - 4(1)(-1) = 1 + 4 = 5$ มากกว่าศูนย์ มีสองคำตอบ
</Steps>
</Example>

{/* check: [(-6)**2 - 4*1*9, 3**2 - 4*2*5, 1**2 - 4*1*(-1)] == [0, -31, 5] */}
{/* check: [len(roots(x**2 - 6*x + 9)), len(roots(2*x**2 + 3*x + 5)), len(roots(x**2 + x - 1))] == [1, 0, 2] */}

<Example n={5}>

หาค่า $k$ ที่ทำให้สมการ $x^2 + kx + 9 = 0$ มีคำตอบเดียว

<Steps reveal>
1. มีคำตอบเดียวเมื่อ $b^2 - 4ac = 0$ ในที่นี้ $a = 1$ $b = k$ $c = 9$
2. $k^2 - 4(1)(9) = 0$ ได้ $k^2 = 36$
3. $k = 6$ หรือ $k = -6$ ตรวจ $k = 6$ ได้ $x^2 + 6x + 9 = (x + 3)^2$ และ $k = -6$ ได้ $(x - 3)^2$ เป็นกำลังสองสมบูรณ์ทั้งคู่
</Steps>
</Example>

{/* check: solve(k**2 - 4*1*9, k) == [-6, 6] */}

## เลือกวิธีไหนดี

| สมการหน้าตาแบบนี้ | วิธีที่เร็ว |
|---|---|
| ไม่มีพจน์ $x$ เช่น $3x^2 = 27$ | จัดเป็น $x^2 = k$ แล้วถอดราก |
| ไม่มีค่าคงตัว เช่น $x^2 = 4x$ | ดึงตัวร่วม $x$ |
| เห็นตัวประกอบที่เป็นจำนวนเต็มเร็ว | แยกตัวประกอบ |
| อยู่ในรูป $(x + p)^2 = q$ แล้ว | ถอดรากทั้งก้อน |
| นอกจากนั้น | สูตรสมการกำลังสอง |

{/* check: roots(3*x**2 - 27) == [-3, 3] */}

สูตรใช้ได้กับทุกสมการ ถ้าลังเลก็ใช้สูตรได้เสมอ แต่ถ้าสมการแยกตัวประกอบง่าย การแยกตัวประกอบพลาดน้อยกว่าเพราะคิดเลขน้อยกว่า

## สรุป

- $x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$ ได้จากการทำกำลังสองสมบูรณ์กับ $ax^2 + bx + c = 0$
- จัดสมการให้ข้างหนึ่งเป็นศูนย์ก่อน แล้วเขียน $a$ $b$ $c$ พร้อมเครื่องหมาย
- ใส่วงเล็บตอนแทนค่าติดลบ เช่น $(-3)^2 = 9$ และ $-4(1)(-5) = 20$
- $b^2 - 4ac$ มากกว่าศูนย์ มีสองคำตอบ เท่ากับศูนย์ มีคำตอบเดียว น้อยกว่าศูนย์ ไม่มีคำตอบที่เป็นจำนวนจริง
