เก้าโมงเช้า นักเรียนคนหนึ่งสูง 150 เซนติเมตร ยืนข้างเสาธง เงาของเขายาว 200 เซนติเมตร ส่วนเงาของเสาธงยาว 12 เมตร เสาธงสูงเท่าไร

แสงแดดตกลงมาเป็นมุมเดียวกันทั้งที่ตัวนักเรียนและที่เสาธง ตัวคนกับเงา และเสาธงกับเงา จึงเป็นรูปสามเหลี่ยมมุมฉากที่มีมุมเท่ากันทุกมุม ซึ่งเป็นรูปสามเหลี่ยมที่คล้ายกันตามบทที่ 24 ด้านจึงเป็นสัดส่วนกัน

$$
\frac{\text{ความสูง}}{\text{ความยาวเงา}} = \frac{150}{200} = 0.75
$$

เสาธงก็ต้องสูงเป็น $0.75$ เท่าของเงา คือ $0.75 \times 12 = 9$ เมตร

{/* check: Rational(150, 200)*12 == 9 */}

ตัวเลข $0.75$ นี้ไม่ได้ขึ้นกับว่าวัดคนหรือวัดเสา ขึ้นกับมุมของแสงแดดอย่างเดียว ถ้าเป็นตอนเที่ยง แดดสูงกว่านี้ อัตราส่วนก็เปลี่ยนไป อัตราส่วนของด้านที่ผูกกับมุมแบบนี้คือเรื่องของบทนี้ทั้งบท

## ชื่อของด้านทั้งสาม

ในรูปสามเหลี่ยมมุมฉาก ด้านที่อยู่ตรงข้ามมุมฉากมีชื่อเรียกอยู่แล้ว ส่วนอีกสองด้านจะเรียกชื่อได้ก็ต่อเมื่อเลือกมุมแหลมมุมหนึ่งเป็นหลักก่อน

<Def>

ในรูปสามเหลี่ยม $ABC$ ที่มีมุม $C$ เป็นมุมฉาก เมื่อมองจากมุม $A$

- **ด้านตรงข้ามมุมฉาก** คือ $AB$ เป็นด้านที่ยาวที่สุด
- **ด้านตรงข้ามมุม** $A$ คือ $BC$ เป็นด้านที่ไม่แตะมุม $A$ เลย
- **ด้านประชิดมุม** $A$ คือ $AC$ เป็นด้านที่แตะมุม $A$ และไม่ใช่ด้านตรงข้ามมุมฉาก

</Def>

มุม $A$ ถูกล้อมด้วยสองด้าน คือ $AB$ กับ $AC$ แต่ $AB$ มีชื่อว่าด้านตรงข้ามมุมฉากแล้ว ด้านประชิดจึงเหลือ $AC$ ด้านเดียว

<Think>

ถ้าเปลี่ยนไปมองจากมุม $B$ แทน ด้านไหนเป็นด้านตรงข้ามมุม $B$ และด้านไหนเป็นด้านประชิดมุม $B$

<Reveal>
ด้านตรงข้ามมุม $B$ คือ $AC$ และด้านประชิดมุม $B$ คือ $BC$ สลับกับตอนมองจากมุม $A$ พอดี ส่วนด้านตรงข้ามมุมฉากยังเป็น $AB$ เหมือนเดิม คำว่าตรงข้ามกับประชิดจึงต้องบอกเสมอว่าเทียบกับมุมไหน ถ้าไม่บอกมุมก็ตอบไม่ได้
</Reveal>
</Think>

## อัตราส่วนตรีโกณมิติ

จับด้านมาหารกันทีละคู่ได้อัตราส่วนสามตัวที่ใช้บ่อยที่สุด แต่ละตัวมีชื่อของมันเอง

<Def>

ในรูปสามเหลี่ยม $ABC$ ที่มีมุม $C$ เป็นมุมฉาก

$$
\begin{aligned}
\sin A &= \frac{\text{ความยาวของด้านตรงข้ามมุม } A}{\text{ความยาวของด้านตรงข้ามมุมฉาก}} = \frac{BC}{AB} \\[6pt]
\cos A &= \frac{\text{ความยาวของด้านประชิดมุม } A}{\text{ความยาวของด้านตรงข้ามมุมฉาก}} = \frac{AC}{AB} \\[6pt]
\tan A &= \frac{\text{ความยาวของด้านตรงข้ามมุม } A}{\text{ความยาวของด้านประชิดมุม } A} = \frac{BC}{AC}
\end{aligned}
$$

อ่านว่า ไซน์ เอ โคไซน์ เอ และแทนเจนต์ เอ เรียกรวมกันว่า**อัตราส่วนตรีโกณมิติ**ของมุม $A$
</Def>

$\sin A$ เป็นชื่อของตัวเลขตัวเดียว ไม่ได้แปลว่า $\sin$ คูณ $A$ เหมือน $2A$ ที่แปลว่า $2$ คูณ $A$

## ทำไมค่าขึ้นกับมุมอย่างเดียว

เลื่อนแถบ ขนาด ให้รูปสามเหลี่ยมใหญ่ขึ้นหรือเล็กลงโดยไม่แตะมุม แล้วดูค่า sin cos tan ข้างล่าง จากนั้นค่อยเลื่อนแถบ มุม $A$

<Board name="c31-ratios" label="รูปสามเหลี่ยมมุมฉาก มุม C เป็นมุมฉาก ปรับมุม A และขนาดของรูปได้ มีความยาวด้านทั้งสามกำกับไว้">
ด้านสีส้มคือด้านตรงข้ามมุม $A$ ด้านสีเขียวคือด้านประชิดมุม $A$ ด้านสีม่วงคือด้านตรงข้ามมุมฉาก
</Board>

ตอนเปลี่ยนขนาด ด้านทุกด้านยาวขึ้นหรือสั้นลง แต่อัตราส่วนไม่ขยับเลย เหตุผลคือรูปสามเหลี่ยมมุมฉากสองรูปที่มีมุม $A$ เท่ากัน มีมุมฉากเท่ากัน และมุมที่สามก็ต้องเท่ากันด้วย จึงเป็นรูปสามเหลี่ยมที่คล้ายกัน ด้านคู่ที่สมนัยกันเป็นสัดส่วนกัน อัตราส่วนของด้านภายในรูปเดียวกันจึงเท่ากันทั้งสองรูป

เช่น รูปที่มีด้าน $3$ $4$ $5$ กับรูปที่มีด้าน $6$ $8$ $10$ ซึ่งมีมุมเท่ากัน ได้ $\sin A = \tfrac{3}{5}$ กับ $\tfrac{6}{10}$ ซึ่งเป็นค่าเดียวกัน

{/* check: Rational(3, 5) == Rational(6, 10) */}

<Thm>

ค่าของ $\sin A$ $\cos A$ และ $\tan A$ ขึ้นอยู่กับขนาดของมุม $A$ อย่างเดียว ไม่ขึ้นกับขนาดของรูปสามเหลี่ยมมุมฉากที่ใช้หา

</Thm>

นี่คือเหตุผลที่เขียน $\sin 35^\circ$ ได้โดยไม่ต้องบอกว่ารูปสามเหลี่ยมใหญ่แค่ไหน และเครื่องคิดเลขบอกค่าได้ทันที

<Think>

เพื่อนบอกว่ารูปสามเหลี่ยมยิ่งใหญ่ ด้านตรงข้ามมุม $A$ ยิ่งยาว ค่า $\sin A$ จึงยิ่งมาก เพื่อนพูดถูกไหม

<Reveal>
ไม่ถูก ด้านตรงข้ามมุม $A$ ยาวขึ้นก็จริง แต่ด้านตรงข้ามมุมฉากก็ยาวขึ้นด้วยในอัตราเดียวกัน ขยายรูปสองเท่า ทั้งเศษและส่วนของ $\sin A$ ก็คูณสองทั้งคู่ ผลหารจึงเท่าเดิม ลองเลื่อนแถบ ขนาด ในรูปข้างบนดูอีกครั้ง สิ่งเดียวที่ทำให้ $\sin A$ เปลี่ยนคือขนาดของมุม $A$
</Reveal>
</Think>

## หาอัตราส่วนจากความยาวด้าน

<Example n={1}>

รูปสามเหลี่ยม $ABC$ มีมุม $C$ เป็นมุมฉาก $BC = 5$ $AC = 12$ และ $AB = 13$ หน่วย จงหา sin cos tan ของมุม $A$ และของมุม $B$

<Steps reveal>
1. ด้านตรงข้ามมุมฉากคือ $AB = 13$ ใช้ทั้งสองมุม
2. มองจากมุม $A$ ด้านตรงข้ามคือ $BC = 5$ ด้านประชิดคือ $AC = 12$ ได้ $\sin A = \tfrac{5}{13}$ $\cos A = \tfrac{12}{13}$ $\tan A = \tfrac{5}{12}$
3. มองจากมุม $B$ ด้านตรงข้ามคือ $AC = 12$ ด้านประชิดคือ $BC = 5$ ได้ $\sin B = \tfrac{12}{13}$ $\cos B = \tfrac{5}{13}$ $\tan B = \tfrac{12}{5}$
</Steps>
</Example>

{/* check: sqrt(5**2 + 12**2) == 13 */}

สังเกตว่า $\sin A = \cos B$ และ $\cos A = \sin B$ เพราะด้านที่ตรงข้ามมุมหนึ่งคือด้านที่ประชิดอีกมุมหนึ่ง เรื่องนี้จะกลับมาอีกในหน้า 31.2

<Note kind="tip" title="ค่าที่เป็นไปได้">
ด้านตรงข้ามมุมฉากยาวที่สุดเสมอ $\sin A$ กับ $\cos A$ ของมุมแหลมจึงน้อยกว่า $1$ ทุกครั้ง ถ้าคำนวณได้ $\sin A = \tfrac{13}{5}$ แปลว่าเอาด้านมาหารกลับข้าง ส่วน $\tan A$ มากกว่า $1$ ได้ เช่น $\tan B = \tfrac{12}{5}$ ในตัวอย่างข้างบน
</Note>

<Example n={2}>

รูปสามเหลี่ยม $ABC$ มีมุม $C$ เป็นมุมฉาก $AB = 17$ และ $AC = 8$ หน่วย จงหา $\sin A$ $\cos A$ และ $\tan A$

<Steps reveal>
1. ยังไม่รู้ด้าน $BC$ ซึ่งเป็นด้านตรงข้ามมุม $A$ หาด้วยทฤษฎีบทพีทาโกรัส $BC = \sqrt{17^2 - 8^2} = \sqrt{289 - 64} = \sqrt{225} = 15$
2. $\sin A = \dfrac{BC}{AB} = \dfrac{15}{17}$
3. $\cos A = \dfrac{AC}{AB} = \dfrac{8}{17}$
4. $\tan A = \dfrac{BC}{AC} = \dfrac{15}{8}$
</Steps>
</Example>

{/* check: sqrt(17**2 - 8**2) == 15 */}

## รู้อัตราส่วนหนึ่งตัว หาอีกสองตัว

ถ้ารู้ค่าอัตราส่วนตรีโกณมิติแค่ตัวเดียว ก็หาอีกสองตัวได้ ด้วยการวาดรูปสามเหลี่ยมมุมฉากที่มีอัตราส่วนนั้นขึ้นมาเอง รูปใหญ่หรือเล็กไม่สำคัญ เพราะค่าขึ้นกับมุมอย่างเดียว

<Example n={3}>

มุม $A$ เป็นมุมแหลม และ $\sin A = \tfrac{2}{3}$ จงหา $\cos A$ และ $\tan A$

<Steps reveal>
1. วาดรูปสามเหลี่ยมมุมฉากที่ด้านตรงข้ามมุม $A$ ยาว $2$ และด้านตรงข้ามมุมฉากยาว $3$ ก็จะได้ $\sin A = \tfrac{2}{3}$ ตามต้องการ
2. ด้านประชิดมุม $A$ ยาว $\sqrt{3^2 - 2^2} = \sqrt{5}$
3. $\cos A = \dfrac{\sqrt{5}}{3}$
4. $\tan A = \dfrac{2}{\sqrt{5}} = \dfrac{2\sqrt{5}}{5}$ โดยคูณทั้งเศษและส่วนด้วย $\sqrt{5}$
</Steps>
</Example>

{/* check: sqrt(3**2 - 2**2) == sqrt(5) */}
{/* check: simplify(2/sqrt(5) - 2*sqrt(5)/5) == 0 */}

<Think>

จาก $\sin A = \tfrac{2}{3}$ สรุปได้ไหมว่าด้านตรงข้ามมุม $A$ ยาว $2$ หน่วย

<Reveal>
สรุปไม่ได้ $\sin A = \tfrac{2}{3}$ บอกแค่ว่าด้านตรงข้ามมุม $A$ ยาวเป็นสองในสามของด้านตรงข้ามมุมฉาก ด้านจริงอาจยาว $4$ กับ $6$ หรือ $10$ กับ $15$ ก็ได้ ในตัวอย่าง 3 เราเลือก $2$ กับ $3$ เพราะคำนวณง่าย และคำตอบ $\cos A$ กับ $\tan A$ ออกมาเท่ากันไม่ว่าจะเลือกขนาดไหน
</Reveal>
</Think>

## สรุป

- ด้านตรงข้ามมุมฉากยาวที่สุด ด้านตรงข้ามมุมกับด้านประชิดมุมต้องบอกว่าเทียบกับมุมไหน
- $\sin A = \dfrac{\text{ตรงข้าม}}{\text{ตรงข้ามมุมฉาก}}$ $\cos A = \dfrac{\text{ประชิด}}{\text{ตรงข้ามมุมฉาก}}$ $\tan A = \dfrac{\text{ตรงข้าม}}{\text{ประชิด}}$
- ค่าขึ้นกับขนาดของมุมอย่างเดียว เพราะรูปสามเหลี่ยมมุมฉากที่มีมุมแหลมเท่ากันเป็นรูปที่คล้ายกัน
- รู้ด้านสองด้าน หาด้านที่สามด้วยพีทาโกรัสก่อน แล้วหาอัตราส่วนครบทั้งสามตัว
- $\sin A$ และ $\cos A$ ของมุมแหลมน้อยกว่า $1$ เสมอ
