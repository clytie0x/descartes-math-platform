ลองดูตัวเลขที่เจอในวันเดียว ข้าวมันไก่จานละ $50$ บาท อุณหภูมิบนยอดดอยตอนเช้า $-2$ องศาเซลเซียส ร้านลดราคา $0.25$ ของราคาเต็ม แบตโทรศัพท์เหลือ $\tfrac{2}{3}$ ของหลอด และเพื่อนสามคนหารค่าพิซซ่า $100$ บาท ได้คนละ $33.333\ldots$ บาท

ตัวเลขเหล่านี้หน้าตาต่างกันมาก มีทั้งจำนวนเต็ม จำนวนลบ ทศนิยม และเศษส่วน แต่ทุกตัวมีอย่างหนึ่งที่เหมือนกัน คือเขียนเป็นเศษส่วนของจำนวนเต็มได้ หน้านี้ตั้งชื่อให้กลุ่มนี้ และหาว่าจำนวนแบบไหนบ้างที่อยู่ในกลุ่ม

## จำนวนตรรกยะคืออะไร

<Def>
**จำนวนตรรกยะ** (rational number) คือจำนวนที่เขียนได้ในรูป

$$
\frac{a}{b}
$$

เมื่อ $a$ และ $b$ เป็นจำนวนเต็ม และ $b \neq 0$
</Def>

ที่ต้องมี $b \neq 0$ เพราะการหารด้วยศูนย์ไม่มีความหมาย ไม่มีจำนวนใดคูณ $0$ แล้วได้ $5$ ดังนั้น $\tfrac{5}{0}$ จึงไม่ใช่จำนวน

จะพิสูจน์ว่าจำนวนหนึ่งเป็นจำนวนตรรกยะ แค่หาเศษส่วนของจำนวนเต็มที่เท่ากับมันได้สักแบบก็พอ ไม่จำเป็นต้องเป็นเศษส่วนอย่างต่ำ

<Example n={1}>
แสดงว่าจำนวนต่อไปนี้เป็นจำนวนตรรกยะ $50$ $-2$ $0$ $2\tfrac{1}{2}$ $0.25$ และ $-1.2$

<Steps reveal>
1. จำนวนเต็มทุกตัวหารด้วย $1$ ได้ตัวเอง $50 = \tfrac{50}{1}$ และ $-2 = \tfrac{-2}{1}$
2. $0 = \tfrac{0}{1}$ ตัวเศษเป็นศูนย์ได้ ห้ามแค่ตัวส่วน
3. จำนวนคละเปลี่ยนเป็นเศษเกิน $2\tfrac{1}{2} = \tfrac{4}{2} + \tfrac{1}{2} = \tfrac{5}{2}$
4. ทศนิยมรู้จบเขียนเป็นเศษส่วนที่มีตัวส่วนเป็น $10$ $100$ $1000$ ได้ $0.25 = \tfrac{25}{100} = \tfrac{1}{4}$
5. $-1.2 = -\tfrac{12}{10} = \tfrac{-6}{5}$
</Steps>
</Example>

{/* check: 2 + Rational(1, 2) == Rational(5, 2) and Rational('0.25') == Rational(1, 4) and Rational('-1.2') == Rational(-6, 5) */}

จากตัวอย่างนี้ได้ข้อสรุปสองข้อ จำนวนเต็มทุกตัวเป็นจำนวนตรรกยะ และทศนิยมรู้จบทุกตัวก็เป็นจำนวนตรรกยะ

<Think>

$0.1234567891$ ยาวตั้งสิบตำแหน่ง ตัวเลขก็ไม่ซ้ำกันเลย จะเป็นจำนวนตรรกยะได้ไหม

<Reveal>
ได้ ยาวแค่ไหนก็ไม่สำคัญ ขอให้จบ ทศนิยมสิบตำแหน่งเขียนเป็นเศษส่วนที่มีตัวส่วน $10^{10}$ ได้ทันที คือ $\tfrac{1234567891}{10000000000}$ ซึ่งเป็นเศษส่วนของจำนวนเต็ม สิ่งที่ทำให้จำนวนหนึ่งไม่เป็นจำนวนตรรกยะ ไม่ใช่ความยาว แต่เป็นทศนิยมที่ไม่รู้จบและไม่ซ้ำ ซึ่งจะเจอในหน้าถัดไป
</Reveal>
</Think>

{/* check: Rational('0.1234567891') == Rational(1234567891, 10**10) */}

## ทศนิยมซ้ำก็เป็นจำนวนตรรกยะ

ในบทที่ 4 เราเปลี่ยนทศนิยมซ้ำเป็นเศษส่วนด้วยการคูณ $10$ หรือ $100$ ให้หางที่ซ้ำตรงกัน แล้วลบให้หางหายไป วิธีนี้ใช้ได้กับทศนิยมซ้ำทุกตัว ทศนิยมซ้ำทุกตัวจึงเป็นจำนวนตรรกยะด้วย

<Example n={2}>
เขียน $0.\dot{2}\dot{7}$ และ $1.\dot{6}$ เป็นเศษส่วนอย่างต่ำ

<Steps reveal>
1. ให้ $N = 0.272727\ldots$ ชุดที่ซ้ำยาวสองตัว จึงคูณด้วย $100$ ได้ $100N = 27.2727\ldots$
2. ลบกัน $100N - N = 27$ ได้ $99N = 27$ จึงได้ $N = \tfrac{27}{99} = \tfrac{3}{11}$
3. ให้ $M = 1.666\ldots$ ซ้ำตัวเดียว คูณด้วย $10$ ได้ $10M = 16.666\ldots$
4. ลบกัน $10M - M = 15$ ได้ $9M = 15$ จึงได้ $M = \tfrac{15}{9} = \tfrac{5}{3}$
</Steps>
</Example>

{/* check: Rational(27, 99) == Rational(3, 11) and floor(Rational(3, 11) * 10**6) == 272727 */}
{/* check: Rational(15, 9) == Rational(5, 3) and floor(Rational(5, 3) * 10**6) == 1666666 */}

ในทางกลับกัน บทที่ 4 แสดงไว้แล้วว่าเศษส่วนทุกตัวหารออกมาได้ทศนิยมรู้จบหรือทศนิยมซ้ำเท่านั้น เพราะเศษจากการหารยาวมีให้เลือกจำกัด สักวันต้องวนกลับมาซ้ำ สองข้อนี้รวมกันได้สมบัติที่ใช้แยกจำนวนตรรกยะออกจากจำนวนอื่น

<Thm>

- จำนวนตรรกยะทุกจำนวนเขียนเป็นทศนิยมรู้จบหรือทศนิยมซ้ำได้
- ทศนิยมรู้จบและทศนิยมซ้ำทุกจำนวนเป็นจำนวนตรรกยะ

</Thm>

ดังนั้นจะดูว่าจำนวนหนึ่งเป็นจำนวนตรรกยะไหม ดูได้สองทาง ทางแรกหาเศษส่วนของจำนวนเต็มที่เท่ากับมัน ทางที่สองเขียนเป็นทศนิยมแล้วดูว่าจบหรือซ้ำ

<Think>

$0.121121112\ldots$ หลังเลข $2$ แต่ละตัวมีเลข $1$ เพิ่มขึ้นทีละตัว เพื่อนบอกว่าเป็นทศนิยมซ้ำ เพราะเห็นแบบรูปชัดเจน เพื่อนพูดถูกไหม

<Reveal>
ไม่ถูก ทศนิยมซ้ำต้องมีตัวเลข**ชุดเดิม**ซ้ำไปตลอด เช่น $0.\dot{1}\dot{2} = 0.121212\ldots$ ซ้ำชุด $12$ ทุกครั้ง แต่ $0.121121112\ldots$ ชุดยาวขึ้นเรื่อยๆ ไม่มีชุดไหนวนกลับมาเหมือนเดิม มีแบบรูปก็จริง แต่ไม่ใช่การซ้ำ จำนวนนี้จึงไม่เป็นจำนวนตรรกยะ
</Reveal>
</Think>

## เปรียบเทียบจำนวนตรรกยะ

จำนวนตรรกยะทุกตัวอยู่บนเส้นจำนวนได้ จะเปรียบเทียบสองจำนวน ให้เปลี่ยนเป็นทศนิยม หรือทำตัวส่วนให้เท่ากัน แล้วเทียบเหมือนที่ทำตอน ม.1

<Example n={3}>
เรียงจำนวนต่อไปนี้จากน้อยไปมาก $-\tfrac{3}{8}$ $-0.4$ $-\tfrac{1}{3}$

<Steps reveal>
1. เปลี่ยนเป็นทศนิยม $-\tfrac{3}{8} = -0.375$ และ $-\tfrac{1}{3} = -0.333\ldots$
2. จำนวนลบที่อยู่ห่างศูนย์มากกว่าจะอยู่ทางซ้ายมากกว่า จึงมีค่าน้อยกว่า ห่างศูนย์มากที่สุดคือ $0.4$ แล้ว $0.375$ แล้ว $0.333\ldots$
3. เรียงจากน้อยไปมากได้ $-0.4$ $-\tfrac{3}{8}$ $-\tfrac{1}{3}$
</Steps>
</Example>

{/* check: Rational(-2, 5) < Rational(-3, 8) < Rational(-1, 3) */}

### ระหว่างสองจำนวนมีจำนวนอื่นเสมอ

จำนวนเต็ม $1$ กับ $2$ ไม่มีจำนวนเต็มอยู่ระหว่างกลาง แต่จำนวนตรรกยะไม่เป็นแบบนั้น ระหว่างจำนวนตรรกยะสองจำนวนใดๆ หาจำนวนตรรกยะอีกตัวได้เสมอ วิธีที่ง่ายที่สุดคือหาค่าเฉลี่ย ซึ่งอยู่ตรงกลางพอดี

<Example n={4}>
หาจำนวนตรรกยะที่อยู่ระหว่าง $\tfrac{1}{3}$ กับ $\tfrac{1}{2}$ มาหนึ่งจำนวน

<Steps reveal>
1. บวกกัน $\tfrac{1}{3} + \tfrac{1}{2} = \tfrac{2}{6} + \tfrac{3}{6} = \tfrac{5}{6}$
2. หารด้วย $2$ ได้ค่าเฉลี่ย $\tfrac{5}{6} \div 2 = \tfrac{5}{12}$
3. ตรวจด้วยทศนิยม $\tfrac{1}{3} = 0.333\ldots$ $\tfrac{5}{12} = 0.4166\ldots$ $\tfrac{1}{2} = 0.5$ จึงได้ $\tfrac{1}{3} < \tfrac{5}{12} < \tfrac{1}{2}$ จริง
</Steps>
</Example>

{/* check: (Rational(1, 3) + Rational(1, 2)) / 2 == Rational(5, 12) and Rational(1, 3) < Rational(5, 12) < Rational(1, 2) */}

หาค่าเฉลี่ยของ $\tfrac{1}{3}$ กับ $\tfrac{5}{12}$ ต่อได้อีก แล้วทำซ้ำไปเรื่อยๆ ไม่มีวันหมด ระหว่างสองจำนวนตรรกยะจึงมีจำนวนตรรกยะอยู่นับไม่ถ้วน จนดูเหมือนจุดของจำนวนตรรกยะจะเต็มเส้นจำนวน แต่หน้าถัดไปจะเห็นว่ายังมีช่องว่างอยู่

## สรุป

- จำนวนตรรกยะคือจำนวนที่เขียนในรูป $\tfrac{a}{b}$ ได้ เมื่อ $a$ และ $b$ เป็นจำนวนเต็ม และ $b \neq 0$
- จำนวนเต็ม เศษส่วน ทศนิยมรู้จบ และทศนิยมซ้ำ เป็นจำนวนตรรกยะทั้งหมด
- จำนวนตรรกยะเขียนเป็นทศนิยมได้แค่สองแบบ คือรู้จบหรือซ้ำ
- ทศนิยมที่มีแบบรูปแต่ไม่มีชุดเดิมซ้ำ ไม่ใช่ทศนิยมซ้ำ
- ระหว่างจำนวนตรรกยะสองจำนวน หาจำนวนตรรกยะอื่นได้เสมอ เช่น ค่าเฉลี่ยของสองจำนวนนั้น
