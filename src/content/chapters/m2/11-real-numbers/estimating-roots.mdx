จะตัดกระดาษสีเป็นรูปสี่เหลี่ยมจัตุรัสพื้นที่ $50$ ตารางเซนติเมตร ไปติดบอร์ดหน้าห้อง ด้านต้องยาว $\sqrt{50}$ เซนติเมตร แต่ $50$ ไม่ใช่จำนวนกำลังสองสมบูรณ์ $\sqrt{50}$ จึงเป็นจำนวนอตรรกยะ เขียนเป็นทศนิยมให้ครบไม่ได้

ไม้บรรทัดวัดได้ละเอียดแค่มิลลิเมตร คือทศนิยมหนึ่งตำแหน่งของเซนติเมตร เราจึงไม่ต้องการค่าที่แม่นทุกตำแหน่ง ต้องการแค่ค่าประมาณที่ดีพอ หน้านี้ประมาณค่ารากที่สองด้วยการบีบช่วงให้แคบลงทีละขั้น

## อยู่ระหว่างจำนวนเต็มใด

จำนวนบวกที่มากกว่า ยกกำลังสองแล้วได้ค่ามากกว่า และกลับกันก็จริง จึงเทียบรากที่สองได้จากการเทียบจำนวนข้างใน

<Thm>

ถ้า $a$ $b$ และ $c$ เป็นจำนวนบวก และ $a^2 < b < c^2$ แล้ว $a < \sqrt{b} < c$

</Thm>

วิธีหาว่า $\sqrt{b}$ อยู่ระหว่างจำนวนเต็มใด คือหาจำนวนกำลังสองสมบูรณ์สองตัวที่อยู่ติดกัน ตัวหนึ่งน้อยกว่า $b$ อีกตัวมากกว่า $b$

<Example n={1}>
$\sqrt{50}$ และ $\sqrt{90}$ อยู่ระหว่างจำนวนเต็มสองจำนวนใดที่อยู่ติดกัน และใกล้จำนวนไหนมากกว่า

<Steps reveal>
1. $7^2 = 49$ และ $8^2 = 64$ ได้ $49 < 50 < 64$ จึงได้ $7 < \sqrt{50} < 8$
2. ตรงกลางระหว่าง $7$ กับ $8$ คือ $7.5$ และ $7.5^2 = 56.25$ มากกว่า $50$ จึงได้ $\sqrt{50} < 7.5$ ใกล้ $7$ มากกว่า
3. $9^2 = 81$ และ $10^2 = 100$ ได้ $81 < 90 < 100$ จึงได้ $9 < \sqrt{90} < 10$
4. $9.5^2 = 90.25$ มากกว่า $90$ อยู่นิดเดียว จึงได้ $\sqrt{90} < 9.5$ ใกล้ $9$ มากกว่า แต่เกือบอยู่ตรงกลาง
</Steps>
</Example>

{/* check: 7 < sqrt(50) < 8 and Rational('7.5')**2 == Rational('56.25') and 9 < sqrt(90) < 10 and Rational('9.5')**2 == Rational('90.25') and sqrt(90) < Rational('9.5') */}

<Think>

$-\sqrt{20}$ อยู่ระหว่างจำนวนเต็มใด เพื่อนตอบว่า $-4 < -\sqrt{20} < -5$ ถูกไหม

<Reveal>
ตัวเลขถูก แต่ลำดับผิด $16 < 20 < 25$ จึงได้ $4 < \sqrt{20} < 5$ พอใส่เครื่องหมายลบ ลำดับต้องกลับข้าง เพราะบนเส้นจำนวน $-5$ อยู่ทางซ้ายของ $-4$ คำตอบที่ถูกคือ $-5 < -\sqrt{20} < -4$ ซึ่ง $-\sqrt{20} \approx -4.47$ อยู่ระหว่าง $-5$ กับ $-4$ จริง
</Reveal>
</Think>

{/* check: 4 < sqrt(20) < 5 and -5 < -sqrt(20) < -4 */}

## ประมาณเป็นทศนิยม

รู้แล้วว่า $1 < \sqrt{2} < 2$ เพราะ $1^2 = 1$ และ $2^2 = 4$ จะให้แม่นขึ้น แบ่งช่วง $1$ ถึง $2$ เป็นสิบช่อง ทีละ $0.1$ แล้วยกกำลังสองไล่ไป

| $s$ | $1.1$ | $1.2$ | $1.3$ | $1.4$ | $1.5$ |
|---|---|---|---|---|---|
| $s^2$ | $1.21$ | $1.44$ | $1.69$ | $1.96$ | $2.25$ |

{/* check: [Rational(v)**2 for v in ['1.1', '1.2', '1.3', '1.4', '1.5']] == [Rational('1.21'), Rational('1.44'), Rational('1.69'), Rational('1.96'), Rational('2.25')] */}

$1.96 < 2 < 2.25$ จึงได้ $1.4 < \sqrt{2} < 1.5$ ทำซ้ำกับช่วง $1.4$ ถึง $1.5$ ทีละ $0.01$ จะเจอว่า $1.41^2 = 1.9881$ และ $1.42^2 = 2.0164$ จึงได้ $1.41 < \sqrt{2} < 1.42$ ทุกครั้งที่ทำ ช่วงแคบลงสิบเท่า

{/* check: Rational('1.41')**2 == Rational('1.9881') and Rational('1.42')**2 == Rational('2.0164') */}

<Board name="c11-root-zoom" label="เส้นจำนวนสามเส้นซ้อนกัน เส้นบนเป็นจำนวนเต็ม เส้นกลางขยายช่วงที่มีรากที่สองของ n ให้เห็นทีละ 0.1 เส้นล่างขยายต่อให้เห็นทีละ 0.01">
เลื่อนแถบขยายทีละขั้น แล้วดูว่า $\sqrt{2}$ อยู่ในช่องไหน ลองเปลี่ยน $n$ เป็น $50$ หรือ $90$ แล้วเทียบกับตัวอย่าง 1
</Board>

### ปัดเป็นทศนิยมหนึ่งตำแหน่ง

รู้ว่าอยู่ในช่วง $1.4$ ถึง $1.5$ ยังตอบไม่ได้ว่าปัดแล้วได้ $1.4$ หรือ $1.5$ ต้องดูว่าอยู่ซีกไหนของ $1.45$ ซึ่ง $1.45^2 = 2.1025$ มากกว่า $2$ จึงได้ $\sqrt{2} < 1.45$ ปัดได้ $1.4$

{/* check: Rational('1.45')**2 == Rational('2.1025') and sqrt(2) < Rational('1.45') */}

<Example n={2}>
กลับไปที่กระดาษสีพื้นที่ $50$ ตารางเซนติเมตร ด้านยาวประมาณกี่เซนติเมตร ตอบเป็นทศนิยมหนึ่งตำแหน่ง

<Steps reveal>
1. จากตัวอย่าง 1 ได้ $7 < \sqrt{50} < 7.5$ จึงลองตั้งแต่ $7.1$ ได้ $7.1^2 = 50.41$ เกิน $50$ แล้ว
2. จึงได้ $7.0 < \sqrt{50} < 7.1$ ยังต้องดูว่าอยู่ซีกไหนของ $7.05$
3. $7.05^2 = 49.7025$ น้อยกว่า $50$ จึงได้ $7.05 < \sqrt{50} < 7.1$
4. ปัดเป็นทศนิยมหนึ่งตำแหน่งได้ $7.1$ ตัดกระดาษด้านละประมาณ $7.1$ เซนติเมตร
</Steps>
</Example>

{/* check: Rational('7.1')**2 == Rational('50.41') and Rational('7.05')**2 == Rational('49.7025') and Rational('7.05') < sqrt(50) < Rational('7.1') */}

ข้อนี้พลาดกันบ่อย เห็นว่า $50$ ห่างจาก $49$ แค่ $1$ เลยคิดว่า $\sqrt{50}$ ต้องใกล้ $7$ มากจนปัดได้ $7.0$ แต่ที่จริง $\sqrt{50} \approx 7.07$ ปัดได้ $7.1$ ต้องยกกำลังสองจุดกึ่งกลาง $7.05$ ดูก่อนปัดเสมอ

<Note kind="tip" title="เครื่องคิดเลขก็ให้ค่าประมาณ">
กดปุ่ม $\sqrt{\phantom{a}}$ บนเครื่องคิดเลขได้ $\sqrt{50} \approx 7.0710678$ ก็ยังเป็นค่าประมาณ เพราะหน้าจอมีที่จำกัด ส่วน $\sqrt{50}$ จริงเป็นทศนิยมไม่รู้จบ การประมาณด้วยมือช่วยให้รู้ว่าค่าที่กดได้สมเหตุสมผลไหม เช่น ถ้ากดผิดได้ $25$ จะรู้ทันทีว่าผิด เพราะต้องอยู่ระหว่าง $7$ กับ $8$
</Note>

{/* check: abs(sqrt(50) - 7.0710678) < 1e-7 */}

## ตำแหน่งของ √2 บนเส้นจำนวน

ทศนิยมประมาณได้ใกล้แค่ไหนก็ยังไม่ใช่ $\sqrt{2}$ พอดี แต่บนเส้นจำนวนเราหาจุด $\sqrt{2}$ ได้ตรงเป๊ะด้วยวงเวียน โดยใช้ทฤษฎีบทพีทาโกรัสจากบทที่ 10

สร้างรูปสี่เหลี่ยมจัตุรัสด้านยาว $1$ หน่วยบนเส้นจำนวน ให้ด้านล่างอยู่ระหว่าง $0$ กับ $1$ เส้นทแยงมุมเป็นด้านตรงข้ามมุมฉากของรูปสามเหลี่ยมมุมฉากที่มีด้านประกอบมุมฉากยาว $1$ ทั้งสองด้าน จึงยาว $\sqrt{1^2 + 1^2} = \sqrt{2}$ หน่วย กางวงเวียนยาวเท่าเส้นทแยงมุม ใช้ $0$ เป็นจุดศูนย์กลาง เขียนส่วนโค้งลงมาตัดเส้นจำนวน จุดตัดอยู่ห่าง $0$ เป็นระยะ $\sqrt{2}$ พอดี

{/* check: 1**2 + 1**2 == 2 */}

จุดที่ได้อยู่ระหว่าง $1.41$ กับ $1.42$ ตรงกับที่ประมาณไว้ ถ้าเขียนส่วนโค้งไปทางซ้ายแทน จะได้จุด $-\sqrt{2}$

<Example n={3}>
หาตำแหน่งของ $\sqrt{5}$ บนเส้นจำนวนด้วยวงเวียน

<Steps reveal>
1. หาสองจำนวนที่ยกกำลังสองแล้วบวกกันได้ $5$ ได้ $2^2 + 1^2 = 4 + 1 = 5$
2. ที่จุด $2$ บนเส้นจำนวน สร้างเส้นตั้งฉากยาว $1$ หน่วย
3. ลากเส้นจาก $0$ ไปที่ปลายเส้นตั้งฉาก ได้รูปสามเหลี่ยมมุมฉากที่มีด้านประกอบมุมฉากยาว $2$ และ $1$ ด้านตรงข้ามมุมฉากยาว $\sqrt{5}$
4. กางวงเวียนยาวเท่าด้านตรงข้ามมุมฉาก ใช้ $0$ เป็นจุดศูนย์กลาง เขียนส่วนโค้งตัดเส้นจำนวนทางขวา จุดตัดคือ $\sqrt{5}$ ซึ่งอยู่ระหว่าง $2$ กับ $3$
</Steps>
</Example>

{/* check: 2**2 + 1**2 == 5 and 2 < sqrt(5) < 3 */}

<Think>

<Reveal>
ใช้ $\sqrt{2}$ ที่สร้างไว้แล้วเป็นด้านหนึ่ง เพราะ $(\sqrt{2})^2 + 1^2 = 2 + 1 = 3$ ที่จุด $\sqrt{2}$ บนเส้นจำนวน สร้างเส้นตั้งฉากยาว $1$ หน่วย ลากจาก $0$ ไปที่ปลายเส้นตั้งฉาก ได้ด้านตรงข้ามมุมฉากยาว $\sqrt{3}$ แล้วเขียนส่วนโค้งลงมาเหมือนเดิม ทำต่อไปเรื่อยๆ จะได้ $\sqrt{4}$ $\sqrt{5}$ $\sqrt{6}$ ทีละตัว
</Reveal>
</Think>

{/* check: sqrt(2)**2 + 1**2 == 3 */}

## สรุป

- ถ้า $a^2 < b < c^2$ เมื่อ $a$ $b$ $c$ เป็นบวก แล้ว $a < \sqrt{b} < c$ ใช้จำนวนกำลังสองสมบูรณ์ที่อยู่ติดกันบอกว่า $\sqrt{b}$ อยู่ระหว่างจำนวนเต็มใด
- ประมาณให้แม่นขึ้นด้วยการแบ่งช่วงเป็นสิบช่องแล้วยกกำลังสองไล่ไป ช่วงแคบลงสิบเท่าทุกครั้ง
- ก่อนปัดเป็นทศนิยมหนึ่งตำแหน่ง ต้องยกกำลังสองจุดกึ่งกลาง เช่น $7.05$ ดูว่าอยู่ซีกไหน
- ใส่เครื่องหมายลบแล้วลำดับกลับข้าง $-5 < -\sqrt{20} < -4$
- หาตำแหน่ง $\sqrt{2}$ บนเส้นจำนวนได้ด้วยเส้นทแยงมุมของสี่เหลี่ยมจัตุรัสด้าน $1$ หน่วยกับวงเวียน
