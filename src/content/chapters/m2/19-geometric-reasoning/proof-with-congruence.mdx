ต้นทำว่าวจากไม้ไผ่ ผูกเชือกรอบโครงเป็นรูปสี่เหลี่ยม $ABCD$ โดยให้เชือกสองเส้นบนยาวเท่ากัน คือ $AB = AD$ และเชือกสองเส้นล่างยาวเท่ากัน คือ $CB = CD$ พอยกขึ้นดู มุมที่ปีกซ้าย $B$ กับปีกขวา $D$ กางเท่ากันพอดี ว่าวจึงไม่เอียง

ต้นไม่ได้วัดมุมเลย ทำไมมุมสองมุมนี้ต้องเท่ากัน คำตอบอยู่ในรูปสามเหลี่ยมสองรูปที่ซ่อนอยู่ในว่าว

## แผนการพิสูจน์

โจทย์ที่ให้พิสูจน์ว่าด้านสองด้านยาวเท่ากัน หรือมุมสองมุมเท่ากัน ส่วนมากทำด้วยแผนเดียวกัน

1. หารูปสามเหลี่ยมสองรูป ที่รูปหนึ่งมีส่วนแรก อีกรูปมีส่วนที่สองที่ต้องการให้เท่ากัน ถ้ายังไม่มี ให้ลากเส้นเพิ่มเพื่อสร้างรูปสามเหลี่ยม
2. หาส่วนที่เท่ากันให้ได้สามคู่ จากที่กำหนดให้ ด้านร่วม มุมตรงข้าม หรือมุมแย้งของเส้นขนาน
3. ดูว่าสามคู่นั้นเข้ากับแบบไหน ด.ม.ด. ม.ด.ม. หรือ ด.ด.ด. แล้วสรุปว่ารูปสามเหลี่ยมทั้งสองเท่ากันทุกประการ
4. สรุปส่วนที่ต้องการ ด้วยเหตุผลว่าเป็นด้านหรือมุมคู่ที่สมนัยกันของรูปสามเหลี่ยมที่เท่ากันทุกประการ

<Example n={1}>

**กำหนดให้** รูปสี่เหลี่ยม $ABCD$ มี $AB = AD$ และ $CB = CD$

**ต้องการพิสูจน์ว่า** $A\hat{B}C = A\hat{D}C$

<Steps reveal>
1. มุม $A\hat{B}C$ กับ $A\hat{D}C$ ยังไม่อยู่ในรูปสามเหลี่ยมใด ลากเส้นทแยงมุม $AC$ จะได้ $\triangle ABC$ ที่มีมุม $B$ และ $\triangle ADC$ ที่มีมุม $D$
2. หาส่วนที่เท่ากัน ได้ด้านสองคู่จากที่กำหนดให้ และ $AC$ เป็นด้านของทั้งสองรูป ครบสามด้าน ใช้ ด.ด.ด. ได้
3. สรุปว่ารูปสามเหลี่ยมทั้งสองเท่ากันทุกประการ แล้วอ้างมุมคู่ที่สมนัยกัน
</Steps>

<Reveal summary="ดูการพิสูจน์แบบตาราง">

| ข้อความ | เหตุผล |
|---|---|
| (1) $AB = AD$ | กำหนดให้ |
| (2) $CB = CD$ | กำหนดให้ |
| (3) $AC = AC$ | เป็นด้านร่วม |
| (4) $\triangle ABC \cong \triangle ADC$ | ด.ด.ด. จาก (1) (2) (3) |
| (5) $A\hat{B}C = A\hat{D}C$ | มุมคู่ที่สมนัยกันของรูปสามเหลี่ยมที่เท่ากันทุกประการมีขนาดเท่ากัน |

</Reveal>
</Example>

ตารางนี้ได้มากกว่าที่ถามด้วย จากบรรทัด (4) ได้ $B\hat{A}C = D\hat{A}C$ คือไม้ตั้ง $AC$ แบ่งครึ่งมุมที่หัวว่าวพอดี ทั้งที่ไม่ได้กำหนดไว้เลย

<Note kind="warning" title="เรียงชื่อจุดให้ตรงกัน">
การเขียน $\triangle ABC \cong \triangle ADC$ บอกว่า $A$ คู่กับ $A$ $B$ คู่กับ $D$ และ $C$ คู่กับ $C$ ตามลำดับตัวอักษร ถ้าเขียนเป็น $\triangle ABC \cong \triangle ACD$ จะแปลว่า $B$ คู่กับ $C$ ซึ่งผิด เขียนชื่อจุดทีละคู่ให้ตรงกับส่วนที่เท่ากันเสมอ แล้วการอ่านด้านหรือมุมคู่ที่สมนัยกันในบรรทัดสุดท้ายจะไม่พลาด
</Note>

<Example n={2}>

ว่าวของต้นมีความยาว $AB = 30$ เซนติเมตร $CB = 45$ เซนติเมตร มุมที่ปีก $A\hat{B}C = 100^\circ$ และมุมที่หัวว่าว $B\hat{A}D = 70^\circ$ หาความยาวเชือกทั้งหมดที่ใช้ผูกรอบว่าว และขนาดของมุมที่หางว่าว $B\hat{C}D$

<Steps reveal>
1. จากที่กำหนดให้ $AD = AB = 30$ และ $CD = CB = 45$ เชือกรอบว่าวยาว $30 + 45 + 45 + 30 = 150$ เซนติเมตร
2. จากตัวอย่าง 1 ได้ $A\hat{D}C = A\hat{B}C = 100^\circ$
3. มุมภายในของรูปสี่เหลี่ยมรวมกันได้ $360^\circ$ จึงได้ $B\hat{C}D = 360^\circ - 70^\circ - 100^\circ - 100^\circ = 90^\circ$
</Steps>
</Example>

{/* check: 360 - 70 - 100 - 100 == 90 */}

<Example n={3}>

**กำหนดให้** $\overline{AB}$ กับ $\overline{CD}$ ตัดกันที่ $O$ โดย $AO = OB$ และ $CO = OD$

**ต้องการพิสูจน์ว่า** $AC = BD$ และ $\overleftrightarrow{AC} \parallel \overleftrightarrow{DB}$

<Steps reveal>
1. $AC$ อยู่ใน $\triangle AOC$ และ $BD$ อยู่ใน $\triangle BOD$ ที่กำหนดให้มีด้านสองคู่ ส่วนมุมที่ $O$ ของทั้งสองรูปเป็นมุมตรงข้ามกัน มุมนี้อยู่ระหว่างด้านสองคู่นั้นพอดี จึงใช้ ด.ม.ด. ได้
2. ได้รูปสามเหลี่ยมเท่ากันทุกประการแล้ว $AC$ กับ $BD$ เป็นด้านคู่ที่สมนัยกัน จึงยาวเท่ากัน
3. ส่วนเรื่องขนาน ต้องหามุมแย้งที่เท่ากัน $O\hat{A}C$ กับ $O\hat{B}D$ เป็นมุมแย้งเมื่อมี $\overleftrightarrow{AB}$ เป็นเส้นตัด และเป็นมุมคู่ที่สมนัยกันด้วย
</Steps>

<Reveal summary="ดูการพิสูจน์แบบตาราง">

| ข้อความ | เหตุผล |
|---|---|
| (1) $AO = BO$ | กำหนดให้ |
| (2) $A\hat{O}C = B\hat{O}D$ | มุมตรงข้าม |
| (3) $CO = DO$ | กำหนดให้ |
| (4) $\triangle AOC \cong \triangle BOD$ | ด.ม.ด. จาก (1) (2) (3) |
| (5) $AC = BD$ | ด้านคู่ที่สมนัยกันของรูปสามเหลี่ยมที่เท่ากันทุกประการยาวเท่ากัน |
| (6) $O\hat{A}C = O\hat{B}D$ | มุมคู่ที่สมนัยกันของรูปสามเหลี่ยมที่เท่ากันทุกประการมีขนาดเท่ากัน |
| (7) $\overleftrightarrow{AC} \parallel \overleftrightarrow{DB}$ | มี $\overleftrightarrow{AB}$ เป็นเส้นตัด และมุมแย้ง $O\hat{A}C$ กับ $O\hat{B}D$ มีขนาดเท่ากัน จาก (6) |

</Reveal>
</Example>

บรรทัด (7) ใช้สมบัติจากบทที่ 18 ว่า ถ้ามุมแย้งมีขนาดเท่ากัน แล้วเส้นตรงสองเส้นขนานกัน ระวังว่าข้อความนี้กลับข้างกับข้อความที่ว่า ถ้าเส้นตรงขนานกัน แล้วมุมแย้งเท่ากัน สองข้อความนี้ต่างกัน และต้องรู้ว่าแต่ละข้อจริงหรือไม่แยกกัน เรื่องนี้คือเรื่องของหน้าถัดไป

## สรุป

- จะพิสูจน์ว่าด้านหรือมุมสองส่วนเท่ากัน ให้หารูปสามเหลี่ยมสองรูปที่มีส่วนนั้น ถ้าไม่มีให้ลากเส้นเพิ่ม
- ส่วนที่เท่ากันได้มาจากที่กำหนดให้ ด้านร่วม มุมตรงข้าม หรือมุมแย้งของเส้นขนาน
- สรุปด้วย ด.ม.ด. ม.ด.ม. หรือ ด.ด.ด. แล้วจึงอ้างด้านหรือมุมคู่ที่สมนัยกัน
- เขียนชื่อจุดของรูปสามเหลี่ยมสองรูปให้คู่กันตามลำดับ
- มุมเท่ากันสามคู่ไม่พอให้รูปสามเหลี่ยมเท่ากันทุกประการ
