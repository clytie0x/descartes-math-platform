ช่างไม้ทำโครงหลังคาทรงจั่ว โดยตัดไม้จันทันสองท่อนให้ยาวเท่ากัน ปลายบนชนกันที่ยอดจั่ว ปลายล่างวางบนคานสองฝั่ง ช่างไม่ต้องวัดมุมที่ไม้จันทันวางบนคานเลย เพราะรู้ว่าสองข้างจะเอียงเท่ากันเอง หน้านี้จะพิสูจน์ว่าทำไม

## ส่วนต่างๆ ของรูปสามเหลี่ยมหน้าจั่ว

<Def>

**รูปสามเหลี่ยมหน้าจั่ว** คือรูปสามเหลี่ยมที่มีด้านยาวเท่ากันอย่างน้อยสองด้าน

- ด้านที่ยาวเท่ากันสองด้าน เรียกว่า **ด้านประกอบมุมยอด**
- มุมที่อยู่ระหว่างด้านประกอบมุมยอด เรียกว่า **มุมยอด**
- ด้านที่สาม เรียกว่า **ฐาน** และมุมสองมุมที่อยู่ปลายฐาน เรียกว่า **มุมที่ฐาน**

</Def>

ลองลากจุด $A$ ในรูปข้างล่าง ฐาน $BC$ อยู่กับที่ เส้นประสีเขียวคือเส้นที่ตั้งฉากกับ $BC$ และผ่านจุดกึ่งกลางของ $BC$ ดูว่ามุมที่ฐานสองมุมเท่ากันเมื่อไร

<Board name="c19-isosceles" label="รูปสามเหลี่ยม ABC ฐาน BC อยู่กับที่ ลากจุดยอด A ได้ แสดงความยาว AB AC และขนาดของมุม B กับมุม C">
ลาก $A$ ไปไว้บนเส้นประหลายตำแหน่ง แล้วลองลากออกนอกเส้นประ
</Board>

จะเห็นว่ามุมที่ฐานเท่ากันทุกครั้งที่ $AB = AC$ แต่นี่คือการลองดู ยังไม่ใช่การพิสูจน์ ต่อไปจะพิสูจน์

## มุมที่ฐานเท่ากัน

<Thm label="ทฤษฎีบท">
ถ้ารูปสามเหลี่ยมเป็นรูปสามเหลี่ยมหน้าจั่ว แล้วมุมที่ฐานมีขนาดเท่ากัน
</Thm>

<figcaption>เส้นสีเขียว $AD$ แบ่งมุมยอดเป็นสองส่วนเท่ากัน มุมสีม่วงคือมุมที่ฐานที่ต้องพิสูจน์</figcaption>
</figure>

**กำหนดให้** $\triangle ABC$ มี $AB = AC$

**ต้องการพิสูจน์ว่า** $A\hat{B}C = A\hat{C}B$

มุม $B$ กับมุม $C$ อยู่ในรูปสามเหลี่ยมรูปเดียวกัน ยังจับคู่เป็นรูปสามเหลี่ยมสองรูปไม่ได้ จึงต้องลากเส้นเพิ่ม ลาก $\overline{AD}$ แบ่งครึ่ง $B\hat{A}C$ ตัด $\overline{BC}$ ที่ $D$ (ทุกมุมแบ่งครึ่งได้ด้วยการสร้างที่เรียนตอน ม.1) จะได้ $\triangle ABD$ ที่มีมุม $B$ และ $\triangle ACD$ ที่มีมุม $C$

**พิสูจน์**

| ข้อความ | เหตุผล |
|---|---|
| (1) $AB = AC$ | กำหนดให้ |
| (2) $B\hat{A}D = C\hat{A}D$ | $\overline{AD}$ แบ่งครึ่ง $B\hat{A}C$ |
| (3) $AD = AD$ | เป็นด้านร่วม |
| (4) $\triangle ABD \cong \triangle ACD$ | ด.ม.ด. จาก (1) (2) (3) |
| (5) $A\hat{B}D = A\hat{C}D$ | มุมคู่ที่สมนัยกันของรูปสามเหลี่ยมที่เท่ากันทุกประการมีขนาดเท่ากัน |

$A\hat{B}D$ คือมุมเดียวกับ $A\hat{B}C$ และ $A\hat{C}D$ คือมุมเดียวกับ $A\hat{C}B$ เพราะ $D$ อยู่บน $\overline{BC}$ จึงได้สิ่งที่ต้องพิสูจน์

## ได้อะไรเพิ่มจากการพิสูจน์เดียวกัน

บรรทัด (4) บอกว่ารูปสามเหลี่ยมสองรูปเท่ากันทุกประการ จึงอ่านส่วนที่สมนัยกันได้อีก

| ข้อความ | เหตุผล |
|---|---|
| (6) $BD = CD$ | ด้านคู่ที่สมนัยกันของรูปสามเหลี่ยมที่เท่ากันทุกประการ |
| (7) $A\hat{D}B = A\hat{D}C$ | มุมคู่ที่สมนัยกันของรูปสามเหลี่ยมที่เท่ากันทุกประการ |
| (8) $A\hat{D}B + A\hat{D}C = 180^\circ$ | $B$ $D$ $C$ อยู่บนเส้นตรงเดียวกัน |
| (9) $A\hat{D}B = A\hat{D}C = 90^\circ$ | จาก (7) และ (8) มุมสองมุมที่เท่ากันและรวมกันได้ $180^\circ$ ต้องเป็นมุมละ $90^\circ$ |

<Thm>
เส้นแบ่งครึ่งมุมยอดของรูปสามเหลี่ยมหน้าจั่ว แบ่งฐานออกเป็นสองส่วนยาวเท่ากัน และตั้งฉากกับฐาน
</Thm>

ช่างไม้ใช้สมบัตินี้ทุกวัน เสาที่ตั้งจากยอดจั่วลงมาตั้งฉากกับคาน จะลงตรงกึ่งกลางคานพอดี

<Example n={1}>

หลังคาทรงจั่วหลังหนึ่งมีมุมยอดจั่ว $120^\circ$ ไม้จันทันสองข้างยาวเท่ากัน ไม้จันทันแต่ละข้างทำมุมกับคานกี่องศา

<Steps reveal>
1. ไม้จันทันสองข้างกับคานเป็นรูปสามเหลี่ยมหน้าจั่ว มุมที่ไม้จันทันทำกับคานคือมุมที่ฐาน
2. มุมที่ฐานเท่ากัน ให้แต่ละมุมเป็น $x$ องศา ได้ $120 + x + x = 180$
3. $2x = 60$ จึงได้ $x = 30$ ไม้จันทันแต่ละข้างทำมุม $30^\circ$ กับคาน
</Steps>
</Example>

{/* check: solve(Eq(120 + 2*x, 180), x) == [30] */}

<Example n={2}>

รูปสามเหลี่ยมหน้าจั่วรูปหนึ่งมีมุมที่ฐานมุมหนึ่งเท่ากับ $52^\circ$ มุมยอดมีขนาดเท่าใด

<Steps reveal>
1. มุมที่ฐานอีกมุมหนึ่งก็เท่ากับ $52^\circ$
2. มุมยอดเท่ากับ $180^\circ - 52^\circ - 52^\circ = 76^\circ$
</Steps>
</Example>

{/* check: 180 - 52 - 52 == 76 */}

<Think>

ก้อยเริ่มพิสูจน์ทฤษฎีบทมุมที่ฐานแบบนี้ "ลาก $\overline{AD}$ ให้ตั้งฉากกับ $\overline{BC}$ และแบ่งครึ่ง $\overline{BC}$ ที่ $D$" แล้วใช้ ด.ม.ด. กับ $BD = CD$ $A\hat{D}B = A\hat{D}C$ และ $AD = AD$ การพิสูจน์ของก้อยมีปัญหาตรงไหน

<Reveal>
ก้อยสั่งให้เส้นเส้นเดียวทำสองอย่างพร้อมกัน คือตั้งฉากกับ $BC$ และผ่านจุดกึ่งกลางของ $BC$ ด้วย แต่เส้นจาก $A$ ที่ตั้งฉากกับ $BC$ มีได้เส้นเดียว จะผ่านจุดกึ่งกลางหรือไม่ยังไม่รู้ ต้องพิสูจน์ก่อน และนั่นก็คือสิ่งที่ได้ตอนท้ายของการพิสูจน์ข้างบน ก้อยจึงแอบใช้ข้อสรุปเป็นสิ่งที่กำหนดให้ เวลาลากเส้นเพิ่ม ให้ลากโดยกำหนดเงื่อนไขเพียงข้อเดียว เช่น แบ่งครึ่งมุม หรือลากไปจุดกึ่งกลางของฐาน แล้วพิสูจน์ส่วนที่เหลือ
</Reveal>
</Think>

## บทกลับ มุมเท่ากันแล้วด้านเท่ากัน

บทกลับของทฤษฎีบทมุมที่ฐานคือ "ถ้ารูปสามเหลี่ยมมีมุมสองมุมขนาดเท่ากัน แล้วด้านที่อยู่ตรงข้ามมุมทั้งสองยาวเท่ากัน" ในกราฟข้างบน ถ้าลาก $A$ จนมุม $B$ เท่ากับมุม $C$ จะเห็นว่า $AB = AC$ ทุกครั้ง หน้า 19.3 เตือนไว้ว่าบทกลับต้องพิสูจน์แยก จึงพิสูจน์ต่อ

<figcaption>คราวนี้รู้แค่ว่ามุมสีม่วงสองมุมเท่ากัน ยังไม่รู้ว่า $AB$ กับ $AC$ ยาวเท่ากันหรือไม่</figcaption>
</figure>

**กำหนดให้** $\triangle ABC$ มี $A\hat{B}C = A\hat{C}B$

**ต้องการพิสูจน์ว่า** $AB = AC$

ลาก $\overline{AD}$ แบ่งครึ่ง $B\hat{A}C$ ตัด $\overline{BC}$ ที่ $D$ เหมือนเดิม คราวนี้รู้มุมสองคู่แต่ด้านคู่เดียว คือ $AD$ ซึ่งไม่ได้อยู่ระหว่างมุมที่รู้ ต้องหามุมคู่ที่สามก่อน แล้วจึงใช้ ม.ด.ม. ได้

**พิสูจน์**

| ข้อความ | เหตุผล |
|---|---|
| (1) $B\hat{A}D = C\hat{A}D$ | $\overline{AD}$ แบ่งครึ่ง $B\hat{A}C$ |
| (2) $A\hat{B}D = A\hat{C}D$ | กำหนดให้ |
| (3) $A\hat{D}B = A\hat{D}C$ | มุมภายในของรูปสามเหลี่ยมรวมกันได้ $180^\circ$ จึงได้ $A\hat{D}B = 180^\circ - B\hat{A}D - A\hat{B}D$ และ $A\hat{D}C = 180^\circ - C\hat{A}D - A\hat{C}D$ ซึ่งเท่ากันจาก (1) และ (2) |
| (4) $AD = AD$ | เป็นด้านร่วม |
| (5) $\triangle ABD \cong \triangle ACD$ | ม.ด.ม. จาก (1) (4) (3) |
| (6) $AB = AC$ | ด้านคู่ที่สมนัยกันของรูปสามเหลี่ยมที่เท่ากันทุกประการยาวเท่ากัน |

ข้อความกับบทกลับจริงทั้งคู่ จึงเขียนรวมได้ว่า ด้านสองด้านของรูปสามเหลี่ยมยาวเท่ากัน ก็ต่อเมื่อ มุมที่อยู่ตรงข้ามด้านทั้งสองมีขนาดเท่ากัน

<Example n={3}>

แสดงว่ามุมทุกมุมของรูปสามเหลี่ยมด้านเท่ามีขนาด $60^\circ$

<Steps reveal>
1. ให้ $\triangle ABC$ มี $AB = BC = CA$
2. $AB = AC$ จึงได้มุมที่อยู่ตรงข้าม $A\hat{C}B = A\hat{B}C$ ตามทฤษฎีบทมุมที่ฐาน
3. $BA = BC$ จึงได้ $B\hat{C}A = B\hat{A}C$ ด้วยเหตุผลเดียวกัน
4. มุมทั้งสามจึงเท่ากันหมด และรวมกันได้ $180^\circ$ แต่ละมุมจึงเท่ากับ $180^\circ \div 3 = 60^\circ$
</Steps>
</Example>

{/* check: Rational(180, 3) == 60 */}

## สรุป

- รูปสามเหลี่ยมหน้าจั่วมีมุมที่ฐานเท่ากัน พิสูจน์ด้วยการลากเส้นแบ่งครึ่งมุมยอดแล้วใช้ ด.ม.ด.
- เส้นแบ่งครึ่งมุมยอดแบ่งครึ่งฐานและตั้งฉากกับฐาน
- บทกลับก็จริง ถ้ามุมสองมุมเท่ากัน ด้านที่อยู่ตรงข้ามมุมทั้งสองยาวเท่ากัน พิสูจน์ด้วย ม.ด.ม.
- เวลาลากเส้นเพิ่ม กำหนดเงื่อนไขให้เส้นนั้นได้ทีละหนึ่งข้อ
