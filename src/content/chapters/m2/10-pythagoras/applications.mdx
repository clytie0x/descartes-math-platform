โจทย์ในหน้า 10.2 บอกมาเลยว่าเป็นรูปสามเหลี่ยมมุมฉาก และด้านไหนยาวเท่าไร โจทย์จริงไม่บอกแบบนั้น มีแต่บันได ผนัง สนาม หรือจอโทรศัพท์ งานส่วนใหญ่จึงอยู่ที่การมองให้เห็นว่ารูปสามเหลี่ยมมุมฉากซ่อนอยู่ตรงไหน คำนวณเป็นขั้นสุดท้าย

<Thm label="ขั้นตอนทำโจทย์">

1. วาดรูปคร่าวๆ ใส่ความยาวที่รู้ และใส่ตัวแปรแทนความยาวที่ถาม
2. หามุมฉาก มักมาจากผนังตั้งฉากกับพื้น มุมของรูปสี่เหลี่ยมผืนผ้า หรือทิศที่ตั้งฉากกัน
3. บอกว่าด้านไหนเป็นด้านตรงข้ามมุมฉาก แล้วเลือกบวกหรือลบ
4. คำนวณ ตอบพร้อมหน่วย และตรวจว่าด้านตรงข้ามมุมฉากยาวที่สุด

</Thm>

<Example n={1}>

ช่างทาสีพาดบันไดยาว $6.5$ เมตรกับผนังตึก เท้าบันไดห่างจากผนัง $2.5$ เมตร ยอดบันไดแตะผนังที่ความสูงกี่เมตร

<Steps reveal>
1. ผนังตั้งฉากกับพื้น บันไดอยู่ตรงข้ามมุมฉาก จึงเป็นด้านตรงข้ามมุมฉาก ยาว $6.5$ เมตร
2. ความสูง $h$ ที่ถามเป็นด้านประกอบมุมฉาก จึงต้องลบ $h^2 = 6.5^2 - 2.5^2 = 42.25 - 6.25 = 36$
3. $6^2 = 36$ ยอดบันไดแตะผนังที่ความสูง $6$ เมตร
4. ตรวจ $6.5$ ยาวกว่า $6$ และ $2.5$ ถูกต้อง
</Steps>
</Example>

{/* check: sqrt(Rational('6.5')**2 - Rational('2.5')**2) == 6 */}

<Think>

บันไดยาว $5$ เมตร พาดผนังแล้วยอดบันไดสูง $4$ เมตร เพื่อนคิดว่าเท้าบันไดห่างผนัง $\sqrt{41}$ เมตร เพราะ $5^2 + 4^2 = 41$ เพื่อนคิดถูกไหม

<Reveal>
ไม่ถูก $\sqrt{41}$ มากกว่า $6$ ยาวกว่าตัวบันไดเอง ซึ่งเป็นไปไม่ได้ บันไดเป็นด้านตรงข้ามมุมฉาก ระยะที่หาเป็นด้านประกอบมุมฉาก ต้องลบ $5^2 - 4^2 = 9$ ได้ $3$ เมตร
</Reveal>
</Think>

{/* check: 5**2 + 4**2 > 6**2 and 5**2 - 4**2 == 3**2 */}

## เดินตัดสนาม

<Example n={2}>

สนามหญ้าหน้าโรงเรียนเป็นรูปสี่เหลี่ยมผืนผ้ากว้าง $30$ เมตร ยาว $40$ เมตร นักเรียนเดินจากมุมหนึ่งไปมุมตรงข้าม ถ้าเดินตัดสนามตามแนวเส้นทแยงมุม จะเดินน้อยกว่าเดินตามขอบสนามกี่เมตร

<Steps reveal>
1. มุมของรูปสี่เหลี่ยมผืนผ้าเป็นมุมฉาก เส้นทแยงมุมแบ่งสนามเป็นรูปสามเหลี่ยมมุมฉากที่มีด้านประกอบมุมฉาก $30$ และ $40$ เมตร
2. เส้นทแยงมุมเป็นด้านตรงข้ามมุมฉาก $30, 40$ คือ $3, 4$ คูณ $10$ จึงยาว $50$ เมตร ตรวจ $900 + 1{,}600 = 2{,}500 = 50^2$
3. เดินตามขอบ $30 + 40 = 70$ เมตร
4. เดินตัดสนามน้อยกว่า $70 - 50 = 20$ เมตร
</Steps>
</Example>

{/* check: 30 + 40 - sqrt(30**2 + 40**2) == 20 */}

คำถามนี้ไม่ได้ถามความยาวเส้นทแยงมุม ถ้าตอบ 50 เมตรก็ยังไม่ตรงคำถาม หาด้านได้แล้วให้กลับไปอ่านว่าโจทย์ถามอะไร

## ขนาดจอ

โฆษณาโทรศัพท์ที่บอกว่าจอ 6.7 นิ้ว หมายถึงความยาวเส้นทแยงมุมของจอ ไม่ใช่ความกว้างหรือความสูง

<Example n={3}>

จอโทรศัพท์เครื่องหนึ่งกว้าง $6.5$ เซนติเมตร สูง $15.6$ เซนติเมตร เส้นทแยงมุมยาวกี่เซนติเมตร และประมาณกี่นิ้ว เมื่อ $1$ นิ้วยาว $2.54$ เซนติเมตร

<Steps reveal>
1. มุมของจอเป็นมุมฉาก เส้นทแยงมุมเป็นด้านตรงข้ามมุมฉาก
2. $c^2 = 6.5^2 + 15.6^2 = 42.25 + 243.36 = 285.61$
3. ใช้เครื่องคิดเลขหารากที่สองของ $285.61$ ได้ $16.9$ พอดี ตรวจ $16.9^2 = 285.61$ เส้นทแยงมุมยาว $16.9$ เซนติเมตร
4. แปลงเป็นนิ้ว $16.9 \div 2.54 \approx 6.65$ นิ้ว ปัดเป็นทศนิยมหนึ่งตำแหน่งได้ประมาณ $6.7$ นิ้ว ตรงกับที่โฆษณา
</Steps>
</Example>

{/* check: Rational('6.5')**2 + Rational('15.6')**2 == Rational('16.9')**2 and abs(Rational('16.9')/Rational('2.54') - Rational('6.65')) < Rational('0.005') */}

ตัวเลขชุดนี้ลงตัวเพราะ $6.5, 15.6, 16.9$ คือชุด $5, 12, 13$ คูณ $1.3$ โจทย์ส่วนใหญ่ไม่ลงตัวแบบนี้ ให้หาค่าประมาณแบบตัวอย่างที่ 5 ของหน้า 10.2

จงหาระยะระหว่างจุด $A(-2, 1)$ กับจุด $B(4, 9)$

<Steps reveal>
1. ลากเส้นแนวนอนผ่าน $A$ กับเส้นแนวตั้งผ่าน $B$ มาพบกันที่ $D(4, 1)$ เส้นแนวนอนตั้งฉากกับเส้นแนวตั้ง มุม $D$ จึงเป็นมุมฉาก
2. $AD$ ยาวเท่ากับผลต่างของพิกัด $x$ คือ $4 - (-2) = 6$ หน่วย
3. $DB$ ยาวเท่ากับผลต่างของพิกัด $y$ คือ $9 - 1 = 8$ หน่วย
4. $AB$ เป็นด้านตรงข้ามมุมฉาก $AB^2 = 6^2 + 8^2 = 36 + 64 = 100$ จึงได้ $AB = 10$ หน่วย
</Steps>
</Example>

{/* check: (4 - (-2))**2 + (9 - 1)**2 == 10**2 */}

ระวังขั้นที่ 2 ผลต่างระหว่าง $4$ กับ $-2$ คือ $6$ ไม่ใช่ $2$ นับช่องบนรูปดูก็ได้ ระยะเป็นความยาว จึงเป็นบวกเสมอ

## รูปที่ต้องแบ่งก่อน

บางรูปไม่ได้เป็นรูปสามเหลี่ยมมุมฉากเอง แต่แบ่งออกเป็นรูปสามเหลี่ยมมุมฉากได้

<Example n={5}>

ซุ้มประตูงานกีฬาสีทำเป็นรูปสามเหลี่ยมหน้าจั่ว ฐานกว้าง $10$ เมตร ด้านเอียงทั้งสองข้างยาวข้างละ $13$ เมตร ยอดซุ้มสูงจากพื้นกี่เมตร

<Steps reveal>
1. ลากเส้นจากยอดตั้งฉากลงมาที่ฐาน รูปสามเหลี่ยมหน้าจั่วถูกแบ่งเป็นรูปสามเหลี่ยมมุมฉากสองรูปที่เหมือนกัน และเส้นนี้แบ่งฐานเป็นสองส่วนเท่ากัน ส่วนละ $5$ เมตร
2. ในรูปสามเหลี่ยมมุมฉากหนึ่งรูป ด้านเอียง $13$ เมตรเป็นด้านตรงข้ามมุมฉาก ฐาน $5$ เมตรกับความสูง $h$ เป็นด้านประกอบมุมฉาก
3. $h^2 = 13^2 - 5^2 = 169 - 25 = 144$ ได้ $h = 12$ เมตร
</Steps>
</Example>

{/* check: 13**2 - (Rational(10, 2))**2 == 12**2 */}

จุดที่พลาดบ่อยคือใช้ฐานทั้งหมด $10$ เมตรแทนครึ่งหนึ่ง จะได้ $13^2 - 10^2 = 69$ ซึ่งไม่ใช่ความสูง เพราะด้าน $10$ เมตรไม่ได้อยู่ในรูปสามเหลี่ยมมุมฉากรูปเดียวกับความสูง

{/* check: 13**2 - 10**2 == 69 */}

## สรุป

- วาดรูปก่อนเสมอ หามุมฉากจากผนังกับพื้น มุมของรูปสี่เหลี่ยมผืนผ้า หรือเส้นแนวนอนกับแนวตั้ง
- บอกให้ได้ว่าด้านที่หาเป็นด้านตรงข้ามมุมฉากหรือไม่ แล้วเลือกบวกหรือลบ
- ระยะระหว่างจุดสองจุดบนระนาบพิกัด ใช้ผลต่างของพิกัด $x$ และผลต่างของพิกัด $y$ เป็นด้านประกอบมุมฉาก
- รูปที่ไม่ใช่รูปสามเหลี่ยมมุมฉาก ลองลากเส้นตั้งฉากแบ่งให้ได้รูปสามเหลี่ยมมุมฉากก่อน
- ตอบให้ตรงคำถามพร้อมหน่วย
