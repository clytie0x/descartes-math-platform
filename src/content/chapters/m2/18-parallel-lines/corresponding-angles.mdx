มุมคู่นี้มองหาง่ายถ้ามองหารูปตัว F เส้นตั้งของตัว F คือเส้นตัด ขาสองขาคือเส้นขนาน มุมใต้ขาบนกับมุมใต้ขาล่างคือมุมคู่นี้

## ทำไมจึงเท่ากัน

ให้ $\overleftrightarrow{AB} \parallel \overleftrightarrow{CD}$ และ $\overleftrightarrow{EF}$ เป็นเส้นตัด จะพิสูจน์ว่า $\hat{2} = \hat{6}$

<Steps>
1. $\hat{2} = \hat{3}$ เพราะเป็นมุมตรงข้าม
2. $\hat{3} = \hat{6}$ เพราะเป็นมุมแย้ง และเส้นทั้งสองขนานกัน
3. จึงได้ $\hat{2} = \hat{6}$
</Steps>

ย้อนทางกลับก็ได้ ถ้า $\hat{2} = \hat{6}$ แล้ว $\hat{3} = \hat{2} = \hat{6}$ มุมแย้งเท่ากัน เส้นทั้งสองจึงขนานกัน

<Thm label="ทฤษฎีบท">

1. ถ้าเส้นตรงสองเส้นขนานกันและมีเส้นตัด แล้วมุมภายนอกและมุมภายในที่อยู่ตรงข้ามบนข้างเดียวกันของเส้นตัดมีขนาดเท่ากัน
2. ถ้าเส้นตรงเส้นหนึ่งตัดเส้นตรงคู่หนึ่ง ทำให้มุมภายนอกและมุมภายในที่อยู่ตรงข้ามบนข้างเดียวกันของเส้นตัดมีขนาดเท่ากัน แล้วเส้นตรงคู่นั้นขนานกัน

</Thm>

ข้อ 2 คือเหตุผลของการสร้างเส้นขนานในบทที่ 2 ที่ลากเส้นผ่านจุด $P$ ไปตัดเส้นเดิม แล้วสร้างมุมขนาดเท่ากันที่ $P$ ในตำแหน่งเดียวกัน มุมสองมุมนั้นคือมุมภายนอกและมุมภายในที่อยู่ตรงข้ามบนข้างเดียวกันของเส้นตัด เส้นที่ได้จึงขนานกับเส้นเดิม

## สามวิธีตรวจว่าเส้นขนาน

สามหน้าที่ผ่านมาได้สมบัติสามแบบ ทั้งหมดใช้ได้ทั้งสองทาง คือเส้นขนานกันก็ต่อเมื่อข้อใดข้อหนึ่งเป็นจริง

| สมบัติ | ตัวอย่างคู่มุม |
|---|---|
| มุมภายในที่อยู่บนข้างเดียวกันของเส้นตัดรวมกันได้ $180^\circ$ | $\hat{3} + \hat{5}$ และ $\hat{4} + \hat{6}$ |
| มุมแย้งเท่ากัน | $\hat{3} = \hat{6}$ และ $\hat{4} = \hat{5}$ |
| มุมภายนอกและมุมภายในที่อยู่ตรงข้ามบนข้างเดียวกันของเส้นตัดเท่ากัน | $\hat{1} = \hat{5}$ $\hat{2} = \hat{6}$ $\hat{3} = \hat{7}$ $\hat{4} = \hat{8}$ |

กราฟข้างล่างระบายมุมที่มีขนาดเท่ากันด้วยสีเดียวกัน หมุนเส้นตัดแล้วนับว่าตอนเส้นขนานกัน มุมทั้งแปดมีกี่สี จากนั้นเอียงเส้นล่างแล้วดูว่าสีเปลี่ยนไปอย่างไร

<Board name="c18-transversal" label="เส้นตรงสองเส้นกับเส้นตัดที่หมุนได้ มุมที่มีขนาดเท่ากันได้สีเดียวกัน มีแถบเลื่อนเอียงเส้นล่าง และช่องติ๊กแสดงขนาดมุม">
ลองหมุนเส้นตัดให้ตั้งฉากกับเส้นทั้งสอง มุมทั้งแปดมีกี่สี เพราะอะไร
</Board>

ตอนที่เส้นขนานกัน มุมทั้งแปดมีขนาดอย่างมากสองแบบ คือ $x$ กับ $180^\circ - x$ ถ้าเส้นตัดตั้งฉากกับเส้นขนาน ทั้งสองค่าจะเท่ากับ $90^\circ$ จึงเหลือขนาดเดียว รู้มุมเดียวก็รู้ครบทั้งแปดมุม

<Example n={1}>

กำหนดให้ $\overleftrightarrow{AB} \parallel \overleftrightarrow{CD}$ ถ้า $\hat{7} = 58^\circ$ หาขนาดของมุมที่เหลืออีกเจ็ดมุม

<Steps reveal>
1. $\hat{8} = 180^\circ - 58^\circ = 122^\circ$ เพราะ $\hat{7}$ กับ $\hat{8}$ อยู่ติดกันบนเส้นตรง
2. $\hat{6} = \hat{7} = 58^\circ$ และ $\hat{5} = \hat{8} = 122^\circ$ เพราะเป็นมุมตรงข้าม
3. $\hat{3} = \hat{7} = 58^\circ$ เพราะเป็นมุมภายนอกและมุมภายในที่อยู่ตรงข้ามบนข้างเดียวกันของเส้นตัด ในทำนองเดียวกัน $\hat{4} = \hat{8} = 122^\circ$
4. $\hat{2} = \hat{3} = 58^\circ$ และ $\hat{1} = \hat{4} = 122^\circ$ เพราะเป็นมุมตรงข้าม
5. ได้ $\hat{2} = \hat{3} = \hat{6} = \hat{7} = 58^\circ$ และ $\hat{1} = \hat{4} = \hat{5} = \hat{8} = 122^\circ$
</Steps>
</Example>

{/* check: 180 - 58 == 122 and 4*58 + 4*122 == 720 */}

<Example n={2}>

กำหนดให้ $\overleftrightarrow{AB} \parallel \overleftrightarrow{CD}$ มี $\hat{2} = (3x + 3)^\circ$ และ $\hat{6} = (5x - 37)^\circ$ หาค่า $x$ และขนาดของ $\hat{2}$

<Steps reveal>
1. $\hat{2}$ กับ $\hat{6}$ เป็นมุมภายนอกและมุมภายในที่อยู่ตรงข้ามบนข้างเดียวกันของเส้นตัด เส้นขนานกันจึงได้ $3x + 3 = 5x - 37$
2. $3 + 37 = 5x - 3x$ ได้ $40 = 2x$ จึงได้ $x = 20$
3. $\hat{2} = 3(20) + 3 = 63^\circ$ ตรวจ $\hat{6} = 5(20) - 37 = 63^\circ$
</Steps>
</Example>

{/* check: solve(Eq(3*x + 3, 5*x - 37), x) == [20] and 3*20 + 3 == 63 and 5*20 - 37 == 63 */}

## สรุป

- มุมภายนอกและมุมภายในที่อยู่ตรงข้ามบนข้างเดียวกันของเส้นตัด อยู่ตำแหน่งเดียวกันที่จุดตัดสองจุด มองหารูปตัว F
- เส้นขนานกันก็ต่อเมื่อมุมคู่นี้มีขนาดเท่ากัน
- เมื่อเส้นขนานกัน มุมแปดมุมมีขนาดอย่างมากสองแบบ คือ $x$ กับ $180^\circ - x$ ถ้า $x=90^\circ$ จะมีขนาดเดียว
- ตรวจว่าเส้นขนานได้สามวิธี มุมภายในบนข้างเดียวกันรวม $180^\circ$ มุมแย้งเท่ากัน หรือมุมคู่ในหน้านี้เท่ากัน
