ตัดกระดาษเป็นรูปสามเหลี่ยมรูปไหนก็ได้ ฉีกมุมทั้งสามออกมา แล้ววางเรียงให้จุดยอดชนกันและขอบติดกัน มุมทั้งสามจะต่อกันเป็นเส้นตรงพอดี ทำกับสามเหลี่ยมผอมสูงหรืออ้วนเตี้ยก็ได้ผลเหมือนเดิม การทดลองบอกว่าน่าจะจริงเสมอ แต่ยังไม่ใช่เหตุผล หน้านี้จะใช้เส้นขนานอธิบายว่าทำไม

## มุมภายในทั้งสามมุมรวมกันได้ 180°

ให้ $ABC$ เป็นรูปสามเหลี่ยมใดๆ ลาก $\overleftrightarrow{DE}$ ผ่านจุด $A$ ให้ขนานกับ $\overline{BC}$

<Steps>
1. $\overline{AB}$ เป็นเส้นตัดของเส้นขนาน $\overleftrightarrow{DE}$ กับ $\overleftrightarrow{BC}$ ได้มุมแย้ง $D\hat{A}B = A\hat{B}C$
2. $\overline{AC}$ ก็เป็นเส้นตัดของเส้นขนานคู่เดียวกัน ได้มุมแย้ง $E\hat{A}C = A\hat{C}B$
3. มุมสามมุมที่จุด $A$ บน $\overleftrightarrow{DE}$ ประกอบกันเป็นมุมตรง $D\hat{A}B + B\hat{A}C + E\hat{A}C = 180^\circ$
4. แทนค่าจากขั้นที่ 1 และ 2 ได้ $A\hat{B}C + B\hat{A}C + A\hat{C}B = 180^\circ$
</Steps>

เหตุผลนี้ไม่ได้ใช้ขนาดของมุมใดเลย จึงใช้ได้กับรูปสามเหลี่ยมทุกรูป ตรงกับการฉีกกระดาษ มุมสีส้มกับสีเขียวที่จุด $A$ คือมุม $B$ กับมุม $C$ ที่ย้ายขึ้นไปวางเรียงกับมุม $A$

<Thm label="ทฤษฎีบท">
ขนาดของมุมภายในทั้งสามมุมของรูปสามเหลี่ยมรวมกันเท่ากับ $180^\circ$
</Thm>

ลากจุด $A$ ไปที่อื่น แล้วดูว่าผลบวกยังเป็น $180^\circ$ หรือไม่ จากนั้นติ๊กช่องเพื่อแสดงเส้นขนานผ่าน $A$

<Board name="c18-triangle" label="รูปสามเหลี่ยม ABC ลากจุด A ได้ มุมทั้งสามระบายคนละสี ติ๊กช่องเพื่อแสดงเส้นที่ผ่าน A ขนานกับ BC และมุมแย้งที่เท่ากับมุม B และมุม C">
ลองลากจุด $A$ ไปทางซ้ายจนมุม $B$ เป็นมุมป้าน แล้วดูว่ามุม $A$ กับมุม $C$ เหลือรวมกันเท่าไร
</Board>

<Example n={1}>

รูปสามเหลี่ยม $ABC$ มี $B\hat{A}C = 48^\circ$ และ $A\hat{B}C = 67^\circ$ หาขนาดของ $A\hat{C}B$

<Steps reveal>
1. มุมภายในทั้งสามรวมกัน $180^\circ$ จึงได้ $A\hat{C}B = 180^\circ - 48^\circ - 67^\circ$
2. $A\hat{C}B = 65^\circ$
</Steps>
</Example>

{/* check: 180 - 48 - 67 == 65 */}

<Example n={2}>

มุมภายในทั้งสามของรูปสามเหลี่ยมรูปหนึ่งมีอัตราส่วน $2 : 3 : 4$ หาขนาดของแต่ละมุม

<Steps reveal>
1. ให้มุมทั้งสามเป็น $2k$ $3k$ และ $4k$ องศา
2. $2k + 3k + 4k = 180$ ได้ $9k = 180$ จึงได้ $k = 20$
3. มุมทั้งสามคือ $40^\circ$ $60^\circ$ และ $80^\circ$ รวมกันได้ $180^\circ$ จริง
</Steps>
</Example>

{/* check: solve(Eq(2*k + 3*k + 4*k, 180), k) == [20] and [2*20, 3*20, 4*20] == [40, 60, 80] */}

<Example n={3}>

รูปสามเหลี่ยมหน้าจั่วรูปหนึ่งมีมุมยอดขนาด $40^\circ$ มุมที่ฐานแต่ละมุมมีขนาดเท่าไร

<Steps reveal>
1. มุมที่ฐานของรูปสามเหลี่ยมหน้าจั่วมีขนาดเท่ากัน ตามที่เรียนในบทที่ 17 ให้มีขนาดมุมละ $y$ องศา
2. $40 + y + y = 180$ ได้ $2y = 140$
3. $y = 70$ มุมที่ฐานมีขนาดมุมละ $70^\circ$
</Steps>
</Example>

{/* check: solve(Eq(40 + 2*y, 180), y) == [70] */}

### ผลที่ตามมา

จากทฤษฎีบทนี้ได้ข้อสรุปอีกหลายข้อ ทุกข้อมาจากการนับให้ครบ $180^\circ$

- รูปสามเหลี่ยมมุมฉาก มุมแหลมสองมุมรวมกันได้ $180^\circ - 90^\circ = 90^\circ$
- รูปสามเหลี่ยมด้านเท่ามีมุมเท่ากันทั้งสามมุม จึงมีขนาดมุมละ $180^\circ \div 3 = 60^\circ$
- ถ้ารูปสามเหลี่ยมสองรูปมีมุมเท่ากันสองคู่ มุมคู่ที่สามจะเท่ากันด้วย เพราะต่างก็เป็น $180^\circ$ ลบผลบวกของสองมุมแรก

{/* check: 180 - 90 == 90 and Rational(180, 3) == 60 */}

<Think>

เพื่อนวาดรูปสามเหลี่ยมที่มีมุม $100^\circ$ และ $85^\circ$ ได้หรือไม่

<Reveal>
ไม่ได้ สองมุมนี้รวมกันได้ $185^\circ$ เกิน $180^\circ$ ไปแล้ว มุมที่สามจะต้องติดลบ ข้อนี้บอกด้วยว่ารูปสามเหลี่ยมมีมุมป้านหรือมุมฉากได้อย่างมากหนึ่งมุม เพราะสองมุมที่ไม่น้อยกว่า $90^\circ$ รวมกันก็ได้อย่างน้อย $180^\circ$ แล้ว
</Reveal>
</Think>

{/* check: 100 + 85 == 185 and 180 - 185 < 0 */}

## มุมภายนอกของรูปสามเหลี่ยม

ต่อด้าน $\overline{BC}$ ของรูปสามเหลี่ยม $ABC$ ออกไปทาง $C$ ถึงจุด $D$ มุม $A\hat{C}D$ ที่เกิดขึ้นเรียกว่า**มุมภายนอก**ของรูปสามเหลี่ยม มุมภายใน $A\hat{C}B$ ที่อยู่ติดกับมันเรียกว่า**มุมประชิด**ของมุมภายนอกนั้น ส่วนมุม $A$ กับมุม $B$ เป็นมุมภายในที่ไม่ใช่มุมประชิด

  <figcaption>มุมภายนอก ACD สีม่วง เท่ากับมุม A สีส้มรวมกับมุม B สีเขียว</figcaption>
</figure>

1. $A\hat{C}D + A\hat{C}B = 180^\circ$ เพราะประกอบกันเป็นมุมตรงบน $\overleftrightarrow{BD}$
2. $B\hat{A}C + A\hat{B}C + A\hat{C}B = 180^\circ$ เพราะเป็นมุมภายในของรูปสามเหลี่ยม
3. ทั้งสองบรรทัดมี $A\hat{C}B$ และรวมกันได้ $180^\circ$ เท่ากัน จึงได้ $A\hat{C}D = B\hat{A}C + A\hat{B}C$

<Thm label="ทฤษฎีบท">
ถ้าต่อด้านใดด้านหนึ่งของรูปสามเหลี่ยมออกไป ขนาดของมุมภายนอกที่เกิดขึ้นจะเท่ากับผลบวกของขนาดของมุมภายในที่ไม่ใช่มุมประชิดของมุมภายนอกนั้น
</Thm>

สมบัตินี้ทำให้หามุมภายนอกได้ในขั้นเดียว ไม่ต้องหามุมภายในที่สามก่อน

<Example n={4}>

รูปสามเหลี่ยม $ABC$ มี $B\hat{A}C = 64^\circ$ และ $A\hat{B}C = 51^\circ$ ต่อ $\overline{BC}$ ไปถึง $D$ หาขนาดของ $A\hat{C}D$ และ $A\hat{C}B$

<Steps reveal>
1. $A\hat{C}D$ เป็นมุมภายนอก มุมภายในที่ไม่ใช่มุมประชิดคือ $B\hat{A}C$ กับ $A\hat{B}C$ จึงได้ $A\hat{C}D = 64^\circ + 51^\circ = 115^\circ$
2. $A\hat{C}B = 180^\circ - 115^\circ = 65^\circ$
3. ตรวจ $64^\circ + 51^\circ + 65^\circ = 180^\circ$
</Steps>
</Example>

{/* check: 64 + 51 == 115 and 180 - 115 == 65 and 64 + 51 + 65 == 180 */}

<Example n={5}>

รูปสามเหลี่ยม $ABC$ มี $B\hat{A}C = (x + 25)^\circ$ และ $A\hat{B}C = (2x - 10)^\circ$ ต่อ $\overline{BC}$ ไปถึง $D$ ได้ $A\hat{C}D = (4x - 15)^\circ$ หาค่า $x$ และขนาดของมุมทั้งสาม

<Steps reveal>
1. มุมภายนอกเท่ากับผลบวกของมุมภายในที่ไม่ใช่มุมประชิด $(x + 25) + (2x - 10) = 4x - 15$
2. $3x + 15 = 4x - 15$ ได้ $x = 30$
3. $B\hat{A}C = 55^\circ$ และ $A\hat{B}C = 50^\circ$ มุมภายในที่ $C$ คือ $A\hat{C}B = 180^\circ - 105^\circ = 75^\circ$ จึงได้มุมภายในทั้งสามเป็น $55^\circ$ $50^\circ$ และ $75^\circ$ ตรวจผลรวมได้ $180^\circ$ และมุมภายนอก $A\hat{C}D = 105^\circ$ เท่ากับ $55^\circ + 50^\circ$
</Steps>
</Example>

{/* check: solve(Eq((x + 25) + (2*x - 10), 4*x - 15), x) == [30] and [30 + 25, 2*30 - 10, 4*30 - 15] == [55, 50, 105] */}
{/* check: 180 - 105 == 75 and 55 + 50 + 75 == 180 */}

<Think>

ที่จุดยอดแต่ละจุดของรูปสามเหลี่ยม ต่อด้านออกไปให้เกิดมุมภายนอกจุดละหนึ่งมุม มุมภายนอกทั้งสามมุมรวมกันได้เท่าไร เพื่อนตอบว่า $180^\circ$ เหมือนมุมภายใน ถูกหรือไม่

<Reveal>
ไม่ถูก ที่จุดยอดแต่ละจุด มุมภายนอกกับมุมภายในรวมกันได้ $180^\circ$ สามจุดรวมกันได้ $3 \times 180^\circ = 540^\circ$ ในนั้นเป็นมุมภายใน $180^\circ$ มุมภายนอกทั้งสามจึงรวมกันได้ $540^\circ - 180^\circ = 360^\circ$ เช่นสามเหลี่ยมด้านเท่ามีมุมภายนอกมุมละ $120^\circ$ สามมุมรวมกันได้ $360^\circ$
</Reveal>
</Think>

{/* check: 3*180 - 180 == 360 and 3*(180 - 60) == 360 */}

## สรุป

- มุมภายในทั้งสามมุมของรูปสามเหลี่ยมรวมกันได้ $180^\circ$ พิสูจน์ด้วยการลากเส้นขนานผ่านจุดยอดแล้วใช้มุมแย้ง
- รูปสามเหลี่ยมมีมุมป้านหรือมุมฉากได้อย่างมากหนึ่งมุม
- มุมภายนอกเท่ากับผลบวกของมุมภายในที่ไม่ใช่มุมประชิดของมัน
- มุมภายนอกกับมุมประชิดของมันรวมกันได้ $180^\circ$
