ร้านเครื่องเขียนหน้าโรงเรียนขายสมุดเล่มละ $x$ บาท ซื้อ $3$ เล่ม จ่าย $3x$ บาท พื้นห้องรูปสี่เหลี่ยมจัตุรัสยาวด้านละ $y$ เมตร มีพื้นที่ $y^2$ ตารางเมตร กล่องที่กว้าง $a$ ยาว $2a$ สูง $b$ มีปริมาตร $2a^2b$

นิพจน์ $3x$ $y^2$ และ $2a^2b$ มีหน้าตาแบบเดียวกัน คือเป็นตัวเลขคูณกับตัวแปร ไม่มีการบวก ไม่มีการลบ และไม่มีตัวแปรอยู่ในตัวส่วน นิพจน์แบบนี้เป็นก้อนพื้นฐานของทั้งบท

## เอกนามคืออะไร

<Def>
**เอกนาม** (monomial) คือนิพจน์ที่เขียนได้ในรูปการคูณของค่าคงตัวกับตัวแปรตั้งแต่หนึ่งตัวขึ้นไป โดยเลขชี้กำลังของตัวแปรแต่ละตัวเป็นศูนย์หรือจำนวนเต็มบวก

ค่าคงตัวในเอกนามเรียกว่า**สัมประสิทธิ์** (coefficient) ของเอกนามนั้น
</Def>

ค่าคงตัวอย่างเดียว เช่น $7$ ก็เป็นเอกนาม เพราะเขียนเป็น $7x^0$ ได้ และ $x^0 = 1$ ส่วน $x$ เฉยๆ มีสัมประสิทธิ์เป็น $1$ และ $-y$ มีสัมประสิทธิ์เป็น $-1$

<Example n={1}>
นิพจน์ใดต่อไปนี้เป็นเอกนาม ถ้าเป็น ให้บอกสัมประสิทธิ์

(1) $-4x^2y$   (2) $\tfrac{2}{3}a^3$   (3) $12$   (4) $\tfrac{5}{x}$   (5) $x + 2$   (6) $\sqrt{x}$

<Steps reveal>
1. $-4x^2y$ เป็น สัมประสิทธิ์คือ $-4$ ต้องเก็บเครื่องหมายลบไว้ด้วย
2. $\tfrac{2}{3}a^3$ เป็น สัมประสิทธิ์คือ $\tfrac{2}{3}$ สัมประสิทธิ์เป็นเศษส่วนได้
3. $12$ เป็น เพราะ $12 = 12x^0$ สัมประสิทธิ์คือ $12$
4. $\tfrac{5}{x}$ ไม่เป็น เพราะ $\tfrac{5}{x} = 5x^{-1}$ เลขชี้กำลังเป็นจำนวนเต็มลบ
5. $x + 2$ ไม่เป็น เพราะเป็นผลบวก ไม่ใช่การคูณ
6. $\sqrt{x}$ ไม่เป็น เพราะ $\sqrt{x} = x^{1/2}$ เลขชี้กำลังไม่ใช่จำนวนเต็ม
</Steps>
</Example>

{/* check: 5/x == 5*x**(-1) */}
{/* check: sqrt(x) == x**Rational(1, 2) */}

<Think>
$\tfrac{x}{3}$ กับ $\tfrac{3}{x}$ เป็นเอกนามทั้งคู่ไหม ดูแล้วเป็นเศษส่วนที่มี $x$ เหมือนกัน

<Reveal>
ไม่ทั้งคู่ $\tfrac{x}{3} = \tfrac{1}{3}x$ เป็นเอกนามที่มีสัมประสิทธิ์ $\tfrac{1}{3}$ เพราะตัวแปรอยู่ที่ตัวเศษ เลขชี้กำลังของ $x$ คือ $1$ แต่ $\tfrac{3}{x} = 3x^{-1}$ ตัวแปรอยู่ที่ตัวส่วน เลขชี้กำลังติดลบ จึงไม่เป็นเอกนาม ตัวที่ต้องดูคือตัวแปร ไม่ใช่ตัวเลข
</Reveal>
</Think>

## ดีกรีของเอกนาม

<Def>
**ดีกรีของเอกนาม** คือผลบวกของเลขชี้กำลังของตัวแปรทุกตัวในเอกนามนั้น

ค่าคงตัวที่ไม่ใช่ศูนย์มีดีกรีเป็น $0$ ส่วนเอกนาม $0$ ไม่บอกดีกรี
</Def>

ดีกรีบอกว่าเอกนามนั้นเป็นตัวแปรคูณกันกี่ตัว เช่น $x^2y^3 = x \cdot x \cdot y \cdot y \cdot y$ มีตัวแปรคูณกันห้าตัว จึงมีดีกรี $5$

<Example n={2}>
หาดีกรีของเอกนาม $5x^3$  $-2x^2y^4$  $xy$  และ $-9$

<Steps reveal>
1. $5x^3$ มีตัวแปรตัวเดียวคือ $x$ เลขชี้กำลัง $3$ ดีกรีคือ $3$
2. $-2x^2y^4$ เลขชี้กำลังของ $x$ คือ $2$ ของ $y$ คือ $4$ ดีกรีคือ $2 + 4 = 6$ สัมประสิทธิ์ $-2$ ไม่เกี่ยวกับดีกรี
3. $xy$ คือ $x^1y^1$ ดีกรีคือ $1 + 1 = 2$
4. $-9$ เป็นค่าคงตัวที่ไม่ใช่ศูนย์ ดีกรีคือ $0$
</Steps>
</Example>

{/* check: [Poly(e, x, y).total_degree() for e in [5*x**3, -2*x**2*y**4, x*y, -9]] == [3, 6, 2, 0] */}

<Think>
เพื่อนบอกว่า $2^3x^2$ มีดีกรี $5$ เพราะ $3 + 2 = 5$ เพื่อนพูดถูกไหม

<Reveal>
ไม่ถูก $2^3$ เป็นตัวเลข ไม่ใช่ตัวแปร $2^3x^2 = 8x^2$ สัมประสิทธิ์คือ $8$ ดีกรีนับเฉพาะเลขชี้กำลังของตัวแปร จึงได้ดีกรี $2$
</Reveal>
</Think>

{/* check: Poly(2**3*x**2, x).degree() == 2 */}

## เอกนามคล้าย

<Def>
เอกนามสองเอกนาม**คล้ายกัน** เมื่อมีตัวแปรชุดเดียวกัน และเลขชี้กำลังของตัวแปรแต่ละตัวเท่ากัน
</Def>

สัมประสิทธิ์จะต่างกันก็ได้ ดูแค่ส่วนที่เป็นตัวแปร

- $3x^2y$ กับ $-5x^2y$ คล้ายกัน ตัวแปรเป็น $x^2y$ เหมือนกัน
- $4ab$ กับ $-ba$ คล้ายกัน เพราะ $ba = ab$ การคูณสลับที่ได้
- $3x^2y$ กับ $3xy^2$ ไม่คล้ายกัน ตัวแปรชุดเดียวกันก็จริง แต่เลขชี้กำลังของ $x$ ต่างกัน
- $6x$ กับ $6x^2$ ไม่คล้ายกัน ถึงสัมประสิทธิ์จะเท่ากัน

## บวกและลบเอกนามที่คล้ายกัน

ซื้อสมุดเล่มละ $x$ บาท วันจันทร์ $3$ เล่ม วันอังคารอีก $5$ เล่ม รวมเป็นสมุด $8$ เล่ม จ่ายไป $8x$ บาท เขียนเป็นนิพจน์ได้ว่า $3x + 5x = (3 + 5)x = 8x$ ซึ่งก็คือสมบัติการแจกแจงนั่นเอง

<Thm>
เอกนามที่คล้ายกันบวกหรือลบกันได้ โดยนำสัมประสิทธิ์มาบวกหรือลบกัน ส่วนที่เป็นตัวแปรคงเดิม

$$
mx^ny^k + px^ny^k = (m + p)x^ny^k
$$

เอกนามที่ไม่คล้ายกันรวมเป็นเอกนามเดียวไม่ได้
</Thm>

<Example n={3}>
หาผลลัพธ์

(1) $7x^2 + 4x^2$   (2) $3ab - 8ab$   (3) $6xy^2 - (-2xy^2)$   (4) $5x^2 + 3x$

<Steps reveal>
1. คล้ายกัน $7x^2 + 4x^2 = (7 + 4)x^2 = 11x^2$
2. คล้ายกัน $3ab - 8ab = (3 - 8)ab = -5ab$
3. คล้ายกัน $6xy^2 - (-2xy^2) = (6 + 2)xy^2 = 8xy^2$ ลบด้วยจำนวนลบคือบวกด้วยจำนวนบวก
4. $5x^2$ กับ $3x$ ไม่คล้ายกัน รวมกันไม่ได้ คำตอบคือ $5x^2 + 3x$ ตามเดิม
</Steps>
</Example>

{/* check: 7*x**2 + 4*x**2 == 11*x**2 */}
{/* check: 3*a*b - 8*a*b == -5*a*b */}
{/* check: 6*x*y**2 - (-2*x*y**2) == 8*x*y**2 */}

<Think>
เพื่อนคิดว่า $2x^3 + 3x^3 = 5x^6$ เพราะบวกตัวเลขข้างหน้าแล้วก็บวกเลขชี้กำลังด้วย เพื่อนพลาดตรงไหน

<Reveal>
ตอนบวก ส่วนที่เป็นตัวแปรต้องคงเดิม ที่ถูกคือ $2x^3 + 3x^3 = 5x^3$ เพราะเป็น $x^3$ สองก้อนรวมกับสามก้อน ได้ห้าก้อน ลองแทน $x = 2$ ตรวจ $2(8) + 3(8) = 40$ ตรงกับ $5(8) = 40$ แต่ $5x^6 = 5(64) = 320$ ไม่ตรง การบวกเลขชี้กำลังเป็นเรื่องของการคูณ ซึ่งจะเจอในหน้า 15.3
</Reveal>
</Think>

## สรุป

- เอกนามคือค่าคงตัวคูณกับตัวแปรที่มีเลขชี้กำลังเป็นศูนย์หรือจำนวนเต็มบวก ค่าคงตัวนั้นคือสัมประสิทธิ์
- ตัวแปรในตัวส่วน รากที่สองของตัวแปร หรือการบวกลบ ทำให้ไม่เป็นเอกนาม
- ดีกรีของเอกนามคือผลบวกของเลขชี้กำลังของตัวแปร ไม่นับตัวเลข
- เอกนามคล้ายกันเมื่อส่วนที่เป็นตัวแปรเหมือนกันทุกตัว
- บวกลบเอกนามที่คล้ายกัน ให้บวกลบแค่สัมประสิทธิ์ ตัวแปรคงเดิม
