แผ่นป้ายรูปสี่เหลี่ยมผืนผ้ามีพื้นที่ $15x^3$ ตารางเซนติเมตร และกว้าง $3x$ เซนติเมตร ป้ายนี้ยาวเท่าไร

ความยาวคือจำนวนที่คูณกับ $3x$ แล้วได้ $15x^3$ ซึ่งก็คือ $15x^3 \div 3x$ การหารจึงเป็นการทำย้อนกลับของการคูณ หน้าที่แล้วคูณได้ หน้านี้ก็หารได้ด้วยหลักเดียวกัน

## เอกนามหารด้วยเอกนาม

ตัวเลขหารตัวเลข ตัวแปรเดียวกันหารกันโดยใช้สมบัติของเลขยกกำลังจากบทที่ 14

$$
a^m \div a^n = a^{m-n}
$$

เมื่อ $a \neq 0$ เพราะหารด้วยศูนย์ไม่ได้

กลับไปที่แผ่นป้าย $\dfrac{15x^3}{3x} = \dfrac{15}{3} \cdot x^{3-1} = 5x^2$ ป้ายยาว $5x^2$ เซนติเมตร ตรวจด้วยการคูณกลับ $(3x)(5x^2) = 15x^3$ ตรงกับพื้นที่

{/* check: simplify(15*x**3/(3*x)) == 5*x**2 */}

<Example n={1}>
หาผลหาร และบอกว่าผลหารเป็นเอกนามหรือไม่

(1) $\dfrac{18x^5}{3x^2}$   (2) $\dfrac{-24a^4b^3}{6a^2b}$   (3) $\dfrac{10x^2y}{4x^2y}$   (4) $\dfrac{6x^2}{2x^5}$

<Steps reveal>
1. $\dfrac{18}{3} \cdot x^{5-2} = 6x^3$ เป็นเอกนาม
2. $\dfrac{-24}{6} \cdot a^{4-2} \cdot b^{3-1} = -4a^2b^2$ เป็นเอกนาม
3. $\dfrac{10}{4} \cdot x^{2-2} \cdot y^{1-1} = \tfrac{5}{2}x^0y^0 = \tfrac{5}{2}$ ตัวแปรหักล้างกันหมด เหลือค่าคงตัว ซึ่งก็เป็นเอกนาม
4. $\dfrac{6}{2} \cdot x^{2-5} = 3x^{-3}$ เลขชี้กำลังติดลบ ผลหารจึงไม่เป็นเอกนาม
</Steps>
</Example>

{/* check: simplify(18*x**5/(3*x**2)) == 6*x**3 */}
{/* check: simplify(-24*a**4*b**3/(6*a**2*b)) == -4*a**2*b**2 */}
{/* check: simplify(10*x**2*y/(4*x**2*y)) == Rational(5, 2) */}
{/* check: simplify(6*x**2/(2*x**5)) == 3*x**(-3) */}

จากข้อ 4 ผลหารของเอกนามด้วยเอกนามจะเป็นเอกนามก็ต่อเมื่อตัวแปรทุกตัวของตัวหารมีอยู่ในตัวตั้ง และเลขชี้กำลังในตัวตั้งมากกว่าหรือเท่ากับในตัวหาร

<Think>
เพื่อนหา $12x^6 \div 4x^2$ ได้ $3x^3$ เพราะ $6 \div 2 = 3$ เพื่อนพลาดตรงไหน

<Reveal>
เลขชี้กำลังต้องลบกัน ไม่ใช่หารกัน $x^6 \div x^2 = x^{6-2} = x^4$ คำตอบที่ถูกคือ $3x^4$ ตรวจด้วยการคูณกลับ $(4x^2)(3x^4) = 12x^6$ ตรง แต่ $(4x^2)(3x^3) = 12x^5$ ไม่ตรง
</Reveal>
</Think>

{/* check: simplify(12*x**6/(4*x**2)) == 3*x**4 */}
{/* check: expand((4*x**2)*(3*x**3)) == 12*x**5 */}

## พหุนามหารด้วยเอกนาม

แบ่งค่าขนม $30 + 12$ บาทให้น้อง $3$ คน จะเอา $42 \div 3 = 14$ หรือแบ่งทีละก้อน $\tfrac{30}{3} + \tfrac{12}{3} = 10 + 4 = 14$ ก็ได้เท่ากัน พหุนามหารด้วยเอกนามใช้วิธีแบ่งทีละก้อนนี้

{/* check: Rational(30 + 12, 3) == Rational(30, 3) + Rational(12, 3) */}

<Thm>
หารพหุนามด้วยเอกนาม ให้นำเอกนามไปหาร**ทุกพจน์**ของพหุนาม แล้วนำผลหารมาบวกกัน

$$
\frac{p + q + r}{m} = \frac{p}{m} + \frac{q}{m} + \frac{r}{m}
$$
</Thm>

<Example n={2}>
หา $(8x^3 - 12x^2 + 4x) \div 4x$

<Steps reveal>
1. หารทีละพจน์ $\dfrac{8x^3}{4x} - \dfrac{12x^2}{4x} + \dfrac{4x}{4x}$
2. ได้ $2x^2 - 3x + 1$ พจน์สุดท้าย $\tfrac{4x}{4x} = 1$ ไม่ใช่ $0$
3. ตรวจด้วยการคูณกลับ $4x(2x^2 - 3x + 1) = 8x^3 - 12x^2 + 4x$ ตรงกับตัวตั้ง
</Steps>
</Example>

{/* check: expand((8*x**3 - 12*x**2 + 4*x)/(4*x)) == 2*x**2 - 3*x + 1 */}
{/* check: expand(4*x*(2*x**2 - 3*x + 1)) == 8*x**3 - 12*x**2 + 4*x */}

<Example n={3}>
หา $(15a^3b^2 - 10a^2b + 5ab) \div (-5ab)$

<Steps reveal>
1. หารทีละพจน์ ตัวหารติดลบ เครื่องหมายของทุกพจน์จึงกลับ
2. $\dfrac{15a^3b^2}{-5ab} = -3a^2b$
3. $\dfrac{-10a^2b}{-5ab} = 2a$ ลบหารลบได้บวก
4. $\dfrac{5ab}{-5ab} = -1$
5. ได้ $-3a^2b + 2a - 1$ ตรวจ $(-5ab)(-3a^2b + 2a - 1) = 15a^3b^2 - 10a^2b + 5ab$
</Steps>
</Example>

{/* check: expand((15*a**3*b**2 - 10*a**2*b + 5*a*b)/(-5*a*b)) == -3*a**2*b + 2*a - 1 */}
{/* check: expand(-5*a*b*(-3*a**2*b + 2*a - 1)) == 15*a**3*b**2 - 10*a**2*b + 5*a*b */}

<Think>
$(6x^2 + 3) \div 3x$ ได้ผลหารเป็นพหุนามไหม

<Reveal>
ไม่ได้ หารทีละพจน์ได้ $\tfrac{6x^2}{3x} + \tfrac{3}{3x} = 2x + \tfrac{1}{x}$ พจน์ $\tfrac{1}{x}$ มีตัวแปรอยู่ในตัวส่วน ไม่เป็นเอกนาม ผลหารจึงไม่เป็นพหุนาม การหารพหุนามด้วยเอกนามจะได้พหุนามก็ต่อเมื่อเอกนามนั้นหารทุกพจน์ได้เป็นเอกนาม
</Reveal>
</Think>

{/* check: expand((6*x**2 + 3)/(3*x)) == 2*x + 1/x */}

## โจทย์ปัญหา

<Example n={4}>
ห้องสมุดซื้อหนังสือ $5x$ เล่ม ราคาเท่ากันทุกเล่ม จ่ายเงินรวม $20x^2 + 35x$ บาท หนังสือราคาเล่มละเท่าไร และถ้า $x = 6$ ซื้อหนังสือกี่เล่ม เล่มละกี่บาท

<Steps reveal>
1. ราคาต่อเล่มคือราคารวมหารด้วยจำนวนเล่ม $\dfrac{20x^2 + 35x}{5x} = \dfrac{20x^2}{5x} + \dfrac{35x}{5x} = 4x + 7$ บาท
2. ถ้า $x = 6$ ซื้อหนังสือ $5(6) = 30$ เล่ม เล่มละ $4(6) + 7 = 31$ บาท
3. ตรวจ ราคารวม $20(36) + 35(6) = 930$ บาท และ $30 \times 31 = 930$ ตรงกัน
</Steps>
</Example>

{/* check: expand((20*x**2 + 35*x)/(5*x)) == 4*x + 7 */}
{/* check: (4*x + 7).subs(x, 6) == 31 and (20*x**2 + 35*x).subs(x, 6) == 930 and 30*31 == 930 */}

## สรุป

- เอกนามหารเอกนาม ตัวเลขหารตัวเลข ตัวแปรเดียวกันลบเลขชี้กำลัง
- ผลหารเป็นเอกนามเมื่อเลขชี้กำลังของทุกตัวแปรไม่ติดลบ
- พหุนามหารด้วยเอกนาม หารทุกพจน์ พจน์ที่หารกันพอดีได้ $1$ ไม่ใช่ $0$
- ตัวหารติดลบ เครื่องหมายของทุกพจน์ในผลหารกลับ
- ตรวจคำตอบด้วยการคูณกลับ ตัวหารคูณผลหารต้องได้ตัวตั้ง
