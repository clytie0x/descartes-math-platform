สนามหญ้าหน้าโรงเรียนเป็นรูปสี่เหลี่ยมจัตุรัสยาวด้านละ $x$ เมตร โรงเรียนจะขยายด้านหนึ่งออกไปอีก $4$ เมตร และอีกด้านหนึ่งอีก $2$ เมตร สนามใหม่มีพื้นที่ $(x + 4)(x + 2)$ ตารางเมตร แล้วพื้นที่เพิ่มขึ้นจากเดิมเท่าไร

จะตอบคำถามนี้ได้ต้องคูณพหุนามสองตัวให้ออกมาเป็นพหุนามตัวเดียว หน้านี้เริ่มจากการคูณที่ง่ายที่สุดก่อน

## เอกนามคูณเอกนาม

การคูณสลับที่และจัดกลุ่มได้ จึงแยกตัวเลขไปคูณกับตัวเลข ตัวแปรไปคูณกับตัวแปรตัวเดียวกัน แล้วใช้สมบัติของเลขยกกำลังจากบทที่ 14

$$
a^m \times a^n = a^{m+n}
$$

<Example n={1}>
หาผลคูณ

(1) $(3x^2)(4x^5)$   (2) $(-2a^3b)(5ab^4)$   (3) $(-3x^2y)^2$

<Steps reveal>
1. $(3x^2)(4x^5) = (3 \times 4)(x^2 \times x^5) = 12x^{2+5} = 12x^7$
2. $(-2a^3b)(5ab^4) = (-2 \times 5)(a^3 \times a)(b \times b^4) = -10a^4b^5$ ตัวแปรที่ไม่เขียนเลขชี้กำลัง เช่น $a$ คือ $a^1$
3. $(-3x^2y)^2 = (-3x^2y)(-3x^2y) = 9x^4y^2$ ลบคูณลบได้บวก
</Steps>
</Example>

{/* check: expand((3*x**2)*(4*x**5)) == 12*x**7 */}
{/* check: expand((-2*a**3*b)*(5*a*b**4)) == -10*a**4*b**5 */}
{/* check: expand((-3*x**2*y)**2) == 9*x**4*y**2 */}

<Think>
$(2x^3)(3x^4)$ เท่ากับเท่าไร มีคนตอบ $5x^7$ และมีคนตอบ $6x^{12}$ ใครถูก

<Reveal>
ไม่มีใครถูก ตัวเลขต้องคูณกัน $2 \times 3 = 6$ ไม่ใช่บวกกัน ส่วนเลขชี้กำลังของ $x$ ตัวเดียวกันต้องบวกกัน $3 + 4 = 7$ ไม่ใช่คูณกัน คำตอบคือ $6x^7$ จำง่ายๆ ว่า $x^3 \times x^4$ คือ $x$ คูณกันสามตัวแล้วคูณต่ออีกสี่ตัว รวมเป็นเจ็ดตัว
</Reveal>
</Think>

{/* check: expand((2*x**3)*(3*x**4)) == 6*x**7 */}

## เอกนามคูณพหุนาม

ดูรูปสี่เหลี่ยมผืนผ้าสูง $2x$ ยาว $3x + 5$ พื้นที่ทั้งรูปคือ $2x(3x + 5)$ แต่ถ้าแบ่งเป็นสองชิ้นตามรอยต่อ ชิ้นซ้ายมีพื้นที่ $2x \cdot 3x = 6x^2$ ชิ้นขวามีพื้นที่ $2x \cdot 5 = 10x$

{/* check: expand(2*x*(3*x + 5)) == 6*x**2 + 10*x */}

รูปนี้คือสมบัติการแจกแจง เอกนามข้างนอกวงเล็บต้องคูณกับ**ทุกพจน์**ในวงเล็บ

$$
m(p + q + r) = mp + mq + mr
$$

<Example n={2}>
หา $-3x(2x^2 - 4x + 1)$

<Steps reveal>
1. คูณ $-3x$ กับพจน์แรก $(-3x)(2x^2) = -6x^3$
2. คูณกับพจน์ที่สอง $(-3x)(-4x) = 12x^2$ ลบคูณลบได้บวก
3. คูณกับพจน์ที่สาม $(-3x)(1) = -3x$
4. ได้ $-6x^3 + 12x^2 - 3x$
</Steps>
</Example>

{/* check: expand(-3*x*(2*x**2 - 4*x + 1)) == -6*x**3 + 12*x**2 - 3*x */}

<Note kind="warning" title="คูณให้ครบทุกพจน์">
ที่พลาดบ่อยคือคูณแค่พจน์แรกแล้วลอกพจน์ที่เหลือมาเฉยๆ เช่น เขียน $-3x(2x^2 - 4x + 1)$ เป็น $-6x^3 - 4x + 1$ หรือลืมว่าเครื่องหมายลบข้างหน้า $3x$ ต้องคูณเข้าไปทุกพจน์ด้วย
</Note>

## พหุนามคูณพหุนาม

กลับมาที่สนามหญ้า ลองเปลี่ยนตัวเลขเป็น $(x + a)(x + b)$ แล้วดูว่าพื้นที่ทั้งรูปแบ่งเป็นกี่ชิ้น

<Board name="c15-area-model" label="สี่เหลี่ยมผืนผ้ากว้าง x บวก a สูง x บวก b แบ่งเป็นสี่ชิ้น ปรับ x a b ด้วยแถบเลื่อน">
เลื่อน $x$ ไปหลายค่า พื้นที่ทั้งรูปกับผลรวมสี่ชิ้นเท่ากันทุกครั้ง แล้วลองดูว่าสองชิ้นสีเขียวรวมกันได้พจน์ไหน
</Board>

ทุกครั้งได้สี่ชิ้น เพราะพจน์ $x$ กับ $a$ ของวงเล็บแรก แต่ละตัวต้องคูณกับพจน์ $x$ กับ $b$ ของวงเล็บหลัง ได้ $2 \times 2 = 4$ คู่

<Thm>
คูณพหุนามกับพหุนาม ให้นำแต่ละพจน์ของพหุนามตัวแรกไปคูณกับทุกพจน์ของพหุนามตัวหลัง แล้วรวมพจน์ที่คล้ายกัน

$$
(p + q)(r + s) = pr + ps + qr + qs
$$
</Thm>

<Example n={3}>
หา $(x + 5)(x - 2)$

<Steps reveal>
1. $x$ คูณทุกพจน์ของวงเล็บหลัง $x \cdot x + x \cdot (-2) = x^2 - 2x$
2. $5$ คูณทุกพจน์ของวงเล็บหลัง $5 \cdot x + 5 \cdot (-2) = 5x - 10$
3. รวมกัน $x^2 - 2x + 5x - 10 = x^2 + 3x - 10$
</Steps>
</Example>

{/* check: expand((x + 5)*(x - 2)) == x**2 + 3*x - 10 */}

<Example n={4}>
หา $(2x - 3)(3x + 4)$

<Steps reveal>
1. คูณให้ครบสี่คู่ $(2x)(3x) + (2x)(4) + (-3)(3x) + (-3)(4)$
2. ได้ $6x^2 + 8x - 9x - 12$
3. รวมพจน์ $x$ ได้ $8x - 9x = -x$ คำตอบคือ $6x^2 - x - 12$
</Steps>
</Example>

{/* check: expand((2*x - 3)*(3*x + 4)) == 6*x**2 - x - 12 */}

ถ้าวงเล็บหลังมีสามพจน์ ก็ต้องคูณ $2 \times 3 = 6$ คู่ นับคู่ก่อนรวม จะได้รู้ว่าลืมคู่ไหนไปหรือเปล่า

<Example n={5}>
หา $(x + 2)(x^2 - 3x + 1)$

<Steps reveal>
1. $x$ คูณสามพจน์ $x^3 - 3x^2 + x$
2. $2$ คูณสามพจน์ $2x^2 - 6x + 2$
3. รวมหกพจน์ $x^3 - 3x^2 + x + 2x^2 - 6x + 2$
4. รวมพจน์ที่คล้ายกัน $-3x^2 + 2x^2 = -x^2$ และ $x - 6x = -5x$ ได้ $x^3 - x^2 - 5x + 2$
</Steps>
</Example>

{/* check: expand((x + 2)*(x**2 - 3*x + 1)) == x**3 - x**2 - 5*x + 2 */}

<Think>
เพื่อนเขียนว่า $(x + 3)^2 = x^2 + 9$ เพราะยกกำลังสองทีละตัว เพื่อนพูดถูกไหม

<Reveal>
ไม่ถูก $(x + 3)^2 = (x + 3)(x + 3)$ ต้องคูณครบสี่คู่ ได้ $x^2 + 3x + 3x + 9 = x^2 + 6x + 9$ ในกราฟข้างบน ตั้ง $a = 3$ และ $b = 3$ จะเห็นว่ารูปเป็นสี่เหลี่ยมจัตุรัส และมีชิ้นสีเขียว $3x$ สองชิ้นที่ $x^2 + 9$ ลืมไป ลองแทน $x = 1$ ก็ได้ $(1 + 3)^2 = 16$ แต่ $1 + 9 = 10$
</Reveal>
</Think>

{/* check: expand((x + 3)**2) == x**2 + 6*x + 9 */}
{/* check: ((x + 3)**2).subs(x, 1) == 16 and (x**2 + 9).subs(x, 1) == 10 */}

## กลับไปที่สนามหญ้า

<Example n={6}>
สนามหญ้ารูปสี่เหลี่ยมจัตุรัสยาวด้านละ $x$ เมตร ขยายด้านหนึ่งออกไป $4$ เมตร อีกด้านหนึ่ง $2$ เมตร พื้นที่เพิ่มขึ้นกี่ตารางเมตร ถ้าเดิมสนามยาวด้านละ $10$ เมตร พื้นที่เพิ่มขึ้นเท่าไร

<Steps reveal>
1. พื้นที่ใหม่ $(x + 4)(x + 2) = x^2 + 2x + 4x + 8 = x^2 + 6x + 8$ ตารางเมตร
2. พื้นที่เดิม $x^2$ ตารางเมตร พื้นที่เพิ่มขึ้น $(x^2 + 6x + 8) - x^2 = 6x + 8$ ตารางเมตร
3. ถ้า $x = 10$ พื้นที่เพิ่มขึ้น $6(10) + 8 = 68$ ตารางเมตร ตรวจได้ สนามใหม่ $14 \times 12 = 168$ สนามเดิม $100$ ต่างกัน $68$
</Steps>
</Example>

{/* check: expand((x + 4)*(x + 2)) == x**2 + 6*x + 8 */}
{/* check: expand((x + 4)*(x + 2) - x**2).subs(x, 10) == 68 and 14*12 - 100 == 68 */}

## สรุป

- เอกนามคูณเอกนาม ตัวเลขคูณตัวเลข ตัวแปรเดียวกันบวกเลขชี้กำลัง
- เอกนามคูณพหุนาม คูณเข้าไปทุกพจน์ ระวังเครื่องหมายลบ
- พหุนามคูณพหุนาม ทุกพจน์ของตัวแรกคูณกับทุกพจน์ของตัวหลัง สองพจน์คูณสองพจน์ได้สี่คู่ สองพจน์คูณสามพจน์ได้หกคู่ แล้วรวมพจน์ที่คล้ายกัน
- $(x + 3)^2$ ไม่เท่ากับ $x^2 + 9$
