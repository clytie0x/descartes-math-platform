แปลงผักรูปสี่เหลี่ยมผืนผ้ามีพื้นที่ $x^2 + 7x + 12$ ตารางเมตร และกว้าง $x + 3$ เมตร แปลงนี้ยาวเท่าไร

ตัวหารคราวนี้มีสองพจน์ หารทีละพจน์แบบหน้าที่แล้วไม่ได้ เพราะ $\tfrac{x^2 + 7x + 12}{x + 3}$ ไม่เท่ากับ $\tfrac{x^2}{x} + \tfrac{7x}{3} + \ldots$ แต่ใช้วิธีตั้งหารยาวแบบที่เคยหารตัวเลขได้

## นึกถึงการหารยาวของตัวเลข

หาร $157$ ด้วย $12$ ทำซ้ำสี่ขั้นจนหารต่อไม่ได้ คือ หาร คูณ ลบ แล้วดึงหลักถัดไปลงมา

1. $15 \div 12$ ได้ $1$ คูณกลับ $1 \times 12 = 12$ ลบ $15 - 12 = 3$ ดึง $7$ ลงมาเป็น $37$
2. $37 \div 12$ ได้ $3$ คูณกลับ $3 \times 12 = 36$ ลบ $37 - 36 = 1$
3. $1$ น้อยกว่า $12$ หารต่อไม่ได้ ผลหารคือ $13$ เศษ $1$

ตรวจได้ว่า $157 = 12 \times 13 + 1$ การหารพหุนามใช้สี่ขั้นนี้ทุกอย่าง ต่างกันแค่ว่าหารทีละพจน์แทนทีละหลัก

{/* check: 157 == 12*13 + 1 */}

## ตั้งหารยาว

<Example n={1}>
หา $(x^2 + 7x + 12) \div (x + 3)$ แล้วบอกความยาวของแปลงผัก

<Steps reveal>
1. เรียงพจน์ของตัวตั้งและตัวหารจากดีกรีมากไปน้อย ซึ่งเรียงไว้แล้ว
2. **หาร** พจน์แรกของตัวตั้งด้วยพจน์แรกของตัวหาร $x^2 \div x = x$ เขียน $x$ เป็นพจน์แรกของผลหาร
3. **คูณ** $x$ กับตัวหารทั้งตัว $x(x + 3) = x^2 + 3x$ เขียนไว้ใต้ตัวตั้ง ให้พจน์ที่คล้ายกันตรงกัน
4. **ลบ** $(x^2 + 7x) - (x^2 + 3x) = 4x$ แล้ว**ดึง** $+12$ ลงมา ได้ $4x + 12$
5. ทำซ้ำ $4x \div x = 4$ คูณ $4(x + 3) = 4x + 12$ ลบได้ $0$
6. ผลหารคือ $x + 4$ เศษ $0$ แปลงผักยาว $x + 4$ เมตร ตรวจ $(x + 3)(x + 4) = x^2 + 7x + 12$
</Steps>
</Example>

{/* check: div(x**2 + 7*x + 12, x + 3) == (x + 4, 0) */}
{/* check: expand((x + 3)*(x + 4)) == x**2 + 7*x + 12 */}

เขียนเป็นการตั้งหารยาวได้แบบนี้ ตัวหารอยู่ทางซ้าย ผลหารอยู่ข้างบน แต่ละรอบเขียนผลคูณไว้แล้วขีดเส้นใต้ก่อนลบ

$$
\begin{array}{r}
x + 4 \\
x + 3\,\big)\,\overline{x^2 + 7x + 12} \\
\underline{x^2 + 3x}\phantom{{} + 12} \\
4x + 12 \\
\underline{4x + 12} \\
0
\end{array}
$$

<Thm label="ขั้นตอนการหารยาว">

1. เรียงพจน์ของตัวตั้งและตัวหารจากดีกรีมากไปน้อย
2. หารพจน์แรกของตัวตั้งด้วยพจน์แรกของตัวหาร ได้พจน์หนึ่งของผลหาร
3. คูณพจน์นั้นกับตัวหารทั้งตัว แล้วนำไปลบออกจากตัวตั้ง
4. ใช้ผลลบเป็นตัวตั้งใหม่ ทำข้อ 2 และ 3 ซ้ำ จนผลลบมีดีกรีน้อยกว่าตัวหาร ผลลบสุดท้ายคือเศษ

</Thm>

<Think>
เพื่อนหาร $x^2 - x - 6$ ด้วย $x + 2$ ขั้นแรกได้ $x$ คูณกลับได้ $x^2 + 2x$ แล้วลบได้ $x - 6$ ทำต่อจนได้ผลหาร $x + 1$ เศษ $-8$ เพื่อนพลาดตรงไหน

<Reveal>
พลาดตอนลบ $-x - 2x = -3x$ ไม่ใช่ $x$ เพื่อนเอา $2x$ ไปลบแบบกลับข้าง ทำใหม่จะได้ $-3x - 6$ หาร $x$ ได้ $-3$ คูณกลับ $-3(x + 2) = -3x - 6$ ลบได้ $0$ ผลหารที่ถูกคือ $x - 3$ เศษ $0$

ตรวจคำตอบของเพื่อนด้วยการคูณกลับ $(x + 2)(x + 1) - 8 = x^2 + 3x - 6$ ไม่ตรงกับตัวตั้ง จึงรู้ทันทีว่าผิด ส่วน $(x + 2)(x - 3) = x^2 - x - 6$ ตรง
</Reveal>
</Think>

{/* check: div(x**2 - x - 6, x + 2) == (x - 3, 0) */}
{/* check: expand((x + 2)*(x + 1) - 8) == x**2 + 3*x - 6 */}

<Note kind="warning" title="ลบทุกพจน์">
ขั้นลบคือลบพหุนามทั้งก้อน ต้องเปลี่ยนเครื่องหมายทุกพจน์ของผลคูณก่อนรวม เหมือนการลบพหุนามในหน้า 15.2 ขั้นนี้คือจุดที่ผิดบ่อยที่สุดของการหารยาว
</Note>

## เมื่อหารไม่ลงตัว

ตัวเลขหารแล้วอาจมีเศษ พหุนามก็เหมือนกัน

<Example n={2}>
หา $(2x^2 + 5x - 4) \div (x + 3)$

<Steps reveal>
1. $2x^2 \div x = 2x$ คูณกลับ $2x(x + 3) = 2x^2 + 6x$ ลบ $(2x^2 + 5x) - (2x^2 + 6x) = -x$ ดึง $-4$ ลงมา ได้ $-x - 4$
2. $-x \div x = -1$ คูณกลับ $-1(x + 3) = -x - 3$ ลบ $(-x - 4) - (-x - 3) = -1$
3. $-1$ มีดีกรี $0$ น้อยกว่าดีกรีของ $x + 3$ ซึ่งเป็น $1$ จึงหยุด ผลหารคือ $2x - 1$ เศษ $-1$
</Steps>
</Example>

{/* check: div(2*x**2 + 5*x - 4, x + 3) == (2*x - 1, -1) */}

$$
\begin{array}{r}
2x - 1 \\
x + 3\,\big)\,\overline{2x^2 + 5x - 4} \\
\underline{2x^2 + 6x}\phantom{{} - 4} \\
-x - 4 \\
\underline{-x - 3} \\
-1
\end{array}
$$

<Thm>
เมื่อหารพหุนามด้วยพหุนาม

**ตัวตั้ง $=$ ตัวหาร $\times$ ผลหาร $+$ เศษ**

โดยเศษเป็น $0$ หรือมีดีกรีน้อยกว่าตัวหาร ถ้าเศษเป็น $0$ เรียกว่าหารลงตัว
</Thm>

ตรวจตัวอย่างที่ 2 ได้ $(x + 3)(2x - 1) + (-1) = 2x^2 + 5x - 3 - 1 = 2x^2 + 5x - 4$ ตรงกับตัวตั้ง

{/* check: expand((x + 3)*(2*x - 1) - 1) == 2*x**2 + 5*x - 4 */}

## เมื่อตัวตั้งขาดบางพจน์

<Example n={3}>
หา $(x^3 - 8) \div (x - 2)$

<Steps reveal>
1. ตัวตั้งไม่มีพจน์ $x^2$ และ $x$ ให้เติม $0x^2$ กับ $0x$ ไว้จองที่ เขียนเป็น $x^3 + 0x^2 + 0x - 8$
2. $x^3 \div x = x^2$ คูณกลับ $x^2(x - 2) = x^3 - 2x^2$ ลบได้ $0x^2 - (-2x^2) = 2x^2$ ดึง $0x$ ลงมา ได้ $2x^2 + 0x$
3. $2x^2 \div x = 2x$ คูณกลับ $2x(x - 2) = 2x^2 - 4x$ ลบได้ $4x$ ดึง $-8$ ลงมา ได้ $4x - 8$
4. $4x \div x = 4$ คูณกลับ $4(x - 2) = 4x - 8$ ลบได้ $0$
5. ผลหารคือ $x^2 + 2x + 4$ หารลงตัว
</Steps>
</Example>

{/* check: div(x**3 - 8, x - 2) == (x**2 + 2*x + 4, 0) */}

$$
\begin{array}{r}
x^2 + 2x + 4 \\
x - 2\,\big)\,\overline{x^3 + 0x^2 + 0x - 8} \\
\underline{x^3 - 2x^2}\phantom{{} + 0x - 8} \\
2x^2 + 0x\phantom{{} - 8} \\
\underline{2x^2 - 4x}\phantom{{} - 8} \\
4x - 8 \\
\underline{4x - 8} \\
0
\end{array}
$$

ถ้าไม่จองที่ไว้ พจน์ $2x^2$ ที่เกิดจากการลบจะไม่มีพจน์ไหนในตัวตั้งให้ตั้งตรง แล้วจะลบผิดหลักได้ง่าย เหมือนเลข $0$ สองตัวใน $1008$ ที่ต้องเขียนไว้ ไม่อย่างนั้นจะกลายเป็น $18$ และ $1$ จะไม่อยู่ในหลักพัน

## โจทย์ปัญหา

<Example n={4}>
ป้ายผ้ารูปสี่เหลี่ยมผืนผ้าสำหรับงานกีฬาสีมีพื้นที่ $2x^2 + 7x + 3$ ตารางเมตร และสูง $x + 3$ เมตร ป้ายนี้ยาวเท่าไร ถ้า $x = 4$ ป้ายยาวกี่เมตร

<Steps reveal>
1. ความยาวคือพื้นที่หารด้วยความสูง ตั้งหาร $(2x^2 + 7x + 3) \div (x + 3)$
2. $2x^2 \div x = 2x$ คูณกลับ $2x(x + 3) = 2x^2 + 6x$ ลบได้ $x$ ดึง $+3$ ลงมา ได้ $x + 3$
3. $x \div x = 1$ คูณกลับ $1(x + 3) = x + 3$ ลบได้ $0$ ผลหารคือ $2x + 1$
4. ป้ายยาว $2x + 1$ เมตร ถ้า $x = 4$ ป้ายสูง $7$ เมตร ยาว $9$ เมตร ตรวจ $7 \times 9 = 63$ และ $2(16) + 7(4) + 3 = 63$ ตรงกัน
</Steps>
</Example>

{/* check: div(2*x**2 + 7*x + 3, x + 3) == (2*x + 1, 0) */}
{/* check: (2*x + 1).subs(x, 4) == 9 and (2*x**2 + 7*x + 3).subs(x, 4) == 63 and 7*9 == 63 */}

## สรุป

- หารยาวพหุนามทำซ้ำสี่ขั้น หาร คูณ ลบ ดึงลง จนผลลบมีดีกรีน้อยกว่าตัวหาร
- หารพจน์แรกด้วยพจน์แรกเสมอ ได้พจน์ของผลหารทีละพจน์
- ขั้นลบต้องเปลี่ยนเครื่องหมายทุกพจน์ของผลคูณ
- ตัวตั้งที่ขาดพจน์ ให้เติมพจน์ที่มีสัมประสิทธิ์ $0$ จองที่ไว้
- ตัวตั้ง $=$ ตัวหาร $\times$ ผลหาร $+$ เศษ ใช้ตรวจคำตอบทุกครั้ง
