พหุนามที่เขียนเป็นกำลังสองของพหุนามอีกตัวได้แบบนี้เรียกว่า**กำลังสองสมบูรณ์** ถ้าดูออกตั้งแต่แรก จะแยกตัวประกอบได้ในบรรทัดเดียว ไม่ต้องไล่หาคู่จำนวน

## สูตรกำลังสองสมบูรณ์

แทน $x$ ด้วย $A$ และ $3$ ด้วย $B$ ในรูปข้างบน จะได้สี่ส่วนเป็น $A^2$ $AB$ $AB$ และ $B^2$ ถ้าส่วนที่เพิ่มเป็นการลดลงแทน ก็ได้สูตรคู่กันที่มีเครื่องหมายลบ

<Thm label="กำลังสองสมบูรณ์">

$$
A^2 + 2AB + B^2 = (A + B)^2
$$

$$
A^2 - 2AB + B^2 = (A - B)^2
$$

</Thm>

{/* check: expand((a + b)**2) == a**2 + 2*a*b + b**2 */}
{/* check: expand((a - b)**2) == a**2 - 2*a*b + b**2 */}

พหุนามสามพจน์จะเป็นกำลังสองสมบูรณ์ ต้องผ่านครบสามข้อ

1. พจน์แรกเป็นกำลังสองของบางอย่าง เรียกว่า $A$
2. พจน์ท้ายเป็นกำลังสองของบางอย่าง เรียกว่า $B$ จึงเป็นบวก
3. พจน์กลางเท่ากับ $2AB$ หรือ $-2AB$ เครื่องหมายของพจน์กลางคือเครื่องหมายในวงเล็บ

<Example n={1}>
แยกตัวประกอบของ $x^2 + 10x + 25$ และ $x^2 - 12x + 36$

<Steps reveal>
1. $x^2 + 10x + 25$ มี $x^2 = (x)^2$ และ $25 = 5^2$ จึงลอง $A = x$ $B = 5$
2. ตรวจพจน์กลาง $2AB = 2(x)(5) = 10x$ ตรงกับโจทย์ ได้ $x^2 + 10x + 25 = (x + 5)^2$
3. $x^2 - 12x + 36$ มี $A = x$ และ $B = 6$ ตรวจ $2AB = 12x$ พจน์กลางเป็น $-12x$
4. ได้ $x^2 - 12x + 36 = (x - 6)^2$
</Steps>
</Example>

{/* check: expand((x + 5)**2) == x**2 + 10*x + 25 */}
{/* check: expand((x - 6)**2) == x**2 - 12*x + 36 */}

<Example n={2}>
แยกตัวประกอบของ $4x^2 + 12x + 9$

<Steps reveal>
1. $4x^2 = (2x)^2$ และ $9 = 3^2$ จึงลอง $A = 2x$ $B = 3$
2. ตรวจพจน์กลาง $2AB = 2(2x)(3) = 12x$ ตรงกับโจทย์
3. ได้ $4x^2 + 12x + 9 = (2x + 3)^2$
</Steps>
</Example>

{/* check: expand((2*x + 3)**2) == 4*x**2 + 12*x + 9 */}

<Example n={3}>
แยกตัวประกอบของ $9x^2 - 24xy + 16y^2$

<Steps reveal>
1. $9x^2 = (3x)^2$ และ $16y^2 = (4y)^2$ ลอง $A = 3x$ $B = 4y$
2. $2AB = 2(3x)(4y) = 24xy$ พจน์กลางเป็น $-24xy$ จึงใช้สูตรที่มีเครื่องหมายลบ
3. ได้ $9x^2 - 24xy + 16y^2 = (3x - 4y)^2$
</Steps>
</Example>

{/* check: expand((3*x - 4*y)**2) == 9*x**2 - 24*x*y + 16*y**2 */}

## ตัวไหนไม่ใช่

ข้อสามข้อข้างบนต้องตรวจให้ครบ หน้าตาคล้ายแต่ไม่ใช่มีบ่อย

| พหุนาม | เป็นกำลังสองสมบูรณ์ไหม | เหตุผล |
|---|---|---|
| $x^2 + 6x + 4$ | ไม่เป็น | $4 = 2^2$ ได้ $2AB = 4x$ ไม่ใช่ $6x$ |
| $x^2 + 8x - 16$ | ไม่เป็น | พจน์ท้ายติดลบ เป็นกำลังสองไม่ได้ |
| $x^2 + 5x + 25$ | ไม่เป็น | $25 = 5^2$ ได้ $2AB = 10x$ ไม่ใช่ $5x$ |
| $x^2 - 14x + 49$ | เป็น | $49 = 7^2$ และ $2AB = 14x$ ได้ $(x - 7)^2$ |

นัทบอกว่า $(x + 4)^2 = x^2 + 16$ เพราะยกกำลังสองทีละตัว $x$ ยกกำลังสองได้ $x^2$ และ $4$ ยกกำลังสองได้ $16$ ถูกไหม

<Reveal>
ไม่ถูก ลองแทน $x = 1$ ฝั่งซ้ายได้ $(1 + 4)^2 = 25$ ฝั่งขวาได้ $1 + 16 = 17$ ไม่เท่ากัน ที่หายไปคือสองแถบตรงกลางในรูปลานกีฬา $(x + 4)^2 = (x + 4)(x + 4)$ ต้องคูณครบสี่คู่ ได้ $x^2 + 4x + 4x + 16 = x^2 + 8x + 16$ พจน์กลาง $2AB$ คือส่วนที่ลืมกันบ่อยที่สุด
</Reveal>
</Think>

## เติมให้เป็นกำลังสองสมบูรณ์

บางครั้งต้องทำกลับกัน คือมี $x^2 + bx$ อยู่แล้ว และต้องหาว่าเติมค่าคงตัวเท่าไรจึงเป็นกำลังสองสมบูรณ์ เรื่องนี้ใช้มากในการแก้สมการกำลังสองบทที่ 23 และการหาจุดยอดของพาราโบลาบทที่ 25

ถ้า $x^2 + bx$ จะเป็น $(x + B)^2 = x^2 + 2Bx + B^2$ ต้องมี $2B = b$ คือ $B = \tfrac{b}{2}$ ค่าคงตัวที่ต้องเติมจึงเป็น $B^2$

<Thm>

$$
x^2 + bx + \left(\frac{b}{2}\right)^2 = \left(x + \frac{b}{2}\right)^2
$$

ค่าที่ต้องเติมคือ**ครึ่งหนึ่งของสัมประสิทธิ์ของ $x$ แล้วยกกำลังสอง**

</Thm>

{/* check: expand((x + b/2)**2) == expand(x**2 + b*x + (b/2)**2) */}

<Example n={4}>
เติมค่าคงตัวให้แต่ละพหุนามเป็นกำลังสองสมบูรณ์ แล้วเขียนในรูปกำลังสอง (1) $x^2 + 8x$ (2) $x^2 - 10x$ (3) $x^2 + 3x$

<Steps reveal>
1. $x^2 + 8x$ ครึ่งหนึ่งของ $8$ คือ $4$ ยกกำลังสองได้ $16$ จึงได้ $x^2 + 8x + 16 = (x + 4)^2$
2. $x^2 - 10x$ ครึ่งหนึ่งของ $-10$ คือ $-5$ ยกกำลังสองได้ $25$ จึงได้ $x^2 - 10x + 25 = (x - 5)^2$
3. $x^2 + 3x$ ครึ่งหนึ่งของ $3$ คือ $\tfrac{3}{2}$ ยกกำลังสองได้ $\tfrac{9}{4}$ จึงได้ $x^2 + 3x + \tfrac{9}{4} = \left(x + \tfrac{3}{2}\right)^2$
</Steps>
</Example>

{/* check: expand((x + 4)**2) == x**2 + 8*x + 16 */}
{/* check: expand((x - 5)**2) == x**2 - 10*x + 25 */}
{/* check: expand((x + Rational(3, 2))**2) == x**2 + 3*x + Rational(9, 4) */}

<Example n={5}>
ถ้า $x^2 + kx + 49$ เป็นกำลังสองสมบูรณ์ $k$ มีค่าเท่าใดได้บ้าง

<Steps reveal>
1. $49 = 7^2$ จึงต้องเป็น $(x + 7)^2$ หรือ $(x - 7)^2$
2. $(x + 7)^2 = x^2 + 14x + 49$ ได้ $k = 14$
3. $(x - 7)^2 = x^2 - 14x + 49$ ได้ $k = -14$
4. ตอบ $k = 14$ หรือ $k = -14$ ลืมค่าที่ติดลบกันบ่อย
</Steps>
</Example>

{/* check: expand((x + 7)**2) == x**2 + 14*x + 49 and expand((x - 7)**2) == x**2 - 14*x + 49 */}

### เขียนในรูปกำลังสองบวกค่าคงตัว

พหุนาม $x^2 + 6x + 5$ ไม่ใช่กำลังสองสมบูรณ์ แต่เขียนเป็นกำลังสองสมบูรณ์บวกหรือลบค่าคงตัวได้เสมอ ใช้วิธีเติมแล้วหักออก ค่าของพหุนามจึงไม่เปลี่ยน

<Example n={6}>
เขียน $x^2 + 6x + 5$ และ $x^2 - 4x + 7$ ในรูป $(x + B)^2 + C$

<Steps reveal>
1. $x^2 + 6x$ ต้องเติม $9$ จึงเติม $9$ แล้วลบ $9$ ออก $x^2 + 6x + 5 = (x^2 + 6x + 9) - 9 + 5$
2. ได้ $x^2 + 6x + 5 = (x + 3)^2 - 4$
3. $x^2 - 4x$ ต้องเติม $4$ ได้ $x^2 - 4x + 7 = (x^2 - 4x + 4) - 4 + 7 = (x - 2)^2 + 3$
</Steps>
</Example>

{/* check: expand((x + 3)**2 - 4) == x**2 + 6*x + 5 */}
{/* check: expand((x - 2)**2 + 3) == x**2 - 4*x + 7 */}

รูป $(x - 2)^2 + 3$ บอกอะไรได้มากกว่ารูปเดิม เช่น $(x - 2)^2$ ไม่เคยติดลบ พหุนามนี้จึงมีค่าอย่างน้อย $3$ เสมอ และเท่ากับ $3$ เมื่อ $x = 2$ บทที่ 25 ใช้ข้อสังเกตนี้หาจุดยอดของกราฟ ส่วน $(x + 3)^2 - 4$ จะแยกตัวประกอบต่อได้ด้วยผลต่างของกำลังสองในหน้าถัดไป

## สรุป

- $A^2 + 2AB + B^2 = (A + B)^2$ และ $A^2 - 2AB + B^2 = (A - B)^2$
- เป็นกำลังสองสมบูรณ์เมื่อพจน์แรกและพจน์ท้ายเป็นกำลังสอง และพจน์กลางเท่ากับ $\pm 2AB$
- $(A + B)^2$ ไม่เท่ากับ $A^2 + B^2$ พจน์กลาง $2AB$ หายไม่ได้
- เติม $x^2 + bx$ ให้เป็นกำลังสองสมบูรณ์ ด้วย $\left(\tfrac{b}{2}\right)^2$
- พหุนามดีกรีสองทุกตัวที่ $a = 1$ เขียนเป็น $(x + B)^2 + C$ ได้ด้วยการเติมแล้วหักออก
