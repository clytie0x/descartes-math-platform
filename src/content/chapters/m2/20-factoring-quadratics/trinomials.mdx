ลองคูณ $(x + 3)(x + 4)$ ด้วยวิธีในบทที่ 15

$$
(x + 3)(x + 4) = x^2 + 4x + 3x + 12 = x^2 + 7x + 12
$$

ดูว่าตัวเลขในคำตอบมาจากไหน $7$ มาจาก $3 + 4$ ส่วน $12$ มาจาก $3 \times 4$ ทุกครั้งที่คูณ $(x + p)(x + q)$ จะได้แบบนี้เสมอ

$$
(x + p)(x + q) = x^2 + (p + q)x + pq
$$

{/* check: expand((x + 3)*(x + 4)) == x**2 + 7*x + 12 */}
{/* check: expand((x + a)*(x + b)) == expand(x**2 + (a + b)*x + a*b) */}

ถ้าต้องการแยกตัวประกอบของ $x^2 + bx + c$ จึงต้องหาสองจำนวนที่**คูณกันได้ $c$ และบวกกันได้ $b$** หน้านี้ทั้งหน้าคือการหาสองจำนวนนี้ให้เร็วและไม่พลาดเรื่องเครื่องหมาย

## ดูด้วยแผ่นพีชคณิต

ให้แผ่นสี่เหลี่ยมจัตุรัสใหญ่มีพื้นที่ $x^2$ แผ่นยาวกว้าง 1 ยาว $x$ มีพื้นที่ $x$ และแผ่นเล็กมีพื้นที่ $1$ พหุนาม $x^2 + 5x + 6$ คือแผ่นใหญ่ 1 แผ่น แผ่นยาว 5 แผ่น และแผ่นเล็ก 6 แผ่น ถ้าจัดแผ่นทั้งหมดให้เป็นสี่เหลี่ยมผืนผ้าได้ พื้นที่ของสี่เหลี่ยมคือกว้างคูณยาว ความยาวสองด้านจึงเป็นตัวประกอบสองตัว

<Board name="c20-tiles" label="แผ่นพีชคณิตของ x กำลังสอง บวก b x บวก c ปรับ b และ c ด้วยแถบเลื่อน ถ้าแยกตัวประกอบได้ แผ่นจะเรียงเป็นสี่เหลี่ยมผืนผ้า">
แผ่นสีเขียวเป็นบวก แผ่นสีม่วงเป็นลบ ลองตั้ง $b = 7$ กับ $c = 12$ แล้วลองเปลี่ยน $c$ เป็น $11$ ดูว่าเกิดอะไรขึ้น
</Board>

ถ้า $c = 12$ แผ่นเล็ก 12 แผ่นวางเป็นมุมขนาด $3 \times 4$ ได้พอดี แต่ถ้า $c = 11$ ไม่มีทางวางเป็นมุมที่ทำให้แผ่นยาวทั้ง 7 แผ่นลงตัว พหุนามบางตัวจึงแยกตัวประกอบด้วยจำนวนเต็มไม่ได้

## กรณี a = 1 ที่ทุกพจน์เป็นบวก

<Example n={1}>
แยกตัวประกอบของ $x^2 + 7x + 12$

<Steps reveal>
1. หาสองจำนวนที่คูณกันได้ $12$ และบวกกันได้ $7$
2. ไล่คู่ที่คูณกันได้ $12$ คือ $1 \times 12$ $2 \times 6$ $3 \times 4$ ผลบวกเป็น $13$ $8$ $7$ ตามลำดับ
3. คู่ที่ใช้ได้คือ $3$ กับ $4$ จึงได้ $x^2 + 7x + 12 = (x + 3)(x + 4)$
</Steps>
</Example>

{/* check: expand((x + 3)*(x + 4)) == x**2 + 7*x + 12 */}

ไล่จากคู่ที่คูณกันได้ $c$ ก่อน ไม่ไล่จากคู่ที่บวกกันได้ $b$ เพราะคู่ที่คูณกันได้ $c$ มีจำนวนจำกัด ไล่ครบได้แน่นอน

## เมื่อมีพจน์ติดลบ

ดูเครื่องหมายของ $c$ ก่อน แล้วค่อยดู $b$

| $c$ | $b$ | สองจำนวนที่หา | ตัวอย่าง |
|---|---|---|---|
| บวก | บวก | บวกทั้งคู่ | $x^2 + 7x + 12 = (x + 3)(x + 4)$ |
| บวก | ลบ | ลบทั้งคู่ | $x^2 - 8x + 15 = (x - 3)(x - 5)$ |
| ลบ | บวก | ต่างเครื่องหมาย ตัวที่ค่าสัมบูรณ์มากกว่าเป็นบวก | $x^2 + 2x - 15 = (x + 5)(x - 3)$ |
| ลบ | ลบ | ต่างเครื่องหมาย ตัวที่ค่าสัมบูรณ์มากกว่าเป็นลบ | $x^2 - 2x - 15 = (x - 5)(x + 3)$ |

{/* check: expand((x - 3)*(x - 5)) == x**2 - 8*x + 15 */}
{/* check: expand((x + 5)*(x - 3)) == x**2 + 2*x - 15 */}
{/* check: expand((x - 5)*(x + 3)) == x**2 - 2*x - 15 */}

เหตุผลคือ ผลคูณเป็นบวกเมื่อเครื่องหมายเหมือนกัน แล้วผลบวกจะมีเครื่องหมายเดียวกับทั้งสองตัว ส่วนผลคูณเป็นลบเมื่อเครื่องหมายต่างกัน แล้วผลบวกจะมีเครื่องหมายตามตัวที่ค่าสัมบูรณ์มากกว่า

<Example n={2}>
แยกตัวประกอบของ $x^2 - 9x + 14$

<Steps reveal>
1. $c = 14$ เป็นบวก และ $b = -9$ เป็นลบ สองจำนวนจึงลบทั้งคู่
2. คู่ที่คูณกันได้ $14$ และลบทั้งคู่ คือ $-1$ กับ $-14$ และ $-2$ กับ $-7$ ผลบวกเป็น $-15$ และ $-9$
3. ได้ $x^2 - 9x + 14 = (x - 2)(x - 7)$
</Steps>
</Example>

{/* check: expand((x - 2)*(x - 7)) == x**2 - 9*x + 14 */}

<Example n={3}>
แยกตัวประกอบของ $x^2 + x - 20$

<Steps reveal>
1. $c = -20$ เป็นลบ สองจำนวนต่างเครื่องหมาย และ $b = 1$ เป็นบวก ตัวที่ค่าสัมบูรณ์มากกว่าจึงเป็นบวก
2. คู่ที่คูณกันได้ $20$ คือ $1, 20$ และ $2, 10$ และ $4, 5$ ต้องการคู่ที่ต่างกัน $1$ ได้ $4$ กับ $5$
3. ให้ตัวที่มากกว่าเป็นบวก ได้ $5$ กับ $-4$ ซึ่งคูณกันได้ $-20$ บวกกันได้ $1$
4. ได้ $x^2 + x - 20 = (x + 5)(x - 4)$
</Steps>
</Example>

{/* check: expand((x + 5)*(x - 4)) == x**2 + x - 20 */}

### แยกไม่ได้ก็มี

$x^2 + 4x + 6$ ต้องการสองจำนวนที่คูณกันได้ $6$ บวกกันได้ $4$ คู่จำนวนเต็มที่คูณกันได้ $6$ มี $1, 6$ และ $2, 3$ และคู่ที่ลบทั้งคู่ ผลบวกเป็น $7$ $5$ $-7$ $-5$ ไม่มี $4$ เลย จึงตอบว่าแยกตัวประกอบด้วยจำนวนเต็มไม่ได้ ไล่คู่ให้ครบก่อนตอบแบบนี้ทุกครั้ง

## กรณี a ไม่เท่ากับ 1

ลองคูณ $(2x + 1)(x + 3)$ ด้วยวิธีกระจายทีละพจน์

$$
(2x + 1)(x + 3) = 2x^2 + 6x + x + 3 = 2x^2 + 7x + 3
$$

{/* check: expand((2*x + 1)*(x + 3)) == 2*x**2 + 7*x + 3 */}

ก่อนรวมพจน์ $7x$ เคยเป็น $6x + x$ และสองจำนวนนี้คือ $6$ กับ $1$ ซึ่งคูณกันได้ $6 = 2 \times 3$ คือสัมประสิทธิ์หน้า $x^2$ คูณกับค่าคงตัว ข้อสังเกตนี้ให้วิธีที่ใช้ได้ทุกครั้ง เรียกว่า**การแยกพจน์กลาง**

<Thm label="การแยกพจน์กลาง">

แยกตัวประกอบของ $ax^2 + bx + c$

1. หาสองจำนวนที่คูณกันได้ $ac$ และบวกกันได้ $b$
2. แยกพจน์ $bx$ เป็นสองพจน์ตามสองจำนวนนั้น
3. จัดกลุ่มทีละสองพจน์แล้วดึงตัวร่วม แบบหน้า 20.1

</Thm>

<Example n={4}>
แยกตัวประกอบของ $2x^2 + 7x + 3$

<Steps reveal>
1. $ac = 2 \times 3 = 6$ หาสองจำนวนที่คูณกันได้ $6$ บวกกันได้ $7$ ได้ $1$ กับ $6$
2. แยกพจน์กลาง $2x^2 + 7x + 3 = 2x^2 + x + 6x + 3$
3. จัดกลุ่ม $x(2x + 1) + 3(2x + 1)$
4. ดึง $(2x + 1)$ ออก ได้ $(2x + 1)(x + 3)$
</Steps>
</Example>

{/* check: expand(x*(2*x + 1) + 3*(2*x + 1)) == 2*x**2 + 7*x + 3 */}

ลำดับของสองพจน์ที่แยกออกมาสลับกันได้ ถ้าเขียน $2x^2 + 6x + x + 3$ จะได้ $2x(x + 3) + 1(x + 3) = (x + 3)(2x + 1)$ คำตอบเดียวกัน

<Example n={5}>
แยกตัวประกอบของ $3x^2 - 10x + 8$

<Steps reveal>
1. $ac = 3 \times 8 = 24$ ต้องการคูณกันได้ $24$ บวกกันได้ $-10$ จึงลบทั้งคู่ ได้ $-4$ กับ $-6$
2. $3x^2 - 10x + 8 = 3x^2 - 6x - 4x + 8$
3. จัดกลุ่ม $3x(x - 2) - 4(x - 2)$ คู่หลังดึง $-4$ ออก วงเล็บจะได้ตรงกัน
4. ได้ $(x - 2)(3x - 4)$
</Steps>
</Example>

{/* check: expand((x - 2)*(3*x - 4)) == 3*x**2 - 10*x + 8 */}

<Example n={6}>
แยกตัวประกอบของ $6x^2 + x - 2$

<Steps reveal>
1. $ac = 6 \times (-2) = -12$ ต้องการคูณกันได้ $-12$ บวกกันได้ $1$ ได้ $4$ กับ $-3$
2. $6x^2 + x - 2 = 6x^2 + 4x - 3x - 2$
3. จัดกลุ่ม $2x(3x + 2) - 1(3x + 2)$
4. ได้ $(3x + 2)(2x - 1)$
</Steps>
</Example>

{/* check: expand((3*x + 2)*(2*x - 1)) == 6*x**2 + x - 2 */}

## ดึงตัวร่วมก่อนเสมอ

<Example n={7}>
แยกตัวประกอบของ $2x^2 + 10x + 12$

<Steps reveal>
1. ทุกพจน์มี $2$ เป็นตัวร่วม ดึงออกก่อน $2(x^2 + 5x + 6)$
2. ในวงเล็บ หาสองจำนวนที่คูณกันได้ $6$ บวกกันได้ $5$ ได้ $2$ กับ $3$
3. ได้ $2x^2 + 10x + 12 = 2(x + 2)(x + 3)$
</Steps>
</Example>

{/* check: expand(2*(x + 2)*(x + 3)) == 2*x**2 + 10*x + 12 */}

ถ้าไม่ดึง $2$ ก่อน อาจได้ $(2x + 4)(x + 3)$ ซึ่งค่าเท่ากัน แต่ $2x + 4$ ยังดึง $2$ ออกได้ จึงยังแยกไม่ครบ ดึงตัวร่วมก่อนยังทำให้ตัวเลขเล็กลงและหาคู่ได้ง่ายขึ้นด้วย

## สรุป

- $(x + p)(x + q) = x^2 + (p + q)x + pq$ จึงแยก $x^2 + bx + c$ ด้วยสองจำนวนที่คูณกันได้ $c$ และบวกกันได้ $b$
- ดูเครื่องหมายของ $c$ ก่อน $c$ บวก สองจำนวนเครื่องหมายเหมือนกัน $c$ ลบ สองจำนวนต่างเครื่องหมาย
- เมื่อ $a \neq 1$ หาสองจำนวนที่คูณกันได้ $ac$ บวกกันได้ $b$ แยกพจน์กลาง แล้วจัดกลุ่ม
- ดึงตัวร่วมออกก่อนเสมอ และคูณกลับตรวจพจน์กลางทุกครั้ง
- ไล่คู่ครบแล้วไม่มีคู่ที่ใช้ได้ แปลว่าแยกตัวประกอบด้วยจำนวนเต็มไม่ได้
