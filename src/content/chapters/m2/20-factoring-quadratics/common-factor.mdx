ฝนซื้อสมุดเล่มละ $x$ บาท 3 เล่ม กับปากกาด้ามละ 5 บาท 3 ด้าม จ่ายทั้งหมด $3x + 15$ บาท ส่วนแป้งคิดอีกแบบ ซื้อสมุดหนึ่งเล่มกับปากกาหนึ่งด้ามเป็นหนึ่งชุด ราคา $x + 5$ บาท ฝนซื้อไป 3 ชุด จึงจ่าย $3(x + 5)$ บาท

ทั้งสองคนคิดเงินก้อนเดียวกัน จึงได้ $3x + 15 = 3(x + 5)$ ฝั่งซ้ายเป็นผลบวกของสองพจน์ ฝั่งขวาเป็นผลคูณของ $3$ กับ $x + 5$ การเปลี่ยนจากฝั่งซ้ายไปเป็นฝั่งขวาคือเรื่องของบทนี้ทั้งบท

{/* check: expand(3*(x + 5)) == 3*x + 15 */}

## การแยกตัวประกอบคืออะไร

<Def>
**การแยกตัวประกอบของพหุนาม**คือการเขียนพหุนามนั้นให้อยู่ในรูปการคูณกันของพหุนาม พหุนามแต่ละตัวที่คูณกันเรียกว่า**ตัวประกอบ** ตัวประกอบอาจเป็นค่าคงตัวได้ เช่น $3x+15=3(x+5)$ จึงไม่จำเป็นที่ตัวประกอบทุกตัวต้องมีดีกรีต่ำกว่าพหุนามเดิม
</Def>

เทียบกับจำนวน การแยกตัวประกอบของ $12$ คือเขียน $12 = 2 \times 2 \times 3$ ส่วนการแยกตัวประกอบของ $x^2 + 7x + 10$ คือเขียน $x^2 + 7x + 10 = (x + 2)(x + 5)$ ซึ่งเป็นการคูณพหุนามในบทที่ 15 แบบย้อนกลับ

| การคูณ (บทที่ 15) | การแยกตัวประกอบ (บทนี้) |
|---|---|
| $3(x + 5) = 3x + 15$ | $3x + 15 = 3(x + 5)$ |
| $(x + 2)(x + 5) = x^2 + 7x + 10$ | $x^2 + 7x + 10 = (x + 2)(x + 5)$ |

{/* check: expand((x + 2)*(x + 5)) == x**2 + 7*x + 10 */}

ข้อดีอย่างหนึ่งคือตรวจคำตอบได้เสมอ แยกตัวประกอบเสร็จแล้วคูณกลับ ถ้าได้พหุนามตัวเดิมก็ถูก

## ดึงตัวร่วมออกมา

เครื่องมือแรกคือสมบัติการแจกแจงที่ใช้มาตั้งแต่ ม.1 เขียนกลับด้าน

<Thm label="สมบัติการแจกแจง">

$$
ab + ac = a(b + c) \qquad ab - ac = a(b - c)
$$

</Thm>

ตัว $a$ ที่ทุกพจน์มีเหมือนกันเรียกว่า**ตัวร่วม** การดึงตัวร่วมให้ได้ครบในครั้งเดียว ทำทีละส่วน

1. สัมประสิทธิ์ ใช้ ห.ร.ม. ของสัมประสิทธิ์ทุกพจน์
2. ตัวแปร ตัวแปรที่มีในทุกพจน์ ใช้เลขชี้กำลังที่น้อยที่สุด
3. หารแต่ละพจน์ด้วยตัวร่วม ผลที่ได้ใส่ไว้ในวงเล็บ

<Example n={1}>
แยกตัวประกอบของ $6x + 9$ และ $x^2 - 5x$

<Steps reveal>
1. $6x + 9$ ห.ร.ม. ของ $6$ กับ $9$ คือ $3$ ส่วน $x$ ไม่ได้อยู่ในทุกพจน์ ตัวร่วมจึงเป็น $3$
2. $6x \div 3 = 2x$ และ $9 \div 3 = 3$ ได้ $6x + 9 = 3(2x + 3)$
3. $x^2 - 5x$ สัมประสิทธิ์ $1$ กับ $-5$ ไม่มีตัวร่วมที่มากกว่า $1$ แต่ทั้งสองพจน์มี $x$ อย่างน้อยหนึ่งตัว ตัวร่วมจึงเป็น $x$
4. $x^2 \div x = x$ และ $-5x \div x = -5$ ได้ $x^2 - 5x = x(x - 5)$
</Steps>
</Example>

{/* check: expand(3*(2*x + 3)) == 6*x + 9 */}
{/* check: expand(x*(x - 5)) == x**2 - 5*x */}

<Example n={2}>
แยกตัวประกอบของ $8x^2 + 12x$

<Steps reveal>
1. ห.ร.ม. ของ $8$ กับ $12$ คือ $4$
2. $x^2$ กับ $x$ มี $x$ ร่วมกันหนึ่งตัว เลขชี้กำลังที่น้อยที่สุดคือ $1$
3. ตัวร่วมคือ $4x$ หารแต่ละพจน์ได้ $8x^2 \div 4x = 2x$ และ $12x \div 4x = 3$
4. ได้ $8x^2 + 12x = 4x(2x + 3)$ คูณกลับตรวจ $4x \cdot 2x + 4x \cdot 3 = 8x^2 + 12x$ ถูกต้อง
</Steps>
</Example>

{/* check: expand(4*x*(2*x + 3)) == 8*x**2 + 12*x */}

<Think>
ภูมิแยกตัวประกอบของ $8x^2 + 12x$ ได้ $2x(4x + 6)$ ส่วนมายด์ได้ $4(2x^2 + 3x)$ คูณกลับแล้วถูกทั้งคู่ คำตอบของใครใช้ได้

<Reveal>
ยังไม่ครบทั้งคู่ ในวงเล็บของภูมิ $4x + 6$ ยังดึง $2$ ออกได้อีก ในวงเล็บของมายด์ $2x^2 + 3x$ ยังดึง $x$ ออกได้อีก ถ้าทำต่อจะได้ $4x(2x + 3)$ เหมือนกัน การแยกตัวประกอบต้องทำจนในวงเล็บไม่มีตัวร่วมเหลือ วิธีกันพลาดคือใช้ ห.ร.ม. ของสัมประสิทธิ์ทั้งหมดกับเลขชี้กำลังที่น้อยที่สุดตั้งแต่แรก
</Reveal>
</Think>

{/* check: expand(2*x*(4*x + 6)) == expand(4*(2*x**2 + 3*x)) == 8*x**2 + 12*x */}

<Example n={3}>
แยกตัวประกอบของ $x^2 + x$ และ $6x^2y - 9xy^2$

<Steps reveal>
1. $x^2 + x$ ตัวร่วมคือ $x$ หารได้ $x^2 \div x = x$ และ $x \div x = 1$ จึงได้ $x(x + 1)$
2. $6x^2y - 9xy^2$ ห.ร.ม. ของ $6$ กับ $9$ คือ $3$ ทั้งสองพจน์มี $x$ อย่างน้อยหนึ่งตัวและ $y$ อย่างน้อยหนึ่งตัว ตัวร่วมจึงเป็น $3xy$
3. $6x^2y \div 3xy = 2x$ และ $-9xy^2 \div 3xy = -3y$ ได้ $3xy(2x - 3y)$
</Steps>
</Example>

{/* check: expand(x*(x + 1)) == x**2 + x */}
{/* check: expand(3*x*y*(2*x - 3*y)) == 6*x**2*y - 9*x*y**2 */}

<Note kind="warning" title="ดึงพจน์ออกหมดแล้วเหลือ 1">
พจน์ที่เท่ากับตัวร่วมพอดี เมื่อหารแล้วเหลือ $1$ ไม่ใช่ $0$ คำตอบ $x^2 + x = x(x)$ ผิด เพราะ $x \cdot x = x^2$ พจน์ $x$ หายไปหนึ่งพจน์ จำนวนพจน์ในวงเล็บต้องเท่ากับจำนวนพจน์ของโจทย์เสมอ
</Note>

### ดึงเครื่องหมายลบออก

ถ้าพจน์แรกติดลบ นิยมดึงตัวร่วมที่ติดลบออกมา ให้พจน์แรกในวงเล็บเป็นบวก เช่น $-x^2 + 4x = -x(x - 4)$ ระวังว่าทุกพจน์ในวงเล็บต้องเปลี่ยนเครื่องหมาย เพราะ $4x \div (-x) = -4$

{/* check: expand(-x*(x - 4)) == -x**2 + 4*x */}

## ตัวร่วมที่เป็นพหุนาม

ตัวร่วมไม่จำเป็นต้องเป็นเอกนาม ใน $x(x - 2) + 3(x - 2)$ ทั้งสองพจน์มี $(x - 2)$ เป็นตัวประกอบ จึงดึง $(x - 2)$ ออกมาทั้งก้อนได้ เหมือนดึง $A$ ออกจาก $xA + 3A$

$$
x(x - 2) + 3(x - 2) = (x - 2)(x + 3)
$$

{/* check: expand(x*(x - 2) + 3*(x - 2)) == expand((x - 2)*(x + 3)) */}

### จัดกลุ่มก่อนแล้วค่อยดึง

บางพหุนามไม่มีตัวร่วมที่ทุกพจน์มี แต่ถ้าจับคู่พจน์ให้ดี แต่ละคู่จะมีตัวร่วม แล้วได้ตัวร่วมก้อนเดียวกัน วิธีนี้เรียกว่า**การจัดกลุ่ม** และจะใช้อีกครั้งในหน้า 20.2

<Example n={4}>
แยกตัวประกอบของ $x^2 + 3x + 2x + 6$

<Steps reveal>
1. ทั้งสี่พจน์ไม่มีตัวร่วม จับคู่สองพจน์แรกกับสองพจน์หลัง $(x^2 + 3x) + (2x + 6)$
2. คู่แรกดึง $x$ ได้ $x(x + 3)$ คู่หลังดึง $2$ ได้ $2(x + 3)$
3. ทั้งสองก้อนมี $(x + 3)$ ร่วมกัน ดึงออกได้ $(x + 3)(x + 2)$
4. ตรวจ $(x + 3)(x + 2) = x^2 + 5x + 6$ ซึ่งเท่ากับ $x^2 + 3x + 2x + 6$ ถูกต้อง
</Steps>
</Example>

{/* check: expand((x + 3)*(x + 2)) == x**2 + 3*x + 2*x + 6 */}

<Example n={5}>
แยกตัวประกอบของ $2x^2 - 6x + 5x - 15$

<Steps reveal>
1. คู่แรก $2x^2 - 6x = 2x(x - 3)$
2. คู่หลัง $5x - 15 = 5(x - 3)$
3. ได้ $2x(x - 3) + 5(x - 3) = (x - 3)(2x + 5)$
</Steps>
</Example>

{/* check: expand((x - 3)*(2*x + 5)) == 2*x**2 - 6*x + 5*x - 15 */}

<Think>
ถ้าเปลี่ยนตัวอย่าง 5 เป็น $2x^2 - 6x - 5x + 15$ คู่หลัง $-5x + 15$ ควรดึงอะไรออก

<Reveal>
ดึง $-5$ ออก ได้ $-5x + 15 = -5(x - 3)$ จะได้วงเล็บ $(x - 3)$ ตรงกับคู่แรก แล้วแยกต่อได้ $2x(x - 3) - 5(x - 3) = (x - 3)(2x - 5)$ ถ้าดึง $5$ ออกจะได้ $5(-x + 3)$ ซึ่งวงเล็บไม่ตรงกับคู่แรก ทำต่อไม่ได้ เมื่อจัดกลุ่มแล้ววงเล็บไม่ตรงกัน ให้ลองดึงตัวร่วมที่ติดลบ
</Reveal>
</Think>

{/* check: expand((x - 3)*(2*x - 5)) == 2*x**2 - 6*x - 5*x + 15 */}

## สรุป

- การแยกตัวประกอบคือการเขียนพหุนามเป็นผลคูณ ตรวจคำตอบได้ด้วยการคูณกลับ
- ตัวร่วมที่ครบ ใช้ ห.ร.ม. ของสัมประสิทธิ์ กับตัวแปรที่ทุกพจน์มีโดยใช้เลขชี้กำลังที่น้อยที่สุด
- ดึงตัวร่วมแล้วในวงเล็บต้องไม่มีตัวร่วมเหลือ และจำนวนพจน์ในวงเล็บเท่ากับของเดิม
- พหุนามสี่พจน์ที่ไม่มีตัวร่วม ลองจัดกลุ่มทีละสองพจน์ แล้วดึงวงเล็บที่เหมือนกันออก
