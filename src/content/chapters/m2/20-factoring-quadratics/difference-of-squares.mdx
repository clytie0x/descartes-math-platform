ลองคิดในใจ $21 \times 19$ ดูว่าเร็วแค่ไหน ถ้าเขียนเป็น $(20 + 1)(20 - 1)$ แล้วกระจาย จะได้ $400 - 20 + 20 - 1$ สองพจน์ตรงกลางหักล้างกันพอดี เหลือ $400 - 1 = 399$ คูณเลขสองหลักกลายเป็นยกกำลังสองแล้วลบ

{/* check: 21*19 == 20**2 - 1**2 == 399 */}

หน้านี้ใช้ข้อสังเกตเดียวกันกลับด้าน ถ้าเจอพหุนามที่เป็นกำลังสองลบกำลังสอง จะแยกเป็นผลคูณได้ทันที

## สูตรผลต่างของกำลังสอง

<Thm label="ผลต่างของกำลังสอง">

$$
A^2 - B^2 = (A + B)(A - B)
$$

</Thm>

{/* check: expand((a + b)*(a - b)) == a**2 - b**2 */}

ตรวจด้วยการคูณ $(A + B)(A - B) = A^2 - AB + AB - B^2 = A^2 - B^2$ พจน์ $AB$ กับ $-AB$ หักล้างกัน จึงไม่มีพจน์กลาง

ดูเป็นรูปก็ได้ เริ่มจากสี่เหลี่ยมจัตุรัสด้าน $a$ ตัดมุมที่เป็นสี่เหลี่ยมจัตุรัสด้าน $b$ ออก พื้นที่ที่เหลือคือ $a^2 - b^2$ แล้วตัดส่วนที่เหลือเป็นสองชิ้นย้ายไปต่อกันใหม่

<Board name="c20-diff-squares" label="สี่เหลี่ยมจัตุรัสด้าน a ที่ตัดมุมด้าน b ออก แบ่งเป็นสองชิ้น เลื่อนแถบเพื่อย้ายชิ้นหนึ่งไปต่อเป็นสี่เหลี่ยมผืนผ้า">
ก่อนเลื่อนแถบย้ายชิ้น ลองเดาว่าสี่เหลี่ยมผืนผ้าที่ได้จะกว้างและยาวเท่าไร
</Board>

ชิ้นสีส้มกว้าง $a - b$ ยาว $b$ หมุนแล้วไปต่อทางขวาของชิ้นสีเขียว ได้สี่เหลี่ยมผืนผ้ายาว $a + b$ กว้าง $a - b$ พื้นที่ไม่เปลี่ยน จึงได้ $a^2 - b^2 = (a + b)(a - b)$

พหุนามจะใช้สูตรนี้ได้ ต้องมีสองพจน์ ทั้งสองพจน์เป็นกำลังสอง และเป็น**ผลต่าง** คือลบกัน

<Example n={1}>
แยกตัวประกอบของ $x^2 - 49$ และ $25 - x^2$

<Steps reveal>
1. $x^2 - 49 = x^2 - 7^2$ ได้ $A = x$ $B = 7$
2. $x^2 - 49 = (x + 7)(x - 7)$
3. $25 - x^2 = 5^2 - x^2$ ได้ $A = 5$ $B = x$ ระวังว่าตัวที่ถูกลบคือ $x^2$
4. $25 - x^2 = (5 + x)(5 - x)$
</Steps>
</Example>

{/* check: expand((x + 7)*(x - 7)) == x**2 - 49 */}
{/* check: expand((5 + x)*(5 - x)) == 25 - x**2 */}

<Example n={2}>
แยกตัวประกอบของ $9x^2 - 25$ และ $16x^2 - 81y^2$

<Steps reveal>
1. $9x^2 = (3x)^2$ และ $25 = 5^2$ ได้ $9x^2 - 25 = (3x + 5)(3x - 5)$
2. $16x^2 = (4x)^2$ และ $81y^2 = (9y)^2$ ได้ $16x^2 - 81y^2 = (4x + 9y)(4x - 9y)$
</Steps>
</Example>

{/* check: expand((3*x + 5)*(3*x - 5)) == 9*x**2 - 25 */}
{/* check: expand((4*x + 9*y)*(4*x - 9*y)) == 16*x**2 - 81*y**2 */}

<Reveal>
ไม่ถูก $(x - 4)^2 = x^2 - 8x + 16$ มีพจน์กลาง และพจน์ท้ายเป็น $+16$ ไม่ใช่ $-16$ ผลต่างของกำลังสองต้องได้วงเล็บสองตัวที่เครื่องหมายต่างกัน $x^2 - 16 = (x + 4)(x - 4)$ พจน์กลางจึงหักล้างกันหมด ถ้าวงเล็บสองตัวเหมือนกันจะได้กำลังสองสมบูรณ์ ซึ่งมีสามพจน์เสมอ
</Reveal>
</Think>

{/* check: expand((x - 4)**2) == x**2 - 8*x + 16 */}
{/* check: expand((x + 4)*(x - 4)) == x**2 - 16 */}

</Reveal>
</Think>

## ดึงตัวร่วมก่อน

<Example n={3}>
แยกตัวประกอบของ $2x^2 - 18$

<Steps reveal>
1. $2x^2$ กับ $18$ ไม่ใช่กำลังสองทั้งคู่ แต่มี $2$ เป็นตัวร่วม ดึงออกก่อน $2(x^2 - 9)$
2. ในวงเล็บเป็นผลต่างของกำลังสอง $x^2 - 9 = (x + 3)(x - 3)$
3. ได้ $2x^2 - 18 = 2(x + 3)(x - 3)$
</Steps>
</Example>

{/* check: expand(2*(x + 3)*(x - 3)) == 2*x**2 - 18 */}

## A และ B เป็นพหุนามได้

สูตรใช้ได้ไม่ว่า $A$ กับ $B$ จะเป็นอะไร ขอให้มีรูปกำลังสองลบกำลังสอง ให้ใส่วงเล็บครอบ $A$ และ $B$ ไว้ก่อนแทนลงในสูตร จะไม่พลาดเรื่องเครื่องหมาย

<Example n={4}>
แยกตัวประกอบของ $(x + 2)^2 - 9$

<Steps reveal>
1. $A = x + 2$ และ $9 = 3^2$ ได้ $B = 3$
2. $(x + 2)^2 - 9 = \big[(x + 2) + 3\big]\big[(x + 2) - 3\big]$
3. รวมพจน์ในวงเล็บ ได้ $(x + 5)(x - 1)$
4. ตรวจ $(x + 5)(x - 1) = x^2 + 4x - 5$ และ $(x + 2)^2 - 9 = x^2 + 4x + 4 - 9 = x^2 + 4x - 5$ ตรงกัน
</Steps>
</Example>

{/* check: expand((x + 2)**2 - 9) == expand((x + 5)*(x - 1)) == x**2 + 4*x - 5 */}

หน้า 20.3 เขียน $x^2 + 6x + 5 = (x + 3)^2 - 4$ ไว้แล้ว ตอนนี้แยกต่อได้ด้วยสูตรเดียวกัน

$$
(x + 3)^2 - 2^2 = (x + 3 + 2)(x + 3 - 2) = (x + 5)(x + 1)
$$

{/* check: expand((x + 5)*(x + 1)) == x**2 + 6*x + 5 */}

ได้คำตอบเดียวกับการหาสองจำนวนที่คูณกันได้ $5$ บวกกันได้ $6$ การทำเป็นกำลังสองสมบูรณ์แล้วใช้ผลต่างของกำลังสองเป็นอีกทางหนึ่งที่ใช้ได้ทุกครั้ง แม้จะหาคู่จำนวนไม่เจอ ซึ่งจะได้ใช้ในบทที่ 23

## คิดเลขในใจ

<Example n={5}>
หาค่าของ $102^2 - 98^2$ และ $45 \times 35$ โดยไม่ใช้เครื่องคิดเลข

<Steps reveal>
1. $102^2 - 98^2 = (102 + 98)(102 - 98) = 200 \times 4 = 800$
2. $45$ กับ $35$ อยู่ห่างจาก $40$ เท่ากันคือ $5$ เขียน $45 \times 35 = (40 + 5)(40 - 5)$
3. $= 40^2 - 5^2 = 1600 - 25 = 1575$
</Steps>
</Example>

{/* check: 102**2 - 98**2 == 800 */}
{/* check: 45*35 == 40**2 - 5**2 == 1575 */}

## เลือกวิธีแยกตัวประกอบ

ทั้งบทมีสี่วิธี เจอพหุนามดีกรีสองตัวไหนก็ไล่ตามลำดับนี้

1. **ดึงตัวร่วม**ก่อนเสมอ ถ้ามี
2. ดูจำนวนพจน์ที่เหลือ
   - สองพจน์ที่ลบกันและเป็นกำลังสองทั้งคู่ ใช้**ผลต่างของกำลังสอง**
   - สามพจน์ ดูก่อนว่าเป็น**กำลังสองสมบูรณ์**ไหม ถ้าไม่ใช่ หาสองจำนวนที่คูณกันได้ $ac$ บวกกันได้ $b$
   - สี่พจน์ ลอง**จัดกลุ่ม**
3. ดูตัวประกอบแต่ละตัวว่าแยกต่อได้อีกไหม แล้วคูณกลับตรวจ

<Example n={6}>
แยกตัวประกอบของ $3x^2 - 12x + 12$

<Steps reveal>
1. ดึงตัวร่วม $3$ ออก ได้ $3(x^2 - 4x + 4)$
2. ในวงเล็บมีสามพจน์ $x^2 = (x)^2$ และ $4 = 2^2$ ตรวจ $2AB = 4x$ ตรงกับพจน์กลาง จึงเป็นกำลังสองสมบูรณ์
3. ได้ $3x^2 - 12x + 12 = 3(x - 2)^2$
</Steps>
</Example>

{/* check: expand(3*(x - 2)**2) == 3*x**2 - 12*x + 12 */}

## สรุป

- $A^2 - B^2 = (A + B)(A - B)$ ใช้กับสองพจน์ที่เป็นกำลังสองและลบกันเท่านั้น
- $A$ กับ $B$ เป็นพหุนามได้ ใส่วงเล็บครอบก่อนแทนในสูตร
- ผลบวกของกำลังสอง เช่น $x^2 + 25$ แยกด้วยจำนวนเต็มไม่ได้
- ใช้คิดเลขในใจได้ เช่น $45 \times 35 = 40^2 - 5^2$
- ลำดับการแยกตัวประกอบ ดึงตัวร่วม ดูจำนวนพจน์ เลือกวิธี แล้วตรวจว่าแยกครบ
