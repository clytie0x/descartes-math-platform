จอคอมพิวเตอร์รุ่นหนึ่งมีจุดภาพแนวนอน $2{,}048$ จุด แนวตั้ง $1{,}024$ จุด ทั้งสองจำนวนเป็นเลขยกกำลังของ $2$ คือ $2^{11}$ กับ $2^{10}$ จำนวนจุดภาพทั้งจอคือ $2^{11} \times 2^{10}$ ถ้าตอบในรูป $2$ ยกกำลังอะไรสักอย่าง จะได้ $2$ ยกกำลังเท่าไร

ใช้เครื่องคิดเลขก็ได้ $2{,}097{,}152$ แต่ไม่ต้องคูณเลยก็ตอบได้ ถ้าเข้าใจว่าเลขยกกำลังคือการนับจำนวนตัวคูณ

{/* check: 2**11 * 2**10 == 2048 * 1024 == 2097152 == 2**21 */}

## คูณเลขยกกำลังที่ฐานเท่ากัน

$2^{11}$ คือ $2$ คูณกัน $11$ ตัว และ $2^{10}$ คือ $2$ คูณกัน $10$ ตัว เอามาคูณกันก็คือ $2$ คูณกันทั้งหมด $11 + 10 = 21$ ตัว จึงได้ $2^{21}$ ลองดูกรณีที่เลขน้อยกว่านี้ให้เห็นชัด

$$
a^3 \times a^4 = (a \times a \times a) \times (a \times a \times a \times a) = a^7
$$

$a$ สามตัวรวมกับ $a$ สี่ตัวเป็นเจ็ดตัว เลขชี้กำลังจึงบวกกัน ไม่ว่า $a$ จะเป็นจำนวนอะไร

{/* check: a**3 * a**4 == a**7 */}

<Thm>

ถ้า $a$ เป็นจำนวนใดๆ และ $m$ กับ $n$ เป็นจำนวนเต็มบวก

$$
a^m \times a^n = a^{m + n}
$$

ใช้ได้เฉพาะเมื่อ**ฐานเท่ากัน**เท่านั้น

</Thm>

<Example n={1}>
เขียนผลคูณต่อไปนี้ในรูปเลขยกกำลังอย่างง่าย

(1) $3^2 \times 3^5$   (2) $x^4 \times x \times x^3$   (3) $(-2)^3 \times (-2)^2$   (4) $2a^3 \times 5a^4$

<Steps reveal>
1. ฐานเป็น $3$ ทั้งคู่ บวกเลขชี้กำลัง $2 + 5 = 7$ ได้ $3^7$
2. $x$ ตัวกลางไม่มีเลขชี้กำลัง แต่มันคือ $x^1$ จึงบวกได้ $4 + 1 + 3 = 8$ ได้ $x^8$
3. ฐานคือ $-2$ ทั้งคู่ ได้ $(-2)^{3 + 2} = (-2)^5$ เลขชี้กำลังเป็นคี่ ผลจึงเป็นลบ คือ $-32$
4. ตัวเลขข้างหน้าคูณกันตามปกติ $2 \times 5 = 10$ ส่วน $a^3 \times a^4 = a^7$ จึงได้ $10a^7$
</Steps>
</Example>

{/* check: [3**2 * 3**5, (-2)**3 * (-2)**2] == [3**7, -32] */}
{/* check: x**4 * x * x**3 == x**8 */}
{/* check: 2*a**3 * 5*a**4 == 10*a**7 */}

ข้อ 2 เป็นจุดที่ตกกันบ่อย $x$ ที่ไม่มีเลขชี้กำลังกำกับมีเลขชี้กำลังเป็น $1$ เสมอ ถ้าลืมนับจะได้ $x^7$ ซึ่งขาดไปหนึ่งตัว

<Think>
เพื่อนสองคนทำ $2^3 \times 2^4$ คนแรกได้ $4^7$ เพราะคิดว่า $2 \times 2 = 4$ และ $3 + 4 = 7$ คนที่สองได้ $2^{12}$ เพราะคิดว่าคูณกันก็ต้องคูณเลขชี้กำลังด้วย ใครถูก

<Reveal>
ผิดทั้งคู่ $2^3 \times 2^4$ คือ $2$ คูณกันสามตัวแล้วคูณกับ $2$ อีกสี่ตัว ได้ $2$ คูณกันเจ็ดตัว ฐานยังเป็น $2$ เหมือนเดิม และเลขชี้กำลังบวกกัน คำตอบคือ $2^7 = 128$

ตรวจได้ง่ายด้วยการหาค่าจริง $2^3 \times 2^4 = 8 \times 16 = 128$ ขณะที่ $4^7 = 16{,}384$ และ $2^{12} = 4{,}096$ ไม่ตรงทั้งคู่
</Reveal>
</Think>

{/* check: [2**3 * 2**4, 8*16, 4**7, 2**12] == [128, 128, 16384, 4096] */}

<Note kind="warning" title="สมบัตินี้ใช้กับการบวกและฐานต่างกันไม่ได้">

- $2^3 + 2^4$ ไม่เท่ากับ $2^7$ เพราะ $8 + 16 = 24$ แต่ $2^7 = 128$ สมบัตินี้เป็นของการ**คูณ**เท่านั้น
- $2^3 \times 3^2$ รวมเป็นเลขยกกำลังตัวเดียวไม่ได้ เพราะฐานไม่เท่ากัน ต้องหาค่าแยกกัน $8 \times 9 = 72$

</Note>

{/* check: [2**3 + 2**4, 2**7, 2**3 * 3**2] == [24, 128, 72] */}

## เลขยกกำลังของเลขยกกำลัง

กล่องลูกบาศก์ใบหนึ่งยาวด้านละ $1$ เมตร หรือ $100 = 10^2$ เซนติเมตร ปริมาตรของกล่องคือ $(10^2)^3$ ลูกบาศก์เซนติเมตร เพราะต้องเอาความยาวด้านมาคูณกันสามตัว

$$
(10^2)^3 = 10^2 \times 10^2 \times 10^2 = 10^{2 + 2 + 2} = 10^6
$$

ได้หนึ่งล้านลูกบาศก์เซนติเมตร มี $10^2$ อยู่สามก้อน แต่ละก้อนมี $10$ สองตัว รวมเป็น $10$ จำนวน $2 \times 3 = 6$ ตัว ครั้งนี้เลขชี้กำลังจึงคูณกัน

{/* check: (10**2)**3 == 10**2 * 10**2 * 10**2 == 10**6 == 1000000 */}

<Thm>

ถ้า $a$ เป็นจำนวนใดๆ และ $m$ กับ $n$ เป็นจำนวนเต็มบวก

$$
(a^m)^n = a^{mn}
$$

</Thm>

<Example n={2}>
เขียนในรูปเลขยกกำลังอย่างง่าย $(5^2)^3$ $(x^4)^5$ และ $(a^2)^3 \times a^4$

<Steps reveal>
1. $(5^2)^3 = 5^{2 \times 3} = 5^6$
2. $(x^4)^5 = x^{4 \times 5} = x^{20}$
3. ทำวงเล็บก่อน $(a^2)^3 = a^6$ แล้วจึงคูณกับ $a^4$ ซึ่งฐานเท่ากัน บวกเลขชี้กำลัง ได้ $a^{6 + 4} = a^{10}$
</Steps>
</Example>

{/* check: (5**2)**3 == 5**6 */}
{/* check: [(x**4)**5, (a**2)**3 * a**4] == [x**20, a**10] */}

<Think>
$(x^3)^2$ $x^3 \times x^2$ และ $x^{3^2}$ สามตัวนี้ตัวไหนเท่ากันบ้าง

<Reveal>
ไม่มีคู่ไหนเท่ากันเลย

- $(x^3)^2 = x^3 \times x^3 = x^6$ เลขชี้กำลังคูณกัน
- $x^3 \times x^2 = x^5$ เลขชี้กำลังบวกกัน
- $x^{3^2}$ ต้องหาเลขชี้กำลังก่อน $3^2 = 9$ จึงได้ $x^9$

ลองแทน $x = 2$ จะได้ $64$ $32$ และ $512$ ตามลำดับ วิธีจำคือ ถ้ามีวงเล็บกั้นแล้วยกกำลังทั้งก้อน ให้คูณ ถ้าวางคูณกันเฉยๆ ให้บวก
</Reveal>
</Think>

{/* check: [(2**3)**2, 2**3 * 2**2, 2**(3**2)] == [64, 32, 512] */}

## เลขยกกำลังของผลคูณ

$(3x)^2$ คือ $3x$ คูณกันสองตัว สลับที่การคูณได้ จึงจัดเลขไว้ด้วยกันและตัวแปรไว้ด้วยกัน

$$
(3x)^2 = 3x \times 3x = (3 \times 3) \times (x \times x) = 3^2 x^2 = 9x^2
$$

ทุกตัวในวงเล็บถูกยกกำลังเท่ากันหมด

{/* check: expand((3*x)**2) == 9*x**2 */}

<Thm>

ถ้า $a$ และ $b$ เป็นจำนวนใดๆ และ $n$ เป็นจำนวนเต็มบวก

$$
(ab)^n = a^n b^n
$$

</Thm>

<Example n={3}>
ทำให้เป็นรูปอย่างง่าย $(2a^3)^4$ และ $(-x^2y)^3$

<Steps reveal>
1. $(2a^3)^4$ ยกกำลังสี่ทั้ง $2$ และ $a^3$ ได้ $2^4 \times (a^3)^4 = 16a^{12}$
2. $(-x^2y)^3$ มีสามตัวในวงเล็บคือ $-1$ $x^2$ และ $y$ ยกกำลังสามทุกตัว ได้ $(-1)^3 (x^2)^3 y^3$
3. $(-1)^3 = -1$ เพราะเลขชี้กำลังเป็นคี่ จึงได้ $-x^6y^3$
</Steps>
</Example>

{/* check: [expand((2*a**3)**4), expand((-x**2*y)**3)] == [16*a**12, -x**6*y**3] */}

<Think>
เพื่อนเขียนว่า $(2a)^3 = 2a^3$ ถูกไหม

<Reveal>
ไม่ถูก เลขชี้กำลังนอกวงเล็บต้องเกาะทุกตัวในวงเล็บ $(2a)^3 = 2^3a^3 = 8a^3$ ส่วน $2a^3$ ยกกำลังเฉพาะ $a$

ลองแทน $a = 5$ จะเห็นชัด $(2 \times 5)^3 = 10^3 = 1{,}000$ แต่ $2 \times 5^3 = 250$ ต่างกันถึงสี่เท่า
</Reveal>
</Think>

{/* check: [(2*5)**3, 2*5**3] == [1000, 250] */}

สมบัตินี้ใช้กลับทางก็ได้ ช่วยให้คิดเลขในใจได้เร็ว

<Example n={4}>
หาค่าของ $25^3 \times 4^3$ โดยไม่ใช้เครื่องคิดเลข

<Steps reveal>
1. เลขชี้กำลังเท่ากันคือ $3$ ทั้งคู่ ใช้ $a^n b^n = (ab)^n$ ได้ $(25 \times 4)^3$
2. $25 \times 4 = 100$ จึงได้ $100^3 = 1{,}000{,}000$
3. ถ้าหาค่า $25^3 = 15{,}625$ กับ $4^3 = 64$ ก่อนแล้วคูณกัน ก็ได้เท่ากัน แต่ยากกว่ามาก
</Steps>
</Example>

{/* check: 25**3 * 4**3 == (25*4)**3 == 1000000 */}
{/* check: [25**3, 4**3] == [15625, 64] */}

## สรุป

- $a^m \times a^n = a^{m + n}$ ฐานต้องเท่ากัน และใช้กับการบวกไม่ได้
- $(a^m)^n = a^{mn}$ ยกกำลังซ้อนกันให้คูณเลขชี้กำลัง
- $(ab)^n = a^n b^n$ ทุกตัวในวงเล็บต้องยกกำลังด้วย รวมทั้งตัวเลขและเครื่องหมายลบ
- $x$ ที่ไม่มีเลขชี้กำลังกำกับ คือ $x^1$
