ในคอมพิวเตอร์ ความจุ $1$ กิกะไบต์นับเป็น $2^{30}$ ไบต์ ส่วนเพลงความยาวราวหนึ่งนาทีใช้ที่ประมาณ $1$ เมกะไบต์ ซึ่งนับเป็น $2^{20}$ ไบต์ ความจุ $1$ กิกะไบต์จึงเก็บไฟล์ขนาดนี้ได้ $2^{30} \div 2^{20}$ ไฟล์

หน้าที่แล้วคูณเลขยกกำลังด้วยการบวกเลขชี้กำลัง เดาได้ไหมว่าหารจะทำยังไง

## หารเลขยกกำลังที่ฐานเท่ากัน

เขียน $a^5 \div a^2$ เป็นเศษส่วนแล้วกระจายตัวคูณออกมา

$$
\frac{a^5}{a^2} = \frac{a \times a \times a \times a \times a}{a \times a} = a \times a \times a = a^3
$$

$a$ ในส่วนสองตัวตัดกับ $a$ ในเศษได้สองตัว เศษจึงเหลือ $a$ จำนวน $5 - 2 = 3$ ตัว เลขชี้กำลังจึงลบกัน การตัดกันแบบนี้ทำได้เมื่อ $a$ ไม่เป็นศูนย์เท่านั้น เพราะหารด้วยศูนย์ไม่ได้

{/* check: a**5 / a**2 == a**3 */}

<Thm>

ถ้า $a$ เป็นจำนวนใดๆ ที่ไม่เท่ากับ $0$ และ $m$ กับ $n$ เป็นจำนวนเต็มบวกที่ $m > n$

$$
a^m \div a^n = a^{m - n}
$$

</Thm>

กลับไปที่คำถามตอนต้น $2^{30} \div 2^{20} = 2^{10} = 1{,}024$ ไฟล์

{/* check: 2**30 // 2**20 == 2**10 == 1024 */}

<Example n={1}>
หาผลหารต่อไปนี้

(1) $7^9 \div 7^7$   (2) $\dfrac{x^{10}}{x^4}$   (3) $\dfrac{18a^7}{6a^2}$   (4) $(-3)^8 \div (-3)^5$

<Steps reveal>
1. ฐานเท่ากัน ลบเลขชี้กำลัง $9 - 7 = 2$ ได้ $7^2 = 49$ ไม่ต้องหาค่า $7^9$ เลย
2. $x^{10 - 4} = x^6$
3. ตัวเลขหารกันตามปกติ $18 \div 6 = 3$ ส่วนตัวแปร $a^{7 - 2} = a^5$ จึงได้ $3a^5$
4. ฐานคือ $-3$ ทั้งคู่ ได้ $(-3)^{8 - 5} = (-3)^3 = -27$
</Steps>
</Example>

{/* check: [Integer(7)**9 / 7**7, Integer(-3)**8 / (-3)**5] == [49, -27] */}
{/* check: [x**10 / x**4, 18*a**7 / (6*a**2)] == [x**6, 3*a**5] */}

<Think>
เพื่อนทำ $x^8 \div x^2$ ได้ $x^4$ เพราะ $8 \div 2 = 4$ ถูกไหม

<Reveal>
ไม่ถูก การหารเลขยกกำลังให้**ลบ**เลขชี้กำลัง ไม่ใช่หาร $x^8 \div x^2 = x^{8 - 2} = x^6$ เพราะ $x$ ในส่วนสองตัวตัดกับ $x$ ในเศษได้แค่สองตัว เหลือหกตัว

ตรวจด้วยการแทน $x = 2$ ได้ $2^8 \div 2^2 = 256 \div 4 = 64 = 2^6$ ส่วน $2^4$ เท่ากับ $16$ เท่านั้น ความผิดนี้เป็นคู่กับการคูณเลขชี้กำลังตอนที่ควรบวกในหน้าที่แล้ว
</Reveal>
</Think>

{/* check: [2**8 // 2**2, 2**6, 2**4] == [64, 64, 16] */}

## เลขยกกำลังของผลหาร

บทที่ 3 หาค่า $\left(\tfrac{2}{3}\right)^3$ ด้วยการยกกำลังทั้งเศษและส่วน เหตุผลเดียวกันใช้ได้เมื่อมีตัวแปร

<Thm>

ถ้า $a$ และ $b$ เป็นจำนวนใดๆ ที่ $b \neq 0$ และ $n$ เป็นจำนวนเต็มบวก

$$
\left(\frac{a}{b}\right)^n = \frac{a^n}{b^n}
$$

</Thm>

<Example n={2}>
ทำให้เป็นรูปอย่างง่าย $\left(\dfrac{x}{3}\right)^4$ และ $\left(\dfrac{2a^2}{b}\right)^3$

<Steps reveal>
1. $\left(\dfrac{x}{3}\right)^4 = \dfrac{x^4}{3^4} = \dfrac{x^4}{81}$
2. เศษคือ $2a^2$ ยกกำลังสามทั้งก้อนตามหน้าที่แล้ว ได้ $2^3(a^2)^3 = 8a^6$
3. ส่วนคือ $b^3$ จึงได้ $\dfrac{8a^6}{b^3}$
</Steps>
</Example>

{/* check: [(x/3)**4, (2*a**2/b)**3] == [x**4/81, 8*a**6/b**3] */}

## ใช้หลายสมบัติในข้อเดียว

โจทย์ส่วนใหญ่ต้องใช้หลายสมบัติต่อกัน ให้ทำทีละขั้นตามลำดับ วงเล็บก่อน แล้วคูณ แล้วหาร

<Example n={3}>
ทำให้เป็นรูปอย่างง่าย $\dfrac{(x^3)^4 \times x^2}{x^5}$

<Steps reveal>
1. วงเล็บก่อน $(x^3)^4 = x^{12}$
2. คูณในเศษ $x^{12} \times x^2 = x^{14}$
3. หาร $\dfrac{x^{14}}{x^5} = x^9$
</Steps>
</Example>

{/* check: (x**3)**4 * x**2 / x**5 == x**9 */}

<Example n={4}>
การ์ดหน่วยความจำของกล้องถ่ายรูปจุ $2^{35}$ ไบต์ ถ้ารูปแต่ละรูปใช้ที่ $2^{22}$ ไบต์ การ์ดนี้เก็บรูปได้กี่รูป

<Steps reveal>
1. จำนวนรูปคือ $2^{35} \div 2^{22} = 2^{35 - 22} = 2^{13}$
2. หาค่า $2^{13} = 2^{10} \times 2^3 = 1{,}024 \times 8 = 8{,}192$ รูป ใช้ $2^{10} = 1{,}024$ ที่หาไว้ตอนต้นหน้า
</Steps>
</Example>

{/* check: 2**35 // 2**22 == 2**13 == 1024 * 8 == 8192 */}

<Note kind="tip" title="ถ้าเลขชี้กำลังของตัวหารไม่น้อยกว่า">
สมบัติข้างบนให้ $m > n$ ถ้า $m = n$ เช่น $a^5 \div a^5$ จำนวนใดหารด้วยตัวเองก็ได้ $1$ แต่การลบเลขชี้กำลังได้ $a^0$ และถ้า $m$ น้อยกว่า $n$ เช่น $a^2 \div a^5 = \dfrac{1}{a^3}$ การลบเลขชี้กำลังได้ $a^{-3}$ ซึ่งยังไม่เคยมีความหมาย หน้าถัดไปจะกำหนดความหมายให้สองแบบนี้
</Note>

{/* check: [a**5 / a**5, a**2 / a**5] == [1, 1/a**3] */}

## สรุป

- $a^m \div a^n = a^{m - n}$ เมื่อ $a \neq 0$ ฐานต้องเท่ากัน และให้ลบเลขชี้กำลัง ไม่ใช่หาร
- ตัวเลขข้างหน้าหารกันตามปกติ แยกจากเลขชี้กำลัง
- $\left(\tfrac{a}{b}\right)^n = \tfrac{a^n}{b^n}$ เมื่อ $b \neq 0$
- โจทย์ที่ใช้หลายสมบัติ ทำวงเล็บก่อน แล้วคูณ แล้วหาร
