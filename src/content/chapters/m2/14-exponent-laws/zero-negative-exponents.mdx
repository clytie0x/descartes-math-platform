$2^0$ เท่ากับเท่าไร ถ้าคิดว่า $2$ คูณกันศูนย์ตัว ก็ตอบไม่ได้ เพราะไม่มีอะไรให้คูณ แล้ว $2^{-3}$ ล่ะ คูณกันลบสามตัวยิ่งไม่มีความหมาย ความหมายเดิมของเลขยกกำลังใช้ไม่ได้ตรงนี้ ต้องกำหนดความหมายใหม่ที่เข้ากับของเดิม

ลองดูแบบรูปของ $2^n$ เมื่อเลขชี้กำลังลดลงทีละหนึ่ง

| $2^n$ | $2^4$ | $2^3$ | $2^2$ | $2^1$ | $2^0$ | $2^{-1}$ | $2^{-2}$ | $2^{-3}$ |
|---|---|---|---|---|---|---|---|---|
| ค่า | 16 | 8 | 4 | 2 | ? | ? | ? | ? |

เลขชี้กำลังลดลงหนึ่ง ค่าหารด้วย $2$ ทุกครั้ง ถ้าให้แบบรูปนี้เดินต่อไป ช่องว่างจะเป็น $1$ แล้ว $\tfrac{1}{2}$ แล้ว $\tfrac{1}{4}$ แล้ว $\tfrac{1}{8}$ หน้านี้จะกำหนดความหมายให้ตรงกับแบบรูปนี้

{/* check: [Integer(2)**n for n in range(4, -4, -1)] == [16, 8, 4, 2, 1, Rational(1, 2), Rational(1, 4), Rational(1, 8)] */}

## เลขชี้กำลังเป็นศูนย์

หน้าที่แล้วพบว่า $a^5 \div a^5 = 1$ เพราะจำนวนใดหารด้วยตัวเองได้ $1$ ถ้าจะให้สมบัติการหารใช้ได้ด้วย ก็ต้องได้ $a^{5 - 5} = a^0$ ดังนั้น $a^0$ ต้องเท่ากับ $1$ ตรงกับแบบรูปในตาราง

<Def>
ถ้า $a$ เป็นจำนวนใดๆ ที่ไม่เท่ากับ $0$

$$
a^0 = 1
$$

ส่วน $0^0$ ไม่มีความหมาย
</Def>

ที่ต้องมี $a \neq 0$ เพราะเหตุผลข้างบนใช้การหารด้วย $a$ ซึ่งทำไม่ได้เมื่อ $a = 0$

<Example n={1}>
หาค่าของ $7^0$ $(-3)^0$ $-3^0$ และ $5x^0$ เมื่อ $x \neq 0$

<Steps reveal>
1. $7^0 = 1$
2. $(-3)^0$ ฐานคือ $-3$ ซึ่งไม่เป็นศูนย์ ได้ $1$
3. $-3^0$ ไม่มีวงเล็บ ฐานคือ $3$ ตัวเดียวแบบเดียวกับ $-3^2$ ในบทที่ 3 ได้ $-(3^0) = -1$
4. $5x^0$ เลขชี้กำลังเกาะ $x$ ตัวเดียว $x^0 = 1$ จึงได้ $5 \times 1 = 5$ ถ้าต้องการให้ $5x$ ทั้งก้อนเป็นฐานต้องเขียน $(5x)^0$ ซึ่งเท่ากับ $1$
</Steps>
</Example>

{/* check: [Integer(7)**0, Integer(-3)**0, -Integer(3)**0, 5*x**0, (5*x)**0] == [1, 1, -1, 5, 1] */}

<Think>
เพื่อนคนหนึ่งตอบว่า $5^0 = 0$ เพราะคูณกันศูนย์ตัวก็ไม่ได้อะไร อีกคนตอบว่า $5^0 = 5$ เพราะไม่ได้คูณอะไรเพิ่ม ใครถูก

<Reveal>
ไม่มีใครถูก $5^0 = 1$ ดูจากแบบรูป $5^2 = 25$ แล้ว $5^1 = 5$ ลดเลขชี้กำลังลงหนึ่งคือหารด้วย $5$ ทุกครั้ง ขั้นต่อไปจึงได้ $5 \div 5 = 1$

หรือดูจากการหาร $\tfrac{5^3}{5^3} = \tfrac{125}{125} = 1$ ซึ่งสมบัติการหารบอกว่าเท่ากับ $5^0$
</Reveal>
</Think>

{/* check: [Integer(5)**2, Integer(5)**1, Integer(5)**1 / 5, Integer(5)**0] == [25, 5, 1, 1] */}

## เลขชี้กำลังเป็นจำนวนลบ

หน้าที่แล้วพบว่า $a^2 \div a^5 = \dfrac{1}{a^3}$ ถ้าใช้สมบัติการหารจะได้ $a^{2 - 5} = a^{-3}$ จึงกำหนดให้ $a^{-3}$ หมายถึง $\dfrac{1}{a^3}$ ซึ่งตรงกับแบบรูปในตาราง $2^{-3} = \tfrac{1}{8} = \tfrac{1}{2^3}$

<Def>
ถ้า $a$ เป็นจำนวนใดๆ ที่ไม่เท่ากับ $0$ และ $n$ เป็นจำนวนเต็มบวก

$$
a^{-n} = \frac{1}{a^n}
$$
</Def>

เลขชี้กำลังติดลบจึงไม่ได้ทำให้ค่าติดลบ แต่บอกให้กลับเศษเป็นส่วน

<Example n={2}>
หาค่าของ $2^{-3}$ $10^{-2}$ $(-4)^{-2}$ $(-2)^{-3}$ และ $\left(\tfrac{1}{3}\right)^{-2}$

<Steps reveal>
1. $2^{-3} = \dfrac{1}{2^3} = \dfrac{1}{8}$
2. $10^{-2} = \dfrac{1}{10^2} = \dfrac{1}{100} = 0.01$
3. $(-4)^{-2} = \dfrac{1}{(-4)^2} = \dfrac{1}{16}$ ผลเป็นบวกเพราะเลขชี้กำลัง $2$ เป็นคู่
4. $(-2)^{-3} = \dfrac{1}{(-2)^3} = \dfrac{1}{-8} = -\dfrac{1}{8}$ ผลเป็นลบเพราะฐานติดลบและ $3$ เป็นคี่ ไม่ใช่เพราะเลขชี้กำลังติดลบ
5. $\left(\tfrac{1}{3}\right)^{-2} = \dfrac{1}{\left(\frac{1}{3}\right)^2} = \dfrac{1}{\frac{1}{9}} = 9$ ฐานเป็นเศษส่วน เลขชี้กำลังติดลบทำให้เศษส่วนกลับหัว
</Steps>
</Example>

{/* check: [Integer(2)**-3, Integer(10)**-2, Integer(-4)**-2, Integer(-2)**-3, Rational(1, 3)**-2] == [Rational(1, 8), Rational('0.01'), Rational(1, 16), Rational(-1, 8), 9] */}

<Think>
เพื่อนหาค่า $2^{-3}$ ได้ $-8$ อีกคนได้ $-6$ ผิดตรงไหน

<Reveal>
คนแรกคิดว่าเลขชี้กำลังติดลบทำให้ผลติดลบ คนที่สองเอา $2 \times (-3)$ ซึ่งเป็นความผิดเดียวกับการคิดว่า $2^3 = 6$ ในบทที่ 3

ที่ถูกคือ $2^{-3} = \dfrac{1}{2^3} = \dfrac{1}{8}$ เป็นจำนวนบวกที่น้อยกว่า $1$ ตรงกับแบบรูปในตาราง ที่ค่าหารด้วย $2$ ไปเรื่อยๆ แต่ไม่มีทางติดลบ
</Reveal>
</Think>

{/* check: [Integer(2)**-3 == -8, Integer(2)**-3 == -6, Integer(2)**-3] == [False, False, Rational(1, 8)] */}

ใช้ความหมายนี้กลับทางได้ด้วย ถ้าเลขยกกำลังที่เลขชี้กำลังติดลบอยู่ในส่วน ก็ย้ายขึ้นมาเป็นเศษได้ เช่น $\dfrac{1}{2^{-3}} = \dfrac{1}{\frac{1}{8}} = 8 = 2^3$

{/* check: 1 / Integer(2)**-3 == 2**3 == 8 */}

## สมบัติเดิมใช้ได้กับเลขชี้กำลังทุกจำนวนเต็ม

ความหมายของ $a^0$ กับ $a^{-n}$ ถูกกำหนดมาให้สมบัติจากสองหน้าแรกใช้ได้ต่อ ไม่ต้องมีเงื่อนไข $m > n$ อีกแล้ว

<Thm>

ถ้า $a$ และ $b$ เป็นจำนวนที่ไม่เท่ากับ $0$ และ $m$ กับ $n$ เป็นจำนวนเต็มใดๆ

- $a^m \times a^n = a^{m + n}$
- $a^m \div a^n = a^{m - n}$
- $(a^m)^n = a^{mn}$
- $(ab)^n = a^n b^n$ และ $\left(\dfrac{a}{b}\right)^n = \dfrac{a^n}{b^n}$

</Thm>

<Example n={3}>
ทำให้เป็นรูปอย่างง่าย และเขียนคำตอบให้มีเลขชี้กำลังเป็นบวก

(1) $a^{-4} \times a^6$   (2) $\dfrac{x^3}{x^7}$   (3) $(y^{-2})^3$   (4) $5^{-3} \times 5^5$

<Steps reveal>
1. บวกเลขชี้กำลัง $-4 + 6 = 2$ ได้ $a^2$
2. ลบเลขชี้กำลัง $3 - 7 = -4$ ได้ $x^{-4} = \dfrac{1}{x^4}$
3. คูณเลขชี้กำลัง $(-2) \times 3 = -6$ ได้ $y^{-6} = \dfrac{1}{y^6}$
4. $5^{-3 + 5} = 5^2 = 25$
</Steps>
</Example>

{/* check: [a**-4 * a**6, x**3 / x**7, (y**-2)**3] == [a**2, 1/x**4, 1/y**6] */}
{/* check: Integer(5)**-3 * 5**5 == 25 */}

<Example n={4}>
ทำ $\dfrac{(3x^{-2}y^3)^2}{x^{-5}y}$ ให้เป็นรูปอย่างง่าย เมื่อ $x$ และ $y$ ไม่เป็นศูนย์

<Steps reveal>
1. ยกกำลังสองทุกตัวในวงเล็บ $(3x^{-2}y^3)^2 = 9x^{-4}y^6$
2. หาร $x$ ด้วย $x$ ลบเลขชี้กำลัง $-4 - (-5) = -4 + 5 = 1$ ได้ $x^1 = x$
3. หาร $y$ ด้วย $y$ ลบเลขชี้กำลัง $6 - 1 = 5$ ได้ $y^5$
4. ได้ $9xy^5$
</Steps>
</Example>

{/* check: simplify((3*x**-2*y**3)**2 / (x**-5*y) - 9*x*y**5) == 0 */}

ขั้นที่ 2 เป็นจุดที่พลาดบ่อยที่สุด ลบด้วยจำนวนลบต้องกลายเป็นบวก ถ้าเขียน $-4 - 5 = -9$ จะได้ $9x^{-9}y^5$ ซึ่งผิด เขียนวงเล็บครอบเลขชี้กำลังที่ติดลบทุกครั้งที่ลบ จะช่วยกันพลาดตรงนี้ได้

## สรุป

- $a^0 = 1$ เมื่อ $a \neq 0$ และ $0^0$ ไม่มีความหมาย
- $a^{-n} = \dfrac{1}{a^n}$ เมื่อ $a \neq 0$ เลขชี้กำลังติดลบไม่ได้ทำให้ค่าติดลบ
- $-3^0 = -1$ แต่ $(-3)^0 = 1$ ดูให้ดีว่าฐานคืออะไร
- สมบัติการคูณ การหาร และการยกกำลังซ้อน ใช้ได้กับเลขชี้กำลังที่เป็นจำนวนเต็มทุกจำนวน
- ตอนลบเลขชี้กำลังที่ติดลบ ใส่วงเล็บกันพลาด
