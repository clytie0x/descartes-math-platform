เงื่อนไขทั้งสี่ข้อมีประโยชน์ตรงที่เปลี่ยนเรื่องที่ไม่รู้ให้เป็นเรื่องที่รู้ ถ้าอยากรู้ว่าด้านสองด้านยาวเท่ากันไหม แต่วัดไม่ได้หรือไม่อยากวัด ให้หารูปสามเหลี่ยมสองรูปที่มีสองด้านนั้นเป็นด้านคู่ที่สมนัยกัน แล้วแสดงว่ารูปสามเหลี่ยมทั้งสองเท่ากันทุกประการ ด้านคู่นั้นก็ยาวเท่ากันทันที มุมก็ใช้วิธีเดียวกัน

## เขียนการพิสูจน์

การพิสูจน์ทางเรขาคณิตเขียนเป็นขั้น ทุกขั้นต้องมีเหตุผลกำกับ เหตุผลที่ใช้บ่อยในบทนี้มีห้าแบบ

- **กำหนดให้** คือสิ่งที่โจทย์บอกมา
- **ด้านร่วม** หรือ**มุมร่วม** คือด้านหรือมุมที่รูปสามเหลี่ยมสองรูปใช้ร่วมกัน
- **มุมตรงข้าม** คือมุมที่เกิดจากเส้นตรงสองเส้นตัดกันแล้วอยู่ตรงข้ามกัน ซึ่งมีขนาดเท่ากันเสมอ
- **ชื่อเงื่อนไข** คือ ด.ม.ด. ม.ด.ม. ด.ด.ด. หรือ ฉ.ด.ด. ใช้ในขั้นที่สรุปว่ารูปสามเหลี่ยมเท่ากันทุกประการ
- **ด้านคู่ที่สมนัยกันหรือมุมคู่ที่สมนัยกันของรูปสามเหลี่ยมที่เท่ากันทุกประการ** ใช้ในขั้นสุดท้ายที่ดึงสิ่งที่ต้องการออกมา

<Note title="ทำไมมุมตรงข้ามจึงเท่ากัน">
เส้นตรงสองเส้นตัดกันเกิดมุมสี่มุม มุมที่อยู่ติดกันรวมกันได้ $180^\circ$ เพราะประกอบกันเป็นมุมตรง ถ้ามุมหนึ่งเป็น $50^\circ$ มุมที่อยู่ติดกันต้องเป็น $130^\circ$ และมุมที่อยู่ตรงข้ามกับมุมแรกก็ติดกับมุม $130^\circ$ เหมือนกัน จึงเป็น $180^\circ - 130^\circ = 50^\circ$ เท่ากับมุมแรก ใช้เหตุผลเดียวกันได้กับมุมทุกขนาด
</Note>

{/* check: 180 - (180 - 50) == 50 */}

<Steps reveal>
1. $AB = AC$ (กำหนดให้)
2. $B\hat{A}D = C\hat{A}D$ ($\overline{AD}$ แบ่งครึ่ง $B\hat{A}C$)
3. $AD = AD$ (ด้านร่วม)
4. $\triangle ABD \cong \triangle ACD$ (ด.ม.ด.) เพราะมุมในขั้นที่ 2 อยู่ระหว่างด้านในขั้นที่ 1 กับขั้นที่ 3 พอดี
5. $A\hat{B}D = A\hat{C}D$ (มุมคู่ที่สมนัยกันของรูปสามเหลี่ยมที่เท่ากันทุกประการ)
6. $D$ อยู่บน $\overline{BC}$ มุม $A\hat{B}D$ จึงเป็นมุมเดียวกับ $A\hat{B}C$ และ $A\hat{C}D$ เป็นมุมเดียวกับ $A\hat{C}B$ ได้ $A\hat{B}C = A\hat{C}B$ ตามที่ต้องการ
</Steps>
</Example>

ในกระดาษ นิยมเขียนการพิสูจน์เป็นตารางสองช่อง ช่องซ้ายเป็นข้อความ ช่องขวาเป็นเหตุผล

| ข้อความ | เหตุผล |
|---|---|
| $AB = AC$ | กำหนดให้ |
| $B\hat{A}D = C\hat{A}D$ | $\overline{AD}$ แบ่งครึ่ง $B\hat{A}C$ |
| $AD = AD$ | ด้านร่วม |
| $\triangle ABD \cong \triangle ACD$ | ด.ม.ด. |
| $A\hat{B}C = A\hat{C}B$ | มุมคู่ที่สมนัยกันของรูปสามเหลี่ยมที่เท่ากันทุกประการ |

ผลของตัวอย่างนี้ใช้บ่อยมากจนตั้งเป็นสมบัติ

<Thm label="รูปสามเหลี่ยมหน้าจั่ว">

ถ้ารูปสามเหลี่ยมมีด้านยาวเท่ากันสองด้าน มุมที่อยู่ตรงข้ามด้านทั้งสองนั้น ซึ่งเรียกว่ามุมที่ฐาน มีขนาดเท่ากัน

</Thm>

จาก $\triangle ABD \cong \triangle ACD$ ในตัวอย่าง 1 ยังได้อีกสองอย่าง คือ $BD = CD$ แปลว่า $D$ เป็นจุดกึ่งกลางของ $\overline{BC}$ และ $A\hat{D}B = A\hat{D}C$ ซึ่งสองมุมนี้รวมกันเป็นมุมตรง $180^\circ$ จึงเป็นมุมละ $90^\circ$ เส้นแบ่งครึ่งมุมยอดของรูปสามเหลี่ยมหน้าจั่วจึงตั้งฉากกับฐานและแบ่งฐานออกเป็นสองส่วนเท่ากัน

{/* check: Rational(180, 2) == 90 */}

<Think>

เพื่อนพิสูจน์ตัวอย่าง 1 แบบนี้ ขั้นแรก $A\hat{B}D = A\hat{C}D$ เพราะเป็นมุมที่ฐานของรูปสามเหลี่ยมหน้าจั่ว ขั้นต่อมา $AB = AC$ และ $B\hat{A}D = C\hat{A}D$ แล้วสรุปว่า $\triangle ABD \cong \triangle ACD$ แบบ ม.ด.ม. สุดท้ายจึงได้ $A\hat{B}C = A\hat{C}B$ การพิสูจน์นี้มีปัญหาตรงไหน

<Reveal>
ขั้นแรกใช้สิ่งที่โจทย์ให้พิสูจน์มาเป็นเหตุผล มุมที่ฐานเท่ากันคือข้อสรุปที่ต้องการ ตอนนั้นยังไม่ได้พิสูจน์ จึงยกมาใช้ไม่ได้ การพิสูจน์แบบนี้วนกลับมาที่จุดเริ่มต้นโดยไม่ได้แสดงอะไรเลย เหตุผลทุกขั้นต้องมาจากสิ่งที่กำหนดให้ สมบัติที่พิสูจน์ไว้แล้ว หรือขั้นก่อนหน้าเท่านั้น
</Reveal>
</Think>

## สรุป

- พิสูจน์ว่าด้านหรือมุมสองอย่างเท่ากัน ด้วยการหารูปสามเหลี่ยมสองรูปที่เท่ากันทุกประการ ซึ่งมีด้านหรือมุมนั้นเป็นคู่ที่สมนัยกัน
- ทุกขั้นต้องมีเหตุผล ห้ามใช้สิ่งที่ต้องพิสูจน์เป็นเหตุผล
- มองหาด้านร่วม มุมร่วม และมุมตรงข้าม ซึ่งมักเป็นข้อมูลที่โจทย์ไม่ได้บอกตรงๆ
- มุมที่ฐานของรูปสามเหลี่ยมหน้าจั่วเท่ากัน และเส้นแบ่งครึ่งมุมยอดตั้งฉากกับฐานที่จุดกึ่งกลาง
