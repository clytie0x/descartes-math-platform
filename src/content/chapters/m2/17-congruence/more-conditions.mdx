ด.ม.ด. ไม่ใช่ทางเดียว ในบทที่ 2 ยังสร้างรูปสามเหลี่ยมได้อีกสองแบบ คือรู้มุมสองมุมกับด้านในระหว่าง และรู้ความยาวของด้านทั้งสาม ทั้งสองแบบสร้างแล้วได้รูปเดียวเสมอ จึงกลายเป็นเงื่อนไขของความเท่ากันทุกประการได้อีกสองข้อ และยังมีเงื่อนไขพิเศษสำหรับรูปสามเหลี่ยมมุมฉากอีกหนึ่งข้อ

ด้านในระหว่างมุมสองมุม คือด้านที่มีจุดยอดของสองมุมนั้นเป็นปลายทั้งสองข้าง เช่น $\hat{B}$ กับ $\hat{C}$ มีด้านในระหว่างคือ $BC$

เหตุผลคล้ายกับ ด.ม.ด. วาง $EF$ ทับ $BC$ ได้พอดีเพราะยาวเท่ากัน มุมที่ $E$ เท่ากับมุมที่ $B$ แขน $ED$ จึงวางตามแนว $BA$ มุมที่ $F$ เท่ากับมุมที่ $C$ แขน $FD$ จึงวางตามแนว $CA$ จุด $A$ คือจุดที่แนว $BA$ กับแนว $CA$ ตัดกัน จุด $D$ ก็เป็นจุดตัดของแนวเดียวกันนี้ แนวสองแนวตัดกันได้จุดเดียว $D$ จึงทับ $A$

<Example n={1}>

$\triangle ABC$ มี $\hat{B} = 50^\circ$ $BC = 8$ เซนติเมตร และ $\hat{C} = 60^\circ$ ส่วน $\triangle XYZ$ มี $\hat{Y} = 50^\circ$ $YZ = 8$ เซนติเมตร และ $\hat{Z} = 60^\circ$ จงบอกว่าสองรูปนี้เท่ากันทุกประการหรือไม่ แล้วหาขนาดของ $\hat{X}$ และบอกว่า $XY$ ยาวเท่ากับด้านใดของ $\triangle ABC$

<Steps reveal>
1. $BC$ มีปลายเป็น $B$ และ $C$ จึงเป็นด้านในระหว่าง $\hat{B}$ กับ $\hat{C}$ ทำนองเดียวกัน $YZ$ เป็นด้านในระหว่าง $\hat{Y}$ กับ $\hat{Z}$
2. $\hat{B} = \hat{Y}$ $BC = YZ$ และ $\hat{C} = \hat{Z}$ จึงได้ $\triangle ABC \cong \triangle XYZ$ (ม.ด.ม.)
3. $\hat{X}$ สมนัยกับ $\hat{A} = 180^\circ - 50^\circ - 60^\circ = 70^\circ$ จึงได้ $\hat{X} = 70^\circ$
4. $XY$ สมนัยกับ $AB$ จึงได้ $XY = AB$
</Steps>
</Example>

{/* check: 180 - 50 - 60 == 70 */}

<Note kind="tip" title="ถ้าด้านไม่อยู่ระหว่างสองมุม">
มุมภายในของรูปสามเหลี่ยมรวมกันได้ $180^\circ$ ถ้ามุมเท่ากันสองคู่ มุมคู่ที่สามก็เท่ากันเองเสมอ ดังนั้นเมื่อได้ข้อมูลเป็นมุมสองคู่กับด้านคู่ที่สมนัยกันหนึ่งคู่ซึ่งไม่ได้อยู่ระหว่างมุมที่ให้มา ให้หามุมคู่ที่สามก่อน แล้วจะได้ ม.ด.ม. เสมอ
</Note>

เหตุผลมาจากการสร้างรูปสามเหลี่ยมจากความยาวด้านสามด้านในบทที่ 2 จุดยอดที่สามเป็นจุดตัดของส่วนโค้งสองเส้น ซึ่งมีแค่จุดตัดด้านบนกับด้านล่าง สองจุดนี้ให้รูปที่พลิกกันเท่านั้น ด้านสามด้านจึงล็อกรูปสามเหลี่ยมไว้ทั้งรูป ไม่ต้องรู้มุมเลยสักมุม

สมบัตินี้คือเหตุที่โครงสร้างรูปสามเหลี่ยมแข็งแรง โครงไม้สามท่อนที่ตอกหมุดตรงมุมบิดเป็นรูปอื่นไม่ได้ เพราะความยาวสามด้านกำหนดรูปไว้แล้ว ต่างจากโครงสี่เหลี่ยมที่ดันเบาๆ ก็เอียงเป็นรูปสี่เหลี่ยมด้านขนานได้ทั้งที่ด้านยาวเท่าเดิม ประตูรั้วเหล็กและเสาส่งไฟฟ้าจึงมีเหล็กค้ำแนวเฉียงที่แบ่งโครงเป็นรูปสามเหลี่ยม

<Example n={2}>

$\triangle ABC$ มี $AB = 5$ $BC = 6$ และ $CA = 7$ เซนติเมตร ส่วน $\triangle PQR$ มี $PQ = 7$ $QR = 5$ และ $RP = 6$ เซนติเมตร จงเขียนประโยคบอกว่ารูปสามเหลี่ยมสองรูปนี้เท่ากันทุกประการ โดยเริ่มจาก $\triangle ABC$

<Steps reveal>
1. จับคู่ด้านตามความยาว $AB = QR = 5$ $BC = RP = 6$ และ $CA = PQ = 7$ ครบสามคู่ จึงเท่ากันทุกประการแบบ ด.ด.ด.
2. หาจุดยอดที่สมนัยกัน $B$ เป็นตัวอักษรร่วมของ $AB$ กับ $BC$ ส่วนด้านคู่ของมันคือ $QR$ กับ $RP$ มีตัวอักษรร่วมคือ $R$ จึงได้ $B$ สมนัยกับ $R$
3. $A$ อยู่ใน $AB$ กับ $CA$ ด้านคู่คือ $QR$ กับ $PQ$ มีตัวร่วมคือ $Q$ จึงได้ $A$ สมนัยกับ $Q$ ที่เหลือ $C$ สมนัยกับ $P$
4. เขียนได้ $\triangle ABC \cong \triangle QRP$
</Steps>
</Example>

{/* check: sorted([5, 6, 7]) == sorted([7, 5, 6]) */}

ถ้าตอบว่า $\triangle ABC \cong \triangle PQR$ จะได้ $AB = PQ$ ซึ่งผิด เพราะ $AB = 5$ แต่ $PQ = 7$ ความยาวเท่ากันครบไม่ได้แปลว่าเรียงชื่อแบบไหนก็ได้

## มุมฉาก ด้าน ด้าน

ในรูปสามเหลี่ยมมุมฉาก ด้านที่อยู่ตรงข้ามมุมฉากเรียกว่า**ด้านตรงข้ามมุมฉาก** ซึ่งยาวที่สุดเสมอ อีกสองด้านเรียกว่า**ด้านประกอบมุมฉาก**

<Thm label="มุมฉาก ด้าน ด้าน (ฉ.ด.ด.)">
ถ้ารูปสามเหลี่ยมมุมฉากสองรูปมีด้านตรงข้ามมุมฉากยาวเท่ากัน และมีด้านประกอบมุมฉากยาวเท่ากันอีกหนึ่งคู่ แล้วรูปสามเหลี่ยมสองรูปนั้นเท่ากันทุกประการ

เหตุผลใช้ทฤษฎีบทพีทาโกรัสจากบทที่ 10 ในรูปข้างบน $BC^2 = AB^2 - AC^2$ และ $EF^2 = DE^2 - DF^2$ เพราะ $AB = DE$ และ $AC = DF$ ทางขวาของสองสมการจึงเท่ากัน ได้ $BC = EF$ ตามไปด้วย ตอนนี้ด้านเท่ากันครบสามคู่ จึงเท่ากันทุกประการแบบ ด.ด.ด.

<Example n={3}>

$\triangle ABC$ มี $\hat{C} = 90^\circ$ $AB = 13$ เซนติเมตร และ $AC = 5$ เซนติเมตร ส่วน $\triangle DEF$ มี $\hat{F} = 90^\circ$ $DE = 13$ เซนติเมตร และ $DF = 5$ เซนติเมตร จงหาความยาวของ $EF$

<Steps reveal>
1. $AB$ อยู่ตรงข้าม $\hat{C}$ และ $DE$ อยู่ตรงข้าม $\hat{F}$ ทั้งคู่จึงเป็นด้านตรงข้ามมุมฉาก และยาวเท่ากัน
2. $AC = DF$ เป็นด้านประกอบมุมฉากที่ยาวเท่ากัน จึงได้ $\triangle ABC \cong \triangle DEF$ (ฉ.ด.ด.)
3. $EF$ สมนัยกับ $BC$ และ $BC = \sqrt{13^2 - 5^2} = \sqrt{144} = 12$
4. ดังนั้น $EF = 12$ เซนติเมตร
</Steps>
</Example>

## เลือกเงื่อนไขให้ถูก

| เงื่อนไข | สิ่งที่ต้องเท่ากัน | จุดที่ต้องดู |
|---|---|---|
| ด.ม.ด. | ด้านสองคู่ มุมหนึ่งคู่ | มุมต้องอยู่ระหว่างสองด้านนั้น |
| ม.ด.ม. | มุมสองคู่ ด้านหนึ่งคู่ | ด้านต้องอยู่ระหว่างสองมุมนั้น ถ้าไม่อยู่ ให้หามุมที่สามก่อน |
| ด.ด.ด. | ด้านสามคู่ | ไม่ต้องรู้มุมเลย |
| ฉ.ด.ด. | มุมฉาก ด้านตรงข้ามมุมฉาก และด้านประกอบมุมฉากหนึ่งคู่ | ใช้กับรูปสามเหลี่ยมมุมฉากเท่านั้น |

ทุกเงื่อนไขต้องเป็นด้านคู่ที่สมนัยกันและมุมคู่ที่สมนัยกัน ก่อนเลือกเงื่อนไข ให้จับคู่จุดยอดให้ได้ก่อนเสมอ

<Think>

$\triangle ABC$ กับ $\triangle DEF$ มี $\hat{A} = \hat{D} = 50^\circ$ $\hat{B} = \hat{E} = 70^\circ$ และ $AC = DF$ เพื่อนบอกว่าใช้ ม.ด.ม. ไม่ได้ เพราะด้านที่เท่ากันไม่ได้อยู่ระหว่าง $\hat{A}$ กับ $\hat{B}$ เพื่อนพูดถูกไหม

<Reveal>
เพื่อนพูดถูกครึ่งเดียว $AC$ ไม่ได้อยู่ระหว่าง $\hat{A}$ กับ $\hat{B}$ จริง แต่หามุมที่สามได้ $\hat{C} = 180^\circ - 50^\circ - 70^\circ = 60^\circ$ และ $\hat{F} = 60^\circ$ เช่นกัน ตอนนี้ $AC$ อยู่ระหว่าง $\hat{A}$ กับ $\hat{C}$ และ $DF$ อยู่ระหว่าง $\hat{D}$ กับ $\hat{F}$ จึงใช้ ม.ด.ม. ได้ สรุปว่า $\triangle ABC \cong \triangle DEF$
</Reveal>
</Think>

## มุม มุม ด้าน

ถ้ารู้มุมสองมุมกับด้านที่ไม่ได้อยู่ในระหว่างมุมทั้งสอง ยังสรุปได้หรือไม่ เช่นรู้มุมที่ $A$ กับ $B$ แต่รู้ด้าน $AC$ แทนด้าน $AB$

<Thm label="มุม มุม ด้าน (ม.ม.ด.)">
ถ้ารูปสามเหลี่ยมสองรูปมีมุมขนาดเท่ากันสองคู่ และมีด้านคู่ที่สมนัยกันซึ่งอยู่ตรงข้ามมุมคู่หนึ่งที่เท่ากันยาวเท่ากัน แล้วรูปสามเหลี่ยมสองรูปนั้นเท่ากันทุกประการ
</Thm>

ผลบวกของมุมภายในเท่ากับ $180^\circ$ จึงหามุมคู่ที่สามได้และมีขนาดเท่ากันด้วย ตอนนี้ด้านที่รู้ยาวเท่ากันจะอยู่ระหว่างมุมคู่ที่เท่ากันสองคู่ จึงใช้ ม.ด.ม. ต่อได้ นี่คือเหตุผลของ ม.ม.ด. และยังต้องจับคู่จุดยอดให้ตรงกันเสมอ

<Example n={4}>
$\triangle ABC$ กับ $\triangle DEF$ มี $\hat A = \hat D = 48^\circ$ $\hat B = \hat E = 67^\circ$ และ $AC = DF = 9$ เซนติเมตร สองรูปนี้เท่ากันทุกประการหรือไม่

<Steps reveal>
1. $AC$ อยู่ตรงข้ามมุม $B$ ส่วน $DF$ อยู่ตรงข้ามมุม $E$ จึงเป็นด้านคู่ที่สมนัยกัน ด้านทั้งสองไม่ได้อยู่ในระหว่างมุมสองมุมที่ให้มา
2. ได้ $\triangle ABC \cong \triangle DEF$ โดย ม.ม.ด.
3. ตรวจด้วยอีกวิธีได้ $\hat C = \hat F = 180^\circ - 48^\circ - 67^\circ = 65^\circ$ แล้วใช้มุม $A$ ด้าน $AC$ และมุม $C$ สรุปโดย ม.ด.ม.
</Steps>
</Example>

<Reveal>

</Reveal>

## สรุป

- ม.ด.ม. ใช้มุมสองคู่กับด้านในระหว่าง ด.ด.ด. ใช้ด้านสามคู่
- ฉ.ด.ด. ใช้กับรูปสามเหลี่ยมมุมฉาก ต้องมีด้านตรงข้ามมุมฉากเท่ากันหนึ่งคู่ และด้านประกอบมุมฉากเท่ากันอีกหนึ่งคู่
- ม.ม.ด. ใช้มุมเท่ากันสองคู่กับด้านคู่ที่สมนัยกันซึ่งไม่ได้อยู่ในระหว่างมุมสองมุมนั้น
- รู้มุมเท่ากันสองคู่ ก็รู้มุมคู่ที่สามด้วย จึงอธิบาย ม.ม.ด. ผ่าน ม.ด.ม. ได้
- จับคู่จุดยอดก่อนเขียนประโยค $\cong$ ทุกครั้ง
