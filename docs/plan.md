## 1. เว็บนี้คืออะไร

เอกสารสอนคณิตศาสตร์มัธยมแบบเดียวกับ [zero-index](https://zero.teerapat.codes/) คืออ่านไล่เป็นบท มีเส้นทางเรียนบนหน้าแรก เมนูซ้าย ปุ่มก่อนหน้าถัดไป และแบบฝึกหัดท้ายบท แต่เนื้อหาเป็นคณิตศาสตร์ ม.1 ถึง ม.6 ตามหลักสูตรแกนกลาง 2551 ฉบับปรับปรุง 2560

ผู้อ่านคือนักเรียนของผู้ใช้ ครอบคลุมนักเรียนมัธยมทุกระดับ ทั้งสายวิทย์ที่เรียนคณิตเพิ่มเติม และสายอื่นที่เรียนแค่คณิตพื้นฐาน

สิ่งที่ต่างจาก zero-index และต้องสร้างเพิ่ม

- สูตรคณิตศาสตร์ต้องแสดงสวยและเร็วบนมือถือ
- กราฟและรูปเรขาคณิตที่ลากเล่นได้ เช่นเลื่อนค่า a ของพาราโบลาแล้วเห็นรูปเปลี่ยนทันที
- แบบฝึกหัดตรวจคำตอบได้ทันทีในเบราว์เซอร์ แทนการส่งโค้ดเข้า grader
- คำตอบตัวอย่างทุกข้อต้องถูกตรวจด้วยเครื่องก่อนขึ้นเว็บ เหมือนที่ zero-index คอมไพล์โค้ดทุกชิ้น

### สิ่งที่จะไม่ทำในรอบแรก

- ไม่มีระบบสมัครสมาชิก ไม่มีหลังบ้าน ความคืบหน้าเก็บในเครื่องนักเรียน (localStorage) แบบเดียวกับเช็กลิสต์ของ zero-index
- ไม่มีหน้าดูคะแนนของครู ถ้าต้องการภายหลังค่อยต่อหลังบ้าน (ดูข้อ 7)
- ไม่คัดลอกเนื้อหา ตัวอย่าง หรือโจทย์จากหนังสือ สสวท. หรือข้อสอบจริง เขียนเองทั้งหมด ใช้แค่ลำดับหัวข้อและตัวชี้วัดของหลักสูตรเป็นกรอบ

## 2. เทคสแต็ก

หลักคือใช้โครงเดียวกับ zero-index ที่ผู้ใช้เลือกไว้แล้วและดูแลเป็นอยู่แล้ว เพิ่มเฉพาะชิ้นที่คณิตศาสตร์ต้องใช้

| ส่วน | ใช้อะไร | เหตุผล |
|---|---|---|
| ตัวสร้างเว็บ | Python 3.11 ขึ้นไป `tools/build.py` อ่าน `src/site.toml` แล้วประกอบหน้า HTML ลง `dist/` | ยกมาจาก zero-index ได้เกือบทั้งไฟล์ สารบัญ เมนูซ้าย ปุ่มก่อนหน้าถัดไป ตรวจลิงก์ มีครบแล้ว |
| เนื้อหา | HTML หนึ่งไฟล์ต่อหน้า เก็บเฉพาะ `<article>` สูตรเขียนเป็น LaTeX ใน `\( \)` และ `\[ \]` | ผู้ใช้เลือก HTML เขียนเองแทน Starlight และ MkDocs แล้วตั้งแต่ทำ zero-index |
| สคริปต์หน้าเว็บ | TypeScript 7.0.2 strict บน Node 24 รวมไฟล์ด้วย esbuild 0.28.2 | ชุดเดียวกับ zero-index |
| แสดงสูตร | KaTeX 0.19.1 (MIT) แปลงเป็น HTML ตอน build ด้วยสคริปต์ Node `tools/render_math.ts` | หน้าเว็บไม่ต้องโหลดตัวคำนวณสูตร เปิดบนมือถือเร็ว ไม่มีสูตรกระพริบ ถ้า LaTeX ผิด build พังทันที ไม่หลุดขึ้นเว็บ |
| กราฟและเรขาคณิตลากได้ | JSXGraph 1.14.2 (MIT หรือ LGPL) โหลดเฉพาะหน้าที่มีกราฟ | ทำได้ทั้งกราฟฟังก์ชันกับแถบเลื่อน และรูปเรขาคณิตที่ลากจุดได้ ไม่ต้องมี API key ต่างจาก Desmos และเบากว่าฝัง GeoGebra |
| ช่องพิมพ์คำตอบเป็นสูตร | MathLive 0.111.1 (MIT) มีแป้นพิมพ์คณิตบนจอ โหลดเฉพาะหน้าแบบฝึกหัดที่ต้องพิมพ์สูตร | นักเรียน ม.1 พิมพ์ LaTeX ไม่เป็น แต่กดแป้นเศษส่วนกับยกกำลังบนมือถือได้ |
| ตรวจคำตอบที่เป็นสูตร | ตัวอ่านนิพจน์ที่เขียนเอง `src/scripts/mathexpr.ts` เทียบสองนิพจน์ด้วยการแทนค่าหลายชุด (เดิมวางไว้เป็น Compute Engine ดูหัวเอกสาร) | ตอบ `2(x+1)` กับ `2x+2` ต้องได้คะแนนทั้งคู่ ส่วนข้อที่สั่งให้แยกตัวประกอบจะตรวจรูปแบบด้วย |
| ตรวจความถูกต้องของเนื้อหา | Python กับ SymPy `tools/check_math.py` | ทุกตัวอย่างที่มีคำตอบ และทุกเฉลยแบบฝึกหัด ต้องคำนวณซ้ำด้วย SymPy แล้วตรงกัน คู่กับ `check_code.py` ของ zero-index |
| ขึ้นเว็บ | GitHub Actions ขึ้น GitHub Pages ทุกครั้งที่ push เข้า main | repo ต้อง public เพราะ Actions ของ repo private โดนบล็อกด้วยบิลลิ่งบัญชี |
| โดเมน | เสนอ `math.teerapat.codes` ผู้ใช้เพิ่ม CNAME ที่ name.com เอง | แบบเดียวกับ zero และ ide |
| ฟอนต์ | ตามที่ zero-index ใช้ตอนนั้น ส่วนสูตรใช้ฟอนต์ของ KaTeX | ให้สองเว็บดูเป็นชุดเดียวกัน |

(แผนเดิม) ไม่ใช้ React Next.js หรือ Astro เพราะเว็บเป็นเอกสารนิ่ง ต่อมาผู้ใช้เลือก Astro + MDX ดูหัวเอกสาร ส่วน Next.js ยังไม่ใช้ เพราะไม่มีหลังบ้าน

### ชนิดแบบฝึกหัด

แต่ละข้อเก็บเป็นโฟลเดอร์ `src/exercises/<ชั้น>/<บท>/<ข้อ>/` มี `task.toml` กับ `statement.html` เหมือน zero-index แต่เปลี่ยนจากชุดทดสอบเป็นเฉลย

| ชนิด | ตัวอย่าง | วิธีตรวจ |
|---|---|---|
| เลือกตอบ | ข้อใดเป็นจำนวนอตรรกยะ | เทียบตัวเลือก |
| ตัวเลข | หาพื้นที่สามเหลี่ยม | เทียบค่า ยอมให้ปัดเศษตามที่โจทย์บอก รับเศษส่วนอย่างต่ำ |
| สูตรหรือนิพจน์ | กระจาย \((x+3)^2\) | Compute Engine เทียบความเท่ากัน บวกเงื่อนไขรูปแบบถ้าโจทย์บังคับ |
| ชุดคำตอบ | แก้สมการกำลังสอง | เทียบเป็นเซตไม่สนลำดับ |
| ลากบนกราฟ | ลากจุดยอดพาราโบลาไปที่ (2, -1) | JSXGraph อ่านพิกัดแล้วเทียบ |
| เรียงขั้นพิสูจน์ | เรียงเหตุผลพิสูจน์ว่าสามเหลี่ยมสองรูปเท่ากันทุกประการ | เทียบลำดับ ยอมหลายลำดับที่ถูกได้ |
| ตรวจเอง | สร้างเส้นแบ่งครึ่งมุมด้วยวงเวียน หรือแปลความหมายแผนภูมิ | เครื่องตรวจไม่ได้ นักเรียนทำในกระดาษ แล้วเปิดเฉลยกับเกณฑ์ให้คะแนนมาเทียบเอง |

ทุกข้อมีคำใบ้ทีละขั้น และเฉลยแบบแสดงวิธีทำที่กดเปิดเองได้ เฉลยที่เป็นตัวเลข สูตร หรือชุดคำตอบผ่าน `check_math.py` ก่อนขึ้นเว็บ ส่วนข้อเรียงขั้นพิสูจน์และข้อตรวจเองตรวจด้วยคนในขั้นตรวจทาน (การตัดสินใจของผู้วางแผน)

แบบฝึกหัดใช้ฝึกเองเท่านั้น ไม่ใช้เก็บคะแนน เพราะเฉลยอยู่ในหน้าเว็บ ใครเปิดซอร์สก็เห็น ถ้าวันหนึ่งจะใช้เก็บคะแนน ต้องย้ายเฉลยไปไว้หลังบ้านตามข้อ 7 (การตัดสินใจของผู้วางแผน ตามที่ไม่มีหลังบ้านในรอบนี้)

### ส่วนประกอบใหม่ในหน้าเนื้อหา

เพิ่มจากชุดของ zero-index (กล่องเตือน หัวข้อขั้นตอน เช็กลิสต์ สารบัญในหน้า)

- กล่องนิยาม ทฤษฎีบท และตัวอย่าง พร้อมวิธีทำแบบกดเปิดทีละขั้น
- กล่อง "ลองคิดก่อน" ถามก่อนเฉลย แทนส่วน "ลองทำให้พัง" ของ zero-index ใช้แสดงวิธีคิดผิดที่นักเรียนชอบทำ
- กราฟลากได้ `<div class="board" data-board="ชื่อ">` ผูกกับไฟล์ TypeScript ของกราฟนั้น
- รูปเรขาคณิตนิ่งเป็น SVG เขียนเอง

## 3. หลักสูตร

### ที่มาของรายชื่อบท

ชื่อบทและลำดับบทยึดหนังสือเรียน สสวท. ฉบับปรับปรุง 2560 ตามหน้าโครงการ 14 ของ สสวท. (proj14.ipst.ac.th) ซึ่งตรวจเมื่อ 28 ต.ค. 2569 ครบทุกเล่ม ม.1 ถึง ม.6 ทั้งพื้นฐานและเพิ่มเติม ส่วนการแบ่งหน้าในแต่ละบทเป็นข้อเสนอของแผนนี้ ไม่ได้ลอกจากสารบัญหนังสือ เพราะหน้า สสวท. ไม่แสดงหัวข้อย่อย

ข้อที่ต่างจากที่มักเข้าใจกัน

- คณิตพื้นฐาน ม.ปลาย มีแค่ 10 บท ม.4 เซต ตรรกศาสตร์เบื้องต้น หลักการนับเบื้องต้น ความน่าจะเป็น ม.5 เลขยกกำลัง ฟังก์ชัน ลำดับและอนุกรม ม.6 สถิติล้วน 3 บท
- ยืนยันเพิ่มจากคู่มือการใช้หลักสูตร สสวท. ม.ปลาย (https://www.scimath.org/e-books/8379/8379.pdf) เมื่อ 28 ต.ค. 2569 เรขาคณิตวิเคราะห์ของเพิ่มเติม ม.4 มีจุดและเส้นตรง วงกลม พาราโบลา วงรี ไฮเพอร์โบลา พื้นฐาน ม.5 มีดอกเบี้ยและมูลค่าของเงิน (ดอกเบี้ย มูลค่าของเงิน ค่ารายงวด) หนังสือพื้นฐาน ม.5 ไม่มีบทแยกสำหรับเรื่องนี้ เว็บนี้จึงใส่ไว้ในบทลำดับและอนุกรม และเพิ่มเติม ม.6 ใช้ลำดับและอนุกรมแก้ปัญหามูลค่าของเงินและค่ารายงวด ส่วนความสัมพันธ์ระหว่างสองตัวแปรไม่อยู่ในสาระของ ม.ปลาย จึงตัดออก

### โครงเว็บ

- **ม.ต้น** 31 บท เรียงตามหนังสือ ม.1 เล่ม 1 ถึง ม.3 เล่ม 2 ทุกคนเรียนเหมือนกัน
- **ม.ปลาย** 19 บท แบ่งตามเรื่อง ไม่แยกเว็บพื้นฐานกับเพิ่มเติม เพราะ 7 เรื่องซ้ำกัน (เซต ตรรกศาสตร์ หลักการนับ ความน่าจะเป็น ฟังก์ชัน ลำดับและอนุกรม สถิติ) ถ้าแยกจะต้องเขียนซ้ำและแก้สองที่
  - แต่ละหน้ามีป้ายระดับ พื้นฐาน หรือ เพิ่มเติม (ในตารางข้างล่าง หน้าที่มี (ม) คือเพิ่มเติมเท่านั้น)
  - หน้าแรกมีเส้นทางเรียนสองเส้น เรียงบทตามหนังสือของแต่ละสาย
  - นักเรียนเลือกสายบนเว็บ เปลี่ยนได้ตลอด (เก็บใน localStorage) สายพื้นฐานจะซ่อนบทและหน้า (ม) ออกจากเมนูซ้าย และปุ่มก่อนหน้าถัดไปเดินตามลำดับบทของหนังสือพื้นฐาน (เซต ตรรกศาสตร์ หลักการนับ ความน่าจะเป็น เลขยกกำลัง ฟังก์ชัน ลำดับและอนุกรม สถิติ) ไม่ใช่ตามเลขบท

## 5. วิธีตรวจว่าเนื้อหาถูก

- `check_math.py` คำนวณซ้ำทุกตัวอย่างที่ติดป้าย `data-check` และทุกเฉลยใน `task.toml` ด้วย SymPy ไม่ตรงคือ build พัง
- `build.py` ตรวจลิงก์ ชื่อหน้า และ LaTeX ที่ KaTeX อ่านไม่ออก
- ทดสอบตัวตรวจคำตอบ ทุกข้อต้องรับเฉลย และปฏิเสธคำตอบผิดที่ใส่ไว้ใน `task.toml` อย่างน้อยหนึ่งแบบ (คำตอบผิดที่นักเรียนชอบตอบ)
- ตรวจด้วยตาบนเบราว์เซอร์ ทั้งจอคอมและจอมือถือ 375 พิกเซล ทุกบทที่มีกราฟ

## 6. เรื่องที่ผู้ใช้ต้องตัดสิน

1. ชื่อเว็บ ชื่อ repo และโดเมน (เสนอ `math.teerapat.codes`)
2. หน้าตา ใช้แนวสมุดกริดแบบ zero-index แต่เปลี่ยนสีหลัก หรือออกแบบใหม่ทั้งหมด
3. โครง ม.ปลาย แบบรวมบทติดป้ายระดับตามข้อ 3 หรือแยกเป็นสองชุด
4. บทต้นแบบ ใช้บทที่ 25 หรือบทที่ผู้ใช้กำลังสอนอยู่จริง
5. ลำดับหลังบทต้นแบบ ไล่ ม.1 ถึง ม.6 หรือเริ่มชั้นที่นักเรียนของผู้ใช้เรียนอยู่ก่อน
6. บทที่ agent เขียนเสร็จและผ่านตัวตรวจอัตโนมัติแล้ว ขึ้นเว็บให้นักเรียนเห็นทันที หรือรอผู้ใช้อ่านทีละบทก่อน (zero-index ใช้วิธีให้บทที่ยังไม่พร้อมขึ้นเป็นสีจางบนหน้าแรก ไม่มีลิงก์)
